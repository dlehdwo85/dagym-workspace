# 레퍼런스 대조 (kit-reference-match)

대표가 레퍼런스를 줬는데 "전혀 반영되지 않았다"는 말을 듣는 이유는 두 가지였습니다.
1. 실제 제품 화면을 보지 않고 검색 요약·도움말로 설계했다.
2. 기능이 '있기만 하면' 완료로 봤다.

이 스킬은 둘 다 막습니다. 결과물은 저장소의 `docs/reference/<레퍼런스이름>/` 아래에 둡니다. 스크린샷 원본은 비공개 저장소가 아니면 커밋하지 않고, 로컬 비공개 폴더(예: `.local-private/reference/`)에 둡니다.

## 규칙 (먼저 읽기)
- **실제 화면으로 본다.** 공개 페이지, 앱스토어 화면, 대표가 보낸 사진, 대표(또는 회사) 체험 계정만 씁니다. 로그인·결제가 필요하면 그때 대표를 부릅니다. 남의 계정은 쓰지 않습니다.
- **읽기만 한다.** 크롤러·대량 내려받기·자동 반복 금지. 원본의 자바스크립트·비공개 API·네트워크 기록을 베끼지 않습니다.
- **기능과 흐름을 가져온다.** 로고·브랜드색·문구·이미지·글꼴은 가져오지 않습니다. 우리 디자인 문서의 토큰으로 만듭니다.
- **체험 계정에서 보내기·결제·서명 완료 같은 실제 동작은 누르지 않는다.** 마지막 확인 직전까지만 봅니다.
- **약관 확인.** 경쟁 제품을 만들려고 쓰는 것을 금지하는 약관이면 공개 자료로만 합니다.

## 1단계 — 범위
대표 말에서 무엇을 닮고 싶은지 한 줄로 정리합니다. 예: "글로싸인처럼 = 계약서 파일을 올려 서명 칸을 끌어 놓고 보내는 흐름".
제품 전체가 아니라 그 핵심 흐름만 다룹니다.

## 2단계 — 실제 화면 확보
| 출처 | 얻는 것 |
|---|---|
| 체험 계정(대표 로그인 뒤) | 모든 단계·상태를 실제로 |
| 앱스토어·소개 페이지 | 핵심 화면, 내세우는 기능 |
| 도움말·요금표 | 기능 목록, 유료로 막은 기능(=중요한 기능) |
| 대표가 보낸 사진 | 대표가 콕 집은 부분 — 최우선 |

화면마다 번호(S01, S02…)를 붙이고, 빈 상태·오류·휴대폰 화면도 찍습니다.

## 3단계 — 화면 목록·흐름·기능표
- 화면 목록: `번호 | 화면 | 들어가는 길 | 목적 | 주요 부품 | 본 상태`
- 흐름: `F01 목표: S03 → S04 → S05`(클릭 수 기록 — 이길 숫자)
- 기능표: `features.csv` (이 폴더의 `templates/features.csv` 형식). 열 이름은 스크립트용이라 영어 그대로 둡니다.
  - `priority`: must(필수) / should(권장) / could(선택)
  - `original`: 원본에 있음 yes
  - `clone`: 우리 구현 yes / partial / no / skip(이유 필수)
  - 대표가 콕 집은 부분은 무조건 must.

## 4단계 — 구현 뒤 대조
1. **기능 점수**
   ```bash
   python -X utf8 scripts/parity.py docs/reference/<이름>/features.csv --markdown
   ```
   must 3·should 2·could 1 가중, partial은 절반. must가 하나라도 빠지면 '반영 안 됨'입니다.
2. **레이아웃 비교**: 같은 화면폭(1440×900, 390×844), 같은 상태로 원본과 우리 화면을 찍고 비교합니다.
   ```bash
   python -X utf8 scripts/imgdiff.py 원본.png 우리.png --out diff.png --json
   ```
   색은 무시하고 배치만 봅니다(우리 색으로 바꾸는 게 정상). 90+ 거의 같음, 75+ 가까움, 50+ 부분, 그 아래는 다름.
3. **동작 비교**: 흐름마다 클릭 수, 오류 때 반응, 다음에 들어왔을 때 기억하는 것을 비교합니다. 원본보다 클릭이 적으면 우리가 이긴 것입니다.
4. **흔적 검사**: 원본의 이름·로고·문구가 우리 화면·코드에 남아 있으면 실패입니다.

## 5단계 — 보고(대표용 쉬운 말)
- 한 줄 결론: "글로싸인 핵심 흐름 기능 점수 82점, 필수 12개 중 11개 — 대면 계약만 남음"
- 표: 필수 기능별 있음/일부/없음
- 화면 비교 이미지 2~3장(원본 | 우리)
- 다음에 만들 것 5개(필수 → 권장 순)

## 도구
- 맥·리눅스는 `python3`, 윈도우는 `python -X utf8`(한글 출력 깨짐 방지)로 실행합니다.
- `scripts/parity.py`, `scripts/imgdiff.py`, `scripts/contrast.py`는 replica-skill(MIT, Jakeschincariol, 커밋 77c9436)에서 가져온 표준 라이브러리 파이썬입니다. 설치할 것이 없습니다. 출처는 각 파일 머리와 `scripts/LICENSE-replica-skill`에 있습니다.
- 스크린샷은 Playwright(노트북 운영 브라우저) 또는 저장소의 E2E 도구로 찍습니다.
