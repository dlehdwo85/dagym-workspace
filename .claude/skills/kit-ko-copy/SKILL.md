# 한국어 문구 기준 (kit-ko-copy)

## 1. 먼저 확인할 사실 (틀리면 바로 신뢰를 잃음)
- **요금**: 워크인 무료 범위는 **14일 무료 체험**입니다(2026-10-23 대표 결정). '5명까지 무료'는 더 이상 쓰지 않습니다. 요금은 저장소의 요금 문서를 다시 확인합니다.
- **명의**: 다짐은 본사(아파트 커뮤니티·피트니스 시설 위탁운영). 하이링크는 커뮤니티 출입·예약 플랫폼. 워크인 판매·결제·통신판매는 하이링크 명의입니다. 문구에서 섞지 않습니다.
- **숫자**: 단지 수·회원 수·만족도 같은 숫자는 근거(내부 자료·계약서)가 있는 것만 씁니다. 없으면 숫자를 빼고 구체적 상황으로 씁니다.
- **AI 표시**: **2026-10-25 대표 결정 — 다짐·하이링크·워크인 마케팅 게시물과 홍보 영상에는 AI 제작 고지를 넣지 않습니다**(AI 기본법 제31조 생성물 표시 의무·과태료 유예 사실은 대표에게 고지됨, 대표 책임 결정). 다만 AI 인물을 실제 고객 후기처럼 쓰지 않고, 제품 안 AI 기능의 '사전 고지'(제31조 ①항)는 약관·설정 화면에 둡니다. 영상의 도입 문의는 전화번호로(URL 은 영상에서 클릭 불가).

## 2. 쓰지 않는 말 (표시광고법·신뢰)
- 최고, 1위, 유일, 최초, 100%, 무조건, 완벽, 국내 최대 — 근거 없이 쓰지 않습니다.
- 효과·결과를 단정하는 말(매출 2배 보장, 무조건 절감).
- 다른 회사를 깎아내리는 비교. 비교는 '우리가 할 수 있는 일'로 씁니다.
- 번역투·빈 말: 혁신적인, 차세대, 올인원 솔루션, 시너지, 극대화.

## 3. 콘텐츠형과 광고형은 따로 쓴다
- **콘텐츠형**(피드·블로그·릴스): 공감·정보로 참여(저장·공유·댓글)를 얻습니다. 판매 권유는 마지막 한 줄.
- **광고형**(메타 광고·파워링크): 전환(문의·가입)을 얻습니다. 순서:
  1. 특정 상황·대상 지목 — "입주 2년 차, 헬스장 운영사 바꾸려는 관리사무소라면"
  2. 제품·가격·조건 — 무엇을, 얼마에, 어떤 조건으로
  3. 문제 한 줄 — 지금 불편한 점
  4. 장점 2~3개 — 숫자·사실로
  5. 권유 1개 — 문의·체험·자료 받기 중 하나만
- 상황을 여러 개로 나눠 소재 3~4개를 동시에 시험하고, 성과가 난 상황으로 좁힙니다.

## 4. 채널별 기본 틀
- **인스타 캡션**: 첫 줄(약 125자 안)에 핵심. 해시태그 5개 이하. 행동 권유 1개.
- **카드뉴스(1080×1350)**: 표지에 'A vs B' 비교나 질문형 제목 → 장마다 한 메시지 → 마지막 장에 행동 권유(예: 댓글로 '자료' 남기기 → 담당자가 직접 답장).
- **숏폼 대본(15~30초)**: 질문(3초 안) → 우리 이야기 → 반전 → 비교 → 자문자답 → 행동 권유(가격·혜택·행동·기한). 화면은 1~2초마다 바꿉니다. 화면 글자는 짧게, 같은 말을 자막·내레이션이 반복하지 않게.
- **블로그**: 제목 1줄 + 소제목 2~3개('■ 소제목'), 문단은 2~3문장. 검색어 1개를 제목·첫 문단에.
- **파워링크**: 제목에 지역·시설·서비스, 설명에 차별점·조건. 키워드는 [지역]×[시설]×[서비스] 조합으로 만들고 제외어를 함께 관리합니다.

## 5. 훅(첫 문장) 공식 — 한국어
| 유형 | 예 |
|---|---|
| 상황 지목 | "관리비 고지서에 헬스장 이용료가 따로 찍혀 문의가 늘었다면" |
| 질문 | "커뮤니티 시설, 지금 몇 곳에서 따로 관리하고 계신가요?" |
| 숫자(근거 있는 것만) | "출입 등록 문의, 하루 30통에서 3통으로" |
| 비교 | "카드 출입 vs 얼굴 출입, 관리실 일이 이렇게 달라집니다" |
| 반전 | "운영사를 바꿨는데, 입주민은 바뀐 줄도 몰랐습니다" |

## 6. 소통 원칙
- 댓글·답글·DM은 초안만 만들고 사람이 읽고 고쳐서 보냅니다. 자동 댓글·자동 팔로우·자동 DM 도구에 계정을 연결하지 않습니다(계정 정지 위험).
- 같은 문장을 여러 계정에 짧은 시간에 반복해서 남기지 않습니다.

## 7. 검수 결과 형식
'통과' 또는 '수정 요청' 두 가지로만 답하고, 수정 요청이면 고칠 문장·이유·고친 문장을 표로 씁니다.

## 8. 가독성 규칙 (2026-10-25 대표 지시 "글 읽기가 피로함")
- 캡션 첫 줄은 훅(약 25자 안). **한 문장 한 줄**, 문단은 3줄 이내, 문단 사이 빈 줄.
- 소제목·목록에 화살표(→)·번호·체크(✔)를 쓰고, 문단마다 **이모지 1~2개**(브랜드별 허용 세트: 다짐 🏢📋✅ · 하이링크 🔑📱🏠 · 워크인 📅✅⏰ · 바디랩 💪🔥🎁). 같은 이모지 연속 금지.
- 핵심 낱말은 【 】 또는 ✔ 로 강조. 해시태그는 본문 아래 빈 줄 뒤 5개 이하.
- 카드뉴스는 표지 포함 4~6장(장마다 한 메시지, 마지막 장 행동 권유), 스토리는 3~5프레임, 블로그는 '■ 소제목' 2~3개 + 본문 사진 3장 이상.
