## 1. 범위 (한 줄)
줌처럼 = **워크인 일정·업무에서 화상회의를 켜면 링크가 자동으로 생기고, 직원과 외부 손님이 앱 설치 없이 그 링크 하나로 들어와(외부 손님은 대기실 → 호스트 허용) 영상·음성·화면 공유·채팅을 하고, 끝나면 녹화·요약·할 일이 그 일정에 남는 흐름.**
웨비나·회의실 장비(Zoom Rooms)·전화(Zoom Phone)·메일·문서는 범위 밖.

## 2. 조사 방법과 약관
- 줌 이용약관 '금지 행위' (vi) "경쟁 제품·서비스를 만들거나 벤치마크하거나, 서비스의 기능·그래픽을 복제" 금지, (vii) "서비스와 실질적으로 비슷한 제품의 개발" 금지 → **줌 계정 체험은 하지 않음.** 공개 자료(앱스토어 사진·소개 페이지·요금표·도움말)로만 조사.
- 가져오는 것: 업계 공통 기능과 흐름(대기실·화면 공유·요약 등). **가져오지 않는 것: 줌 로고·파란 색·아이콘·화면 디자인·문구.** 워크인 디자인 문서 기준으로 새로 그림.
- 캡처 원본은 공개 저장소에 올리지 않음 → 노트북 `C:\Users\User\Claude-Operations\artifacts\reference\zoom\` (S01·S02·S05·S06·play-1~6·play-sheet).
