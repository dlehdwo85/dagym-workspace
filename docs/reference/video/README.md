## 0. 결론 먼저

1. **줌 기능표에 없던 것 중 워크인에 꼭 필요한 것 3개(필수)**
   - 메시지방·사람 이름에서 **예약 없이 바로 거는 통화**(네이버웍스의 기본 흐름). 줌 표는 '일정에서 회의 켜기'만 있었음.
   - 네트워크가 잠깐 끊겨도 **자동 재연결**(지트시 공개 소스에 별도 기능으로 있음).
   - 휴대폰 화면이 꺼지거나 잠겨도 **음성 유지**(앱의 기본기. 공개 자료로 각 제품 동작을 확인하지는 못함).
2. **회의 기록 쪽에서 줌보다 나은 아이디어**: 회의 채팅이 회의 앞뒤로 남음(팀즈) · AI 회의록을 누구에게 보낼지 고르기(전원/우리 직원만/주최자만, 구글 미트) · 녹화 전에 참가자 동의 받기(팀즈) · 일정 만들 때 '자동 녹화·자동 AI 노트' 미리 켜기(구글 미트·네이버웍스).
3. **유료로 막는 기능은 다섯 제품 모두 비슷함**: 회의 시간(무료 30~60분) · 인원(무료 4~100명) · 녹화 · AI 회의록 · 보안(워터마크·인증). 워크인 요금제 한도 설계의 기준선으로 쓸 수 있음(5장).
4. **약관**: 마이크로소프트는 상업용 약관에 '제품 기능을 복제하려고 서비스를 쓰는 것' 금지 문구가 있음(줌과 같은 수준). 구글·웨어바이·지트시·네이버웍스 약관에서는 경쟁 목적 사용·벤치마크 금지 문구를 찾지 못함. 그래도 다섯 곳 모두 **줌과 같은 원칙**(공개 자료만, 계정 체험·로그인 안 함)으로 조사함.

## 7. 시사점 (요금·마케팅)

- **무료 한도 시장선**: 시간 30~60분, 인원 4~100명. 네이버웍스·웨어바이는 무료를 4명으로 아주 좁힘. 워크인 무료(또는 하위 요금제)는 '60분·소수 인원'이 시장 평균.
- **돈 받는 지점**: 녹화·AI 회의록·보안. 워크인은 녹화(저장 비용)·AI 회의록(음성 인식 분당 $0.003)이 원가가 드는 기능이라, 이 둘을 상위 요금제 한도로 묶는 것이 경쟁사와 같은 방식이고 원가와도 맞음(`engine_plan.md` 7장).
- **이길 지점**: 어느 제품도 회의 할 일을 '담당자·마감이 있는 업무'로 바로 만들지는 않음(공개 자료 범위). 네이버웍스는 녹음·회의록이 별도 상품(클로바노트). → 마케팅 문구 후보(과장 없는 사실형): "회의가 끝나면 할 일이 담당자 업무로 바로 들어갑니다", "회의록이 회의 일정 안에 자동으로 남습니다". 실제 구현·시험 전에는 쓰지 않음.
- **우리 약점**: 구글·마이크로소프트·네이버의 품질·브랜드 신뢰, 전 세계 서버망. 워크인은 서울 한 곳 서버로 시작(`engine_plan.md`).
