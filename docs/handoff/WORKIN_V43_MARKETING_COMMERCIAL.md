## 1. 실측 원가 — 게시물 종류별 Higgsfield 크레딧 (이 계정 거래 내역 10/3~10/18)

| 모델 | 1회 크레딧 |
|---|---|
| GPT Image 2.0 (2k·고품질, 실사 재디자인) | 6.5 |
| GPT Image 2.5 Flare (저/중품질) | 0.25 / 2.75 |
| Kling 3.0 (영상 1컷 5초) | 7 ~ 8.75 |
| Grok Video 1.5 (영상 1컷) | 18 ~ 22.5 |
| Minimax Hailuo 2.3 | 6 |
| Seedance 2.5 | 35 ~ 72 |
| 내레이션 (Voiceover / Seed Audio) | 0.15 ~ 0.6 |

게시물 1건 원가(실제 제작한 것 기준):

| 게시물 종류 | 만드는 방법 | 크레딧 |
|---|---|---|
| 실사 피드·포스터·블로그 | 고객 실제 사진 + 코드로 글자·레이아웃 렌더 (예: 다짐 상담 광고 실사안, 고민 체크리스트) | **0** |
| 실사 재디자인 이미지 피드 | 실제 사진을 광고 사진으로 재디자인 1~4장 | 6.5 ~ 26 |
| 실사 기반 릴스·쇼츠 | 실사 컷 + 자막 + 내레이션 (생성 영상 없음) | 0.5 ~ 3 |
| 생성 영상 광고 (15~20초, '삼립급') | 키프레임 5장 + 영상 4~5컷 + 내레이션 (10/17 하이링크 릴스 실측) | **약 80** |
| 수정 1회 | 글자·배치 수정 = 0 / 이미지 다시 생성 = 6.5 / 영상 컷 다시 생성 = 7 ~ 22.5 | 0 ~ 22.5 |

**결론:** 원가는 '생성 영상'과 '재생성 수정'에서만 생긴다. 대표 품질 기준(실사 우선, AI 느낌 금지)을 지키면 대부분 게시물은 0크레딧이다. 고객별 한도는 **생성 영상 편수 + 재생성 횟수**로 거는 것이 맞다.

## 2. 크레딧 공급과 고객 수

- 현재 Ultra 월 3,000 크레딧(지급일 27일, 남은 크레딧은 사라짐). 이 3,000을 고객이 나눠 쓰는 구조라면 **회사 전체 월 예산 = 3,000 − 자사 브랜드 몫**.
- 고객이 늘면 Higgsfield 추가 충전/팀 요금제로 늘린다 — 고객 요금에 '포함 크레딧'을 정하고, 초과분은 고객 승인 후 실비(또는 다음 달 이월 없음)로 한다.
- 크레딧 원화 단가 = (Higgsfield 월 구독료 ÷ 3,000). 구독료 실금액은 대표 결제 내역으로 확정 필요 → 요금표 원가 칸에 반영.

## 5. 수정 요청 처리 — 크레딧과 연결

1. 수정 요청이 들어오면 AI 비서가 먼저 **분류**: 글자·배치(0크레딧) / 이미지 재생성 / 영상 컷 재생성.
2. 재생성이면 남은 '재생성 횟수'와 '크레딧'을 확인 → 남아 있으면 바로 재제작, 없으면 고객에게 "추가 1회 = n크레딧" 승인 요청.
3. 새 버전은 승인함에 '재승인'으로 올라가고 마감 규칙·알림은 그대로 적용. (운영실은 버전 올림 → 승인 해제 → 재승인 구조가 이미 있음)
4. 모든 생성 호출은 **고객·게시물·버전에 크레딧을 기록**(원장). 월말 보고에 사용량 표시.

## 7. 운영실에서 배운 것 (그대로 기능 요구로)
- 고객은 '승인·수정 요청'만 한다. 계획·제작·검수는 AI 비서가 한다.
- 'AI 느낌'이 가장 큰 거절 사유였다 → 기본값은 실사 + 글자 렌더. 생성 이미지·영상은 요금제 옵션.
- 휴대폰 손 합성·생성 인물·슬라이드쇼(사진+느린 줌)는 거절됐다. 레퍼런스는 같은 업종 경쟁사·국내 서비스 홍보 방식에서 가져온다.
- 마감이 지난 시안은 자동으로 다음 칸으로 옮기거나 버린다 — 고객에게 '마감 지남'만 반복해 보이지 않게.
- 숫자(연혁·실적)는 고객이 확인한 값만 쓴다. 회사 소개서·사이트에서 찾은 값은 '확인 필요'로 표시해 묻는다.

## 8. 다음 단계 (워크인 개발 순서 제안)
1. 테넌트·요금제·크레딧 원장 데이터 모델 (고객 id, 요금제, 월/주 한도, 사용 기록)
2. 고객 설정 화면: 채널별 주간 규칙 · 마감 · 알림(마감 N시간 전 · 무알림 시간) · 브랜드 키트
3. 서버 제작 에이전트: 규칙 → 기획 → 제작(실사 우선) → 자동 품질 검사 → 승인함 → 알림
4. 수정 요청 분류·재생성·크레딧 차감·초과 승인
5. 채널 OAuth 연결(Meta 앱 심사부터 — 가장 오래 걸림)
6. 월간 보고서(게시·반응·크레딧)
