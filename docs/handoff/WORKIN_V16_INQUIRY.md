# 워크인 16차 — 다짐·하이링크 웹사이트 문의 → 워크인 업무 자동 등록 (대표 지시 2026-10-14)

> 대표: "하이링크·다짐 웹사이트에 문의가 들어오면 업무관리에 자동 등록. 카테고리·하위 태스크·설명에 문의 내용이 잘 적히게. **슈퍼관리자 계정(다짐 회사)에만**."
> 현재 사이트 구조(로컬 확인): `dagym-website/app/contact/actions.ts`, `hilink-website/app/contact/actions.ts` — 검증 → Lead ID → 공용 Supabase `leads` 저장(source=dagym-web / hilink-web) + 이메일 알림. 필드: inquiry_type(위탁운영·HILINK 플랫폼·운영 진단·…), organization, region, facility_scale, name, phone, email, organization_type, services[], current_operation, message, utm·landing·referrer.

## 방식: 사이트가 워크인으로 보내기(푸시, 최소 권한)
- 워크인 `POST /api/integrations/inquiries` — 헤더 `Authorization: Bearer <연동 토큰>`. 토큰은 **플랫폼 운영 화면(슈퍼관리자 전용) → "웹사이트 문의 연동"** 에서 사이트별(다짐·하이링크) 발급, 한 번만 표시, 해시 저장, 폐기·재발급. 토큰은 **다짐 회사(tenant) 고정** — 다른 회사·체험 계정에는 이 기능·메뉴 없음.
- 사이트 쪽: 기존 Supabase 저장·이메일 뒤에 **비차단(fire-and-forget, 3초 타임아웃)** 으로 워크인 전송. 실패해도 문의 접수는 성공(사이트 영향 0), 실패 시 워크인이 아닌 기존 경로로 계속 처리. (사이트 코드는 각 사이트 담당 세션이 수정)
- 멱등: lead_id 로 중복 등록 방지(재전송 안전).
- 보완(선택): 전송 실패 대비 워크인 정기 실행이 Supabase `leads` 를 읽어 누락분 보충 — Supabase 읽기 키가 필요하므로 2단계.

## 업무로 만드는 형식
- **프로젝트(카테고리)**: "웹사이트 문의" 프로젝트 자동 생성, 섹션 = 문의 유형(위탁운영 / HILINK 플랫폼 / 운영 진단·컨설팅 / 기타), 태그 #다짐웹 #하이링크웹 #지역 #서비스.
- **제목**: `[하이링크 문의] 음성푸르지오더퍼스트 · HILINK 플랫폼 (충북)`
- **설명(표)**: 문의 유형·회사/단지명·지역·시설 규모/세대수·담당자·연락처·이메일·소속·관심 서비스·현재 운영 상황·문의 내용 원문·접수 시각·유입 경로(utm·랜딩 페이지)·Lead ID. 연락처는 기밀 등급 `내부`(보안 15번).
- **체크리스트(하위 단계, 유형별 템플릿)**: ① 1차 연락(접수 24시간 이내) ② 요구사항 확인·현장 정보 수집 ③ 자료/제안서 발송 ④ 견적 ⑤ 미팅 일정 ⑥ 결과 기록(수주·보류·실패). 위탁운영은 "현장 실사", HILINK 는 "데모 일정" 단계 추가.
- **담당자·지시자**: 기본 담당 = 설정값(플랫폼 운영 화면에서 유형별 기본 담당자 지정, 없으면 대표), 지시자 = 대표. 마감 = 접수 + 1영업일 18:00(1차 연락 기준), 우선순위 높음. 담당자에게 즉시 푸시 "새 웹사이트 문의 · 음성푸르지오더퍼스트".
- AI(haiku) 한 줄 요약을 설명 맨 위에(선택, 한도 내).

## 시험
- 토큰 없음/틀림 401, 다른 tenant 차단, 같은 lead_id 두 번 → 1건, 필드 누락 허용(선택 필드), 다짐 외 회사에서 메뉴·API 404.
