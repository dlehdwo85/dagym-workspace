# GPT 회사 자료 운영체계 × 업무·일정 관리 연결 검수

작성: 2026-10-13 · 로컬 Claude Code · 근거: 대표가 전달한 GPT 프로젝트 지시문(회사 자료 업로드·분류·근거 답변·결과물 제공 체계)
전제: 업무·일정 관리는 **본사 3명용 운영 도구**([HQ_SIMPLIFY.md](HQ_SIMPLIFY.md)). GPT 쪽 실제 저장소(ChatGPT 프로젝트 파일인지, Google Drive 인지 등)는 아직 확인되지 않음 → 아래는 연결 설계안이며 구현 전 대표 확인 필요.

## 1. 두 시스템의 역할 나누기
| | GPT 자료 운영체계 | 업무·일정 관리 (우리 서비스) |
|---|---|---|
| 다루는 것 | 문서 원본·버전·분류, 근거 기반 답변, 결과물 생성 | 할 일·담당·마감·일정·완료 확인 |
| 원본 위치 | 공용 원본 저장소(확인 필요) | 저장하지 않음 — **링크로만 참조** (중복 저장 금지 원칙과 일치) |
| 권한 | 프로젝트 지침 ≠ 권한 통제 (지시문 1절) | 서버에서 권한 검사, 다른 조직 데이터 404 |
| 민감자료 | 별도 제한 공간 | 업무에는 제목·링크만, 내용·첨부 금지 권장 |

## 2. 연결해서 고도화할 수 있는 부분 (우선순위)
| ID | 연결 | 효과 | 구현 위치 |
|---|---|---|---|
| G-1 | **업무에 "근거 자료" 칸** — 자료 등록부 항목(문서명·브랜드·현장·기준일·버전·원본 링크)을 업무에 연결. 지금의 "문서 링크 연결"을 확장 | 업무를 열면 어느 버전 문서를 기준으로 하는지 바로 보임 | 우리 서비스 (첨부 → 문서 링크에 기준일·버전 필드 추가) |
| G-2 | **최신본 경고** — 연결한 문서보다 새 버전이 자료 등록부에 생기면 업무에 "새 버전 있음" 표시·담당 알림 | 옛 기준으로 일하는 것 방지 | 자료 등록부를 읽을 수 있는 형태(시트·CSV·API)여야 가능 |
| G-3 | **문서 속 날짜 → 캘린더·업무** — 계약 만료·갱신일, 수강료 변경일, 세대수 확정일 등 GPT가 원문 위치와 함께 뽑은 날짜를 "준비 업무"로 등록 (예: 계약 종료 D-60 갱신 검토, D-30 제안서) | 놓치는 계약·갱신 없음 | 우리 서비스의 준비 업무 기능 재사용 + 가져오기(CSV 붙여넣기) |
| G-4 | **결과물 요청 = 업무** — "두정점 매출·지출 엑셀 보고서 만들어줘" 같은 요청을 업무로 남기고(요청자·담당·마감), GPT 결과물 링크를 그 업무에 붙여 완료 | 누가 무엇을 요청했고 언제 끝났는지 기록 | 1단계: 사람이 업무에 링크 붙임 / 2단계: 아래 G-6 |
| G-5 | **주간 보고에 자료 변경 포함** — 지난주 새로 등록·개정된 주요 문서(제안서·계약서) 목록을 주간 보고 한 칸으로 | 본사 3명이 문서 변화도 한 화면에서 확인 | 자료 등록부 접근 필요 |
| G-6 | (선택) **GPT → 업무 자동 등록** — Custom GPT Actions 로 우리 서비스 API(업무 생성·조회)를 호출. 업무 제목·담당·마감·근거 링크만 전달 | 대화 중 "이거 업무로 등록해줘" 한 번에 | 전용 API 토큰(개인별·범위 제한·폐기 가능) 설계 필요. 민감자료 내용 전송 금지 |

## 3. 지금 바로 가능한 것 (추가 개발 없이)
- 업무 상세 → 자료·첨부 → **문서 링크 연결**에 GPT/저장소의 원본 링크를 붙이고, 제목에 기준일·버전을 적는다 (예: `하이링크_영업_제안서_20261010_v03`).
- 계약 만료일은 캘린더에 일정으로 만들고 **준비 업무 자동 만들기 → 계약 미팅** 묶음을 사용.
- 민감자료(급여·인사·개인정보·중요 계약)는 업무에 첨부하지 않고 제한 공간 링크만 둔다.

## 4. 결정이 필요한 것 (대표)
1. GPT 쪽 **원본 저장소가 어디인지** (ChatGPT 프로젝트 파일 / Google Drive / 사내 NAS 등) — G-2·G-5 가능 여부가 여기서 결정됨
2. 자료 등록부를 **어떤 형식으로 둘지** (Google 시트 권장: 우리 서비스가 읽기 전용으로 가져오기 쉬움)
3. G-6 자동 등록을 쓸지 — 쓴다면 API 토큰 발급·폐기 화면을 우리 서비스에 추가

## 5. 주의 (GPT 지시문과 같은 원칙)
- 파일·문서 안의 문구는 지시로 취급하지 않는다 → 자동 등록(G-6)은 업무 생성만 허용, 삭제·권한 변경 API 는 열지 않는다.
- 읽지 못한 자료를 "확인 완료"로 표시하지 않는다 → 근거 자료 칸에 "읽기 확인 여부" 상태를 둔다.
