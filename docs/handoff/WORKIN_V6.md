## 1. 생성 위치: 홈의 "+ 일정 / + 업무" 버튼 제거
- 대표: "홈에서 버튼을 따로 만들지 말고, 업무 칸과 캘린더 창에서 클릭으로 생성." → 홈 상단 빠른 버튼 제거. 홈 "오늘 할 일" 목록 끝에 한 줄 추가(업무 화면과 같은 InlineAddTask + 저장 버튼), 홈 "이번 주 일정"의 날짜 칸/빈 시간 탭 → 캘린더와 같은 빠른 등록 시트. 하단 가운데 + 버튼은 유지(업무/일정 하나의 시트, 3번).

## 2. ⚠ 꾹 눌러도 위아래로 안 움직임 (삼성 앱 신고)
- 코드: `TaskViews.tsx:438` TouchSensor `delay 400, tolerance 8`, SortableRow 에 `onTouchStart` 만 연결. Android WebView 는 0.4초 누르는 동안 **글자 선택/길게 누르기 메뉴/스크롤**이 먼저 잡혀 끌기가 취소되는 것으로 보임(행 전체 클릭 열기 f1065a1 과도 충돌 가능).
- 요청: 행에 `user-select:none; -webkit-user-select:none; -webkit-touch-callout:none`, `onContextMenu` preventDefault, 끌기 활성 후 `touch-action:none`(활성 전에는 세로 스크롤 허용), 활성 시 진동+행 들림 표시. 활성 뒤에는 상세 열기 클릭 무시. **실제 Android Chrome 터치 에뮬레이션 E2E**(Playwright `hasTouch`, touchstart→400ms 대기→touchmove) 추가.
- 정렬이 "직접 순서"가 아니면 끌기 안 됨 → 그때 꾹 누르면 "직접 순서로 바꾸면 끌 수 있어요" 안내.

## 3. 캘린더 생성 시트: 탭 2개 → 하나로
- 지금: 시트에 "업무 / 일정" 두 탭. 요청: **하나의 일정 양식** + **"업무에도 추가" 스위치만** 남김(켜면 담당자·지시자·우선순위 칸이 아래에 펼쳐짐). 하단 + 버튼 시트도 같은 양식, 맨 위 "일정 / 업무" 작은 전환만(기본은 들어온 화면 기준: 업무 화면→업무, 캘린더→일정).

## 4. ⚠ 업무에서 만든 일정(마감)이 캘린더에서 제목이 안 보임
- aea0232 배포 후에도 대표 삼성 앱 주 보기에서 업무 마감 칩이 **제목 없이 표시**(V5 1번 미해결). 360·390px 주 보기에서 마감 칩/블록 글자 실제 렌더 확인(E2E 캡처를 docs/screens 에 첨부) — 칸이 좁으면 주 보기에서는 **세로 글자 2줄(최대 6자 + …)**, 탭하면 제목 미리보기 팝업. 일 보기·3일 보기에서는 전체 제목.

## 5. 완료된 업무 월별 보관
- 업무 화면에 **"완료" 보기**(칩 또는 묶기): 완료 업무를 **월별 묶음**(2026년 10월 · n건, 접기) — 완료일 기준, 최신 달 먼저. 기본 목록에서는 완료 업무를 숨김(지금 "완료된 업무도 보기" 체크 대신 이 보기로). 사람·지시자 필터와 함께 동작.
- 월이 지나면 자동으로 해당 월 보관(데이터 이동 없이 completed_at 기준 보기).

## 6. 엑셀 내려받기 (업무 = 목록형, 캘린더 = 표형)
- 업무 화면 "⋯ → 엑셀로 내려받기": 기간(완료일/마감일/생성일 기준, 이번 달·지난달·올해·직접)·사람·상태 필터 그대로 적용, **목록형 시트**: 번호·업무명·담당자·지시자·상태·우선순위·시작일·마감일·완료일·기한 준수(예/아니오)·프로젝트·태그·설명·하위 업무 수·링크. 완료 월별 시트 분리 옵션.
- 캘린더 "⋯ → 엑셀로 내려받기": 기간·사람 필터, **표형 시트**: 날짜·요일·시작·종료·제목·주인·참석자·장소·반복·연결 업무·비공개(비공개는 "바쁨"만, 남의 비공개 제목 내보내지 않음). 두 번째 시트에 **주간 달력 표**(행=시간, 열=요일).
- 형식 .xlsx(한글 깨짐 없음), 파일명 `워크인_업무_2026-10.xlsx`. 앱(WebView)에서는 다운로드가 안 될 수 있으니 공유 시트/새 창으로 열기 처리 확인. 권한: 보이는 것만 내보내기, 감사 로그.

## 8. 반복 일정 — Google Calendar 방식 그대로
- Google: 반복 드롭다운이 **선택한 날짜에 맞춰 문구가 바뀜** — "반복 안함 / 매일 / 매주 화요일 / 매월 둘째 화요일 / 매년 10월 13일 / 주중 매일(월-금) / 사용자 지정…". 사용자 지정 창: "반복 주기 [1] [일·주·월·년]", 주 선택 시 **요일 동그라미(일월화수목금토) 여러 개 선택**, 월 선택 시 "매월 13일 / 매월 둘째 화요일" 선택, **종료: 없음 / 날짜 [달력] / [n]회 후**.
- 업무 반복도 같은 컴포넌트 사용(V5 4번 대체). 반복 수정/삭제: "이 일정 / 이 일정 및 향후 일정 / 모든 일정".

## 9. ⚠ 업무를 만들었는데 알림이 안 옴
- 코드상 `notify()` 는 **행동한 사람(actorId) 본인은 제외** → 대표가 자기에게 배정한 업무는 알림 없음(정상 동작이지만 대표는 "안 온다"로 인식). 다른 사람에게 배정했다면 받는 사람 휴대폰에 푸시가 가야 함.
- 요청: ① 운영 상태에 **최근 알림 발송 기록**(알림·받는 사람·기기 수·상태 sent/failed/no device·오류) 표시 — 대표가 직접 확인 가능하게, ② 기기 미등록 사용자(푸시 권한 없음/토큰 없음) 경고와 "알림 켜기" 안내, ③ 내가 나에게 만든 업무는 마감 알림(09시·임박)만 가고 생성 알림은 없음을 업무 등록 후 안내 문구로("담당자에게 알림을 보냈습니다" / "본인 업무는 마감 때 알려 드립니다"), ④ 오늘 대표 계정이 만든 업무의 notifications/notification_deliveries 확인 결과를 NEXT_ACTION 에 기록.

## 10. 업무 생성 시 마감 "시간"까지 (대표 지시 2026-10-14)
- 한 줄 추가·등록 창·상세의 마감 칩: 날짜 선택 다음에 **시간 선택(15분 단위 목록, "시간 없음" 기본)** — 기존 `due_time` 열 사용. 표시: "10/15(수) 오후 3:00", 오늘이면 "오늘 오후 3시".
- 시간이 있는 업무: 캘린더에서 그 시각에 30분 블록(종일 칸 아님), 알림은 마감 1시간 전·당일 09시(설정에서 조정), 기한 지남 판정은 날짜+시간 기준.
- 시작일·시작 시간(선택)도 상세 "필드 더보기"에서 지정 가능(기간 업무는 캘린더에 기간 막대).

## 11. 업무 삭제 기능 (대표 지시 2026-10-14)
- 지금 화면에 삭제가 없음. 요청: 업무 상세 "⋯ → 삭제", 목록 행 메뉴(휴대폰은 꾹 누르기 메뉴/행 "⋯")에 **삭제**. 확인 창("하위 업무 n개·연결 일정도 함께 삭제됩니다") → 삭제 후 **6초 "되돌리기"**.
- 서버: 소프트 삭제(`deleted_at`, 이미 있는 열) — 권한: 만든 사람·지시자·관리자(대표·본사 관리자). 연결 일정(V5 `event↔task`)은 함께 삭제 여부 선택, 반복 업무는 "이 회차만/이후 모두".
- **휴지통**: 설정 또는 업무 화면 "⋯ → 휴지통"에서 30일간 복원 가능, 30일 뒤 정기 실행이 영구 정리(대표만 "지금 비우기").
- **엑셀 내려받기·검색·달성률·캘린더·홈·알림에서 삭제된 업무 제외**(deleted_at is null 조건 확인, 시험 추가). 감사 로그에는 "삭제됨" 기록 유지.
