# Asana 를 넘어서는 개발 계획 (로컬 실측 기반)

작성: 2026-10-13 · 로컬 Claude Code · 대표 지시: "Asana 는 참고만 하고 연동하지 않는다. Asana 보다 높은 수준의 사이트가 되도록 개발한다."
근거: Asana 시험 계정(Advanced 체험, 샘플 프로젝트 "주요 사업 계획")을 실제로 조작해 확인 + 대표 Google Calendar 읽기 전용 확인 + 우리 서비스 Windows 운영 빌드 검수([LOCAL_REVIEW.md](LOCAL_REVIEW.md)).
구현 담당: 클라우드 세션 (`src/` `db/` `tests/`). 로컬은 구현 후 실제 화면 재검수.

## 2. 우리가 이미 Asana 보다 나은 점 (유지·강화)
- 업무와 **시간이 정해진 일정**이 한 서비스에 있음 (Asana 캘린더는 작업 마감만 표시, 회의는 Google Calendar 따로)
- **현장·부서 단위 권한**과 다른 조직 데이터 404 은닉 (Asana 는 프로젝트·팀 단위 공유)
- **검토 요청 → 관리자 최종 확인** 흐름이 모든 업무에 기본 (Asana 승인은 별도 작업 유형)
- 모바일 앱 푸시·오프라인 댓글 재전송, 브랜드(다짐·하이링크·BODY LAB) 구분, 일정 시작 전 알림
- 요금 제한 없음 (필드·타임라인 잠김 없음)

## 3. 개발 과제 — Asana 를 넘어서기 위한 우선순위
### P0 (이번 단계: 일상 사용성에서 Asana 와 동등 이상)
| ID | 과제 | 완료 기준 |
|---|---|---|
| B-1 | **업무 상세 오른쪽 패널** — 목록·보드·내 업무에서 클릭 시 패널로 열고 URL 은 `/tasks/:id` 유지(새로고침·공유 가능). 모바일은 전체 화면 | E2E: 목록에서 열기→수정→닫기 후 스크롤 위치·필터 유지 |
| B-2 | **내 업무 자동 묶음** — 새로 배정됨(확인 전) / 오늘 / 이번 주 / 나중 / 기한 초과. "확인" 누르면 새로 배정됨에서 빠짐 | API·E2E |
| B-3 | **프로젝트 섹션** — 섹션 생성·이름 변경·순서, 업무 끌어서 섹션 이동, 보드 열 = 섹션 선택 가능 | 마이그레이션 추가형, E2E |
| B-4 | **빠른 검색·명령창 Ctrl+K** — 업무·프로젝트·사람·일정 검색, "업무 만들기"·"오늘로 이동" 명령. 권한 밖 결과는 서버에서 제외 | 권한 시험 포함 |
| B-5 | 로컬 검수 R-1~R-5 수정 (migrate Windows 경로, 멘션 UUID 노출·목록 필터, 첨부 KB, 버튼 줄바꿈) | LOCAL_LOG 요청 |
| B-6 | **일정별 알림 여러 개 + 반복 종료 조건**(종료일·횟수·매월 N번째 요일) — R-6·R-7 | API·E2E |

### P1 (Asana 를 넘어서는 차별 기능 — 우리 회사 현장 운영에 맞춤)
| ID | 과제 | Asana 대비 |
|---|---|---|
| B-7 | **사진 증빙 필수 완료** — 업무·템플릿에 "완료 시 사진 N장 필수" 옵션. 앱 카메라로 촬영, 촬영 시각·업로더 기록 | Asana 없음. 현장 점검·시설 보수에 핵심 |
| B-8 | **현장 신고 양식 + QR** — 현장별 QR(시설 고장·회원 민원·비품 요청) → 로그인한 직원은 바로, 비로그인(회원)은 이름·연락처 최소 입력 → 담당 현장 업무 자동 생성·담당자 자동 배정. 스팸 방지(속도 제한) | Asana 양식은 유료·외부 공유 제한, 현장 QR·현장 자동 배정 없음 |
| B-9 | **다단계 결재** — 업무 유형별 결재선(현장 매니저 → 본부 → 대표), 반려 사유 필수, 결재 이력 감사 기록 | Asana 승인은 1인·승인/변경 요청만 |
| B-10 | **자동화 규칙(간단형)** — "상태가 검토 요청이 되면 현장 매니저에게 알림", "마감 1일 전 담당자·관리자 알림", "완료되면 후속 업무 생성", "보드 열 이동 시 담당자 변경". 조직별 규칙, 실행 이력 | Asana 규칙과 동등, 단 현장·브랜드 조건 추가 |
| B-11 | **사용자 지정 필드(프로젝트별)** — 선택형(색)·숫자·날짜·사람. 숫자 집계는 **합계/평균/최소/최대 선택**, 퍼센트는 기본 평균 | Asana 는 퍼센트도 합계(170%) — 우리는 올바른 집계 |
| B-12 | **업무 유형** — 일반 / 마일스톤 / 결재 / 점검(체크리스트+사진). 타임라인에서 마일스톤은 마름모 | Asana 와 동등 + 점검 유형 |
| B-13 | **후속 업무·복제·중복 통합** | Asana 와 동등 |

### P2 (경영 보고 수준을 Asana 이상으로)
| ID | 과제 | Asana 대비 |
|---|---|---|
| B-14 | **현장 비교 대시보드** — 현장·브랜드별 기한 준수율, 평균 처리 시간, 미해결 민원, 점검 수행률, 지난 4주 추이 | Asana 대시보드는 프로젝트 단위, 현장 비교 없음 |
| B-15 | **주간 보고 자동 생성** — 매주 월요일 오전 대표에게 현장별 요약(완료·지연·주요 이슈·사진) 앱 알림 + PDF 내려받기 | Asana 는 수동 상태 업데이트 |
| B-16 | **업무량 보기** — 사람별 이번 주 업무·일정 시간 합계, 휴가·출장 반영, 과부하 표시 | Asana 업무량은 Advanced 이상 유료 |
| B-17 | 키보드 단축키(업무: Tab+S 하위 업무 등, 캘린더: D/W/M/A), 한국 공휴일 캘린더 | 동등 |
| B-18 | (선택) AI 업무 요약·하위 업무 초안 — 외부 AI 사용은 대표 승인 후 | Asana AI 와 동등 |

## 4. 하지 않는 것
- Asana·Google Calendar 연동·가져오기 (참고만). 이미 있는 Google 동기화 코드는 기본 꺼짐 그대로.
- Asana 의 목표(Goals)·포트폴리오 전체 복제 — 우리 규모에서는 프로젝트 개요·현장 대시보드로 대체.
