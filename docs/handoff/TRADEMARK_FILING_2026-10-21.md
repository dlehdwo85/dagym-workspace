## 6. 특허로 「웹작성/제출」 화면 순서 (8단계)

사전 준비: ① 특허고객번호(주식회사 다짐) 발급 완료 ② 법인 공동인증서(범용 또는 특허로 전용)로 특허로 로그인·전자서명 환경(특허로 통합설치 프로그램) 설치 ③ 견본 PNG ④ 아래 지정상품 표.

1. **특허로(https://www.patent.go.kr) 로그인 → 출원신청 → 「웹작성/제출」** 메뉴(서식작성기 설치 없이 웹에서 작성) → 권리 구분 "상표" 선택.
2. **서식 선택: 「상표등록출원서」**(국내, 일반상표). 새 문서 만들기.
3. **출원인 입력: 특허고객번호**로 주식회사 다짐 불러오기(명칭·주소 자동). 대리인 없음. 출원인 전자서명 인증서 = 법인 인증서.
4. **상표 유형/견본**: 상표 유형 "일반상표", 표장 구분 "문자상표", 상표명칭 란에 `워크인`(또는 `WORK-IN`, 결합이면 `워크인 WORK-IN`) 입력, 견본 이미지 업로드(`docs/handoff/trademark/*.png`). 상표 설명·지정 색채 없음.
5. **지정상품 입력: 「지정상품 검색(고시명칭)」**으로 류를 고르고 위 표의 고시명칭을 검색해 체크(직접 타이핑 대신 검색 선택 → 고시명칭 자동 인정, 46,000원 적용). 류별 10개 이하 확인. 다류(09·42·35 / 42·36)를 한 출원서에 넣는다.
6. **우선심사 여부**: 기본 "신청 안 함". 급하면 별도 "우선심사신청서"를 같은 날 제출(1류당 160,000원).
7. **검증 → 전자서명 → 제출**: 작성 완료 후 "서식 검증"(오류 0) → 수수료 미리보기에서 류당 46,000원 × 류 수 확인 → 인증서로 전자서명 → 제출.
8. **접수번호 확인 → 수수료 납부**: 제출 직후 접수번호(출원번호 40-2026-xxxxxxx)와 납부자번호 발급 → 특허로 「수수료납부」에서 **다음 날까지** 납부(대표 결제) → 납부 영수증·접수증 PDF를 `docs/handoff/trademark/`에 저장.

같은 순서로 두 번째 출원서(영문 또는 하이링크)를 작성한다. 제출 후: 출원공고(약 8~12개월) → 이의신청 2개월 → 등록결정 → 2개월 내 등록료 납부.
