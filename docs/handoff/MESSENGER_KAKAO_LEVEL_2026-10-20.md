## 1. 지금 있는 것 (코드 기준, src/components/messenger/Messenger.tsx · src/app/api/chat/*)
- 대화방: 1:1·그룹·업무 대화방 열기, 목록 위 고정, 알림 끄기, 이름 바꾸기(그룹), 나가기, 종류 탭, 대화방·메시지 검색, 대표 감사용 내보내기(CSV)
- 메시지: 답장, 반응(이모지), 고정, 수정·삭제, 사진·파일·음성, 링크, @멘션, 입력 중, 읽음 수, 읽지 않음, "업무로 만들기", 실시간(SSE·폴링)
- 멤버: members POST(추가)는 API만 있고 화면에서 초대 흐름이 약함. "새 대화"는 사람 아이콘을 눌러 1:1 시작 중심.

## 2. 카카오톡 대비 부족 → 요청 (우선순위 순)
### A. 방 만들기·초대 (최우선)
1. [새 대화] → 한 화면에서 **여러 명 체크 선택**: 이름·부서·직급 검색, 부서별 묶음(접기/펼치기), 최근 대화 상대 먼저, 선택한 사람 칩으로 표시 → 1명이면 1:1, 2명 이상이면 그룹(방 이름 자동 "홍길동, 김철수 외 2" + 바로 바꾸기).
2. 방 정보 화면(머리줄 '≡'): 방 이름·방 사진(자료실 업로드), **참여자 목록**(프로필·직급·전화·1:1 열기), [초대], [내보내기(방장·관리자만)], [나가기], 알림 끄기, 고정, 사진·파일·링크 모아보기 탭(기존 files API 활용).
3. 초대: 참여자 목록에서 [초대] → 같은 다중 선택 화면, 초대되면 시스템 메시지 "○○님이 △△님을 초대했습니다", 초대된 사람은 **초대 시점 이후 메시지만** 보이게(회사 보안) 또는 방장이 "이전 대화 공개" 선택.
4. 부서 방 자동: 조직 구성 변경 시 부서 방 자동 생성·인원 반영(옵션), 회사 전체 방 1개 기본.
### B. 대화 기능
5. 메시지 **전달**(다른 방·여러 방 선택), 길게 누르기/우클릭 메뉴(답장·전달·복사·공지 등록·업무로·삭제) 하나로 통일.
6. **공지**: 메시지를 방 공지로 등록 → 방 상단 접힘 바(카톡식), 공지 이력.
7. 읽음: 카톡처럼 메시지 옆 **안 읽은 사람 수**(지금 읽음 수 → 안 읽은 수로 바꾸고 누르면 안 읽은 사람 이름).
8. 사진 여러 장 한 번에 보내기(묶음 미리보기·좌우 넘기기 뷰어·저장), 영상, 파일 미리보기, 긴 글 "전체 보기".
9. 투표(선택지·마감·익명), 일정 잡기(메시지 → 캘린더 일정 제안, 참석자 = 방 참여자), 업무로 만들기는 유지.
10. 이모지·스티커 패널(회사용 기본 스티커 1묶음), 자주 쓰는 반응 6개.
11. 멘션 @전체, 답장 원문 눌러 이동, 날짜 구분선, 새 메시지 "여기까지 읽음" 선.
### C. 알림·휴대폰
12. 방별 알림 설정(끄기·멘션만·전체), 푸시에서 바로 답장(알림 액션 버튼 — 네이티브 쪽 로컬 담당), 앱 아이콘 배지 = 안 읽은 메시지 수.
13. 휴대폰: 방 목록 좌우 스와이프(고정·알림·나가기), 입력창 + 버튼(사진·카메라·파일·음성·투표·일정·업무), 키보드 올라와도 마지막 메시지 보이게.
### D. 관리
14. 방장 권한(이름·사진·초대·내보내기·공지), 퇴사 처리 시 모든 방에서 자동 제거 + 시스템 메시지(사용자관리 퇴사/인수인계와 연결).
15. 검색: 방 안 검색(위/아래 이동·강조), 전체 검색 결과에서 해당 메시지로 이동.

## 3. 배포 묶음 제안
- 메신저 1차(A 1~3 + B 5·6·7): 방 만들기·초대·방 정보·전달·공지·안 읽은 수 → [배포확인요청]
- 메신저 2차(B 8~11 + C 13): 사진 묶음·투표·일정·스티커·휴대폰 입력창
- 메신저 3차(C 12 + D): 알림 설정·방장·퇴사 연동·검색 이동
