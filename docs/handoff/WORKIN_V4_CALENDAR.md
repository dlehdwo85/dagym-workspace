# 워크인 캘린더 4차 — Google Calendar 방식 선택·등록, 서로의 일정 보기 (대표 지시 2026-10-13 17:20)

> 대표: "일정을 누르는 부분이 구글캘린더처럼 캘린더에서 선택이 아니다 — 디벨롭. 다른 직원들 일정도 보이게, 필터로 내 것만 볼 수 있게. 직원 각 계정에서도 마찬가지. 앱 업데이트 없이 바로 적용."
> 구현: 클라우드, 바로 main. **웹 코드만으로**(앱 새 빌드 불필요 — 앱은 운영 주소를 불러옴). 대표 휴대폰 = 삼성 Android 앱.

## 1. 캘린더에서 바로 선택해 등록 (Google Calendar 동작)
- **휴대폰**: 빈 칸을 **한 번 탭**하면 그 시각 1시간짜리 임시 블록(미리보기)이 생기고 아래에서 빠른 등록 시트(제목·시간·저장)가 올라옴. 지금은 길게 누르기(longPressDelay 350)만 되어 "눌러도 안 됨". `dateClick` 로 처리, 블록 위아래 손잡이로 길이 조절, 월 보기 날짜 탭 → 그날 종일/시간 등록.
- **PC**: 지금처럼 끌어서 범위 선택 + 클릭 한 번 = 30분/1시간 블록.
- **등록 창의 날짜·시간 입력**: 브라우저 기본 입력 대신 Google 처럼 **날짜 = 작은 달력 팝업**, **시간 = 15분 단위 목록**(종료 시간 옆에 "(1시간)" 길이 표시), 종일 체크, 반복 선택.
- "+ 만들기"로 열어도 현재 보고 있는 날짜·가까운 다음 정각이 기본값.

## 2. 다른 직원 일정 보기 + 내 일정만 필터 (모든 본사 계정 동일)
- 본사 사람 일정은 **서로 기본 공개(본사 안에서만)**. 다른 조직 404 원칙 유지.
- 캘린더 왼쪽(휴대폰은 위 칩): **전체 · 내 일정 · 사람별(김민수·김소담·이동재 색 구분)**. 사람 칩 = 필터(누르면 그 사람만, 여러 명 선택 가능), 선택은 사용자별로 기억. 업무 화면 사람 칩과 같은 동작.
- 일정 블록에 주인 표시(색 + 이름 머리글자), 참석자 일정은 함께 표시.
- 일정마다 "비공개" 선택 시 다른 사람에게는 제목 없이 "바쁨"으로만.
- 다른 사람 일정은 보기만(수정은 주인·참석자·관리자), 클릭 시 상세 미리보기.

## 3. 완료 기준
- 삼성 휴대폰 앱에서 빈 칸 탭 → 빠른 등록 → 저장 → 다른 계정 캘린더에 보임
- "내 일정" 필터로 내 것만, 사람 칩으로 특정 직원만
- E2E: 모바일 크기 빈 칸 탭 등록, 다른 계정 일정 표시·비공개 "바쁨", 필터 유지

## 4. 대표 추가 지시 (2026-10-13 17:40) — 1~3과 함께 처리
### 4-1. 캘린더 선택 단위 = 1시간 (Google Calendar 조사 반영)
- Google 공식 도움말(support.google.com/calendar/answer/72143): 웹은 빈 시간 클릭 = 그 시각 일정 초안, 끌면 긴 범위. 휴대폰(Day·3일·Week)은 빈 시간 **탭 = 일정 시작**, 새 일정 위아래 **동그라미를 끌어 길이 조절**, 위로 밀면 상세. iOS 설정에 "기본 일정 길이"(기본 60분).
- 워크인: 탭/클릭 = **1시간 블록**(정각 기준), 끌기 선택도 **1시간 단위로 스냅**(FullCalendar `selectMinDistance`·`snapDuration: '01:00'`, 주/일 보기 슬롯 1시간 줄 `slotDuration: '01:00'`). 세밀한 시간은 등록 창 15분 목록에서. 설정에 "기본 일정 길이(30분·1시간·2시간)" — 기본 1시간.
### 4-2. 업무 마감일을 캘린더에 표시 (Google Tasks 방식)
- Google: 마감 있는 할 일은 캘린더 **종일(All day) 칸**에 표시, 왼쪽 "내 캘린더"의 Tasks 체크로 켜고 끔.
- 워크인: 본사 사람 업무 마감을 **종일 칸에 "⏰ 마감: 업무명 (담당자)"** 로 기본 표시(완료 시 취소선/숨김), 기한 지남은 빨간색. 왼쪽/위 칩 "업무 마감" 켜고 끄기, 사람 필터와 연동(내 일정만이면 내 업무 마감만). 누르면 업무 상세. 마감 시각이 있으면 그 시각에 표시.
### 4-3. 홈에 새 업무 바로 표시
- 업무를 등록하면 홈 **"오늘 할 일"**(마감 오늘·기한 지남·오늘 시작)과 **"이번 주"**(이번 주 마감 업무 + 일정)에 즉시 보이게. 마감 없는 새 업무는 "오늘 할 일" 아래 "새로 받은 업무(48시간)"로. 홈 목록도 등록 즉시 갱신(broadcastRefresh 구독).
### 4-4. 아이폰 좌우 스크롤 (가로 넘침)
- 직원 iPhone 에서 화면이 옆으로 조금 밀려야 다 보임. 390·375·360px 에서 업무(전체·사람 묶음, 행 칩·순서 버튼·지시자 표시)·홈·캘린더·상세 전부 `scrollWidth <= innerWidth` 검사(E2E 에 추가). `html,body{overflow-x:hidden}` 로 덮지 말고 넘치는 요소를 줄바꿈/축약.
### 4-5. 업무 순서: 꾹 눌러 위아래로
- 지금 휴대폰은 위/아래 버튼 메뉴. 요청: 행을 **꾹 누르면(0.4초) 들어 올려져 손가락으로 위아래 끌어 순서 변경**(진동 피드백 가능 시), 놓으면 저장. 버튼 메뉴는 보조로 유지.
### 4-6. ⚠ "저장 후 업무가 갑자기 사라짐" — 원인 유력: 밀기(swipe) 오작동
- `TaskViews.tsx` ListRow: 행을 **옆으로 80px 밀면 완료(오른쪽)/보류(왼쪽)** → 완료는 목록에서 숨김. 아이폰에서 화면이 옆으로 넘쳐(4-4) **직원이 옆으로 밀어 보려다 업무가 완료/보류 처리되어 사라진 것**으로 보임. 되돌리기 안내가 짧게 떠서 놓치기 쉬움.
- 요청: ① 밀기 기준을 행 너비 45% 이상 + 손을 뗄 때만, 세로 스크롤 중엔 무시, ② **보류 밀기 제거**(메뉴로만), ③ 완료 후 6초 "되돌리기" + 목록에 "방금 완료한 업무 n건 보기" 줄, ④ 설정에서 "밀어서 완료" 끄기(기본 켬은 유지 or 끔 — 클라우드 판단, 대표 불편 신고 기준이면 끔 권장), ⑤ 운영 DB 에서 오늘 status 가 done/on_hold 로 바뀐 업무와 변경자·시각(activity) 확인해 원인 확정 후 기록.
- E2E: 모바일 크기 가로 30px 끌기에는 상태 안 바뀜, 세로 스크롤 중 상태 안 바뀜.
