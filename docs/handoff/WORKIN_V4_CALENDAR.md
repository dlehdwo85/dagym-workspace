# 워크인 캘린더 4차 — Google Calendar 방식 선택·등록, 서로의 일정 보기 (대표 지시 2026-10-13 17:20)

> 대표: "일정을 누르는 부분이 구글캘린더처럼 캘린더에서 선택이 아니다 — 디벨롭. 다른 직원들 일정도 보이게, 필터로 내 것만 볼 수 있게. 직원 각 계정에서도 마찬가지. 앱 업데이트 없이 바로 적용."
> 구현: 클라우드, 바로 main. **웹 코드만으로**(앱 새 빌드 불필요 — 앱은 운영 주소를 불러옴). 대표 휴대폰 = 삼성 Android 앱.

## 1. 캘린더에서 바로 선택해 등록 (Google Calendar 동작)
- **휴대폰**: 빈 칸을 **한 번 탭**하면 그 시각 1시간짜리 임시 블록(미리보기)이 생기고 아래에서 빠른 등록 시트(제목·시간·저장)가 올라옴. 지금은 길게 누르기(longPressDelay 350)만 되어 "눌러도 안 됨". `dateClick` 로 처리, 블록 위아래 손잡이로 길이 조절, 월 보기 날짜 탭 → 그날 종일/시간 등록.
- **PC**: 지금처럼 끌어서 범위 선택 + 클릭 한 번 = 30분/1시간 블록.
- **등록 창의 날짜·시간 입력**: 브라우저 기본 입력 대신 Google 처럼 **날짜 = 작은 달력 팝업**, **시간 = 15분 단위 목록**(종료 시간 옆에 "(1시간)" 길이 표시), 종일 체크, 반복 선택.
- "+ 만들기"로 열어도 현재 보고 있는 날짜·가까운 다음 정각이 기본값.

## 2. 다른 직원 일정 보기 + 내 일정만 필터 (모든 본사 계정 동일)
- 본사 사람 일정은 **서로 기본 공개(본사 안에서만)**. 다른 조직 404 원칙 유지.
- 캘린더 왼쪽(휴대폰은 위 칩): **전체 · 내 일정 · 사람별(김민수·김소담·이동재 색 구분)**. 사람 칩 = 필터(누르면 그 사람만, 여러 명 선택 가능), 선택은 사용자별로 기억. 업무 화면 사람 칩과 같은 동작.
- 일정 블록에 주인 표시(색 + 이름 머리글자), 참석자 일정은 함께 표시.
- 일정마다 "비공개" 선택 시 다른 사람에게는 제목 없이 "바쁨"으로만.
- 다른 사람 일정은 보기만(수정은 주인·참석자·관리자), 클릭 시 상세 미리보기.

## 3. 완료 기준
- 삼성 휴대폰 앱에서 빈 칸 탭 → 빠른 등록 → 저장 → 다른 계정 캘린더에 보임
- "내 일정" 필터로 내 것만, 사람 칩으로 특정 직원만
- E2E: 모바일 크기 빈 칸 탭 등록, 다른 계정 일정 표시·비공개 "바쁨", 필터 유지
