# 워크인 11차 — 진행 상태 표시·마감 선택창 위치·칩 가독성·음성 등록 가이드 (대표 캡처 2026-10-14)

캡처: `local-screens/56-app-tasks-list.jpg`(업무 목록), `57-app-inline-due-popover.jpg`(한 줄 추가 중 마감 선택). 웹 코드만, 한 커밋.

## 1. 목록에 진행 상태 표시
- 지금 행에 상태가 안 보임(동그라미·마감·담당자·순서 버튼만). → 제목 아래 작은 줄(지금 "본사" 자리)에 **상태 칩**: `진행 전`(회색) · `진행 중`(파랑) · `검토 요청`(보라) · `보류`(주황) · `완료`(초록). 칩을 누르면 바로 상태 변경 메뉴(지시자 알림 15번과 연결).
- 묶기 선택에 "상태별" 추가(진행 전 → 진행 중 → 검토 → 보류). 필터에 상태 칩.
- 용어 통일: 내부 `todo` = "진행 전"(지금 "할 일" 표시를 바꿈).

## 2. 완료 업무 관리 — 현재 상태 정리·마무리
- 이미 반영(4328984): 방금 완료한 건 제자리 취소선, 묶음 끝 "오늘 완료 n건" 접힘 줄, 상단 칩 "완료" = 완료 업무 월별 묶음, 엑셀 월별 시트.
- 남은 정리: 목록 위 **"완료된 업무도 보기" 체크박스 제거**(완료 칩과 중복·혼란). 상단 칩 줄에서 "완료" 칩이 가로 스크롤 끝에 숨어 안 보임 → 칩 줄 끝에 고정 또는 "⋯ 보기" 시트 맨 위 "완료한 업무(월별)" 항목 추가. 완료 보기 머리에 "이번 달 n건 · 지난달 n건" 요약.

## 3. 한 줄 추가 중 마감(날짜·시각) 선택창이 위로 튀어 상태바까지 덮음 / 아래로 가서 키보드에 가림
- 휴대폰(<640px)에서는 **아래에서 올라오는 시트**로: 빠른 선택(오늘·내일·이번 주 금·다음 주 월) + 달력 + **시각 15분 목록**(스크롤 휠 대신 큰 버튼 격자: 09:00 … 18:00 + "직접"), 키보드는 시트 열릴 때 자동으로 내림, 시트 아래 "완료" 버튼. 시트가 키보드·하단 탭·상태바와 겹치지 않게(안전 영역).
- 담당자·지시자·반복·알림 선택도 같은 시트 방식.

## 4. 반복·알림·음성 아이콘 가독성
- 지금: 회색 아이콘만(🔁 🔔 🎤) — 무엇인지·설정됐는지 알 수 없음. → **글자 있는 칩**: "반복 안 함" / "매주 화" , "알림 기본(1시간 전)" / "10분 전", 설정된 칩은 색 채움. 칩 줄이 길면 2줄로 감김(가로 스크롤 금지).
- 음성은 칩이 아니라 **입력칸 오른쪽 큰 마이크 버튼**(44px, 색 있음) + 등록 시트 맨 위 "🎤 말로 등록" 버튼.

## 5. 음성으로 바로 업무 만들기 + 말하기 가이드
- 업무 등록 시트·하단 + 메뉴에 **"🎤 말로 등록"** → 바로 녹음 화면(전체 시트).
- 녹음 시작 화면 안내(큰 글씨): "**업무 내용**과 **마감(언제까지)** 을 말씀해 주세요. 담당자·우선순위는 선택" + 예시 3개(“내일 오후 3시까지 견적서 보내기”, “금요일까지 김민수 두정점 원판 수량 파악, 중요”, “매주 월요일 오전 10시 주간 회의 자료 준비”).
- 말하는 동안 실시간 글자, 끝나면 **인식 결과 카드**: 업무명·마감(날짜·시각)·담당자·지시자·우선순위·반복 — **빠진 필수 항목(업무명·마감)은 빨간 "말씀하지 않으셨어요 — 눌러서 선택"**. 카드에서 바로 고치고 저장.
- 마이크 권한 거부/WebView 미지원 시: 키보드 음성 입력 안내 + 같은 인식 카드(텍스트로).
- E2E: 인식 카드(텍스트 입력으로 대체 시험), 필수 항목 누락 표시.
