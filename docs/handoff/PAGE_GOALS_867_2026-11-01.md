## 2. 페이지 하나에 묶을 것
- 워크인 브랜드 게시물: 주제 풀을 페이지별로 나눠 주마다 돌림(업무관리 → 마케팅 자동화 → 입찰 수집 → 전자결재·협업). 게시물 끝 링크는 그 페이지 + utm(채널·게시물).
- 네이버 검색광고: 광고그룹 = 페이지, 최종 주소 = 그 페이지. 메타 광고는 일시정지 초안까지만(대표 승인 뒤 집행).
- 측정: 페이지별 방문 → 체험 가입 → 영업·마케팅 선택 수를 주간 보고에 한 줄씩.
