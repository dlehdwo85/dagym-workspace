# WORKIN V32 — 실사용 결제 흐름 시험 · 정산 · 가입 화면·연동 안내 · 알림 읽음 (2026-10-16 대표 지시)

## 0. 알림 읽음 버그 (즉시)
대표: "알림을 확인했는데도 확인했다고 표시가 안 되고, 읽고 나서 딜레이도 생긴다."
- 오른쪽 위 알림(종 아이콘) 목록에서 항목을 누르면 **즉시 읽음 처리(낙관적 갱신)** → 숫자 배지 바로 감소, 서버 실패 시에만 되돌림.
- **읽은 알림은 종 아이콘 목록에서 사라짐**(기본 "안 읽음"만, [읽은 알림 보기] 토글·/notifications 전체 화면에는 남김). [모두 읽음] 버튼.
- 해당 업무·대화 화면을 열면 그 대상 알림도 자동 읽음. 앱 푸시를 눌러 들어온 경우도 동일.
- 지연 원인 점검: 읽음 API 응답·목록 재조회 순서, 폴링 간격, 배지 캐시. 지금 대표 화면 배지 46~47 이 줄지 않음.

## 1. 실제 사용자 결제 흐름 (구현·시험)
- 흐름: 회사 관리자 → 사용량·요금제 → 요금제/인원 선택 → 결제 수단(카드·계좌이체·가상계좌) → NICEPAY 결제창 → 승인 → 요금제 즉시 반영·영수증 메일·결제 내역 → (카드 등록 시) 다음 달 자동 결제(빌링).
- **안전한 시험 경로**: /platform 에 [결제 시험 회사 만들기](로그인 계정 없이 회사만, is_test 표시, 퍼널·매출 집계 제외) + [이 회사로 결제창 열기](NICEPAY_MODE=test 강제·시험 상점). 시험 카드 입력은 대표가 직접(로컬은 카드 정보 입력 금지), 시험 결제는 당일 자동 취소.
- 결제 완료 후 확인 항목 자동 체크 화면: 요금제 변경됨 / 결제 내역 1건 / 영수증 메일 발송 / 정산 장부 반영 / 취소 시 원복.
- 실결제(live) 소액 시험은 대표 승인 후 1회, 바로 취소.

## 2. 정산 시스템 (슈퍼 관리자 /platform → "정산")
- **매출 장부**: 결제 건별(회사·요금제·인원·결제 수단·승인/취소·금액·부가세 분리·PG 수수료 추정·정산 예정일[NICEPAY 정산주기: 카드·계좌이체 일일+5일]·정산 상태 대기/완료).
- **일·월 집계**: 총결제·취소·순매출·VAT·PG 수수료·입금 예정액, 결제 수단별·요금제별, 전월 대비. 엑셀 내보내기(세무 자료).
- **입금 대사**: NICEPAY 정산 내역(가맹점 관리자 엑셀 또는 API)을 올리면 장부와 자동 맞춤 → 차이 건 표시.
- **미수·환불**: 미납(B2 던닝) 회사 목록·금액, 환불·부분 취소 처리(사유 필수, 2단계 확인, 감사 기록).
- **세금계산서**: 법인 고객 요청 건 목록(발행 여부 체크 — 발행은 외부 홈택스, 나중에 연동).
- 회사 상세에 해당 회사 결제·정산 이력 탭.

## 3. 가입 화면 UI/UX 개선 + 연동 빠르게
- 가입 단계를 한 화면씩, 진행 표시(1/4): ① 계정(카카오·네이버·이메일, 소셜 이메일 자동 채움) ② 회사(이름·규모·업종 — 규모는 버튼 선택) ③ 연락 채널 연결 ④ 동료 초대(링크 복사·카카오톡 초대·QR). 각 단계 [나중에] 가능, 모바일 우선 큰 버튼.
- **③ 연락 채널 연결 (가입 정보로 최대한 자동)**
  - 메일: "가입한 이메일 ○○○ 를 회사 기본 발송·회신 주소로 쓸까요?" [예, 이 주소로](워크인 발송 + Reply-To = 이 주소, 설정 없이 바로) / [다른 주소] / [회사 메일 계정 연결(고급)]. 최초 가입자 = 회사 대표(관리자) 기준 — 플랫폼 슈퍼 관리자 아님.
  - 문자: 가입 때 휴대폰 번호(선택) → 문자 서명·발신 표시에 사용, "문자는 내 휴대폰 문자앱으로 넘겨 보냅니다(설정 불필요)" 안내.
  - 카카오톡: 카카오로 가입했으면 "카카오톡 공유 준비됨", 아니면 "카카오톡으로 보내기는 바로 가능(앱에서 친구 선택)" 안내.
- **연동 안 된 기능 안내(전역)**: 홈 상단 "연결하면 좋아요" 카드(메일·문자·카카오톡·초대 각 상태 ✓/연결하기), 메일 시안·문자 시안을 열었는데 연동이 없으면 시안 상단에 "아직 ○○ 연결 전 — [지금 연결하기]" 줄, 설정 > 연동 한 화면에 모아 보기.
- 측정: 가입 단계별 이탈률을 가입 퍼널에 추가.

## 4. 마감일 연장 + 마감일 칸 터치 개선 (2026-10-16 대표, V32 0~3 다음)
- 마감일 칸(local-screens/84): 지금은 빨간 작은 칩("10월 15일 · 1일 지남")만 눌러야 해서 누를 수 있는지 모르겠고 아래 "시각 없음" 칸보다 작아 터치가 예민함 → 날짜·시각을 **같은 크기의 버튼 두 개**(최소 높이 44px, 테두리·달력 아이콘·▾ 표시)로, 지연 상태는 버튼 옆/아래 작은 배지로 분리.
- **[마감 연장]** 버튼(지연·임박 업무에서 강조): +1일 / +3일 / +1주 / 날짜 고르기 + **연장 사유(필수, 한 줄)** → 활동 기록에 "마감 연장 10/15 → 10/18 · 사유 · 누가" 남김, 지시자에게 알림 1건(지시자가 본인이면 생략). 업무에 "연장 n회" 표시, 목록 필터 "연장된 업무". 담당자는 연장 요청, 지시자는 바로 연장(권한은 기존 상태 권한과 같은 기준).
- 주간 보고·월 마감 보고에 연장 횟수 집계.

## 5. 처음 사용 안내(코치마크 투어) (2026-10-16 대표)
대표: "처음 앱 화면을 켜면 페이지별·기능별 버튼을 가리키며 안내 문구가 나오는 것. 딱 처음 들어갔을 때만."
- 사람(user)별 1회: 첫 로그인 후 홈에서 자동 시작, 화면별 투어는 그 화면에 처음 들어갔을 때 1회(업무·캘린더·메시지·자료실·AI 비서·업무 상세). 본 기록은 서버(user_onboarding: tour_id, seen_at) — 기기가 바뀌어도 다시 안 뜸.
- 형태: 대상 버튼 주변만 밝게(나머지 어둡게) + 말풍선(제목 한 줄·설명 1~2줄·[다음] [건너뛰기]·n/총수). 휴대폰은 하단 탭·[+] 버튼 중심, PC 는 사이드바·만들기·검색(Ctrl K).
- 홈 투어 예(5단계): [+ 만들기] 업무·일정 등록 → 음성 등록 → 업무 메뉴(목록·보드·캘린더) → AI 비서 → 알림 종. 업무 상세 투어: 진행 단계 바 → 마감 연장 → 이 업무의 AI 비서(메일·문자·카카오톡) → 첨부.
- 역할별: 회사 관리자에게만 "사용자 초대·연동 설정" 단계 추가.
- 다시 보기: 도움말(?) 메뉴 [사용 안내 다시 보기], 설정에서 초기화.
- 라이브러리 없이 자체 컴포넌트 또는 경량 라이브러리, 접근성(키보드·스크린리더), 앱 WebView·safe-area 고려. 심사용 체험 계정은 투어가 처음 한 번 뜨도록 유지(심사관 이해 도움).

## 6. 회사 기본 메일 설정 권한 (2026-10-16 대표)
대표: "대표자 계정 메일 설정 이후 나머지 직원들이 가입할 때도 묻는가? 대표자(권한 있는) 메일로만 기능이 작동하도록."
- "가입 이메일을 회사 기본 발송·회신 주소로 쓸까요?" 질문은 **회사를 만든 사람(회사 관리자)에게만** 1회. 초대받아 합류한 직원에게는 묻지 않음.
- 회사 기본 발송 방식·보내는 주소·회사 메일 계정 연결은 **회사 관리자(대표·관리자 권한)만 변경**(서버 권한 검사, 직원 화면에는 읽기 전용 표시 "회사 기본: ○○ — 관리자만 변경").
- 직원이 보내는 메일: 회사 기본 방식으로 발송, 보내는 이름 "이름 직급 (회사)", Reply-To = 그 직원의 업무 이메일(가입 이메일 자동) — 직원은 자기 회신 주소만 프로필에서 바꿀 수 있음(관리자가 막을 수도 있게 회사 설정 "직원 회신 주소 변경 허용" on/off).
