# 워크인(WorkIn) 홍보 랜딩 레퍼런스 조사

- 조사일: 2026-10-17 (로컬 세션)
- 확인 방법: 각 사이트 실제 페이지를 WebFetch·Playwright(운영 프로필 Chrome)로 열어 본문 텍스트 확인. firecrawl 은 무료 한도 초과로 사용하지 못함.
- 범위: 데스크톱 첫 페이지 본문·가격 페이지 일부. 모바일 폭 화면은 직접 캡처하지 않았고, "모바일" 칸은 앱 다운로드 노출 위치와 반응형 구성 위주로 적음.
- 인용 문구는 구조 파악용 짧은 발췌. 그대로 베껴 쓰지 말 것.

## 2. 공통 패턴과 워크인 적용안

### 2-1. 관찰된 공통 패턴

| 패턴 | 본 곳 | 워크인 적용 |
|---|---|---|
| 헤드라인은 한 줄 주장 + 한 줄 설명 | 거의 전부 | 쉬운 한국어 한 줄 + 대상·효과 한 줄 |

| CTA 밑 안심 문구 | monday·ClickUp | "5명까지 무료 · 카드 등록 없이"(실제 조건과 일치할 때만) |
| 히어로 직후 로고 띠 | 대부분 | 초기엔 고객 로고 대신 **업종 칩**(시설 운영·학원·매장·사무실) 사용, 로고는 고객 동의 받은 뒤 |

| 메인엔 가격 없음, 별도 페이지 | 12곳 중 대부분 | 워크인은 **가격이 강점**이라 메인에 요약 카드 + 상세 페이지 |
