# 워크인 업무 화면 3차 — 서로 배정 · 지시자 · 마감/우선순위/순서 (대표 지시 2026-10-13)

> 대표(운영 화면 캡처): "전체에서 김민수 작업 추가하는 게 안 보인다. 다른 아이디여도 서로에게 업무를 할당할 수 있어야 함. 다만 누가 업무를 부여했는지 선택할 수 있도록. Asana 보면 마감일자·우선순위·업무 순서를 정할 수 있다 — 디벨롭."
> 구현: 클라우드, 바로 main. 로컬은 운영·로컬에서 확인.

## 0. 버그 — 업무 0건인 사람은 담당자 묶음이 안 생김
- 위치: `src/components/TaskViews.tsx` GroupedTasks, `group === 'assignee'` — `ensure(user.id)` + 업무가 있는 담당자만 묶음 생성.
- 결과: 운영에서 칩에는 김민수가 보이는데 목록엔 "이동재" 묶음만 있고 "김민수님에게 업무 추가" 줄이 없음.
- 수정: 상단 사람 칩과 같은 목록(본사 소속 활성 사용자 = `people`)을 **업무가 0건이어도 모두 묶음으로** 만든다(빈 묶음은 "업무 없음" + 추가 줄). 순서: 나 → 나머지 이름순 → 담당자 없음.

## 1. 서로에게 배정
- 본사 사람끼리 누구나 서로에게 업무를 배정(담당자 선택 목록 = 본사 활성 사용자 전체). 서버 `validateRefs` 는 활성 사용자만 검사하므로 유지하되, 배정받은 사람이 그 업무를 볼 수 있는지(담당자 열람 허용) 시험 추가.
- 본사 3명이 서로 전체 업무를 보려면 권한이 **대표 또는 본사 관리자**여야 함 → 사용자 관리 화면에서 "직원" 권한으로 본사 소속이면 "본사 사람끼리 전체 열람" 안내(또는 본사 조직 소속 직원도 본사 업무 전체 열람으로 규칙 조정 — 클라우드 판단, 다른 조직 404 원칙은 유지).

## 2. "지시자(업무를 부여한 사람)" 칸
- 새 필드 `requested_by`(추가형 마이그레이션, 기본값 = 만든 사람). 업무 등록 창·인라인 추가·상세 패널에서 **선택 가능**(본사 사람 목록).
- 목록 행에 "○○ → ○○"(지시자 → 담당자) 작은 표시, 필터·묶기에 "지시자별" 추가, "내가 지시한 업무" 칩(Asana 홈의 "내가 배정한 작업").
- 알림: 담당자가 완료·검토 요청하면 지시자에게 알림. 변경 이력에 지시자 변경 기록.

## 3. 마감일·우선순위·순서 (Asana 목록 수준)
- 목록 행에서 바로 편집: **마감일 칩**(오늘·내일·이번 주 금·다음 주 월·날짜), **우선순위 칩**(긴급·높음·보통·낮음 색 표시), 담당자 칩, 지시자 칩.
- **직접 순서 정하기**: 행 왼쪽 손잡이로 끌어 묶음 안 순서 변경(기존 `sort_order` 사용, 저장 즉시 반영, 다른 사람 화면에도 같은 순서). 묶음 사이로 끌면 담당자/마감 묶음 값 변경.
- 정렬 선택: **직접 순서(기본) · 마감일순 · 우선순위순 · 최근 생성순**. 선택은 사용자별로 기억.
- 열 머리(PC): 업무 이름 | 담당자 | 지시자 | 마감일 | 우선순위 | 상태 — 열 머리 클릭 정렬.

## 4. 완료 기준
- 운영에서 "전체" 보기에 본사 3명 묶음이 모두 보이고 각 묶음 끝 "○○님에게 업무 추가"로 바로 배정
- 지시자 선택·표시·"내가 지시한 업무" 칩 동작, 완료 시 지시자 알림
- 행에서 마감·우선순위 변경, 끌어서 순서 변경 후 새로고침해도 유지
- API·E2E 시험 추가(0건 담당자 묶음, 지시자 저장·알림, 순서 저장)
