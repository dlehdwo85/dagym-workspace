# 후이즈 판매 '네이버웍스' 분석 (대표 요청 2026-10-20, 출처 m.whois.co.kr/nworks.php · whois 공지 · 다우오피스 비교 글 2026-09)

## 1. 정체
- **네이버웍스(NAVER WORKS)** = 네이버(웍스모바일)가 만든 기업용 메신저·메일·드라이브 묶음. **후이즈(Whois)** 는 도메인·호스팅 회사로, 네이버웍스를 **대신 팔아 주는 리셀러**(할인가·무료 셋업·1:1 상담·스타벅스 쿠폰 사은품). 후이즈 자체 그룹웨어 '후이즈웍스'는 별개 상품.
- 핵심 성격: **메신저 + 메일 중심의 협업 도구**. 업무 관리는 '할 일·게시판·캘린더' 수준.

## 2. 요금 (VAT 별도, 1인 월, 정가 → 후이즈 연간 할인가)
| 묶음 | 요금제 | 가격 | 포함 |
|---|---|---|---|
| 메신저·메일 | Lite | 4,000 → 3,000원 | 메신저·캘린더·게시판·할 일, 공용 10GB/인 (메일 없음) |
| | Standard | 8,500 → 7,000원 | + 회사 메일 100GB/인, 공용 100GB/인, 화상회의 200명 |
| | Standard Plus | 13,000 → 11,000원 | + 메일 무제한, 1TB/인, AI(메일 요약·초안·메신저 요약) |
| 드라이브(별매) | Lite/Std/Plus | 3,000 / 5,000 / 6,000원 | 100GB~1TB/인, 상위는 문서 공동편집·OCR |
| 경영지원(별매) | 근태 | 3,000 → 2,000원 | IP·Wi-Fi·GPS 출퇴근, 52시간, 연차 |
| | 결재 | 4,000 → 3,000원 | 표준·커스텀 서식, 조건부 자동 승인, 증명서 발급 |
| AI(별매) | 클로바노트 | 월 18,000원~(팀 86,500·조직 423,000) | 회의 녹음·요약(분 단위 한도) |
| | AI 스튜디오 | 9,000원/인 | 회사 자료 학습 전용 AI, 140만 토큰/인 |
- 2024-06 요금 인상(Basic 6,000 → Standard 7,000, Premium 10,000 → 11,000). 무료 플랜은 네이버 직접 가입 시 30명(공지 참고), 후이즈 페이지엔 무료 체험 없음(1년 계약 시 2개월 무료).
- **실제 '워크인 수준'으로 쓰려면**: Standard 7,000 + 결재 3,000 + 근태 2,000 = **1인 12,000원** + 드라이브·AI 별도.

| 항목 | 네이버웍스 | 워크인 | 메모 |

| 캘린더 | ○ 공유 캘린더 | ◎ 업무 마감 + 일정 한 화면, 색, 미팅 | 강점 |

| 문서 공동편집 | ○ 드라이브 상위 요금제 | ○ 자료실 워크인 문서(1차) | 비슷 |
| 영업·마케팅 공간 | ✕ | ◎ 리드·입찰·광고 운영·콘텐츠 승인 | **우리만 있음** |

## 4. 시사점 (요금·마케팅)
1. 시장 가격선: 국내 그룹웨어 1인 월 3,000~7,000원(메신저형 2,400~4,000, 메일+결재형 4,000~7,000). 결재·근태를 **별매**하는 곳이 많다 → 워크인은 "결재·근태·공지·AI 비서가 기본 포함"을 가격 대비 가치로 내세울 수 있음.
2. V46 잠정안(업무 2,900/5,500/9,900)은 네이버웍스 Standard(7,000)+결재(3,000)+근태(2,000)=12,000 대비 절반 이하 → 가격은 적정, 메신저·화상 부재를 '업무 관리에 집중'으로 설명.
3. 마케팅 문구 후보(경쟁사 이름 없이): "메신저 요금에 결재·근태를 또 내고 계신가요?", "회사 자료를 학습한 AI 가 아니라, 내 업무를 대신 처리하는 AI".
4. 약점 보완 순서: 메시지방 알림·검색 고도화(화상회의는 외부 링크로 충분), 회사 메일함은 범위 밖 유지.
