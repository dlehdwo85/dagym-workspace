# WORKIN V25 — 매출 자료 올리면 자동 분석 (2026-10-15 대표 지시)

## 지시
"자료실에 매출 자료가 올라갈 때마다 관리 > 매출에 매출 분석·동향·향후 대안을 분석해서 관리자들이 확인할 수 있게."

## 지금 있는 것 (src/lib/revenue.ts)
- 매출 화면 [AI 분석]: 버튼을 눌러야 실행, 모델 deep(Opus), 결과는 요약·이상치·현장 비교만(동향·전망·대안 없음).
- aiExtract: 올린 파일에서 매출 숫자 뽑기(revenue_extract).
- 자료실 "매출 근거" 폴더(기밀 고정).
→ 업로드와 분석이 연결돼 있지 않고, 동향·대안이 없다.

## 흐름
1. **감지**: 자료실에 파일이 올라오면(매출 근거 폴더, 또는 자동 정리 결과가 매출 자료 — 엑셀/CSV/PDF/사진, 제목·내용에 매출·정산·월별 실적 등) → 매출 자료로 표시.
2. **숫자 뽑기**(기존 aiExtract, Haiku): 현장·월·매출·지출·회원 수 → **"확인 대기"** 상태로 저장(바로 확정하지 않음). 매출 화면 위에 "새 매출 자료 1건 — 숫자 확인" 카드: 뽑은 표 + 기존 값과 다른 칸 강조 → 관리자 [확정] / 고치기.
3. **분석**(확정되면 자동, 또는 확인 대기 상태로도 "잠정 분석" 표시):
   - 모델 Sonnet(effort medium) — Opus 는 월 마감 종합 보고에만(선택). 입력은 집계 숫자만(개인정보·메모 없음, 기존 aiInput 확장: 최근 24개월).
   - 결과 항목(JSON): 요약 / **동향**(전월·전년 동월·최근 3개월 이동평균, 현장별 성장·하락 순위) / 이상치 / 현장 비교 / **향후 전망**(다음 1~3개월, 근거 숫자와 가정을 함께, "추정" 표시, 범위로) / **대안·실행 제안**(현장별 2~3개, 숫자 근거 연결, 투자 조언·사람 평가 금지) / 확인 필요(빠진 달·이상한 값).
   - 숫자 계산(증감률·이동평균·추세)은 서버 코드가 먼저 계산해 넣고, AI 는 해석·문장만 → 숫자 틀릴 위험·토큰 줄임.
4. **보는 곳**: 관리 > 매출 상단 "AI 분석 보고서" — 최신 보고서 카드(요약·동향 그래프·전망·대안), 보고서 이력(자료별·월별), 근거 파일 링크. PDF/엑셀 내려받기(선택).
5. **알림**: 매출 권한 관리자(대표·본부장)에게 "OO 매출 자료 분석 완료" 1건. 다른 직원에게는 보이지 않음(기밀, 404 원칙).

## 비용·안전
- 같은 달 자료가 여러 번 올라오면 10분 모아 1번만 분석(중복 방지). 분석 1회 예상 50~150원(Sonnet) — V23 4장 정가 기록, 올린 사람이 아니라 "회사 시스템 작업"으로 기록하고 회사 한도에 합산.
- 숫자 확정 전 자동 반영 금지(잘못 읽은 숫자가 실적이 되지 않게).
- 다른 조직 데이터 섞이지 않게 tenant 조건 확인(지금 aiInput 이 tenant = 'default' 고정 → 조직별로 고칠 것, 상업화 대비).

## 시험
- 매출 근거에 월별 엑셀 업로드 → 확인 대기 카드 → 확정 → 보고서(동향·전망·대안) 생성 → 관리자 알림, 직원 계정은 404.
- 같은 달 2번 업로드 → 분석 1번.
- 보고서의 숫자가 서버 계산값과 일치.
