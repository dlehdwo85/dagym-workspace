# WORKIN V23 — AI 비용 관리·상업화 구조 (2026-10-15 대표 지시)

## 1. 지금 바로: Anthropic 크레딧 소진 안내
- Anthropic API 가 크레딧 부족(잔액 부족·결제 필요 오류)을 돌려주면 AI 기능 화면(AI 비서·자료실 자동 정리·매출 추출 등)에 "이번 달 AI 크레딧이 모두 사용되었습니다. 다음 충전일 이후 다시 사용할 수 있습니다." 안내. 업무·일정 등 핵심 기능은 그대로.
- 대표(owner)·플랫폼 운영자에게 알림 1회/일 + 운영 화면(/platform)에 빨간 표시. 원인 문자열(오류 원문)은 로그에만.
- 오류 종류 구분: 크레딧 부족 / 요청 한도(429, 잠시 후 재시도) / 일시 장애(5xx) — 사용자 문구 각각.
- 자동 재시도로 크레딧 부족 요청을 반복 호출하지 않기(1시간 차단 후 1회 확인).
- 사용량 화면(/admin/usage): "Anthropic 비용(실제)" 대비 워크인 자체 집계 표시 — 현재 자체 집계가 콘솔보다 약간 높음(10월: 자체 $0.75 vs 콘솔 workin 키 $0.46). 단가표·캐시 계산 점검.

## 2. 상업화 때 AI 비용 구조
### 2.1 Anthropic 계정
- 지금: 대표 개인 Max 구독에 연결된 콘솔 조직의 월 크레딧(10/24 부터 Max 5x → 월 US$100, 이월 없음, 소진 시 API 정지, 구독 요금으로 추가 청구 없음).
- 상업화: **판매 법인(하이링크) 명의의 별도 콘솔 조직**으로 분리 — 회사 카드로 선불 크레딧 + 자동 충전 + 월 지출 한도, 운영/시험 키 분리(워크스페이스), 사용량 알림. 사용량이 커지면 Anthropic 영업 통한 청구서(후불)·요금 한도 상향. (결제·자동 충전 설정은 대표 승인 사항)
- 큰 고객사용 선택지: 고객사가 자기 Anthropic 키를 넣는 방식(BYOK) — 비용은 고객 부담, 워크인은 기능 요금만.

### 2.2 원가 (10/14~15 실측 기준, Sonnet 5.5)
- AI 비서 대화 1건 평균 약 70원(도구·문맥 포함), 견적서 같은 문서 대화 5턴 약 320원, 자료실 자동 정리 1건 약 0.5원(Haiku).
- 요금제(V17): 팀 1인 3,900원·AI 월 50회 → 50회를 모두 대화(70원)로 쓰면 3,500원 = 요금 대부분이 AI 원가. **그대로는 적자 위험.**

### 2.3 개선안
1. **"AI 회수" → "AI 크레딧"으로 가중치**: 가벼운 질문·분류 1, 업무·일정 만들기 1~2, 문서·엑셀·디자인 생성 10, 디자인 반복 수정 3, 웹 검색 +1. 요금제 포함량은 크레딧으로 표시(예: 팀 1인 월 50크레딧). 추가 팩도 크레딧.
2. **원가 줄이기(목표 대화 1건 25원 이하)**: 프롬프트 캐싱(시스템·도구 고정), 단순 질문·분류는 Haiku 로 먼저 처리하고 필요할 때만 Sonnet, 도구 결과 요약해서 넣기, 대화가 길면 요약, effort 낮게.
3. **조직별 원가 안전장치**: 조직 월 AI 원가가 그 조직 월 요금의 30%를 넘으면 문서 생성부터 제한·안내, 운영 화면에서 조직별 원가율 표시.
4. 체험 14일: AI 300크레딧 → 문서 생성 비중이 크면 원가가 커지므로 체험 중 문서 생성 횟수 상한(예: 10건).
5. 플랫폼 운영 화면: 조직별 AI 원가·매출·원가율, Anthropic 실제 청구와 대조.

## 시험
- 모의로 크레딧 부족 오류 → 안내 문구, 알림 1회, 반복 호출 없음, 업무 기능 정상.
- 크레딧 가중치: 문서 생성 1건 = 10 차감, 팩 구매 반영, 한도 도달 시 안내.

## 3. 안전장치에 걸려도 문서 생성을 계속 쓰고 싶은 고객 대안 (2026-10-15 대표 지시)
원칙: **막는 장치가 아니라 "고르게 하는" 장치.** 한도에 가까워지면 미리 알리고, 다 써도 바로 이어 쓸 길을 화면에서 고르게 한다. 원가 30% 기준은 내부 기준이고, 고객에게는 "이번 달 문서 생성 n건 포함" 처럼 투명한 숫자로 보여 준다.

1. **양식 재사용은 싸게(사실상 계속 쓰기)**: 한 번 만든 양식에 값만 채우는 문서(V22-A)는 1~2크레딧. 새 디자인(10크레딧)은 처음 한 번만 → 반복 업무(견적서·공문·월 보고)는 한도에 거의 안 걸림. 화면에서 "이 문서를 양식으로 저장하면 다음부터 1크레딧" 안내.
2. **문서 생성 팩(선불, 바로 구매)**: 예) 문서 10건 11,900원 / 50건 49,000원. **가격 원칙: 실측 문서 1건 원가의 2배 이상** — 2026-10-15 실측: 새 견적서(xlsx) 1건 $0.40 ≈ 560원(Sonnet, effort medium, 55초). 원가를 낮추면(양식 재사용·effort low·캐싱) 가격도 내림. 회사 카드(나이스페이 빌링키, V18)로 한 번 눌러 구매, 즉시 반영.
3. **초과 사용 자동 결제(선택, 월 상한)**: 관리자가 "포함량을 넘으면 건당 OOO원으로 계속 사용, 월 최대 OO원까지" 동의 → 끊김 없이 사용, 월말 청구. 상한 도달 시 다시 선택지.
4. **AI 플러스 부가 상품(월정액)**: 예) 회사 월 39,000원 — 새 디자인 문서 월 30건 + 양식 채우기 무제한(공정 사용). 원가 2배 원칙(새 문서 560원 기준). 문서를 많이 만드는 회사용.
5. **상위 요금제 안내**: 비즈니스 요금제의 포함량을 크게(예: 1인 월 150 → 문서 생성 비중 반영).
6. **자기 AI 키 연결(BYOK)**: 큰 고객사는 자기 Anthropic 키를 넣으면 AI 한도 없음(비용 고객 부담, 워크인은 기능 요금만).
7. **직원은 관리자에게 요청**: 직원이 한도에 걸리면 [관리자에게 추가 요청] → 관리자가 팩 구매·초과 사용 승인을 앱에서 바로.

### 화면 흐름
- 80% 도달: 관리자에게 알림 + 사용량 화면 배너.
- 100% 도달 시 문서 생성 버튼 → "이번 달 포함량을 모두 썼습니다" + [양식으로 만들기(1크레딧)] [문서 팩 구매] [초과 사용 켜기] [관리자에게 요청]. 일반 대화·업무 기능은 계속.
- 원가율 30%는 운영자 화면 경보용(가격·포함량 조정 근거), 고객 화면에 직접 노출하지 않음.

## 4. 사용자별 AI 한도 + 남은 한도 표시 + "건별 결제 가정" 원가 (2026-10-15 대표 지시, V23-1 과 함께 먼저)
대표: "우리 3명이 써 보는 동안 파일이든 대화든 한도를 걸고, 지금 남은 한도를 보여줘서 그 안에서 쓰게. Max 크레딧이 있더라도 계정별 요청을 그때그때 결제한다고 가정한 비용이 산출돼야 한다."

### 4.1 원가 = 정가(API 표준 단가) 기준으로 항상 계산
- 모든 AI 호출(대화·문서 엔진·자료실 정리·음성 보정·분류)을 **사용자별·건별로 Anthropic 표준 단가**(입력·출력·캐시 쓰기 1.25배·캐시 읽기·코드 실행 시간·웹 검색 건당)로 계산해 ai_usage 에 원화(고정 환율 설정값, 기본 1,400원)와 함께 기록. Max 월 크레딧으로 실제 청구가 0 이어도 "결제했다면 낸 돈"으로 본다.
- 단가표는 코드 상수 → 관리자 설정(플랫폼)에서 바꿀 수 있게, 모델 추가 시 누락되면 가장 비싼 단가로 계산(과소 계산 금지).
- 콘솔 실제 청구와 대조용으로 월 합계 표시(차이 ±10% 넘으면 운영자 알림).

### 4.2 사용자별 월 한도
- 설정 > 사용자 관리에서 사람마다 **월 AI 한도(원)**. 기본값: 1인 월 10,000원(시범 3명 → 회사 합 30,000원, 회사 월 한도 $30 과 비슷). 대표가 사람별로 바꿈.
- 회사 월 한도(기존 ai_limits)는 그대로 상한으로 유지 — 둘 중 먼저 닿는 쪽에서 멈춤.
- 80%: 본인·대표 알림. 100%: 그 사람의 AI 기능(대화·문서·음성 보정) 멈춤 + "이번 달 AI 한도를 모두 썼습니다 — 대표에게 추가 요청" [추가 요청] 버튼 → 대표가 앱에서 +5,000원 등 바로 승인. 업무·일정 등 핵심 기능은 그대로.
- 문서 작업은 시작 전에 예상 비용(최근 같은 종류 평균)을 보고 남은 한도가 모자라면 시작하지 않고 안내.

### 4.3 남은 한도를 사용자에게 보여주기
- AI 비서 화면·패널 상단: "이번 달 남은 AI 6,420원 / 10,000원" 막대 + 환산 "대화 약 90회 · 문서 약 70건 남음"(최근 평균 단가로 계산).
- 답변·문서 카드마다 "이번 요청 약 72원"을 **모든 사용자에게** 작게 표시(지금은 관리자만).
- 관리 > AI 사용 내역: 사람별 이번 달 사용액·남은 한도·건수(대화/문서/기타), 일별 그래프, 비싼 요청 상위 10건.
- 회사 전체: 이번 달 정가 기준 합계, Max 크레딧으로 실제 청구된 금액, 남은 Anthropic 크레딧(콘솔 값은 수동 입력 또는 운영자가 갱신).

### 4.4 시험
- 사용자 한도 1,000원으로 낮춰 대화 반복 → 80% 알림, 100%에서 차단·추가 요청·승인 후 재개.
- 문서 예상 비용 > 남은 한도 → 시작 안 함.
- 단가 계산: 캐시 읽기·쓰기·코드 실행 포함 건이 콘솔과 ±10% 이내.

### 4.5 한도 기준 (2026-10-15 대표: "Claude 가 기준을 세워 달라 — 쓰는 양이 내는 돈보다 앞서나갈까 걱정")
원칙: **쓰는 돈(정가 원가)이 미리 확보된 돈을 절대 넘지 않게** — 위에서 아래로 겹겹이 막는다.
1. **Anthropic 계정(맨 위 안전판)**: 자동 충전 끔(현재 끔). 크레딧이 떨어지면 API 가 멈출 뿐 추가 청구 없음. 상업화 계정에서 자동 충전을 켜더라도 **콘솔 월 지출 한도**를 반드시 같이 건다.
2. **회사 월 한도 = 확보된 돈의 70%**: 지금 확보된 돈 = Max 월 크레딧(10/24부터 $100) → 회사 한도 **$70(약 98,000원)**, 나머지 30%는 개발·시험·자동 작업(매출 분석·자료 정리) 몫. 현재 설정 $30 → 시범 기간 동안은 $30 유지하고, 사용 패턴 보고 올림.
3. **사람별 월 한도(시범 3명)**: 대표 20,000원 · 본부장 2명 각 10,000원 = 40,000원(약 $29) — 회사 한도 $30 안.
4. **사람별 하루 한도 = 월 한도의 20%**(대표 4,000원·본부장 2,000원) — 오류·반복 호출로 하루에 다 쓰는 사고 방지.
5. **건당 상한**: 문서 작업 예상 500원 초과, 대화 1건 300원 초과 시 "비용이 큰 작업입니다(약 OOO원) — 계속할까요?" 확인.
6. **시스템 작업(매출 자동 분석·자료 정리·음성 보정 분류)**: 회사 월 한도의 15% 상한, 넘으면 다음 날로 미룸.
7. **상업화 고객사**: 고객사 월 AI 예산 = 그 고객이 낸 요금 중 AI 몫(요금표에서 정함, 예: 요금의 30%)까지만 — 넘으면 팩·초과 결제 동의가 있어야 계속(3장). 즉 **받은 돈보다 먼저 쓰는 구조를 만들지 않는다**(선결제·월 상한).
- 기본값은 설정에서 바꿀 수 있게, 바꾼 기록은 감사 로그에.

## 5. 월 예상 비용·무료 운영 가능 업체 수·충전 시점 계산 (2026-10-15 대표 지시)
대표: "1개월 예상 금액, $200 안에서 몇 개 업체를 무료로 운영할 수 있는지, 충전 시점이 왔을 때를 고려해 금액을 산정할 수 있어야 한다."

### 5.1 운영자 화면(플랫폼) "AI 원가 전망" — 시스템이 자동 계산
- **이번 달 예상**: 이번 달 누적(정가) ÷ 지난 날짜 × 달 일수 + 예정 시스템 작업. 회사(조직)별·사람별·기능별.
- **단가 실측**: 최근 30일 기능별 평균(대화 1건, 문서 1건, 자료 정리 1건, 매출 분석 1건) — 화면에 표로.
- **사용자 유형별 월 원가**: 실측 사용량으로 "가벼움/보통/많음" 3구간 평균(원/인/월) 자동 산출.
- **크레딧 소진 예상일**: (확보 크레딧 − 이번 달 누적) ÷ 최근 7일 하루 평균 → "이 속도면 10/29 소진".
- **무료 운영 가능 업체 수**: (확보 크레딧 × 70% − 우리 회사 예상) ÷ 업체 1곳 평균 월 원가(인원수 입력 가능, 기본 10명).
- **충전 권장액**: 다음 달 예상 합계 − 다음 달 확보 크레딧 + 20% 여유 → "다음 달 OOO원 충전 권장", 70%·90% 도달 알림.
