## 1. GPT 연동(Custom GPT Action) 제거 → 내장 방식
- 매출 화면의 **"GPT 연동 (Custom GPT Action)" 카드와 "토큰 만들기" 제거**. `/api/public/revenue`·openapi.json 은 기능 플래그(`FEATURE_GPT_ACTION=1` 일 때만)로 기본 꺼짐, 기존 발급 토큰은 무효 처리(감사 로그).
- 대체 입력 방법(모두 워크인 안에서):
  1. **엑셀·CSV 올리기**(기존 유지, 끌어다 놓기 안내 상자).
  2. **자료로 입력(AI)**: 정산서·매출 보고 엑셀/PDF/사진을 올리면 **내장 AI 비서(Anthropic)** 가 현장·월·항목·금액을 뽑아 **미리보기 표** → 대표가 확인·수정 후 "반영". 원본은 R2 자료실 "매출 근거" 폴더에 저장, 각 숫자에 근거 파일 연결.
  3. **AI에게 요청**: "3분기 매출 분석해서 올려줘" → 매출 데이터 집계·비교·보고서(xlsx/문서) 생성 → 업무/자료실 첨부(V9).
- AI 분석 문구의 "서버에 OpenAI 키" → **공급자 어댑터(Anthropic 기본)** 로 교체, 안내 문구 갱신. 회사별 AI 한도·사용량에 포함.

## 2. 매출 메뉴 권한 — 대표만 등급별 on/off
- 사용자 관리에 **"메뉴 권한"** 탭(대표만 보임): 표 형태 — 행 = 메뉴(매출, 주간 보고 모아보기, 운영 상태, 사용량·요금제 등), 열 = 등급(본사 관리자·부서 책임자·현장 관리자·직원), 칸 = 스위치. 이번 차수 필수는 **매출**(보기 / 입력·수정 두 단계).
- 기본값: 매출 = 대표만 켜짐(본사 관리자 포함 나머지 꺼짐) — 대표가 켜 준 등급만 접근.
- 개인별 예외(특정 직원만 허용/차단)도 같은 화면 "사람별 예외".
- 서버에서 강제(`/api/revenue*` 권한 검사, 꺼진 등급은 403·메뉴 숨김), 변경 이력 감사 로그. 대표 본인 권한은 끌 수 없음.
- 시험: 직원 등급 꺼짐 → 403, 대표가 켬 → 200, 대표 외 사용자가 권한 화면 접근 → 403.

## 3. 자료실 AI 자동 정리 (사용자가 수정 가능)
- 자료실(또는 업무 첨부)에 파일이 올라오면 내장 AI 가 내용·파일명·이미지를 보고 **폴더·태그·제목·한 줄 요약**을 **자동 제안 후 바로 적용**(“AI 정리됨” 표시). 예: "다짐_로고_가로형.png" → 폴더 브랜드자료/다짐, 태그 #로고 #다짐 #가로형.
- 사용자는 언제든 폴더 이동·태그·제목 수정, "AI 정리 되돌리기". 사용자가 고친 규칙은 회사별로 학습(다음 정리에 반영: 같은 종류 파일은 같은 폴더).
- 중복 파일 감지(같은 해시) → "이미 있는 파일" 안내. 자료실 "정리 필요" 보기(AI 확신 낮은 파일).
- AI 정리는 회사 AI 한도에 포함(가벼운 모델·짧은 요청), 한도 소진 시 파일명 규칙으로만 정리.

## 4. 자료실 접근 권한 — 사용자 관리에서 등급별 설정
- 2번 "메뉴 권한" 표에 **자료실** 행 추가: 보기 / 올리기·수정 / 삭제 3단계 × 등급. 폴더 단위 권한(예: "매출 근거"·"인사" 폴더는 대표·관리자만)도 폴더 설정에서 지정 가능, 기본은 상위 폴더 권한 상속.
- 서버 강제(파일 내려받기 서명 URL 발급 전 권한 검사), AI 비서도 요청자 권한 안의 파일만 검색.

## 5. (판단 기록) 구글 드라이브·네이버 연결 대신 내장 저장소
- 대표 질문: 외부 드라이브를 API 로 연결해 쓰는 것 vs 내장 저장소. 결론: **내장 R2 를 기본**, 외부 드라이브는 "링크 연결(이미 있음)"과 나중에 선택적 "가져오기"만.
- 이유: Google Drive 전체 접근은 Google 보안 심사(제한 범위·외부 보안 평가) 필요, 네이버 MYBOX 는 외부 개발자용 공개 API 없음, 고객마다 계정 연결·권한이 달라 AI 검색·권한 관리가 어려움, 상용화 원칙(외부 연결 최소화) 위배.

## 6. 업무 미리 알림을 지시자에게도 (대표 질문 2026-10-14)
- 대표: "30분 전 알림으로 설정했으면 30분 전에 지시자와 담당자 모두에게 가는지?"
- 현재 코드: 마감 n분 전·오늘 마감·마감 임박 알림은 **담당자만**(`jobs.ts` notify userIds=[assignee_id], `reminders.ts` upcoming 은 assignee_id = 나). 지시자는 09시 **기한 지남** 알림만 받음.
- 변경: 업무별 미리 알림(🔔 30분 전 등)과 기본 미리 알림을 **담당자 + 지시자(requested_by)** 모두에게. 문구 구분 — 담당자 "30분 후 마감 · 견적서 보내기", 지시자 "30분 후 마감 · 김민수님 '견적서 보내기' (진행 중)".
  - 이미 완료·보류면 둘 다 보내지 않음. 지시자 = 담당자면 1건만. 일괄(batch) 업무는 지시자에게 묶음 1건("3건 중 1건 미완료").
  - 휴대폰 예약 알림(`/api/reminders/upcoming`)에도 `requested_by = 나` 업무 포함(지시자 기기에 예약).
  - 설정 → 알림에 "내가 지시한 업무의 마감 알림" 켜기/끄기(기본 켬).
- 시험: 지시자·담당자 각각 1건, 완료 업무는 0건, batch 묶음 1건.
