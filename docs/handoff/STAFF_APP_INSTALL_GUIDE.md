# 워크인 앱 설치 안내 (직원 발송용 문안) — 2026-10-20

아래 문안을 카카오톡·문자로 그대로 보내면 됩니다. [ ] 안은 보내기 전에 채웁니다.

## 1. 아이폰 (TestFlight)

```
[워크인 앱 설치 안내 — 아이폰]
안녕하세요, 회사 업무·일정 앱 '워크인'을 설치해 주세요. 정식 출시 전이라 애플 TestFlight로 먼저 배포합니다.

1) App Store에서 'TestFlight'(애플 공식 앱)를 설치합니다.
2) 아래 링크를 아이폰에서 엽니다.
   [TestFlight 공개 링크 — 베타 심사 완료 뒤 전달]
3) '테스트 시작' → '설치'를 누르면 워크인이 설치됩니다.
4) 워크인을 열고, 제가 보낸 '직원 초대 링크'로 가입(이름·비밀번호 설정)한 뒤 로그인합니다.
5) 알림 허용을 눌러 주세요(마감·요청 알림이 여기로 옵니다).

이상이 있으면 TestFlight 안 '피드백 보내기' 또는 워크인 더보기 > 의견 보내기로 알려 주세요.
TestFlight 버전은 90일마다 갱신되며, 정식 출시 후에는 App Store 버전으로 바꿔 드립니다.
```

## 2. 안드로이드 (Google Play 내부 테스트)

```
[워크인 앱 설치 안내 — 안드로이드]
안녕하세요, 회사 업무·일정 앱 '워크인'을 설치해 주세요. 정식 출시 심사 중이라 Google Play 내부 테스트로 먼저 배포합니다.

0) 휴대폰 Play 스토어에 로그인된 구글 계정(이메일)을 저에게 알려 주세요. 테스터 명단에 등록해야 설치할 수 있습니다.
1) 등록이 끝나면 아래 링크를 휴대폰에서 엽니다.
   https://play.google.com/apps/internaltest/4701311500260795594
2) '테스터 되기(참여)'를 누른 뒤, 화면의 'Google Play에서 다운로드' 링크로 스토어에 들어가 설치합니다.
3) 워크인을 열고, 제가 보낸 '직원 초대 링크'로 가입(이름·비밀번호 설정)한 뒤 로그인합니다.
4) 알림 허용을 눌러 주세요(마감·요청 알림이 여기로 옵니다).

링크를 눌렀는데 '참여할 수 없음'이 뜨면 스토어 계정이 등록한 이메일과 다른 경우입니다. 계정을 알려 주시면 추가합니다.
정식 출시 후에는 스토어에서 자동 업데이트됩니다.
```

## 3. 관리자(대표) 쪽에서 할 일
- 아이폰: App Store Connect > TestFlight > 외부 테스팅 '직원 공개 링크' 그룹 — 빌드 1.1.1 심사 제출(암호 입력 뒤 '심사를 위해 제출') → 승인 뒤 '공개 링크 활성화' → 링크 복사.
- 안드로이드: Play Console > 내부 테스트 > 테스터 > 이메일 목록 '본사 테스터'에 직원 구글 계정 추가 → 저장.
- 워크인: 관리 > 사용자 관리 > 직원 초대 → 소속 '본사 › 운영부 › 운영팀' 체크(주 소속) → 초대 링크를 함께 보냄.
