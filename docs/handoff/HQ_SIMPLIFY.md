# 본사 운영 도구로 단순화 (대표 지시 2026-10-13)

> 대표: "본사 최고 책임자 3명끼리 쓰는 본사 운영 툴이다. 불필요한 것들이 있어 보인다. 사이드바를 더 단순화(현장 신고 QR 등). 업무는 Asana, 캘린더는 Google Calendar 를 레퍼런스. 지금 업무는 등록 자체가 번거롭다. 만든 업무를 캘린더에 쓸 거면 캘린더에 표기할 수 있도록."
> 구현: 클라우드. 코드와 데이터는 지우지 않고 **화면에서 숨김**(나중에 다시 켤 수 있게). 작업은 바로 main 에 푸시, 운영 주소 https://dagym-workspace.vercel.app 에서 확인.

## 1. 사이드바 — 4개만
| 남김 | 비고 |
|---|---|
| 홈 | 오늘 할 일 · 이번 주 일정 · 검토 대기 · 기한 초과 (대시보드 위젯은 4개 이하) |
| 내 업무 | Asana "내 작업" — 자동 묶음(새로 배정됨·기한 지남·오늘·이번 주·나중) |
| 프로젝트 | Asana 프로젝트 — 목록(섹션) 기본, 보드는 선택. 즐겨찾기 프로젝트는 그 아래 |
| 캘린더 | Google Calendar 형태 (3절) |

위쪽 막대: 검색(Ctrl K) · + 만들기(업무 / 일정) · 알림 종 · 내 계정.
내 계정 메뉴 안으로: 설정·알림, 사용자 관리(초대·권한), 주간 보고, 운영 상태.

**숨김(메뉴·명령창·모바일 탭에서 제거, 코드 보존)**: 현장 신고 QR, 자동화, 현장 비교, 업무량, 결재선, 공휴일(→ 설정 안 하위 항목), 조직 구성, 감사 기록(→ 운영 상태 안 탭), 템플릿 메뉴(업무 등록의 "템플릿에서 시작"만 유지), 전체 업무(→ 내 업무·프로젝트에 필터로), 오늘·이번 주 페이지(→ 캘린더 옆 "미배정 업무" 패널로 합침).
모바일 하단 탭: 홈 · 내 업무 · + · 캘린더 · 알림.

## 2. 업무 등록 — Asana 처럼 한 줄로
1. **목록 안 바로 추가**: 내 업무·프로젝트 목록 맨 위/섹션 끝 "+ 업무 추가" 줄 → 제목 입력 후 Enter 로 즉시 생성(담당 = 나, 마감 없음). 연속 입력 가능. 같은 줄에서 담당자·마감일 칩을 눌러 바로 지정.
2. **+ 만들기 → 업무** 창은 4칸만: 제목 · 담당자 · 마감일 · 프로젝트. "자세히 입력"은 만든 뒤 상세 패널에서.
3. 기본값 변경: "완료 시 관리자 최종 확인" **기본 꺼짐**(본사 3명 사용). 브랜드·소속은 기본 본사로 자동, 등록 창에서 숨김.
4. **상세 패널(Asana 형태)**: 위 완료 버튼 · 제목 · 담당자 · 마감일(시각 선택) · 프로젝트 · 설명 · 하위 업무 · 첨부 · 댓글. 업무 유형·결재선·증빙 사진·반복·예상 소요·태그·협업자·선행 업무는 "필드 더보기"로 접어 둠.
5. 마감일 칩 빠른 선택: 오늘 · 내일 · 이번 주 금요일 · 다음 주 월요일 · 날짜 선택.

## 3. 캘린더 — Google Calendar 처럼
1. 기본 **주 보기**, 왼쪽에 미니 달력 + 캘린더 목록(체크로 켜고 끄기: 내 일정 · 본사 공용 · **업무**).
2. 빈 칸 클릭/드래그 → Google 처럼 **작은 빠른 입력 창**(제목 · 시간 · 저장 · "옵션 더보기"). 탭으로 **일정 / 업무** 전환 (Google 의 "할 일").
3. 일정 클릭 → Google 형태 미리보기: 제목·시간·참석자·장소·메모·연결 업무, 위쪽 편집·삭제·닫기 아이콘.
4. **업무를 캘린더에 표기**:
   - "업무" 캘린더를 켜면 마감일 있는 업무가 그날 칸에 체크 모양으로 표시(마감 시각이 있으면 그 시각에). 클릭 → 업무 상세 패널, 체크 → 완료.
   - 업무 상세에 **"캘린더에 표시"** 스위치(기본: 마감일 있으면 켜짐) — 끄면 캘린더에 안 나옴.
   - 오른쪽 "미배정 업무" 패널에서 업무를 시간 칸으로 끌어 놓으면 작업 시간 블록 생성(기존 /plan 기능 이동).
5. 단축키는 Google 과 동일: D·W·M·Y(연도는 선택)·A, T 오늘, C 새 일정.

## 4. 완료 기준 (로컬이 운영 주소에서 확인)
- 사이드바 4개, 숨김 메뉴는 주소로 직접 들어가도 본사 3명 운영에 지장 없음
- 업무: 목록에서 제목 입력 → Enter → 1초 안에 생성, 클릭 4번 이하로 담당·마감 지정
- 캘린더: 빈 칸 클릭 → 빠른 입력 → 저장 / 업무 탭으로 바꿔 저장하면 업무가 캘린더에 체크로 표시
- 기존 데이터·API·시험은 그대로 통과
