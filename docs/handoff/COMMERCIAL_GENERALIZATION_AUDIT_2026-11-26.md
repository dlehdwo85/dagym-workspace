## 마감 작업 순서(클라우드 전달)
1. 공용 수집 검색어 = 다짐 낱말 + 모든 회사 검색어 합집합(상한) — 다짐은 늘기만 함
2. 판정 규칙을 회사별 묶음으로(다짐은 지금 규칙 그대로, 다른 회사는 검색어 가중치로 점수·즉시 검토)
3. 시설 탭 기본값을 업종 묶음별로(건설 끔)
4. 회사가 원천(게시판 주소·RSS·협력사 모집) 직접 추가
5. 회사별 기능 켜기 표(tenant_features) 하나로 정리 → 'default' 비교 제거
6. 회사가 바꿀 수 있는 용어 넓히기(조직 단위·일정 종류·연락처 소속·민원 이름)
7. 메일 양식·일정 준비 묶음·결재 종류 회사 편집
8. 마케팅 사진 사전 → 업종 묶음/브랜드 키트(다짐은 그대로)
9. 브랜드 이름 기본값 → 다짐 전용 데이터로
10. 영업·마케팅 시작 체크리스트·화면 투어
11. 공개 화면 대체 글·구독 분야·지점 보고 지시문 정리
12. 회귀 시험: '다짐 불변' 스냅샷 + 신규 회사(IT·건설·카페) 영업·마케팅 E2E — 1·2번은 실제 공고 수로 확인해야 '완료'
