# 슈퍼관리자만 알아야 할 것 — 범위 정리 (2026-10-25, 로컬 → 대표·클라우드)

대표 10/25: "플랫폼 운영뿐 아니라 슈퍼관리자만 알고 있으면 되는 사항들이 있다. 취합해 정리해 달라." + "수집기 상태나 이런 건 슈퍼관리자만 볼 수 있게. 고객은 연동하는 방법과 과정만 알면 된다. 문제가 있다는 건 슈퍼관리자만 확인·체크."

## 1. 원칙

- 고객사(관리자·직원)에게는 **할 수 있는 일**만 보인다: 연결하는 방법, 지금 상태(연결됨 / 연결 안 됨 / 다음 할 일), 결과(오늘 새 공고 n건).
- **원인·오류·비용·내부 수치·외부 서비스 이름·다른 회사의 존재**는 슈퍼관리자(SUPER_ADMIN_EMAILS)만 본다.
- 화면에서 숨기는 것으로 끝내지 않고 **서버가 아예 내려보내지 않는다**(API 응답에서 칸을 뺌). 고객 문구는 한곳(서버 문구 사전)에서 만든다.
- 우리 회사(내부 테넌트 default)는 예외 — 지금처럼 전부 본다.

## 3. 고객사 '초기 세팅' 화면에서 같이 볼 것(#599 시뮬레이션 때 점검)

1. 가입 → 회사 정보 → 업종 → 첫 화면까지 **우리 회사 이름·브랜드·사진이 어디에도 안 나오는지**(기본값·예시·자료실 기본 폴더·마케팅 브랜드 키트 예시).
2. 영업 데이터 설정 첫 화면: 수집기 12개 중 **키 없는 것**이 '오류'가 아니라 '신청 필요 — 방법 보기'로 보이는지.
3. 마케팅 첫 화면: 연결 계정 0개일 때 안내가 '연결 3단계'인지, 자동 제작이 브랜드 키트 없이 돌지 않는지.
4. 알림: 가입 첫날 받는 알림이 환영·다음 할 일뿐인지(서버 오류·수집 경고가 섞이지 않는지).
5. 관리 › 사용량: 체험 회사가 보는 AI 예산 문구('5,000원 중 …')에 원가·모델 이름이 없는지.

## 4. 구현 방식(클라우드 제안)

- `isSuperAdmin(u)`(SUPER_ADMIN_EMAILS 기준, 비어 있으면 플랫폼 운영자)로 **API 응답에서 칸을 빼는 공통 함수** 1개 — 수집기·알림·사용량·자동 제작·연결 계정 응답이 같이 쓴다.
- 고객 문구는 `src/lib/customerCopy.ts`(가칭) 한 파일에 — '연결 안 됨 / 신청 필요 / 받지 못했습니다' 등.
- 시험: 고객 관리자 계정으로 각 API를 불러 금지 낱말(오퍼스·하이쿠·Anthropic·Higgsfield·NICEPAY·HTTP·403·원가·$)이 응답에 없는지 자동 검사.
- 확인: 로컬이 '고객사로 보기'(슈퍼관리자용 1회용 데모 로그인, #599)로 화면별 점검.
