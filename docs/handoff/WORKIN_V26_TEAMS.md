# WORKIN V26 — 한 회사 안 팀(부서)별 업무 공간 + 조직도 개편 + 팀별 업무 흐름 (2026-10-15 대표 지시)

## 지시
"상업화했을 때 부서가 여러 개면 한 회사 안에서 팀별로 업무·캘린더·대화 등을 다룰 수 있어야 한다. 팀 간 업무 내용은 공유되지 않게, 조직도 구성을 개편할 수 있게 해서 업무 플로우를 구축."

## 지금 있는 것(확인)
- 조직(org_units: 본사·지점·현장, 상하 관계) + 소속(memberships), `accessibleUnitIds` 로 하위 조직까지 조회.
- 팀(teams, parent_id 계층, R-16·V14 8번): 팀 업무(team_id)는 팀원·"다른 팀 업무 보기" 권한자만. 상위 팀은 하위 팀 업무를 봄.
- 메뉴 권한(menu_role_perms·menu_user_perms).
→ **업무**는 팀 분리가 일부 되어 있으나, 캘린더·메신저·프로젝트·자료실·AI 비서·보고서에 팀 경계가 일관되게 적용되는지 미확인. 조직도 편집 UI·팀별 업무 흐름 없음.

## 1단계: 감사(먼저)
- 기능별로 "팀 A 직원이 팀 B 의 것을 볼 수 있는가" 표를 만들어 E2E 로 확인: 업무·하위 업무·댓글·첨부, 프로젝트, 캘린더 일정(팀 캘린더·개인 일정 참석자), 메신저 채널·DM, 자료실 폴더, 알림, 검색, 홈 요약, 주간 보고, AI 비서 도구 결과(검색·요약에 다른 팀 데이터 섞임), 매출·CRM, 내보내기. 새는 곳은 전부 막기(다른 팀 = 404 원칙).

## 2단계: 팀 공간
- 팀마다: 팀 업무 목록·보드, **팀 캘린더**(팀원만, 회사 전체 공개 일정은 별도), **팀 채널**(메신저, 팀원 자동 가입·탈퇴), 팀 자료실 폴더, 팀 프로젝트.
- 기본 공개 범위 = **내 팀만**. 다른 팀과 일할 때는 명시적으로: "협업 요청" 업무(받는 팀에 사본이 아니라 해당 업무만 공유, 참여자 지정), 일정 참석자 초대, 채널에 개별 초대 — 공유된 그 항목만 보이고 팀 전체는 안 보임.
- 대표·회사 관리자: 전체 조회(감사 로그). 상위 팀(본부)은 하위 팀 조회(지금 규칙 유지, 설정으로 끌 수 있게).
- 겸직: 한 사람이 여러 팀 소속 가능, 화면 상단에서 팀 전환 또는 "내 모든 팀" 보기.

## 3단계: 조직도 편집
- 관리 > 조직도: 트리(회사 > 본부 > 팀 / 지점·현장) **끌어서 옮기기**, 팀 만들기·이름 바꾸기·합치기·나누기·보관, 팀장 지정, 사람 끌어서 팀 이동(겸직 추가).
- 개편 미리보기: 옮기면 누가 무엇을 새로 보게 되고/못 보게 되는지 요약 → [적용]. 적용 시점 예약(예: 다음 달 1일). 변경 이력·되돌리기.
- 팀 이동 시 그 사람의 진행 중 업무 처리 선택(따라가기 / 원래 팀에 남기고 담당자 변경).

## 4단계: 팀별 업무 흐름
- 팀마다 업무 단계(예: 영업팀 "문의→견적→계약→완료", 운영팀 "접수→진행→검수→완료"), 기본 템플릿, 결재선(검토자), 필수 항목, 자동 규칙(단계 바뀌면 알림·담당 변경) — 회사 공통 기본값을 팀이 복사해 고치는 방식.
- 팀 간 넘김: "다음 단계는 운영팀" 규칙 → 넘기면 받는 팀 업무로 공유(V26 2단계 협업 규칙).
- 팀별 대시보드: 진행·지연·검토 대기, 월 마감 기록(V20)을 팀 단위로.

## 상업화
- 요금제: 팀 수·고급 권한은 비즈니스 요금제(V17)에서. 고객사가 첫 설정 때 조직도 마법사(부서 이름만 입력 → 팀·채널·캘린더 자동 생성).

## 시험
- 팀 A/B 직원 계정으로 1단계 표의 모든 항목 교차 확인(다른 팀 404), 협업 요청한 업무만 보임, 조직도에서 팀 이동 후 권한 즉시 반영, 개편 미리보기 숫자 정확.
