# WORKIN V26 — 한 회사 안 팀(부서)별 업무 공간 + 조직도 개편 + 팀별 업무 흐름 (2026-10-15 대표 지시)

## 지시
"상업화했을 때 부서가 여러 개면 한 회사 안에서 팀별로 업무·캘린더·대화 등을 다룰 수 있어야 한다. 팀 간 업무 내용은 공유되지 않게, 조직도 구성을 개편할 수 있게 해서 업무 플로우를 구축."

## 지금 있는 것(확인)
- 조직(org_units: 본사·지점·현장, 상하 관계) + 소속(memberships), `accessibleUnitIds` 로 하위 조직까지 조회.
- 팀(teams, parent_id 계층, R-16·V14 8번): 팀 업무(team_id)는 팀원·"다른 팀 업무 보기" 권한자만. 상위 팀은 하위 팀 업무를 봄.
- 메뉴 권한(menu_role_perms·menu_user_perms).
→ **업무**는 팀 분리가 일부 되어 있으나, 캘린더·메신저·프로젝트·자료실·AI 비서·보고서에 팀 경계가 일관되게 적용되는지 미확인. 조직도 편집 UI·팀별 업무 흐름 없음.

## 1단계: 감사(먼저)
- 기능별로 "팀 A 직원이 팀 B 의 것을 볼 수 있는가" 표를 만들어 E2E 로 확인: 업무·하위 업무·댓글·첨부, 프로젝트, 캘린더 일정(팀 캘린더·개인 일정 참석자), 메신저 채널·DM, 자료실 폴더, 알림, 검색, 홈 요약, 주간 보고, AI 비서 도구 결과(검색·요약에 다른 팀 데이터 섞임), 매출·CRM, 내보내기. 새는 곳은 전부 막기(다른 팀 = 404 원칙).

## 2단계: 팀 공간
- 팀마다: 팀 업무 목록·보드, **팀 캘린더**(팀원만, 회사 전체 공개 일정은 별도), **팀 채널**(메신저, 팀원 자동 가입·탈퇴), 팀 자료실 폴더, 팀 프로젝트.
- 기본 공개 범위 = **내 팀만**. 다른 팀과 일할 때는 명시적으로: "협업 요청" 업무(받는 팀에 사본이 아니라 해당 업무만 공유, 참여자 지정), 일정 참석자 초대, 채널에 개별 초대 — 공유된 그 항목만 보이고 팀 전체는 안 보임.
- 대표·회사 관리자: 전체 조회(감사 로그). 상위 팀(본부)은 하위 팀 조회(지금 규칙 유지, 설정으로 끌 수 있게).
- 겸직: 한 사람이 여러 팀 소속 가능, 화면 상단에서 팀 전환 또는 "내 모든 팀" 보기.

## 3단계: 조직도 편집
- 관리 > 조직도: 트리(회사 > 본부 > 팀 / 지점·현장) **끌어서 옮기기**, 팀 만들기·이름 바꾸기·합치기·나누기·보관, 팀장 지정, 사람 끌어서 팀 이동(겸직 추가).
- 개편 미리보기: 옮기면 누가 무엇을 새로 보게 되고/못 보게 되는지 요약 → [적용]. 적용 시점 예약(예: 다음 달 1일). 변경 이력·되돌리기.
- 팀 이동 시 그 사람의 진행 중 업무 처리 선택(따라가기 / 원래 팀에 남기고 담당자 변경).

## 4단계: 팀별 업무 흐름
- 팀마다 업무 단계(예: 영업팀 "문의→견적→계약→완료", 운영팀 "접수→진행→검수→완료"), 기본 템플릿, 결재선(검토자), 필수 항목, 자동 규칙(단계 바뀌면 알림·담당 변경) — 회사 공통 기본값을 팀이 복사해 고치는 방식.
- 팀 간 넘김: "다음 단계는 운영팀" 규칙 → 넘기면 받는 팀 업무로 공유(V26 2단계 협업 규칙).
- 팀별 대시보드: 진행·지연·검토 대기, 월 마감 기록(V20)을 팀 단위로.

## 상업화
- 요금제: 팀 수·고급 권한은 비즈니스 요금제(V17)에서. 고객사가 첫 설정 때 조직도 마법사(부서 이름만 입력 → 팀·채널·캘린더 자동 생성).

## 시험
- 팀 A/B 직원 계정으로 1단계 표의 모든 항목 교차 확인(다른 팀 404), 협업 요청한 업무만 보임, 조직도에서 팀 이동 후 권한 즉시 반영, 개편 미리보기 숫자 정확.

## 부록 A. 다짐 실제 구성으로 먼저 만든다 (2026-10-15 대표)
"본사 직원 3명 + 현장 관리자 10명. 모두 본사 소속이지만 업무 부서가 다르다. 본사 직원은 운영진이라 권한이 높고, 현장 관리자는 낮게. 업무 소통 환경도 별도로. 부서별 업무 흐름과 부서 간 협업 도구·권한 설정이 필요."

### A1. 부서·역할
| 부서(팀) | 사람 | 역할(기존 role) | 비고 |
|---|---|---|---|
| 운영진 | 대표 이동재, 김소담, 김민수 | owner / admin | 회사 전체 조회·설정 |
| 현장운영팀 | 현장 관리자 10명 | site_manager | 각자 담당 현장(org_unit) 연결, 팀장은 운영진 중 1명 지정 가능 |
- 조직(org_units)과 부서(teams)를 분리해 쓴다: 소속 조직 = 본사, 부서 = 운영진/현장운영팀, 담당 현장 = 현장 org_unit(여러 개 가능).

### A2. 기본 권한표 (관리 > 권한에서 부서·역할별로 바꿀 수 있게, 사람별 예외 가능)
| 기능 | 운영진 | 현장 관리자 |
|---|---|---|
| 업무 보기 | 전체 | 본인 담당·지시·참여 + **본인 담당 현장** 업무 + 현장운영팀 공용 업무. 다른 현장·운영진 업무 안 보임(404) |
| 업무 만들기·지시 | 누구에게나 | 같은 현장·팀원에게 지시 가능. 운영진에게는 **"요청·보고" 업무**로만(지시 X, 운영진이 담당 지정) |
| 상태 변경·완료 | 담당자 | 담당자. 운영진이 지정하면 완료 전 운영진 검토(결재선) |
| 캘린더 | 전체 일정, 운영진 일정은 현장에 "바쁨"으로만 | 본인·현장 일정 + 현장운영팀 캘린더 + 회사 공지 일정 |
| 메신저 | 운영진 방(비공개), 모든 방 참여 가능 | **현장운영팀 방**(운영진도 참여), 현장별 방, 1:1. 운영진 방 안 보임 |
| 공지 | 작성 + 읽음 확인 현황 | 읽기 + [확인] |
| 자료실 | 전체(기밀 포함) | 매뉴얼·양식·현장 폴더 읽기, 본인 현장 폴더에만 올리기. 기밀 안 보임 |
| 매출·CRM·견적 | 전체 | 없음(필요하면 본인 현장 실적 입력만 — 옵션) |
| AI 비서 | 월 한도 대표 20,000·본부장 10,000원 | 월 3,000원(하루 600원), 기밀·매출 자료 도구 차단 |
| 관리 메뉴 | 전체 | 없음 |

### A3. 부서별 업무 흐름(기본 템플릿)
- **현장운영팀**: 일일 점검(체크리스트) · 시설 고장/민원 접수 → 운영진에게 "요청" → 운영진 담당 지정 → 처리 → 현장 확인 완료 · 주간 보고(V 주간 보고 연결) · 구매/비품 요청 → 운영진 승인 → 처리.
- **운영진**: 현장 지시(여러 현장 일괄 지시, 진행률) · 공지(읽음 확인) · 요청 처리함(현장에서 온 요청 모아 보기, 지연 표시) · 월 마감(V20).

### A4. 부서 간 협업 도구
- **요청함**: 현장 → 운영진 요청은 운영진 공용 "요청함"으로 들어가고, 운영진이 담당 지정. 요청자는 진행 상태만 봄.
- **협업 업무**: 특정 업무만 다른 부서 사람을 참여자로 — 그 업무·댓글·첨부만 보임.
- **공지 + 읽음 확인**, **일괄 지시**(현장 10곳에 같은 업무 생성 → 진행률 한눈에).
- 현장운영팀 방에서 메시지 → 업무로 만들기(기존 기능) 시 자동으로 "요청" 업무.

### A5. 바로 할 일
1. 1단계 감사(다른 부서 데이터 새는 곳)와 A2 권한표를 **현장 관리자 초대 전에** 적용 — 순서를 V25·V21 보다 앞으로.
2. 초대: 현장 관리자 명단(이름·연락처·담당 현장)은 대표가 주면 로컬이 사용자 관리에서 초대(개인정보는 저장소에 쓰지 않음).
3. AI 한도: 13명 기준 회사 합 대표 2만 + 본부장 2만 + 현장 3천×10 = 7만 원(약 $50) → 회사 월 한도 $50(확보 금액 $100 의 70% 이내)로 올림.
