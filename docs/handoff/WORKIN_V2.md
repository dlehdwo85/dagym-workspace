## 3. 업무 화면 = 본사 3명 전체 업무 (Asana "팀 작업" 형태)
- 메뉴 이름 "내 업무" → **업무**. 기본 범위 = 전체(본사 3명). 상단 칩: **전체 · 내 업무 · 담당자(사람별)** · 지연 · 이번 주.
- 묶기 선택: **담당자별(기본)** / 마감일(기한 지남·오늘·이번 주·나중) / 프로젝트. 담당자별 묶음 머리에 아바타·진행 수·지연 수.
- 보기: 목록 · 보드 · 캘린더 (타임라인은 프로젝트 안에서).

## 4. 업무 추가 — 진짜 Asana 방식
지금은 우측 상단 "+ 만들기"를 눌러야만 추가됨(대표 확인). 다음을 **업무 화면 안에서** 바로:
1. 목록 왼쪽 위 **"+ 업무 추가"** 버튼(Asana 의 "작업 추가") → 목록 맨 위에 빈 줄이 생기고 커서가 들어감 → 제목 입력 → **Enter = 저장 후 다음 빈 줄**(연속 입력), Esc = 종료.
2. 각 묶음(담당자·섹션) 끝에 회색 **"+ 업무 추가"** 줄 → 그 묶음 값(담당자/섹션/마감 묶음)이 자동으로 채워짐.
3. 줄 안에서 담당자 칩·마감일 칩 클릭으로 바로 지정(오늘·내일·이번 주 금·다음 주 월·날짜).
4. 모바일: 하단 + → 아래에서 올라오는 시트(제목 자동 포커스, 담당·마감 칩, "추가" 후 시트 유지 옵션).
5. 상단 "+ 만들기"는 그대로 두되 보조 수단.

## 5. 홈 대시보드 — 기업용 업무관리 수준
| 영역 | 내용 |
|---|---|
| 오늘 할 일 | 오늘 마감 + 기한 지난 업무 (내 것 / 전체 전환), 줄에서 바로 완료 |
| 이번 주 일정 | 요일별 목록(시간·제목·장소), 오늘 강조 |
| 이달의 일정 | 미니 달력(일정 있는 날 점) + 다가오는 일정 목록, 날짜 누르면 그날 목록 |
| 담당자별 현황 | 3명 카드: 진행·오늘 마감·지연·이번 주 완료 |
| 기한 지남 · 검토 대기 | 수 + 바로가기 |
| 최근 활동 | 업무 생성·완료·댓글 10건 |
모바일은 위에서부터 오늘 할 일 → 이번 주 일정 → 이달의 일정 순서.

## 7. AI 매출 관리 (GPT 연동) — 설계 후 단계 구현
1단계(바로): **매출 화면** — 현장·브랜드별 월 매출·지출·회원 수 입력/엑셀(CSV) 가져오기, 월별 추이·전년 대비·목표 대비 차트, 본사 3명만 열람.
2단계(GPT 연동): GPT 자료 운영체계에서 만든 표준 CSV(현장·월·항목·금액·근거 파일명)를 업로드하거나, Custom GPT Action 이 우리 API 로 월 실적을 전송(전용 토큰, 쓰기 범위=매출 입력만).
3단계(AI 분석): 월 실적 요약·이상치(급감·급증)·현장 비교 코멘트를 자동 생성해 매출 화면·주간 보고에 표시. 외부 AI API 사용 여부·비용·전송 데이터 범위는 **대표 결정 필요**.
근거 표시 원칙(GPT 지시문과 동일): 숫자마다 근거 파일·기준일, 계산값과 AI 제안 구분.
