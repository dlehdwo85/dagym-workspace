## ⑥ 마케팅 홈 (영업 홈과 같은 밀도)
위 → 아래:
0. **회사 채팅 입력창**(폴시아 1): AI 비서를 홈 맨 위에 상시 노출. "이번 주 인스타 게시 뭐 남았어?" → 답은 업무·일정·시안 카드. 기존 AI 비서(/assistant) 대화를 그대로 쓰고, 홈에서는 입력창 + 마지막 답 카드 1개만.
1. **숫자 4칸**: 승인 대기(시안·광고 개선안 수) · 오늘 게시(채널·예약 시각) · 이번 주 게시(완료/예정) · 7일 광고비 또는 문의(광고 연결 없으면 문의 수만).
2. **① 지금 승인할 것**: 승인 대기 큐 상위 3 — 시안 썸네일(이미지 없으면 채널 색 카드) + [승인][수정 요청][미리보기]. 승인 처리는 지금 승인 대기 화면의 API 그대로.
3. **AI 작업 큐**(폴시아 2·3): 대기 → 실행 중 → 완료, 줄마다 [지금 실행]/[밤에]. 자동 제작·광고 개선안·자료 정리·문자/견적 시안 공통 큐. **밤사이 비서**: 22시 이후 승인된 범위(원고 초안·리드 다음 연락 제안·입찰 요약·보고서 초안)만 돌리고, 아침 브리핑과 홈에 "🌙 밤사이 결과" 카드. 돈·외부 발송은 절대 자동 아님(V19 — 사람이 [보내기]).
4. **② 이번 주 게시 캘린더 줄**: 7일 × 채널 점(인스타 분홍·페북 파랑·블로그 초록) 칩, 누르면 콘텐츠 캘린더 그날.
5. **③ 성과 미니 차트(7일)** + **광고 카드**(폴시아 6): 캠페인 상태(켜짐/꺼짐)·일일 예산·오늘 지출·소재별 CTR/CPC·개선안 수. [켜기]는 대표 승인(기존 규칙).
6. **④ 최근 게시물 썸네일 6개** + **[다음 할 일 제안]**(폴시아 4): 회사 상황(승인 대기·시안 없는 예정 게시·하락 소재·미응답 문의·토큰 만료)으로 5개 제안 → 체크 → [업무로 만들기].
7. **⑤ 채널 상태 한 줄**: 인스타·페북·블로그·광고 계정 연결/만료일·워커 PC.
8. ⚙ **카드 켜기/끄기·순서**(폴시아 5): 회사 기본(관리자) + 사람별 덮어쓰기.

앱(390): 같은 순서를 한 열로 — 채팅 입력창(한 줄) → 숫자 4칸 → 승인할 것(썸네일 3) → 이번 주(7칸 작은 점) → AI 작업 큐(2줄) → 성과 7일. 하단 탭 홈·승인 대기·캘린더·광고 성과·더보기.

구현 메모(확인 뒤): API 1개 `/api/spaces/marketing/home`(숫자·승인 3·주간 7일·7일 성과·최근 6·채널 상태·제안 5), 카드 설정 `user_settings.home_cards`/`tenants.home_cards`. AI 작업 큐는 기존 docJobs·mktAuto·ai 제안을 한 표(`ai_jobs` 뷰)로 읽기만 먼저, [밤에] 예약은 `run_after` 열 추가. 밤사이 비서 범위는 운영 상태 › AI 설정에 체크 4개(기본 모두 끔 → 대표가 켬).

## ⑦ 사이드바 3구역 (로컬 제안 그대로)
- 한 사이드바, 세 구역: ① 맨 위 **공간 전환**(업무·영업·마케팅 탭, 공간 색) ② **'○○ 메뉴'**(공간마다 바뀜, 구역 머리에 공간 색 띠와 이름) ③ **'공통'**(캘린더·알림·메시지·자료실·연락처·공지 — 어느 공간에서나 같은 자리) + **'관리'**(접힘, 관리자만).
- 홈은 공간 메뉴 첫 줄(공간마다 다른 홈). 공간 전환 때 ③은 그대로, ②만 바뀜 → 공통 메뉴 위치가 흔들리지 않음.
- 휴대폰: 하단 5칸 = 그 공간 메뉴(업무: 홈·업무·프로젝트·결재·더보기 / 영업: 홈·리드·거래처·영업기회·더보기 / 마케팅: 홈·승인 대기·캘린더·광고 성과·더보기), **'더보기' 시트 = 공간 전환 + 공통 + 관리**(공통은 어느 공간이든 같은 자리).
- 지금과 다른 점: 지금은 공간마다 사이드바가 통째로 바뀜(공통 메뉴가 위아래로 움직임). 바뀌는 건 ② 구역뿐.

구현 메모(확인 뒤): AppShell NAV 를 `spaceNav(space)` + `COMMON_NAV` + `ADMIN_PAGES` 3묶음으로, 활성 표시·단축키(Ctrl 1/2/3)는 그대로. E2E 사이드바 단계(W-1·V41) 기대값 수정.

## 대표 확인 질문
1. ⑥ 홈 맨 위 회사 채팅 입력창 — 홈에 두는 것에 동의하는지(아니면 AI 비서 화면만).
2. 밤사이 비서 범위 4개(원고 초안·리드 다음 연락 제안·입찰 요약·보고서 초안) 기본값: 모두 끔(대표가 켬) vs 모두 켬.
3. ⑦ '홈'을 공통 구역에 둘지(한 홈) vs 공간마다 다른 홈(시안은 공간 메뉴 첫 줄).
