# WORKIN V29 — 가입·결제·쉬운 메일 연결·무료 한도 (2026-10-15 대표 지시)

## 1. 회원가입 절차 + 가입 이메일 바로 연동
대표: "다른 곳들은 회원가입 절차가 있다. 가입할 때 기록한 이메일을 워크인에 쉽게 연동하는 방법도."
- 가입 화면(경쟁사 기준): [Google로 시작] [카카오로 시작] [네이버로 시작] + 이메일 가입(인증 메일). 소셜 로그인으로 가입하면 그 이메일이 계정 이메일·**업무 이메일 기본값**·메일 시안 회신 주소로 자동.
- 가입 단계: ① 계정(소셜/이메일) → ② 회사 만들기(회사 이름·인원 규모·업종) → ③ 동료 초대(이메일·카카오톡 초대 링크·QR) → ④ 무료로 시작(요금 선택은 나중). 초대받은 직원은 링크 → 소셜 로그인 한 번으로 합류.
- 기존 계정은 설정 > 계정에서 소셜 계정 연결.
- 키 발급(Google·Kakao·Naver 로그인 앱)은 로컬이 대표 화면에서 진행 — 카카오는 V28-2 카카오톡 공유 앱과 같은 앱 사용.

## 2. 메일 연결을 더 쉽게 (대표: "네이버 연결 방식이 꽤 복잡")
- **기본 = 설정 없이 바로 발송(워크인 발송)**: 우리 도메인(work-in.dev)으로 인증된 발송 서비스(Resend)에서 `"김민수 본부장 (주식회사 다짐)" <noreply@mail.work-in.dev>` 로 보내고 **Reply-To = 직원 업무 이메일** → 고객 답장은 직원 메일함으로. 직원·회사 아무 설정 불필요.
- 단점 안내: 회사 보낸메일함에는 안 남음 → 워크인 "발송 기록"에 사본(업무·CRM).
- **고급 = 회사/개인 메일 연결**(지금 방식): Gmail·Microsoft 365 는 **[Google로 연결]/[Microsoft로 연결] OAuth 버튼 한 번**(앱 비밀번호 불필요), 네이버·다음은 앱 비밀번호 방식 유지 + 단계별 안내 화면(바로가기 링크·스크린샷).
- 회사 설정에서 기본 발송 방식 선택(워크인 발송 / 회사 메일).
- DNS: work-in.dev 등록 후 로컬이 Resend 도메인 인증(SPF·DKIM·DMARC) 진행.
