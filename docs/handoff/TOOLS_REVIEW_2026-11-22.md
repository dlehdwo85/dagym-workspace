# 클로드 도구 7개 검수 (대표 #1120, 2026-11-22)

자료: 대표가 준 인스타 릴스('클로드 업무 자동화 스킬 7가지') 설명글 + 함께 받은 PDF 5장.
영상 자체(소리·화면)는 보지 못함. 설명글과 PDF 내용으로 검수함.
기준: `.claude/rules/company-basics.md` '외부 도구'
- 내용을 검토하고 커밋을 고정해 키트에 넣은 것만 씀
- 자동으로 갱신하지 않음
- 사용 통계를 보내거나, 자동 훅이 있거나, 외부 실행 파일을 내려받는 도구는 별도 시험 저장소에서만 씀

| # | 도구 | 자료 설명이 맞는가 | 우리 상태 | 결정 |
|---|---|---|---|---|
| 1 | Remotion(코드로 영상) | 대체로 맞음. 설치 명령(`npx create-video`, `npx remotion skills add`)은 공식 문서와 같음 | 없음 | **보류**. 3명 넘는 회사는 유료(크리에이터 월 25달러/1명, 자동 렌더 월 최소 100달러). 쓰려면 대표 승인 뒤 별도 시험 저장소에서 |
