# WORKIN V36 — 근무 상태 자동 · 일정/업무 구분 · 시간 선택 · 앱 일정 글씨 (2026-10-16 대표)

## 1. 근무 상태 자동 (V35-2 보강)
- 캘린더 일정이 **미팅·외근 성격**(장소가 있거나 유형이 미팅/외근/출장, 또는 업무가 "방문·미팅"으로 일정에 들어간 경우)이면 **그 시간 동안만** 상태 "외근·미팅 중"(파랑) 자동 → 끝나면 "근무 중".
- 연차·반차 등록(또는 휴가 결재 승인) → 그 기간 자동 "휴가"(회색). 출장(종일·여러 날) → "출장".
- 사람이 직접 바꾼 상태가 우선(자동은 직접 설정이 없을 때만).

## 2. 연차자 배정 — 제외하지 않기 (V35-2 수정)
대표: "연차자를 빼지는 말아 주세요. 나중에 업무를 잃어버릴 수 있습니다."
- 일괄 배정(팀 전체·여러 명)에서도 **연차자 포함**(자동 제외 없음). 배정 시 "○○님 연차 중 — 복귀 후 확인" 표시만, 업무 카드에 휴가 아이콘. 알림 보류·복귀 요약은 유지.

## 3. 관리자 화면 권한 설정 (잊지 말 것)
- 관리 메뉴 전체 = 회사 관리자만(V33-3 안내 포함), 메뉴 권한 화면(사용자 > 메뉴 권한)에서 관리 메뉴별 보기/편집을 역할별로 줄 수 있게, 직원이 관리 주소 접근 시 안내 화면. 새 관리 화면(정산·근무 현황·연락처·결제 시험 등)도 메뉴 권한 표에 자동 등록되게.

## 4. 이번 주 일정에서 "이동하는 일정" 놓치지 않게
대표: "일정과 업무를 동그라미·선으로 구별하는데, 일정은 직접 이동하는 경우가 많다. 이동하는 업무·일정인지 기준으로 색상·중요 표시로 명확하게."
- 구분 기준을 **이동(장소 있음)** 으로: 장소가 있는 일정·업무(현장 방문·미팅·외근)는 **진한 색 블록 + 🚗/📍 아이콘 + 장소·출발 시간**("14:00 음성아이파크 · 13:20 출발 권장"), 이동 없는 업무는 연한 칩.
- 일정·업무 공통으로 [이동 있음] 표시(장소 입력 시 자동), 이동 일정은 30분 전 알림 기본(설정 가능).
- 범례를 화면 위에 작게: ● 일정 / ▬ 업무 / 📍 이동.

## 5. 시간 고르기에서 새벽 빼기
- 업무·일정 시간 선택 목록 기본 **07:00~22:00**(30분 단위), [그 외 시간 보기] 로 펼침. 회사 설정 "근무 시간"(기본 09~18)이 있으면 그 앞뒤 2시간까지 우선 표시.

## 6. 앱(휴대폰) 일정 화면 글씨 가림
- 앱에서 일정(스케줄) 아래쪽에 시간이 나오며 제목 글씨가 가려지고 잘 안 보임(웹은 괜찮음). 휴대폰 주간·일간 보기에서 블록 높이가 짧으면 시간은 제목 옆 작은 글씨 또는 생략, 제목 두 줄까지, 최소 글씨 12px, 블록 최소 높이. 390px 실기기 기준 E2E 스냅샷.

## 7. 문의 체크리스트 순서
- "미팅 일정" → "플랫폼 시연 일정 잡기 (온라인·방문)" 순서로(시연은 보통 미팅 후). 기존 미체크 항목 순서도 정리.

## 8. 실결제 소액 시험 (대표 승인: 1번)
- 클라우드가 제안한 [실결제 소액 시험] 구현(100원·운영자·시험 회사·하루 3회·확인 문구·1시간 자동 취소·감사 기록). 배포되면 대표가 결제, 로컬이 결과 확인.
