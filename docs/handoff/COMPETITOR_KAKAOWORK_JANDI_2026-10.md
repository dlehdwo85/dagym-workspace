## 공통 수익 모델 패턴
1. **무료 = 인원 많이(20~30명) + 기간·용량·기능으로 묶음**: 메시지 90일, 화상 40분, 할 일 100개, 광고 → "쓰다 보면 불편해서" 유료 전환.
2. **유료 1단계는 메신저 기본 + 보안·관리**(카카오 Mini 2,400 / 잔디 Premium 6,000).
3. **업무 도구(메일·전자결재·프로젝트)는 2단계**(카카오 Standard 6,500 / 잔디 Enterprise 9,000).
4. **AI 는 최상위 요금제 또는 별도 문의**(카카오 Premium 9,900 / 잔디 Intelligence).
5. 연간 할인 18~20%, 인원 일할·후불, 해제 시 무료로 자동 전환.

## 워크인 시사점 → V27 반영 제안
- 무료: 경쟁사처럼 **인원은 넉넉히, 대신 제한**도 고려 — "10명까지 무료 + 메시지 90일 노출 + 저장 1GB + AI 월 10회 + 고급 기능 잠금"이 3명 무료보다 유입에 유리(경쟁사 20~30명 대비 3명은 약함). 원가: 사람당 AI 거의 0 이면 무료 10명도 월 수백 원.
- 워크인 강점(경쟁사 무료·하위 요금제에 없음): **업무 관리가 본체**(잔디 할 일 100개 제한, 프로젝트는 Enterprise), **AI 를 하위 요금제부터**(경쟁사는 최상위), 음성 등록, 문의→업무, 메일·문자 발송.
- 약점: 화상회의 없음, 전자결재 없음(결재선은 있음), 메일 호스팅 없음(회사 메일 연결 방식).
- 과금 방식: **일할 후불 + 해제 시 무료 자동 전환**(경쟁사 공통) 채택 권장.
