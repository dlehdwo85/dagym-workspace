# WORKIN V31 — 회사 공용 연락처(받는 사람 자동 채우기) (2026-10-16 대표 제안)
대표: "직원들 각 개인 핸드폰을 사이트에 등록시키면 연락처 DB 가 공유돼서 이름을 치면 연락처가 기입되도록."

## 판단(로컬)
- 직원 개인 휴대폰 주소록을 **통째로 자동 공유하는 것은 하지 않음**: 주소록 속 제3자(가족·지인) 개인정보를 본인 동의 없이 회사에 넘기는 것이 되어 개인정보보호법 위험(수집·제3자 제공 동의 없음), 스토어 심사(Play 연락처 권한 정책)에서도 "핵심 기능 아님"으로 거절될 수 있음.
- 대신 같은 효과를 내는 **회사 공용 연락처**로 고도화:

## 1. 회사 연락처(고객·거래처) — 자동으로 쌓임
- 메뉴 "연락처"(관리 아님, 전 직원): 이름·회사/단지·직함·휴대폰·이메일·메모·태그·담당 직원, 출처(문의·발송·직접·가져오기).
- **자동 등록**: 메일·문자·카카오톡을 보낼 때 받는 사람(이름+번호/이메일)을 회사 연락처에 저장(이미 있으면 갱신), 웹사이트 문의(이름·연락처) → 자동 등록, 업무의 고객 정보와 연결.
- 직원 목록(사용자 관리의 이름·직급·휴대폰·업무 이메일)도 같은 검색에 포함(내부 표시).
- 엑셀/CSV 가져오기(V30 ① 와 같은 열 맞추기), vCard(.vcf) 가져오기.

## 2. 받는 사람 칸 자동 완성
- 메일·문자·카카오톡 시안의 받는 사람 칸에 이름·회사·번호 일부를 치면 드롭다운(최근 보낸 사람 우선, 같은 업무에 연결된 고객 최상단) → 고르면 번호/이메일 자동 입력, 여러 명은 칩으로.
- 업무 상세에서 문의 고객 정보가 있으면 시안을 열 때 자동으로 채움(지금처럼).

## 3. 휴대폰 주소록에서 "골라서" 가져오기(선택)
- 앱에서만 [휴대폰 연락처에서 추가] → 기기 연락처 선택 화면(한 명씩 또는 여러 명 선택) → 선택한 사람만 회사 연락처로. 전체 동기화·백그라운드 수집 없음. 권한 문구: "고른 연락처만 회사 연락처에 추가합니다".
- 구현: Android/iOS 연락처 선택(피커) 플러그인 — 로컬이 네이티브 설치·권한 설정, 클라우드가 화면.

## 4. 권한·보호
- 회사 단위(테넌트) 격리, 열람 = 같은 회사 직원, 수정·삭제 = 등록자·관리자, 삭제는 휴지통 30일, 변경 기록.
- 개인정보처리방침: "고객 연락처(업무 연락 목적, 회사가 수집한 범위)" 항목 추가, 고객 요청 시 삭제.
- 무료 한도: 연락처 1,000명(V29 업무 한도와 같은 방식).

## 순서
V30 P1 진행 중 → **문자 시안 스크롤 버그(아래) 즉시** → V31 1·2 를 V30 P1 ⑤ 다음, 3 은 P2 와 함께.

## 버그: 휴대폰 앱 문자 시안 시트 스크롤 안 됨 (local-screens/83)
- 업무 상세 → 문자 시안(아래에서 올라오는 시트)에서 위아래로 밀어도 움직이지 않음. 아래 [보내기] 버튼이 업무 상세의 고정 댓글 입력줄("댓글 입력·등록")에 가려 보이지 않음.
- 시트 본문을 스크롤 가능하게(max-height: 100dvh - 상단, overflow-y:auto, overscroll-contain, touch-action pan-y), 시트가 열리면 뒤 댓글 입력줄 숨김, 버튼 줄은 시트 안 고정 + safe-area 하단 여백. 메일 시안·카카오톡 시안도 같은 구조 확인.
