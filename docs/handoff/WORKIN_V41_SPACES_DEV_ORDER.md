# WORKIN V41 — 공간(업무·영업·마케팅) 개발 지시서 (2026-10-17 대표 "개발 시작")

근거 문서: V39(통합 방향·영업 기능 대조표 A~E) · V40(영업 공공데이터 카탈로그·AI 자동 세팅 규칙·활용신청 45건 승인) · 시안 https://claude.ai/artifact/Aw614zc26sXi3ZZqVeWAeH (대표 "마음에 든다")
원칙: **영업관리 기능 빠짐 0** · 워크인 디자인 기준 · 회사(tenant)별 분리 · 추가형 마이그레이션 · 기존 영업관리 사이트는 이전 완료까지 그대로 운영 · 비밀값은 env 로만.

## 단계 1 — 공간 틀 (먼저, 1~2일)
1. **멤버십·공간 권한**: `memberships`(user × tenant × spaces[work|sales|marketing] × role) 추가형 테이블. 기존 users.tenant 는 그대로 두고 멤버십을 기본값으로 채움(업무 공간 = 전원). 관리자는 모든 공간, 직원은 배정된 공간만. `access.ts` 에 공간 검사 추가(없는 공간 → 404).
2. **공간 전환 UI**(시안 그대로)
   - 휴대폰: 머리줄 오른쪽 프로필 → 아래 시트(이름·회사·역할 / 공간 3개 카드: 아이콘·이름·요약 숫자·빨간 배지 / 회사 전환).
   - PC: 왼쪽 위 공간 카드 → 드롭다운(공간 3개 + 배지, 단축키 Ctrl+1·2·3).
   - 공간별 강조색: 업무 #0F766E(지금), 영업 #2563EB(배경 #F5F8FF), 마케팅 #7C3AED(배경 #F8F6FF). 나머지 컴포넌트·글꼴·간격은 워크인 그대로.
   - 주소: `/s/sales/...`, `/s/marketing/...`(업무는 지금 주소 유지). 마지막 공간 기억.
3. **요금제 연결**: 영업·마케팅 공간은 요금제 '공간 추가' 항목(가격은 대표 결정 ⛔ — 우선 관리자 화면에서 켜기/끄기만, 결제 연동은 가격 확정 후).
- 완료 기준: 대표 계정으로 3공간 전환(휴대폰·PC), 영업 공간 미배정 직원은 메뉴에 안 보이고 주소 직접 입력 시 404, 앱(웹뷰)에서 뒤로가기 정상.

## 단계 2 — 영업 공간 1차 (영업관리 이전)
V39 "영업 기능 대조표" A·B·C·D 그대로 구현. 요약:
- A 같이 쓰기: 업무·체크리스트(`lead_id` 연결), 캘린더 일정(`lead_id`, 다음 연락일 점선 합성), AI 비서 도구 12개(이름 V39 A), 자료실 '영업' 폴더(제안서 첨부), 문의함 → [영업 리드로] 전환(신규).
- B 새로: 영업 현황 · 문의/리드·거래처(중복검사·저장필터·CSV 한글/CP949) · 파이프라인(진행영업 칩 6 + 칸반 11열, 휴대폰은 길게 눌러 상태 시트) · 제안·견적 · 계약·ROI · 리드 상세(탭 7·빠른 버튼 5·요약 8) · 입찰·공고 모니터링(세부 전부 + 0037 정정 트리거) · 영업기회 허브(오늘 등록·지금 영업·계약만료·신규단지·준공시설·협력사) · 지역별 · 관리(카테고리·지역·수집 현황·수동 실행).
- C 회사별 분리: 수집 원천 표는 공용(global), 진행 기록은 **칸 단위로** 회사별 표로 분리(notices 5칸·facility 6칸·vendor 3칸 — V39 C-1). 검색어·카테고리는 회사 설정(기본 템플릿 '시설 운영' = 다짐 값).
- 수집기 12개 이전(Vercel cron, 수동 필드 보존) + **13번째: 국토부 건축HUB 신규단지 자동 수집**(대표 결정).
- D 주의점 10건은 V39 D 표의 '제안'대로.
- **데이터 이전**: 1회성 관리자 전용 이전 작업(읽기 전용 원본 → Neon). 원본 접속값은 env(`SALES_SRC_SUPABASE_URL`, `SALES_SRC_SERVICE_KEY`)로 대표가 Vercel 에 직접 입력(⛔ 이전 직전에 요청). 백업 표 2개·미사용 객체는 옮기지 않음. 영업관리 관리자 = 대표 계정(대표 승인).
- 완료 기준(V39 E): 건수 일치(거래처 21·상담 4·업무 8/하위 1·시점 2·진행기록 30·신규단지 22·협력사 164·공고 4,356·시설 4,346), **'관련 654건' 일치**, 화면 38개 대응 확인(로컬 검수), 수집기 하루 실행 성공.

## 단계 3 — 영업 데이터 확장 + AI 자동 세팅 (V40)
1. **원천 카탈로그 표**(global): 원천별 이름·제공기관·data.go.kr 번호·갱신 주기·이용조건(상업 가능/변경금지)·출처 문구. 1차 승인 35건(V40 §5) 수집기 추가 — 인허가 16종은 공통 수집기 1개 + 업종 코드 목록으로.
2. **회사별 원천 설정**: 켠 원천·검색어·지역(시·도)·제외어. 원천 데이터는 공용 1벌, 회사는 필터만.
3. **AI 자동 세팅**: 가입 4단계(V32-3) 마지막 또는 영업 공간 첫 진입에서 업태·종목·지역을 받아 V40 (c) 규칙표로 원천·검색어 추천 → 관리자가 [이대로 켜기]/수정. 맞는 행 없으면 '공통'만 켜고 키워드 3개 질문. Claude(회사 AI 크레딧 차감).
4. 리드 카드에 **출처 표시**(공공누리 조건), 변경금지 데이터는 값 그대로.
5. 광고성 연락 기능(문자·메일 일괄)은 만들지 않음 — 개별 연락만(정보통신망법 검토 전).
- 키: 기존 `DATA_GO_KR_SERVICE_KEY`(같은 인증키로 45건 호출). 개발 한도 넘기 전 운영계정 전환은 로컬이 신청.

## 단계 4 — 마케팅 공간
- 1단계(빠르게): 워크인 로그인으로 마케팅 운영실 진입(짧은 서명 토큰 SSO) + 공간 전환에서 이동. 마케팅 운영실 쪽 수정은 마케팅 세션 담당.
- 2단계(흡수): 마케팅 세션의 기능 목록(docs/marketing/FEATURES_FOR_WORKIN.md, 작성 중) 받은 뒤 V39 영업과 같은 방식의 대조표 → 별도 지시.
