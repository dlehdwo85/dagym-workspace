## 5. 다시 올리는 순서 (대표 지시: 개선한 뒤 승인 다시)
1. 브랜드 키트 색을 3번 표대로 바꾼다(로컬이 운영에서 바꿀 수 있음 — 대표 확인 뒤).
2. 클라우드: 4번 틀을 서버 그리기에 넣고, 틀 돌림·최근 3개 중복 금지·사진 폴더 제한을 적용한다.
3. 자료실 '마케팅/시안 바탕(글자 없는 사진)' 폴더를 만들고 실사(헬스장·독서실·골프·출입기·앱 화면)를 옮긴다(로컬).
4. 초안 보관 중인 자동 시안을 새 틀로 다시 그린 뒤 브랜드별 2~3개씩 승인 요청 → 대표 승인.
