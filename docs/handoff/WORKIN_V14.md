# 워크인 14차 — 재배정 권한·AI 비서 대화 보관·자료실 자동 정리 점검 (대표 지시 2026-10-14)

## 1. 담당자 재배정 권한 — 사용자 관리 "메뉴 권한"에 추가
- 행 "업무 담당자 재배정"(담당자를 다른 사람으로 바꾸기) × 등급 스위치 + 사람별 예외. 기본: 대표·본사 관리자 켬, 지시자는 자기가 지시한 업무만 켬(별도 스위치 "지시자는 자기 업무 재배정 가능", 기본 켬), 나머지 끔. 담당자 본인이 "다른 사람에게 넘기기"는 별도 스위치(기본 끔 — 켜면 지시자 승인 요청 방식).
- 서버 강제(`updateTask` assignee 변경 시 권한 검사 403), 재배정 시 이전·새 담당자·지시자 알림, 변경 이력 "재배정: 김민수 → 김소담 (이동재)". 여러 명 일괄 업무의 재배정도 동일.

## 2. AI 비서 대화 보관(나갔다 들어오면 사라짐)
- 대화 스레드 저장(`ai_threads`, `ai_messages`: 사용자·조직·제목(첫 질문 요약)·연결 업무·첨부 파일 id·제안 id·토큰). 본인만 열람(대표도 남의 대화 못 봄, 감사용 메타데이터만 플랫폼 운영 화면).
- 화면: AI 비서 왼쪽(휴대폰은 상단 "대화 목록") — 최근 대화, 검색, "새 대화", 이름 변경·고정·삭제. 업무 상세에서 연 대화는 그 업무에 묶여 다음에 열면 이어짐("이 업무 대화 n개").
- 문맥: 이어서 질문하면 최근 메시지 20개 + 요약(긴 대화는 서버가 앞부분 요약 저장)만 보내 비용 절감.
- 보관 기간: 기본 90일(설정 → 데이터 보관에서 30/90/365일/무기한), 지난 대화 자동 삭제. 제안 카드의 처리 결과(만들어짐/취소)도 대화에 남김.

## 5. 회사와 무관한 질문 차단(사용량 보호)

- 1인당 일 요청 한도(기본 50회, 설정), 1회 입력 길이·첨부 수 제한, 같은 질문 반복 감지.
- 차단·한도 초과 건은 사용 내역에 "차단됨"으로 기록.

## 6. AI 비서 사용 내역 열람 — 권한으로 (2번 "본인만" 수정)
- 대표 지시로 변경: 메뉴 권한에 **"AI 사용 내역"** 행 — 조회(누가·언제·무슨 질문·요약 답변·비용)/편집(삭제·보관 기간 변경) 별도 스위치 × 등급·사람별. 기본: 대표만 조회·편집.
- 직원 고지: AI 비서 첫 화면·약관에 "회사 업무용이며 관리자가 사용 내역을 볼 수 있습니다" 상시 표시(개인정보·노무 분쟁 예방).

## 7. 관리 메뉴 전체 권한 — 조회/편집 분리 on/off
- 메뉴 권한 표를 **모든 관리 메뉴**로 확장: 주간 보고(모아보기), 매출, 사용자 관리, 운영 상태, 사용량·요금제, 플랫폼 운영(플랫폼 관리자만 대상), 자료실, AI 사용 내역, 업무 재배정, 메뉴 권한 자체(대표 고정).
- **모든 행은 "조회"와 "편집" 두 스위치**(편집 켜면 조회 자동 켜짐, 조회 끄면 편집도 꺼짐) × 등급 + 사람별 예외. 꺼진 메뉴는 사이드바에서 숨김, 조회만이면 읽기 전용(저장·삭제 버튼 없음), 서버에서 403.
- 대표 권한은 끌 수 없음, 권한 변경은 감사 로그.

## 8. 팀 단위 업무 관리 + 팀 정보 권한 (대표 지시)
- **팀**: 사용자 관리 → "팀" 탭에서 팀 만들기(이름·색·팀장 1명 이상·팀원), 한 사람이 여러 팀 가능. 기존 조직 구성(org_units: 본사·지점·위탁현장)과 별개의 업무 묶음(예: 마케팅팀, 운영팀, 영업팀). 기존 org_units 재사용이 맞으면 "팀" 유형 추가로 구현해도 됨(클라우드 판단, NEXT_ACTION 기록).
- 업무에서: ① 담당 대상에 **팀 선택** → "팀원 모두에게 각각"(일괄) 또는 "팀에 배정(팀장이 담당자 지정)" 선택, ② 업무 목록 칩·묶기·필터에 "팀", ③ 팀 보드(팀원별 열), ④ 홈 "우리 팀 오늘 할 일", ⑤ 메신저 팀 대화방 자동 생성, ⑥ 주간 보고 팀별 모아 보기.
- **팀 정보 권한**(메뉴 권한 표에 "팀 업무" 행, 조회/편집 분리): 기본 — 팀원은 자기 팀 업무 조회, 팀장은 자기 팀 조회·편집(재배정 포함), 대표·본사 관리자는 전체. 사람별 예외로 "다른 팀 조회" 허용 가능. 서버 강제(다른 팀 업무 목록·상세 404, 단 본인이 담당·지시·참여자인 업무는 항상 보임).

## 15. 기밀 자료 보호 — 보안 등급 + AI 차단 (대표 지시)
- 대표: "기밀문서·매출 자료는 대표·본부장 외에는 AI 비서로 요청해도 내부 자료 제공 불가."
- **보안 등급(파일·폴더 단위)**: `일반`(전 직원) · `내부`(팀·지정 등급) · `기밀`(대표·본부장 등 지정자만). 폴더에 등급을 주면 하위 파일 상속, 파일 단위로 더 높게만 변경 가능.
- **AI 자동 분류**: 업로드 시 AI 정리(13차)가 내용으로 등급 제안 — 매출·급여·계약서·주민번호/계좌·인사·견적 단가 등은 `기밀` 제안, 대표 확인 전까지 **기본 `내부`(안전한 쪽)**. "매출 근거" 폴더·매출 메뉴에서 올린 파일은 자동 `기밀`.
- **접근 권한**: 메뉴 권한 표에 "기밀 자료 열람"(조회/편집) 행 — 기본 대표만 켬, 대표가 본부장 등 지정. 사람별 예외.
- **AI 비서 강제 규칙(서버, 프롬프트에 의존하지 않음)**:
  1. 검색·파일 읽기 도구가 **요청자 권한 밖 파일은 결과에서 아예 제외**(존재 여부도 노출 안 함 — "찾을 수 없습니다").
  2. 매출 조회 도구는 매출 조회 권한자만 호출 가능(그 외 403 → "권한이 없는 자료입니다").
  3. 대화·요약·업무 생성 시 기밀 파일 내용이 다른 사람에게 전달되지 않도록: 기밀 파일을 근거로 만든 결과물(엑셀·업무 설명)은 같은 등급으로 저장, 권한 없는 사람이 담당자면 첨부 대신 "기밀 자료 — 열람 권한 필요" 표시.
  4. 자료 이름·검색어 우회("매출 알려줘", "파일 목록 전부") 시험 케이스 포함.
- **감사**: 기밀 파일 열람·내려받기·AI 참조 기록(누가·언제), 대표가 플랫폼/사용량 화면에서 확인. 내려받기 워터마크(이름·시각, 이미지·PDF)는 선택.
- 시험: 직원 계정으로 AI 에 기밀 파일 질의 → 내용·제목 미노출, 대표 계정 → 정상, 본부장에게 권한 부여 후 → 정상.

## 25. 메신저 화면 전면 개선 (대표: "너무 대충 만든 느낌", 캡처 `local-screens/68-pc-messenger-dock.png`)
- 우측 하단 메신저 패널에 **새 대화(＋) 버튼 없음**, 대화 목록이 글자만(아바타·시간·안 읽은 수·검색 없음), 빈 공간 과다.

  1. **목록**: 상단 검색 + ＋새 대화(1:1·그룹) + 탭(전체·1:1·그룹·업무방). 행 = 아바타(그룹은 겹친 아바타/#아이콘)·이름(직책 약칭)·마지막 메시지 미리보기 1줄·시간(오늘 시각/어제/날짜)·안 읽은 수 빨간 배지·고정 핀·알림 끔 아이콘. 고정 대화 맨 위.
  2. **대화방**: 상단 = 방 이름·참여자 수·검색·고정 메시지·설정(알림·참여자·나가기). 말풍선: 내 메시지 오른쪽(브랜드 청록), 상대 왼쪽(회색) + 아바타·이름(연속 메시지는 묶어 1번만), 시간은 묶음 마지막에만, 읽음 수("1"이 사라지는 방식), 날짜 구분선, 이미지 썸네일·파일 카드(아이콘·이름·크기), 링크 미리보기, 답장(인용), 이모지 반응, 메시지 hover 메뉴(답장·반응·업무로 만들기·고정·복사·수정·삭제) — 지금처럼 모든 메시지 아래 텍스트 링크 나열 금지.
  3. **입력창**: 한 줄 자동 높이, 📎·📷·😊·@, Enter 보내기(휴대폰은 보내기 버튼), 붙여넣기 이미지 업로드, 끌어다 놓기, 입력 중 표시.
  4. **패널(우측 하단)**: 380×560, 목록↔대화방 전환(뒤로), 확장 버튼으로 /messages 이동, 새 메시지 오면 버튼 배지·작은 미리보기 토스트.
  5. 빈 상태: "대화를 시작해 보세요" + 사람 추천(최근 같이 일한 사람).

## 49. 업무에 올린 파일을 다른 직원이 내려받을 수 있게 (2026-10-15 대표 지시)
코드 확인: 서버는 업무를 볼 수 있는 사람이면 내려받기 허용(`loadAttachment` → 업무 view 권한, `/api/attachments/:id/download` → 120초 서명 URL 로 이동). 문제는 화면·앱 쪽:
- `Attachments.tsx` 파일은 제목 링크(`target=_blank`, `?inline=1`)뿐이라 **[내려받기] 버튼이 없음**(사진 크게 보기에만 "원본 내려받기").
- **앱(Capacitor WebView)은 파일 내려받기를 처리하지 못함** — `target=_blank` + 첨부 응답이 WebView 안에서 아무 일도 안 일어나거나 빈 화면.
수정:
1. 파일·사진마다 **[내려받기] 아이콘 버튼**(+ PDF·이미지는 [미리보기]) — 업무를 볼 수 있는 모든 사람(담당·지시·협업·같은 팀·관리자)에게.
2. 앱: `?json=1` 로 서명 URL 을 받아 **외부 브라우저로 열기**(`location.href = 서명URL` — 다른 도메인이라 Capacitor 가 기기 기본 브라우저로 넘김 → 휴대폰 "다운로드"에 저장) 또는 공유 시트. iOS 는 미리보기(Quick Look) 후 공유. 웹은 지금처럼.
3. 서명 URL 유효 120초 → 앱에서 누르는 순간 새로 발급(이미 그렇게 됨).
4. 기밀(보안 등급) 파일은 권한 없는 사람에게 버튼 숨김(서버도 403), 내려받기 기록(누가 언제) 업무 활동에 남김.
시험: 김민수 계정(지시받은 업무 아닌, 같은 팀 업무)에서 PDF·엑셀·사진 내려받기 — 웹·Android 앱·iOS 앱 각각, 권한 없는 직원은 업무 404.

## 50. 업무 권한 정리 — 상태·승인은 담당자만, 내용·일정 수정은 지시자·담당자만 (2026-10-15 대표 지시)
