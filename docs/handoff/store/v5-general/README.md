## 어떻게 찍었나

- 운영·심사 계정(체험 조직) 자료는 건드리지 않았습니다. 시험 서버 + 시험 DB 에 가상 회사 '하늘솔루션'을 만들어 찍었습니다(`tests/e2e/sample-seed.mjs`).
- 사람: 김하늘(대표)·이서준·박지우·최민서(매니저). 거래처: 한빛상사·새봄디자인·푸른유통. 모두 지어낸 이름입니다.
- 업무: 신제품 소개 자료 최종본 정리 / 거래처 미팅 준비 — 견적서 확인 / 월간 매출 보고서 작성 / 홈페이지 이벤트 배너 교체 / 신규 입사자 교육 일정 잡기 / 사무실 비품 주문 / 고객 문의 답변 정리 / 분기 목표 회의 안건 정리. 일정: 주간 팀 회의·거래처 미팅·신제품 리뷰·점심 세미나·월간 회고.
- 다시 만들기: `npm run build && node tests/e2e/store-shots-v5.mjs` (PostgreSQL 필요, 1분 반쯤). 생성 AI 는 쓰지 않습니다 — AI 비서 화면은 저장해 둔 대화를 보여 줄 뿐입니다.

## 로컬이 올리기 전에 볼 것

- **전화번호는 넣지 않았습니다.** 지어낸 번호가 실제 누군가의 번호일 수 있어서입니다. 그래서 5번(영업 리드) 화면에는 [전화]·[문자] 단추가 없고 '다음 연락일·담당·단계'가 보입니다. 캡션의 '전화·문자'와 화면을 맞추려면 회사가 가진 번호(예: 대표번호)를 정해 주시면 그 번호로 다시 찍겠습니다.
- 6번은 마케팅 홈이 아니라 **승인함**입니다. 새 회사의 마케팅 홈은 채널 연결 안내와 '목표 0원' 칸이 먼저 나와 캡션과 덜 맞습니다.
- 4번(업무 상세)은 화면 위 '새 알림' 한 줄을 접고 찍었습니다(체크리스트가 한 화면에 들어오게).
- 화면 속 날짜는 찍은 날(11/14), 시각은 9:41 로 고정했습니다.
- 실제 직원·거래처 이름과 겹치는지는 클라우드가 확인할 수 없습니다(운영 자료를 보지 않음) — 로컬 확인 부탁드립니다.
