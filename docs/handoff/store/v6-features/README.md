## 어떻게 찍었나

- 운영·심사 계정 자료는 건드리지 않았습니다. 시험 서버 + 시험 DB 에 가상 회사 '하늘솔루션'을 만들어 찍었습니다(`tests/e2e/sample-seed.mjs`).
- 사람: 김하늘(대표)·이서준·박지우·최민서(매니저). 모두 지어낸 이름입니다.
- 다시 만들기: `npm run build && node tests/e2e/store-shots-v6.mjs` (PostgreSQL 필요, 3분 반쯤). 생성 AI 는 쓰지 않습니다 — AI 비서 화면은 저장해 둔 대화를 보여 줄 뿐 모델을 부르지 않습니다.

## 자동 검사(스크린샷에 찍히는 글에 하나라도 있으면 스크립트가 실패)

- 우리 업무·심사용 낱말: 심사·(가상)·영업관리·현장 미등록·피트니스·헬스·아파트·단지·관리사무소·입주·회원·운동기구·샤워실·다짐·하이링크
- 금액·요금 글자: 'n원'·'n회'·가격·무료·체험·요금·크레딧(App Store 2.3.7 거절 사유 재발 방지, Play 에도 같은 기준)

## 로컬이 올리기 전에 볼 것

- **화면에서 접고 찍은 것**: ① 체험 띠·설치 권유·알림 권한 묻기·아침 인사(v5 와 같음) ② '결재할 것 2건' 띠는 1번(홈)에만 두고 나머지에서는 접음 ③ 3번(업무 상세)의 '새 알림' 한 줄과, 아이폰에서만 나오는 "사진을 많이 고르면 멈춘 것처럼 보입니다" 사용 요령 한 줄. 요령 한 줄은 그대로 두는 편이 맞다고 보시면 알려 주세요 — 다시 찍습니다.
- 3번 위 글자의 '댓글'은 화면 아래 댓글 입력 칸으로 보입니다(달린 댓글 목록은 화면 밖). 댓글이 보이게 하려면 화면 위치를 바꿔 다시 찍을 수 있습니다.
- 7번 점검 코스 이름이 '기본 매장 점검'입니다(새 회사가 처음 받는 기본 코스 이름 그대로).
- 8번 대화의 회의 날짜는 찍은 날 기준 '내일'이고, 내일이 주말이면 '월요일'로 바꿔 찍습니다(이번에는 11월 23일 월요일). Play 는 화면이 짧아 두 마디(말하기 → 확인 받기)만 보입니다.
- 화면 속 날짜는 찍은 날(11/20), 시각은 9:41 로 고정했습니다.
- 실제 직원·거래처 이름과 겹치는지는 클라우드가 확인할 수 없습니다(운영 자료를 보지 않음) — 로컬 확인 부탁드립니다.
