## 구현(클라우드) — 정기 구독(17차 요금제)
1. **빌링(카드 자동결제)**: 체험 중/만료 시 "요금제 결제" → NICEPAY 빌키 발급(카드 등록 창) → 빌키 저장(암호화, 카드번호 미저장) → 매월 결제일 서버가 빌키로 승인 요청. 결제 실패 시 3회 재시도(1·3·5일), 7일 유예 후 읽기 전용.
2. **단건 결제(인증결제)**: 연간 결제·추가 팩 구매.
3. **결제통보(웹훅)**: NICEPAY → `/api/billing/nicepay/notify` 결과 수신(서명·금액 검증, 멱등), 영수증·세금계산서 정보 저장.
4. 플랫폼 운영: 회사별 구독 상태·결제 내역·실패·환불(부분 환불 API), 대표 수동 조정.
5. 회사 관리자 화면: 결제 수단(카드 끝 4자리), 다음 결제일·금액, 영수증, 해지(다음 결제일에 종료).
6. 환경변수: `NICEPAY_MODE`(test/live), `NICEPAY_MID`, `NICEPAY_MERCHANT_KEY`, 빌링용 `NICEPAY_BILLING_MID`/`KEY` — **값은 대표가 Vercel 에 입력**(테스트 단계는 공개 테스트 MID, 로컬이 Preview/Production test 모드로 확인).
7. 시험: 테스트 MID 로 빌키 발급→승인→웹훅→구독 활성, 실패→재시도→유예, 해지.
