# 검색 노출(SEO)·광고 문안 점검 보고 — 2026-10-25

- 방식: 세 사이트의 공개 페이지(총 31개 주소)와 robots.txt·sitemap.xml을 **읽기만** 했습니다. 로그인·수정·설치는 하지 않았습니다.
- 참고하라고 받은 체크리스트 파일(`seo-skill-full.md`)은 로그인 벽 뒤의 글이라 **실제 점검 항목이 들어 있지 않았습니다**(설치 명령만 있음). 그래서 업계 공통 점검 항목(제목·설명·canonical·robots·사이트맵·OG·구조화 데이터·alt·링크·모바일·성능·404·네이버·회사정보·키워드·전환 태그·색인)으로 점검했습니다.
- 판정: **통과** = 그대로 둬도 됨 / **수정** = 있지만 고쳐야 함 / **없음** = 아예 없음(새로 만들어야 함).

### 가장 급한 10가지
1. **워크인 전환 태그가 하나도 없음**(gtag·GA4·구글애즈·네이버 모두 없음) → 10/22부터 돌아가는 구글 실적최대화(PMax) 광고가 "가입"을 배울 수 없어 예산이 샙니다. 태그를 붙일 때까지 **일시정지를 대표가 결정**해 주세요. (클라우드 코드 + 대표 계정)
2. **워크인 구글 색인 1건, 그것도 "이 페이지에 대한 정보가 없습니다"** → robots.txt가 `Disallow: /`로 전부 막고 홈만 예외로 열어 둔 구조(CSS·JS까지 차단), canonical·사이트맵·robots가 모두 `work-in.dev`(www 없는 주소)인데 실제 접속은 `www.work-in.dev`, 두 주소가 서로 넘겨주지 않음. → www로 통일(301), robots 다시 쓰기, 사이트맵 수정, 서치콘솔 URL 검사. (클라우드 코드 / 대표 계정)
3. **워크인 네이버 서치어드바이저 인증 태그 없음** → 네이버 검색에 안 잡힐 가능성. (대표 계정: 등록 → 클라우드 코드: 태그 삽입)
4. **워크인 핵심 키워드 5개 모두 해당 페이지 없음**('업무관리'·'전자결재'·'근태'·'협업툴' 단어가 본문에 0회). robots가 이미 `/landing/`을 열어 뒀는데 그 주소는 404. → 키워드별 랜딩 페이지 제작. (클라우드 코드 + 마케팅 문구)
5. **워크인 문구 사실성**: 설명문은 "웹·Android·iOS"인데 본문은 "Google Play 심사 중 · App Store 심사 중". 홈 요금 칸은 "문의해 주세요"인데 가입 페이지엔 "1인 월 2,200원부터(베이직 2,200·스탠다드 4,500·프로 8,500, VAT 별도·최소 3인)". → 둘 다 통일. (마케팅 문구)
6. **파워링크 '시험' 캠페인 이름은 워크인, 소재·연결은 하이링크** → 집행 전 이름 정리, 키워드별 연결 주소 세분화. (마케팅 문구 / 대표 승인)
7. **하이링크 회사 표기 세 갈래**: 워크인 하단 "주식회사 하이링크 603-85-28600", 하이링크 하단 "하이링크 / HI-LINK by 주식회사 다짐 603-85-28600", 회사소개 머리글 "주식회사 다짐", 구조화 데이터는 이름 '주식회사 다짐'+주소는 하이링크(화성). → 대표가 공식 표기를 정하면 세 사이트·구조화 데이터 통일. (대표 결정 → 클라우드 코드)
8. **하이링크 404가 영문 기본 화면**("404: This page could not be found.")이고 robots 신호가 noindex와 index로 충돌. (클라우드 코드)
9. **하이링크 홈 동영상 5.5MB**(외부 저장소 mp4)와 OG 태그(og:url 전부 없음, 하위 페이지 미리보기 제목·이미지가 홈과 동일). (클라우드 코드)
10. **다짐 홈 "work-in 출시 예정 · 출시 소식은 이 페이지에서"** → 워크인은 운영 중(14일 무료 체험). 문구 수정 + work-in.dev 링크 추가(자매 사이트에서 오는 링크가 0개라 색인에도 손해). 세 사이트 모두 GA4·네이버 전환 스크립트 없음(구글애즈 AW 태그만). (마케팅 문구 / 클라우드 코드)
