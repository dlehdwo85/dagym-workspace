# WORKIN V24 — 음성 등록 (2026-10-15 대표 지시)

## 신고·지시
1. "말로 등록" → **"음성 등록"** 으로 문구 교체.
2. **AI 비서도 음성으로** 요청할 수 있게(AI 비서 화면·오른쪽 패널 둘 다).
3. 앱에서 쓰려 하면 "마이크 권한이 없다"며 작동 안 함.
4. 말 인식률을 최대한 높게.

## 원인 (3번)
- 앱(Android) 에 마이크 권한(RECORD_AUDIO)이 선언돼 있지 않았고, iOS 에도 마이크·음성 인식 사용 설명이 없었다 → **로컬이 추가함(이 커밋)**: AndroidManifest `RECORD_AUDIO`·`MODIFY_AUDIO_SETTINGS`·`queries(android.speech.RecognitionService)`, iOS Info.plist `NSMicrophoneUsageDescription`·`NSSpeechRecognitionUsageDescription`.
- 그리고 지금 음성 기능은 브라우저 음성 인식(Web Speech API, `src/lib/nlparse.ts` listenOnce/listenLive)을 쓰는데, **Android 앱 WebView 에서는 이 기능이 사실상 동작하지 않는다**(권한이 있어도 not-allowed/서비스 없음). iOS 앱 WebView 도 불안정. → 권한만으로는 해결 안 됨.

## 개선
### 1단계 (무료, 바로)
- **앱: 휴대폰 자체 음성 인식(네이티브) 사용** — Android SpeechRecognizer(구글 한국어), iOS Speech(애플). Capacitor 플러그인(`@capacitor-community/speech-recognition` 의 Capacitor 8 호환판, 없으면 작은 자체 플러그인)으로 `ko-KR`, 중간 결과(실시간 글자) 표시, 말 끝 자동 감지 + [완료] 버튼, 첫 사용 때 권한 요청 → 거부 시 "설정 > 앱 > 워크인 > 권한 > 마이크" 안내와 [설정 열기].
- **웹(PC·휴대폰 브라우저)**: 지금 Web Speech API 유지(크롬·엣지·사파리), 지원 안 되는 브라우저만 키보드 음성 입력 안내.
- 공통 함수 하나(`voice.listen()`)로 앱/웹 자동 선택 — 업무 등록·AI 비서·댓글 등 어디서나 같은 동작.
- **인식률 높이기(무료에 가까움)**
  - 말이 끝나면 인식 결과(후보 여러 개 maxAlternatives 5)를 **회사 단어장으로 보정**: 직원 이름·직함, 팀, 프로젝트, CRM 고객·아파트·거래처 이름, 자주 쓰는 업무 단어. 먼저 서버에서 비슷한 글자 맞추기(초성·편집거리), 애매할 때만 Haiku 1회 보정(약 0.1원) — 고친 단어는 밑줄로 보여 주고 눌러서 되돌리기.
  - 사용자가 고친 기록을 단어장에 학습(예: "노태" ↔ "노태2단지").
  - 조용히 말해도 되게 안내 문구, 10초 이상 침묵 시 자동 종료, 최대 60초.
- **문구**: 화면·도움말·소개 페이지의 "말로 등록" 전부 "음성 등록"으로(AppShell 메뉴, QuickAddTask, VoiceAddTask, help, welcome, AuthCard, ai-notice). 아이콘 🎤 중복(아이콘 + 이모지) 정리 — 아이콘 하나만.
- **AI 비서 음성**: 입력창 옆 마이크 버튼 → 말하는 동안 입력창에 실시간 글자 → 말이 끝나면 입력창에 남기고 사용자가 확인 후 보내기(바로 보내지 않음, 설정에서 "말 끝나면 바로 보내기" 선택 가능).

### 2단계 (선택, 유료 — 대표 결정)
- 1단계로도 부족하면 서버 음성 인식(STT) 사용: 녹음 → 서버 → 한국어 특화 STT(네이버 클로바 스피치, 리턴제로, OpenAI gpt-4o-transcribe 중 택1, 회사 단어장을 힌트로 전달). 비용 분당 수 원~십수 원, 새 업체 가입·키 필요(대표 승인). 구조만 `voice.listen({ engine })` 로 열어 둘 것.

## 앱 배포
- 네이티브 권한·플러그인이 들어가므로 **앱 새 빌드 필요**(Android versionCode 다음 번호, iOS 1.0.5). 스토어 제출·공개는 대표 승인 후(로컬 담당).
- 웹 화면 문구·AI 비서 마이크 버튼은 웹 배포만으로 바로 반영.

## 시험
- 앱: 처음 누르면 권한 요청 → 허용 후 "내일 3시 김민수 노태2단지 골프 티업기 점검" → 실시간 글자, 이름·장소 보정, 업무 카드 채워짐. 거부 시 설정 안내.
- 웹: 크롬에서 같은 문장, 사파리, 지원 안 되는 브라우저 안내.
- AI 비서: 마이크로 요청 → 입력창 확인 후 보내기.
- 문구에 "말로 등록" 남지 않음(grep).
