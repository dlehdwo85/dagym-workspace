# WORKIN V37 — 홈 중복·일정/업무 정리·뒤로 가기·알림 아이콘·부서 공간 (2026-10-16 대표)

## 1. 홈 "오늘 마감 업무" 중복 (local-screens/85)
- 같은 업무가 담당·지시로 2~3번 나옴(예: "고천대방지구 디에트르센트럴 소장 미팅" 담당 1 + 지시 2 — 담당자마다 나눠 만든 업무 사본을 지시자 입장에서 모두 보여 줌).
- 홈은 **내가 담당인 것만** 기본 표시. 내가 지시한 것은 묶어서 한 줄("내가 지시한 업무 3건 — 진행 1·완료 0") → 누르면 펼침. 같은 원본에서 나눈 사본은 한 줄로 묶고 담당자 수 표시("김민수 외 1").

## 2. 일정과 업무 정리 (대표: "업무도 일정이고 일정도 업무인데 애매함")
- 원칙: **일정 = 시간 블록(언제 어디서 — 가볍게 한눈에)**, **업무 = 할 일(체크하며 끝내는 것)**.
- 캘린더(스케줄) 화면의 [+]·빈 칸 누르기 → **일정 등록이 먼저**(제목·시간·장소만, 한 화면). 업무로 만들려면 "할 일로도 만들기" 체크.
- 업무 화면의 [+] → 업무 등록(지금처럼). 홈 [+] 는 두 버튼(업무 / 일정) 유지.
- 캘린더에 업무는 기본 "마감 시각 있는 업무만" 작은 칩으로(종일 업무는 상단 띠), 일정은 블록. 보기 설정에서 [업무 숨기기] 토글.
- 업무에 시간·장소가 있으면 일정에도 같이 나오되 하나로(중복 블록 금지), 아이콘으로 업무임을 표시.

## 3. 앱 일정 등록 저장 방식
- 앱에서 일정 등록 시 "엔터를 누르세요" 안내가 뜸 → **[저장] 버튼**이 항상 보이게, 다른 곳을 누르거나 시트를 닫으면 **자동 저장**(제목이 있을 때), 엔터 의존 제거. 업무 빠른 등록도 동일.

## 4. 뒤로 가기 검토
- 대표: "뒤로 가기를 누르면 업무 관리 화면이 나와야 하는데 이전에 열었던 업무가 나오는 느낌."
- 원인 후보: 업무 상세를 패널로 열 때마다 history push(/tasks/:id) → 뒤로 가기가 이전 업무로 감. 규칙: 업무 상세 열기는 replace(같은 화면 안 패널 전환은 history 1칸), 뒤로 가기 = 패널 닫기 → 목록. 알림으로 연 경우 = 목록(이미 반영). 시트·모달 열림 중 뒤로 = 시트 닫기. Android 하드웨어 뒤로·iOS 스와이프·웹 브라우저 뒤로 모두 같은 규칙, E2E(목록 → 업무 A → 업무 B → 뒤로 = 목록).

## 6. 부서별 워크인 공간 (대표 제안 — 설계·검토)
대표: "워크인-업무 / 워크인-영업 / 워크인-마케팅으로 첫 화면에서 부서별로 입장, 관리자는 전부(인스타 계정 전환처럼), 직원은 부서 배정 후 팀별로. UI 는 지금 워크인에 맞추되 공간별 배경색만 조금씩 다르게."
- 구조: 회사 안에 **공간(Space)** = 업무(기본)·영업·마케팅(추후 사용자 정의). 공간마다 메뉴 구성이 다름:
  - 업무: 지금 워크인 전체.
  - 영업: 고객·거래처(연락처 V31)·문의(웹사이트 문의 연동)·견적(문서 엔진)·파이프라인 보드(문의 → 미팅 → 시연 → 견적 → 수주/실패)·매출(V25)·영업 일정.
  - 마케팅: 캠페인 보드·콘텐츠 캘린더·광고 성과(퍼널·UTM)·자료(브랜드 자산)·SNS 게시 일정.
- 입장: 로그인 후 공간이 2개 이상이면 첫 화면에 공간 카드 선택, 상단 왼쪽 로고 옆 **공간 전환**(인스타 계정 전환처럼 아래에서 시트), 최근 공간 기억. 관리자 = 전체 공간, 직원 = 배정된 공간만, 공간 안에서 팀(V26) 단위.
- 디자인: 글꼴·크기·도형·컴포넌트 그대로, 공간별 **강조색·배경 톤만** 다르게(업무 초록 / 영업 파랑 / 마케팅 보라), 상단에 공간 이름 칩.
- 데이터: 업무·일정·메신저·자료실·알림은 공간 간 공유(업무에 공간 태그), 영업·마케팅 전용 기능은 해당 공간 메뉴에만.
- 주의: V26(팀·부서 구조)은 "지금 사이트 기능을 다르게 하지 말 것"으로 보류됐었음 → 이번에는 **기존 화면은 그대로 두고 공간을 추가하는 방식**(공간이 1개면 지금과 똑같이 보임).
- 순서: 설계 확정(대표 확인) → 공간 틀·전환 → 영업 공간 1차(문의·파이프라인·연락처·견적) → 마케팅 공간 1차.

## 8. 미팅 업무의 장소 (2026-10-17 대표 승인 — 업무에 장소 칸 대신 연결 일정)
- 업무에 장소 칸을 따로 만들지 않음(경쟁사도 할 일에는 장소 없음, 장소는 일정). 업무 상세·카드에 **[미팅 일정 만들기]**: 장소·시작/끝 시간 입력 → 장소 있는 일정 생성 + 업무와 연결(캘린더에는 블록 하나, V36-4 이동 강조·출발 권장·30분 전 알림 그대로).
- 음성·AI·빠른 등록에서 "미팅·방문·현장·실사·설명회" 등이 나오면 "미팅 일정도 만들까요? 장소:" 제안.
- 업무 카드·목록에 연결 일정의 📍장소·시간 표시(장소 한 번만 입력). 문의 업무 체크리스트 "미팅 일정" 단계에서 바로 [미팅 일정 만들기].
