# WORKIN V28 — 상업화 준비 묶음 (2026-10-15 대표 지시)

## 1. 업무마다 AI 비서 붙이기 (먼저)
대표: "업무를 진행할 때 올려진 파일이나 메일을 업무에서 바로 보낼 수 있게, 메일 제목·내용을 작성하는 AI 비서를 업무에 들어갈 때마다 붙여 달라."
- 업무 상세(휴대폰·PC) 안에 **"이 업무의 AI 비서"** 칸(접기 가능): 이 업무의 제목·설명·체크리스트·댓글·첨부(파일 글자)·문의 내용을 자동 문맥으로.
- 빠른 버튼: [메일 초안] [문자 초안] [카카오톡 초안] [요약] [다음 할 일 제안] + 자유 입력("견적서 첨부해서 관리소장님께 회신 써줘").
- [메일 초안] 결과는 V21 메일 시안 창으로 바로 넘어감(받는 사람·제목·본문·추천 첨부 채움) → 사람이 확인 후 [보내기]. 첨부는 업무에 올려진 파일 중 AI 가 고른 것 체크.
- 비용: 문서 요청 경로처럼 Haiku·짧은 문맥(업무 1건 범위), 사람별 한도 적용, 카드에 "약 N원".
- 대화 기록은 업무 단위로 저장(업무를 다시 열면 이어서).

## 2. 카카오톡 보내기
- **A(무료, 먼저)**: 카카오톡 공유 — 시안 확인 후 [카카오톡으로 보내기] → 휴대폰에서 카카오톡이 열리고 사람이 대화 상대를 골라 전송(카카오 공유 SDK, Kakao Developers 앱 키 필요 — 키 발급은 로컬·대표). PC 는 QR 로 휴대폰에 넘김. 문자 A 와 같은 "보냈어요" 확인 후 기록.
- **B(유료, 나중)**: 카카오 알림톡(비즈니스 채널 + 발송 대행사, 템플릿 사전 심사, 건당 약 수~십수 원) — 회사 채널 이름으로 자동·대량 발송. 대표 결정 후.

## 3. 슈퍼 계정(플랫폼 운영자) — 고객사 전체 관리
대표: "지금 계정(슈퍼 계정)으로 나머지 계정을 컨트롤할 수 있어야."
- /platform: **회사(테넌트) 목록**(가입일·요금제·상태·인원·저장·AI 사용·최근 접속·결제 상태), 검색·필터.
- 회사 상세: 요금제 변경·체험 연장·일시 정지/해제·읽기 전용 전환·삭제 예약(30일 유예, 실행은 2단계 확인), 인원·저장·AI 한도 개별 조정, 크레딧 지급.
- 사용자: 회사별 사용자 목록, 계정 잠금/해제, 비밀번호 재설정 메일 보내기(비밀번호를 직접 보거나 정하지 않음), 2단계 인증 초기화.
- **대리 접속(지원 모드)**: 고객 동의 체크가 있는 회사만, 읽기 전용 기본, 상단에 빨간 띠 "지원 모드 — OOO 회사", 모든 조회·변경 감사 로그, 30분 자동 종료.
- 전체 공지·점검 공지, 장애·오류 대시보드(기존 운영 상태), 매출(결제) 요약, AI 원가 전망(V23 5장) 연결.
- 플랫폼 운영자 권한은 대표 계정만(추가 지정은 2단계 확인).

## 4. 워크인 소개·다운로드 사이트
대표: "잔디는 앱 받기까지 오래 걸렸고 카카오워크는 바로 받을 수 있었다."
- 카카오워크 다운로드 페이지 구조(PC Win/Mac + iOS/Android 버튼 + **QR 코드**, 첫 사용 가이드 링크)를 기준으로, 첫 화면에서 **[무료로 시작] [앱 받기]** 두 버튼, 앱 받기는 휴대폰이면 스토어로 바로, PC 면 QR + 스토어 버튼.
- 페이지: 메인(기능 6개 시연 GIF·짧은 영상), 기능, 요금(V27 확정 후), 다운로드, 고객 사례(나중), 도움말/FAQ, 문의, 개인정보처리방침·이용약관·**계정 삭제 안내**(Play 필수).
- 정식 도메인(대표 결정 필요 — 예: workin.kr / getworkin.com 등 구매는 대표 승인), Vercel 별도 프로젝트 또는 지금 앱의 /welcome 확장. SEO·OG 이미지·네이버/구글 검색 등록, UTM(마케팅 운영실 기획안 기준).
- 지금 /welcome 은 앱 안 소개 페이지 → 정식 사이트로 분리하고 앱은 app.도메인.

## 5. Android 정식 출시(갤럭시 포함) — Play Console 현황(로컬 확인)
- 앱: "다짐 업무일정"(kr.co.dagym.workos), 내부 테스트만, **프로덕션 비활성**, 앱 설정 미완료.
- 출시 전 필수(Play Console "앱 설정"): 개인정보처리방침 URL, 로그인 세부정보(심사용 체험 계정 — DEMO_LOGIN 있음), 광고 여부, 콘텐츠 등급 설문, 타겟층, **데이터 보안 양식**, 정부 앱·금융·건강 여부, 카테고리·연락처, 스토어 등록정보(앱 이름 "워크인", 짧은/긴 설명, 아이콘 512, 그래픽 이미지 1024×500, 휴대폰 스크린샷 2~8장, 태블릿 선택).
- 클라우드 할 일: 계정 삭제 요청 페이지(웹 URL, 앱 안 탈퇴 경로), 개인정보처리방침에 앱 권한(마이크·카메라·알림·정확한 알람) 사용 목적 반영, 앱 내 "탈퇴" 기능 확인, 스토어용 스크린샷 자동 생성 스크립트(휴대폰 크기 6장: 홈·업무·캘린더·음성 등록·AI 비서·메신저, 데모 데이터).
- 로컬 할 일: 스토어 등록정보·설문 초안 작성 → 대표 확인 → 입력, 앱 이름 변경, 정식 버전 AAB(서명) 업로드, **[검토를 위해 전송]은 대표 승인 후**.
- 갤럭시: Play 스토어로 갤럭시 기기 모두 설치 가능(지원 기기 1.2만+ 확인). 갤럭시 스토어 별도 등록은 선택(판매자 가입·심사 별도).
- iOS: TestFlight → App Store 심사도 같은 자료로 이어서(대표 승인).
