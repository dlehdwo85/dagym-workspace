# 워크인 10차(설계) — 회사별 저장공간·AI 사용량 계량과 요금제 (대표 지시 2026-10-14, 상용화 대비)

> 대표: "회사별 저장공간은 어디서 확인? 늘리고 싶으면 저장공간별 요금제를 만들어 진행 — 요금제를 구축해 봐 달라."
> 지금 단계: **계량·한도·요금제 화면까지 구축**(결제 연동 없이 "관리자가 요금제 지정"). 실제 결제(토스페이먼츠 등)는 사업자 계약 후 별도.
> 9차(자료실·AI·R2 어댑터)와 같은 기반 위에서. 기존 조직 격리 유지.

## 1. 계량(사용량 기록)
- 테넌트 = 최상위 조직(회사). `tenant_usage`(추가형): 저장 바이트(파일 올릴 때 +, 영구 삭제 때 −, 휴지통 파일 포함), 이번 달 AI 요청 수·토큰, 활성 사용자 수.
- 매일 정기 실행에서 저장소 실제 합계와 대조(어긋나면 보정 로그).

## 2. 확인 위치
- **회사 관리자**: 관리 → **"사용량·요금제"** — 저장공간 막대(3.2GB / 10GB), 파일 종류별(사진·문서·기타)·큰 파일 TOP 20(바로 정리), 이번 달 AI 사용(312/500회), 사용자 수, 현재 요금제·다음 갱신일, "요금제 변경 요청".
- **플랫폼 운영자(우리)**: `/platform`(대표 전용, 플랫폼 관리자 권한 신설) — 모든 회사 사용량·요금제·한도 초과 목록, 요금제 지정·추가 용량 부여.
- 80%·100% 도달 시 회사 관리자에게 알림.

## 3. 요금제(초안 — 숫자는 설정값, 대표 확정 전)
원가 근거: 저장 R2 GB당 월 약 20원(내려받기 무료), AI 요청 1회 약 5~40원(작업 크기에 따라), 서버·DB 고정비.
| 요금제 | 월 요금(회사당, VAT 별도) | 사용자 | 저장공간 | AI 요청/월 | 비고 |
|---|---|---|---|---|---|
| 무료 | 0원 | 5명 | 2GB | 30회 | 체험·소규모 |
| 스탠다드 | 29,000원 | 20명 | 50GB | 500회 | 일반 사무실 |
| 비즈니스 | 79,000원 | 50명 | 200GB | 1,500회 | 지점 여러 곳 |
| 엔터프라이즈 | 별도 협의 | 무제한 | 1TB~ | 협의 | 전용 지원 |
- **추가 옵션**: 저장공간 +50GB 월 5,000원, AI +500회 월 10,000원, 사용자 +10명 월 10,000원.
- 연 결제 2개월 할인(선택).
- 한도 초과 시: 저장 → 새 파일 올리기 막고 안내(기존 파일 보기·내려받기는 계속), AI → 다음 달까지 사용 중지 안내, 사용자 → 초대 막기. **업무·일정 등 핵심 기능은 절대 막지 않음.**

## 4. 데이터
- `plans`(코드·이름·월 요금·한도 JSON), `tenant_subscriptions`(회사·요금제·추가 옵션·기간·상태), `tenant_usage`. 요금제 숫자는 DB/설정에서 변경(배포 없이).
- 우리 회사(다짐·하이링크)는 "내부" 요금제(무제한) 지정.

## 5. 나중(결제 연동 단계, 별도 명세)
- 토스페이먼츠/포트원 정기결제, 세금계산서, 결제 실패 유예 7일, 해지·환불 규정, 약관·개인정보 처리방침.
