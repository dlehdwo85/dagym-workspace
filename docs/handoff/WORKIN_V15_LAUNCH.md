# 워크인 15차 — 1주일 공개 출시(베타) 준비 (대표 지시 2026-10-14, 목표 2026-10-21)

> 대표: "개인도 쓸 수 있게, 진입장벽은 낮게, 금액은 나중에 올려도 됨. 1주일 이내 상업화."
> 로컬 판단: 1주일 = **공개 베타(무료 가입 + 유료 결제는 '사전 신청')**. 실결제(PG 계약·심사 1~3주)·앱스토어 정식 출시(심사 수일~2주)는 병행 진행, 막히면 웹(PWA)으로 먼저 출시.

## 요금 구조(출시용)
| 요금제 | 가격 | 대상 |
|---|---|---|
| 개인 | **무료** | 1명, 업무·일정·알림·캘린더 전부, 저장 1GB, AI 월 20회 |
| 팀 무료 | 무료 | 5명까지(팀 기능·메신저), 회사 저장 2GB, AI 월 30회 |
| 팀 | 1인 월 3,900원(베타 기간 50% 할인 표기, 실제 과금은 결제 오픈 후) | 인원 무제한, 1인 3GB, AI 1인 월 50회 |
| 팩 | 저장·AI 추가(기존 2안 팩) | |
- 개인 → 팀 전환: 개인 공간에서 "팀 만들기"로 업그레이드(데이터 이전).

## 클라우드 몫(우선순위 순, 1주일)
1. **공개 가입**(`/signup`): 이메일+비밀번호, 이메일 인증, 봇 방지(시도 제한·허니팟), "개인으로 시작 / 팀(회사)으로 시작". Google 로그인(선택, 다음).
2. **개인 공간**: 1인 조직 자동 생성, 관리 메뉴 숨김, 업무·캘린더·알림·AI·자료실만. 지시자=본인.
3. **온보딩**: 첫 로그인 3단계(이름·직책 → 첫 업무 만들기(예시 3개 채워 줌) → 휴대폰 앱/알림 켜기), 빈 화면 안내.
4. **랜딩 페이지**(`/` 비로그인): 한 줄 가치("업무·일정·알림을 한 곳에, 말로 등록하고 정확한 시간에 알림"), 화면 캡처 3장, 요금표, "무료로 시작".
5. **법적 페이지**: 이용약관·개인정보 처리방침·위치기반 미사용 고지·AI 이용 고지 — 초안 작성(사업자 정보 칸은 대표 입력용 자리표시자), 가입 시 동의(필수/선택 분리).
6. **계정 관리**: 비밀번호 재설정(이미 있음 확인), 회원 탈퇴·데이터 내보내기(개인정보 보호법), 회사 삭제.
7. **결제 '사전 신청'**: 사용량·요금제 화면에 "팀 요금제 신청" → 플랫폼 운영 화면 접수(실결제 연동은 PG 계약 후).
8. **운영 안전**: 가입 남용 방지(조직당·IP당 생성 제한), 플랫폼 운영 화면에 신규 가입 목록·차단, 오류 알림(서버 오류 시 대표 메일/푸시).
9. **데이터 백업 확인**: Neon 시점 복구(PITR) 설정 상태 기록, 일일 내보내기.
