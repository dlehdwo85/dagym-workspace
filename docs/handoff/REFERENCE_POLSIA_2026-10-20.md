## 1. 정체
- Polsia Inc.(샌프란시스코, 2025년 창업, 1인 창업자 Ben Cera). 구호 "AI That Runs Your Company While You Sleep".
- **AI 에이전트가 회사를 대신 운영**: 계획·코드·광고·고객 응대·메일·SNS 를 밤마다 자동으로 수행. 1인 창업자·소규모 사업자 대상. 웹 + iOS 앱.
- 요금: Standard $20/월(20크레딧·회사 1개) / Pro $50(50크레딧·회사 3개·Meta 광고) / Max $100~200(100~200크레딧·회사 10개·우선 지원). 1크레딧 = 에이전트 작업 1번. 매출의 3%(결제)·광고비의 20% 수수료.

## 2. 워크인이 가져올 UX 패턴 (중요도 순)
| # | Polsia 패턴 | 워크인 적용안 | 비고 |
|---|---|---|---|
| 1 | **회사와 채팅** — 화면 어디서나 "회사에게" 묻고 시키면 태스크가 됨 | AI 비서를 '회사 채팅'으로 격상: 홈 맨 위 입력창 하나("무엇이든 시키세요"), 답이 곧 업무·일정·시안 카드로 | 지금 AI 비서는 메뉴 안에 있음 → 홈 상단 상시 노출 |
| 2 | **Tasks 큐: queued / running / done** + [Run Now] | AI 가 제안·실행하는 일을 '대기 → 실행 중 → 완료' 큐로 보여 주고, 대표가 [지금 실행]/[밤에] 선택 | 자동 제작·광고 개선안·자료 정리·문자 시안에 공통 큐 |
| 3 | **야간 자율 주기(Night Tasks)** — 밤마다 다음 할 일을 스스로 계획·실행, 크레딧 안에서 | '밤사이 비서': 22시 이후 승인된 범위(원고 초안·리드 다음 연락 제안·입찰 요약·보고서 초안)를 돌리고 **아침 브리핑에 결과 카드**로 | 돈·외부 발송은 절대 자동 아님(V19 원칙 유지) |
| 4 | **New tasks 버튼 — 회사 상황 보고 다음 단계 5개 제안** | 홈에 [다음 할 일 제안] : 지난 업무·리드·승인 대기·광고 성과를 보고 5개 제안 → 체크해서 업무로 | 기존 '홈 디벨롭'과 합침 |
| 5 | **대시보드 위젯 편집**(Tasks·Ads·Website·Email·Teams… 켜고 끄기) | 홈 카드 켜기/끄기·순서 바꾸기(회사별·사람별) | 마케팅 홈 디벨롭에 반영 |
| 6 | **크레딧 = 작업 1번** 단순 과금 | V45/V46 크레딧 설계와 같은 방향 — 화면에 "이번 달 남은 작업 n번" | 이미 설계 중 |
| 7 | **광고 위젯**: 상태·일일 예산·일별 지출·소재별 CTR/CPC | V44 광고 운영실 홈 카드로 동일 구성 | |
| 8 | 공개 회사 대시보드(기본 켬, 검색 노출) | 워크인은 **기본 비공개**. 필요 시 '고객용 진행 현황 공유 링크'만 | 보안 원칙 |

## 3. 가져오지 않을 것
- 사람 승인 없는 외부 집행(광고·메일 발송·코드 배포 자동) — 워크인은 "AI 는 초안·제안, 실행은 사람" 원칙.
- 매출 수수료 과금, 공개 대시보드 기본 켬.

## 4. 클라우드 설계 요청 요약
- 홈 = ① 회사 채팅 입력창 ② 오늘 할 일/이번 주 ③ AI 작업 큐(대기·실행 중·완료, [지금 실행]) ④ [다음 할 일 제안] ⑤ 카드 편집. 밤사이 비서 = 설정에서 범위 체크(기본: 원고 초안·리드 제안·입찰 요약·보고 초안) + 아침 브리핑 결과 카드.
