# 워크인 9차(설계) — 내장 AI 비서·회사 자료실, 상용화 대비 (대표 방향 2026-10-14)

> 대표: "A(워크인 안의 Claude 비서)로. 우리 회사가 먼저 쓰고 **상업화해 판매도 할 계획** → 외부 연결을 최대한 없애 편리하게, 향후 계획 고려해 개발."
> **비용·가입 승인 전**: 기능은 환경변수가 있을 때만 켜지게(없으면 메뉴 숨김) 구현해 두고, 키 등록은 대표 승인 후 로컬이 안내.

## 원칙 (상용화 기준)
- 고객 회사가 **ChatGPT·구글 드라이브·개인 구독 등 외부 계정을 연결하지 않아도** 모든 기능 사용. AI·파일 저장은 **워크인 플랫폼이 제공**(우리 계정의 API 키·저장소), 고객별로 사용량 집계·한도.
- **Claude Code 구독(Max)은 사람 1명의 개발 도구용** — 제품 기능(남의 회사 요청 처리)에 쓰면 이용약관 문제. 제품 AI 는 **Anthropic API(종량제)** 로. (Max 요금에는 API 사용량이 포함되지 않음 → 별도 청구.)
- 공급자 교체 가능 구조: `src/lib/ai/` 에 공급자 어댑터(Anthropic 기본, OpenAI 선택), 모델명 환경변수.
- 저장소도 어댑터: S3 호환(R2 등) — 플랫폼 계정 1개로 모든 고객 회사 파일, 키 경로에 조직 id, 조직별 용량 한도.
- 멀티 테넌트: 이미 있는 조직 격리(access.ts, 다른 조직 404) 유지, AI 도구는 **요청한 사람 권한으로만** 데이터 접근.

## 기능
1. **회사 자료실**: 사이드바 "자료실" — 폴더·파일 올리기(로고·소개서·단가표·보고서), 태그, 검색. 업무/일정 첨부와 같은 저장소. (첫 단계: 지금 ChatGPT 프로젝트 자료를 대표가 한 번 올림)
2. **AI 비서**(업무 상세·홈의 "✨ AI에게 요청" 칸, 음성 입력 연동):
   - 도구(tool use): 자료실 검색·파일 첨부, 업무 만들기/수정(사람 확인 후), 일정 조회, 매출 데이터 조회·집계, 엑셀/문서 생성(서버에서 xlsx·md→pdf), 댓글 작성.
   - 예: "다짐 로고 불러와줘" → 자료실 검색 → 후보 썸네일 → 선택하면 업무에 첨부. "3분기 매출 분석해서 올려줘" → 매출 집계 + 비교 + 표·요약 → xlsx/보고서 업무 첨부 + 요약 댓글.
   - 모든 AI 행동은 "AI 제안"으로 표시, 쓰기 작업은 확인 버튼, 감사 로그·조직별 토큰 사용량 기록, 월 한도(초과 시 안내).
3. **문서 검색(RAG)**: 자료실 텍스트(PDF·문서·엑셀) 추출 → Postgres 전문 검색(+선택: pgvector) — 외부 벡터 DB 없이.
4. 기존 GPT Custom Action(매출 입력 경로)은 유지하되 선택 기능으로.

## 필요한 승인(로컬이 대표에게)
- Anthropic API 계정·결제 등록 → `ANTHROPIC_API_KEY`(Vercel 에 대표가 붙여넣기). 예상: 요청 1회 수 원~수십 원(Haiku/Sonnet 혼용).
- 파일 저장소(R2 무료 10GB, 결제수단 등록) — 플랫폼용 계정.
- 상용화 단계(나중): 결제·구독 관리, 고객 회사 가입 흐름, 약관·개인정보 처리방침, 회사별 도메인 — 별도 명세.
