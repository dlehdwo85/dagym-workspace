# 업무 상세(휴대폰) 칸 구분·정렬 정리 (대표 신고 2026-10-13 19:00, 삼성 앱)

캡처: `local-screens/52-app-task-detail-fields.jpg` — 대표: "칸 구분이 잘 안 되어 보임".

## 보이는 문제
1. **상단 겹침**: 상세 화면 머리(링크·크게 보기·닫기 아이콘)와 "완료됨" 안내(토스트)가 **상태바(시계·배터리) 위에 겹침**. 7884d83 에서 AppShell 머리줄만 안전 영역을 적용했고 상세 패널(전체 화면 시트)·토스트는 빠짐 → `--safe-area-inset-top` 를 상세 시트 머리, 토스트 위치, 모든 전체 화면 모달에 적용.
2. **마감일 칸이 깨짐**: 값 없이 꺾쇠(⌄) 2개와 달력 아이콘만 엉뚱한 위치에 떠 있음(빈 날짜·시간 select). → "마감일 없음" 칩 하나로 표시, 누르면 달력 팝업(V4 와 같은 DuePicker), 시간은 선택 후에만 표시.
3. **칸 구분·정렬**: 이름표(담당자·지시자·마감일·프로젝트·캘린더에 표시) 열 너비가 달라 값 시작 위치가 제각각(아바타 290px, "없음" 320px), "캘린더에 표시"가 두 줄로 꺾임, 행 사이 구분선 없음.
   - 요청: Asana 상세처럼 **2열 표**: 이름표 열 고정 폭(96px, 한 줄, 회색 13px) + 값 열, **행마다 얇은 구분선**과 최소 높이 48px, 값은 모두 같은 x 에서 시작, 누를 수 있는 값은 옅은 테두리/hover 배경. "캘린더에 표시" → "캘린더 표시"(한 줄) + 토글 스위치.
4. **상태 중복**: "● 완료" 배지 + "다시 진행" + "완료" select 가 한 줄에 셋 → 상태 칩 하나(누르면 할 일·진행 중·검토·보류·완료 메뉴) + 완료일 때만 "다시 진행" 버튼.
5. 설명 칸·하위 업무·댓글 사이도 구획(제목 + 구분선) 정리, 하단 탭과 "하위 업무 + 추가" 겹침 없게 아래 여백.
