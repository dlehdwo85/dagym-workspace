# 워크인 8차 — 발전 기능 7가지 (대표 지시 2026-10-14: "모두 추가")

웹 코드만(앱 새 빌드 없이, 음성은 웹 API). 클라우드. 7차(WORKIN_V7) 먼저 끝낸 뒤, 기능별로 묶어 **최대 2커밋**(Vercel 한도). 이미 있는 기반(멘션·첨부·공휴일·템플릿·주간 보고 API)은 **새로 만들지 말고 확인·보완**.

## 1. 아침 브리핑 알림
- 매일 **08:30(Asia/Seoul, 설정에서 시각 변경·끄기)** 사용자별 푸시 1건: "오늘 할 일 3건(기한 지남 1) · 일정 2건 — 첫 일정 10:00 본사 회의". 누르면 홈.
- 정기 실행(tick)에서 하루 1회 dedupe(`briefing:{user}:{date}`), 할 일·일정 0건이면 보내지 않음. 주말·공휴일 끄기 옵션(기본 끔=보내지 않음).

## 2. 주간 보고 자동 초안
- 매주 **금요일 16:00** 사용자별 "이번 주 보고" 초안 자동 작성: 완료 업무(프로젝트별), 진행 중·지연 업무(사유 칸 비움), 다음 주 마감 업무, 이번 주 참석 일정 요약. 기존 주간 보고 화면에 "초안" 표시 → 본인이 고쳐서 제출. 대표는 3명 보고를 한 화면에서.
- AI 문장 다듬기는 OPENAI_API_KEY 있을 때만(선택), 없으면 목록형.

## 3. 업무 템플릿
- 기존 `templates` 확인 후 보완: "현장 점검", "입찰 준비", "견적서 발송" 같은 템플릿 = 제목 패턴·체크리스트(하위 업무)·기본 담당자/지시자·마감 오프셋(D-3 등)·우선순위.
- 업무 등록 시트 상단 "템플릿에서 만들기", 기존 업무 상세 "⋯ → 템플릿으로 저장". 본사 공용/개인 템플릿.

## 4. 음성으로 업무 추가
- 업무 등록 시트·한 줄 추가에 🎤 버튼: Web Speech API(`ko-KR`)로 받아쓰기 → 문장에서 **날짜·시간·담당자 이름** 인식("내일 3시 김민수 견적서 보내기" → 제목 "견적서 보내기", 마감 내일 15:00, 담당 김민수), 확인 후 저장 버튼.
- WebView 에서 마이크 권한: Android WebView 는 `onPermissionRequest` 필요할 수 있음 → **안 되면 키보드 마이크(삼성/구글 키보드 음성 입력) 안내로 대체**하고, 자연어 날짜 해석은 텍스트 입력에도 적용("다음주 월 오전10시"). 네이티브 설정이 필요하면 로컬에 요청(앱 빌드).

## 5. 사진·파일 첨부 강화
- 기존 `attachments` 확인: 업무 상세에서 **카메라로 바로 촬영**(`<input capture="environment">`), 여러 장 한 번에, 업로드 전 자동 축소(긴 변 1600px), 썸네일 격자, 누르면 크게 보기. 댓글에도 사진.
- ⚠ health `fileStorage: local-disk` — Vercel 은 파일이 사라질 수 있음 → 운영 저장소(Vercel Blob 무료 한도 또는 Neon 외 저장소) 확인 후 NEXT_ACTION 에 결정 필요 사항 기록(비용 발생 시 대표 승인).

## 6. 공휴일·연차·외근 표시
- 기존 `holidays` 확인: 캘린더·홈 이번 주에 **공휴일 빨간 표시**(대체공휴일 포함).
- 일정 종류에 **연차·반차·외근·출장** 추가(색은 7차 개인/회사 규칙 안에서 작은 꼬리표로 구분), 본사 모두에게 보이는 "부재" 표시 → 업무 배정 시 담당자가 그날 연차면 경고.

## 7. 댓글 @멘션 알림
- 기존 mention 처리 확인: 댓글 입력에서 `@` → 본사 사람 목록 자동완성, 저장 시 멘션된 사람에게 앱 알림+푸시("이동재님이 댓글에서 회원님을 언급했습니다: …"), 누르면 그 업무의 댓글 위치로. 일정 메모에도 동일.

## 공통 완료 기준
- 각 기능 API 시험 + 휴대폰 360px E2E 캡처 docs/screens, NEXT_ACTION 에 기능별 사용법 3줄(직원 안내용 → 로컬이 사용 안내 문서에 반영).

## 8. 미리 알림 — 기본 시간 + 항목별 지정 (대표 지시 2026-10-14)
- 대표: "업무나 일정이 가까워졌을 때 몇 분 전에 알람이 가도록. 기본 시간을 정하고 알람 오는 시간을 정할 수 있게."
- **기본값(로컬 제안, Google Calendar 기본 10분 참고)**:
  - 일정: **10분 전**
  - 시간 있는 업무: **1시간 전**
  - 날짜만 있는 업무: **당일 09:00**(기존 오늘 마감 알림)
  - 연차·종일 일정: 전날 18:00
- **설정 → 알림**에서 사용자별 기본값 변경(정시·5·10·15·30분·1시간·2시간·1일 전, 여러 개 선택 가능, "끄기").
- **항목별 지정**: 일정·업무 등록 시트와 상세에 "🔔 10분 전" 칩 → 눌러 여러 개 추가/삭제(최대 3개). 지정 안 하면 기본값 따름. 연결된 일정↔업무는 같은 알림 공유(중복 발송 금지).
- 발송: 정기 실행(tick) 정확도가 분 단위가 아니므로 **알림 예정 시각 기준 발송 큐**(next_attempt_at) 사용, tick 주기 확인(GitHub 10분 + 요청 편승 + Vercel 일 1회 → 오차 최대 10분이면 "10분 전" 의미가 없음) → **Vercel Cron 무료는 일 1회뿐**이라, 분 단위 정확도가 필요하면 대안(외부 무료 크론 1분 호출, CRON_SECRET 사용) 비교·제안 기록 — 외부 서비스 가입은 대표 확인.
- 푸시 문구: "10분 후 · 본사 회의 (오후 2:00)", "1시간 후 마감 · 견적서 보내기". 누르면 해당 화면.

## 9. 업무를 만든 뒤 다시 들어가 세부 설정하는 번거로움 해결 (대표 지시)
- **등록 시트 한 번에 끝내기**: 제목 아래 칩 한 줄에 **마감(날짜+시간) · 담당자(여러 명) · 지시자 · 우선순위 · 반복 · 🔔 알림 · 프로젝트**를 모두 배치(가로 스크롤 없이 2줄로 감김), 누르면 바로 아래에서 선택. "설명·하위 업무·첨부" 는 "더 입력 ▾" 펼침. 저장 1번으로 끝.
- **제목에 바로 쓰면 자동 인식**(Todoist/Asana 방식): "내일 3시 견적서 보내기 @김민수 !높음 #입찰 매주" → 마감 내일 15:00, 담당 김민수, 우선순위 높음, 프로젝트 입찰, 반복 매주. 인식된 부분은 칩으로 바뀌고 제목에서 빠짐(되돌리기 가능).
- **마지막 설정 기억**: 직전에 고른 지시자·프로젝트·알림을 다음 등록 기본값으로(사용자별), "기본값으로 저장" 체크.
- **템플릿(8차 3번)** 에서 시작하면 세부값 전부 채워진 상태.
- 한 줄 추가(목록 끝)도 같은 칩·자동 인식 적용, 저장 버튼 유지.
