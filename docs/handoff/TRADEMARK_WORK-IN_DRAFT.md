## 2. 출원안
- 표장: **"워크인 WORK-IN"**(한글+영문 결합 문자상표) 1건 + 필요 시 로고(아이콘 B) 결합상표 별도.
- 출원인: 상표권은 법인 명의 — **주식회사 다짐**(하이링크는 지점이라 별도 권리주체 아님. 하이링크가 별도 법인이면 그 법인) → 대표 확인.
- 지정 분류·상품(예시):
  - 09류: 업무관리용 컴퓨터 소프트웨어, 일정관리용 응용소프트웨어, 스마트폰용 업무관리 애플리케이션, 내려받기 가능한 클라우드 기반 소프트웨어
  - 42류: 서비스형 소프트웨어(SaaS)업, 업무관리 플랫폼 제공업, 클라우드 컴퓨팅 서비스업, 인공지능 기반 소프트웨어 제공업
  - 35류: 사업관리 지원업, 업무 일정 관리 대행업(선택)
  - 38류: 온라인 메시지 전송업(메신저 — 선택)
