## 0. 휴대폰 "서버 오류가 발생했습니다" 원인 (확인 완료)
- 휴대폰이 접속한 곳은 로컬 PC 가 아니라 **Vercel 운영 배포 `https://dagym-workspace.vercel.app`** (GitHub `main` 이 Production 으로 자동 배포 중, 최근 커밋 995c4ac).
- `GET /api/health` → `503 {"ok":false,"db":"error","error":"DATABASE_URL 이 설정되지 않았습니다"}`. 로그인 API 가 DB 에 닿지 못해 500 → 화면 문구 "서버 오류가 발생했습니다".
- 해결: HANDOFF L-1·L-2 (운영 DB 생성, Vercel 환경 변수 `DATABASE_URL`·`APP_SECRET`·`APP_URL`·`SETUP_SECRET`, 마이그레이션, `/setup` 대표 계정 생성). **대표 승인·로그인 필요 — 로컬이 대기 중.**
- 클라우드 요청: DB 미설정일 때 로그인 화면에 "운영 설정이 끝나지 않았습니다(관리자 문의)" 처럼 원인을 보여 줄 것(현재는 일반 500 문구). `/api/health` 503 이면 로그인 화면 상단 안내.

## 1. 지금 일정과 업무가 묶여 있는가 — 검수 결과
| 연결 | 상태 | 확인 |
|---|---|---|
| 업무 마감일이 캘린더에 표시 | ✅ | 주 보기 종일 칸에 점선 칩 |
| 캘린더에서 업무 마감 끌어서 변경 → 업무에 반영 | ✅ | 기존 E2E |
| 업무 → "실행 시간 배정" → 캘린더 일정(task_block) 생성 | ✅ | 10:00~11:30 배정 → 주 보기 표시 |
| 업무 상세에 배정된 실행 시간 목록·캘린더 링크 | ✅ | `TaskDetail.tsx` "배정된 실행 시간" |
| **캘린더 일정 → 연결 업무로 이동** | ❌ | 업무 시간 블록 미리보기에 업무 링크·상태·완료 버튼 없음 (`/tasks/` 링크 0개) |
| **일정(회의)에서 업무 만들기 / 기존 업무 연결** | ❌ | 회의 미리보기·편집에 업무 관련 기능 없음. 일정–업무는 1:1(`events.task_id`)만 |
| 실행 시간 기본 캘린더 | ⚠ | 대표가 이직원 업무에 배정해도 기본값이 **대표 개인 일정**. 담당자 일정·참석자 지정 없음 |
| 업무 시간 블록 제목 | 🐞 | `[업무 시간] [업무] [로컬검수] …` 접두어 중복 (캘린더 칸), 미리보기는 `[업무] …` |
| 시간 표기 | 🐞 | 미리보기 `오후 02:00 ~ 15:00` (12시간·24시간 혼용) |
| 회의 미리보기 정보 | ⚠ | 참석자·장소·설명·연결 업무 없음 |
| 업무량에 일정 반영 | ❌ | 담당자별 업무량은 업무 수만, 회의·휴가 시간 미반영 |

**결론: 업무 → 일정 한 방향만 일부 연결.** 일정 → 업무, 회의 중심 업무 흐름, 시간 기반 계획은 아직 없음. 기업용 도구(Asana·Google Calendar·Monday·ClickUp·Notion·Microsoft Planner/Outlook·플로우·두레이) 수준을 넘으려면 아래가 필요.

## 2. 개발 명세 — 일정 × 업무 통합 (우선순위)
### S-P0 (양방향 연결 완성)
| ID | 과제 | 완료 기준 |
|---|---|---|
| S-1 | **일정–업무 N:M 연결** (`event_tasks` 표, 추가형 마이그레이션). 일정 편집·미리보기에 "연결 업무" 목록(상태 배지·담당자·DueChip), "+ 기존 업무 연결", "+ 새 업무 만들기" | 권한 밖 업무는 연결·표시 불가(404 규칙), API·E2E |
| S-2 | **회의 → 후속 업무** — 일정 상세에 "회의 메모"(서식 텍스트) + 줄마다 "업무로 만들기"(담당=참석자 선택, 마감 기본 회의일+3일, 소속=일정 캘린더 조직). 만든 업무는 자동 연결 | E2E: 회의 메모 2줄 → 업무 2건, 담당자 알림 |
| S-3 | **업무 시간 블록 개선** — 기본 캘린더=담당자 개인 일정(권한 있을 때), 담당자 자동 참석, 제목 접두어 중복 제거(아이콘으로 구분), 미리보기에 업무 링크·상태·"완료" 버튼, 블록에서 완료하면 업무 상태 반영 | E2E |
| S-4 | 미리보기·목록 시간 표기 통일(`오후 2:00~3:00`), 회의 미리보기에 참석자 아바타·장소·연결 업무 수 | 화면 검수 |

### S-P1 (시간 기반 계획 — Asana·Google Calendar 에 없는 수준)
| ID | 과제 | 비고 |
|---|---|---|
| S-5 | **통합 "오늘·이번 주" 화면** — 왼쪽: 내 업무(마감 순, 미배정 시간 표시) / 오른쪽: 내 일정 시간표. 업무를 시간표 빈칸으로 **끌어 놓으면 실행 시간 배정**. 회의 사이 빈 시간을 "집중 가능 2시간"처럼 표시 | 캘린더 주 보기에도 "미배정 업무" 옆 패널 |
| S-6 | **예상 소요 시간**(업무 필드, 분 단위) → 배정된 시간 합계와 비교해 "2h 중 1.5h 배정", 마감까지 가용 시간 < 남은 예상 시간이면 **마감 위험** 배지·관리자 알림 | 업무 목록·대시보드에 위험 필터 |
| S-7 | **사람별 가용 시간·업무량** — 회의·업무 블록·휴가·출장을 합산. 업무 배정 시 "이날 회의 5시간, 남은 가용 1시간" 경고, 관리자용 주간 업무량 히트맵 | 현재 업무 수 기준 업무량 대체 |
| S-8 | **일정 준비 업무 자동 생성** — 일정 종류/템플릿(GX 개강, 현장 점검, 계약 미팅)에 "준비 업무" 규칙(D-7 공지, D-1 장비 확인) → 일정 생성 시 업무 자동 생성·연결, 일정 날짜가 바뀌면 준비 업무 마감도 따라 이동 | 자동화 규칙(B-10)과 연결 |
| S-9 | **반복 회의 ↔ 반복 업무** — 매주 회의마다 "주간 보고 작성(회의 1일 전 마감)" 업무 자동 생성, 회의 취소 시 해당 회차 업무도 취소 | |
| S-10 | **일정 알림에 업무 맥락** — "10분 후 주간 회의 · 연결 업무 3건 중 1건 지연" | 앱 푸시 본문 |

### S-P2 (기업 운영 수준)
| ID | 과제 |
|---|---|
| S-11 | 개인 휴대폰 기본 캘린더에서 우리 일정 보기 — **읽기 전용 ICS 구독 주소**(사용자별 비밀 토큰, 재발급 가능). Google 동기화와 무관한 표준 방식, 기본 꺼짐 |
