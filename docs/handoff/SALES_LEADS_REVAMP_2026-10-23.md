# 거래처·리드 DB 목록 전면 개편안 (2026-10-23, 로컬 → 클라우드 #461)

대표 요청(10/23): "거래처 리드 관리 DB 목록을 전면 개편합니다. 관리 방안을 세워주고 정렬이나 DB들 관리 등 가독성 좋게 확인하면서 놓치는 거래처가 없을 수 있도록 개편해주세요."
같이 온 요청: #459(대상아님·반려가 목록에 바로 보이게), #460(완료할 때 다음 연락일 → 그날 자동 업무, 업무 기록이 거래처 이력에 공유).
참고 화면: 세일즈맵·HubSpot·Pipedrive·리멤버 CRM의 공통 패턴(목록 + 저장된 보기 + 다음 행동 중심). 업종 중립(상업화 원칙): 문구에 우리 업종 용어를 넣지 않고 회사 설정의 단계명·분류를 쓴다.

## 1. 관리 원칙 — "모든 거래처는 다음 행동이 있거나, 종결 사유가 있다"
- **다음 행동(다음 연락일 + 할 일)이 없는 진행 중 거래처 = '놓친 거래처'**로 본다. 목록 맨 위 경고와 매일 아침 알림에 띄운다.
- 단계를 바꾸거나 업무를 완료할 때 **다음 연락일 또는 종결 사유(성사·보류·대상아님·연락두절)** 중 하나를 반드시 고른다(#460).
- **모든 접점이 한 타임라인에** 쌓인다: 전화·문자·메일·미팅·업무 댓글·견적·계약·공고 연결. 사람이 따로 옮겨 적지 않는다.
- 담당자가 없는 거래처는 만들 수 없다. 기본값은 만든 사람이고, 영업 담당 규칙이 있으면 그 규칙을 따른다.

## 2. 목록 화면 구성
### 2-1. 상단 고정 '오늘 볼 것' 띠
`오늘 연락 n · 기한 지남 n · 다음 행동 없음 n · 14일 이상 접촉 없음 n · 새 리드(미배정) n`
각 숫자를 누르면 그 조건으로 목록이 걸러진다.

### 2-2. 저장된 보기(탭) — 기본 7개, 사용자가 추가·순서 변경
| 보기 | 조건 | 기본 정렬 |
|---|---|---|
| 내 거래처 | 담당 = 나, 진행 중 | 다음 연락일 빠른 순 |
| 오늘·지남 | 다음 연락일 ≤ 오늘 | 지난 일수 많은 순 |
| 다음 행동 없음 | 진행 중인데 다음 연락일 없음 | 마지막 접촉 오래된 순 |
| 새 리드 | 단계 = 신규, 최근 7일 | 들어온 순 |
| 전체 진행 중 | 종결 아님 | 단계 → 다음 연락일 |
| 종결 | 성사·보류·대상아님(반려)·연락두절 | 종결일 최근 순 — **대상아님·반려를 체크박스 없이 바로 보이는 탭으로**(#459) |
| 전체 | 모든 상태 | 최근 활동 순 |

### 2-3. 표(데스크톱) — 한 줄에 판단에 필요한 것만
| 열 | 내용 | 비고 |
|---|---|---|
| 거래처·담당자 | 회사명(굵게) + 연락 담당자·직함 | 아래 작은 글씨로 지역·분류 |
| 단계 | 칩(회사 설정 단계명·색) | 단계별 머문 일수 표시(예: 제안 12일) |
| 다음 행동 | 다음 연락일 + 할 일 한 줄 | 지나면 빨강, 오늘이면 주황, 비어 있으면 '⚠ 다음 행동 없음' |
| 마지막 접촉 | 3일 전 · 전화 | 아이콘(전화·문자·메일·미팅) |
| 예상 금액 | 연 계약액(선택) | 합계는 표 하단 |
| 출처 | 공고·리드 광고·전화 문의·소개·직접 | 공고에서 넘어온 건은 공고 링크 |
| 담당 | 아바타 | 미배정이면 '배정' 버튼 |

- 열 표시/숨김, 순서 변경, 너비 조절은 사용자별로 기억한다.
- 정렬은 모든 열 머리를 눌러 하고, 2차 정렬(Shift+클릭)도 지원한다.
- 묶어 보기: 단계별·담당자별·지역별·출처별(접고 펴기, 묶음마다 건수·금액 합계).
- 필터: 단계, 담당자, 지역, 출처, 분류, 금액 범위, 마지막 접촉(7/14/30/90일 이상), 다음 연락일 범위, 태그. 필터 조합은 보기로 저장한다.
- 검색은 회사명·담당자·전화·메일·메모를 한 칸에서 찾는다.
- 칸반 보기(단계 열)는 같은 데이터를 보여 준다. 끌어서 단계를 바꾸면 '다음 연락일 또는 종결 사유' 창이 뜬다.

### 2-4. 휴대폰
- 표 대신 카드로 보여 준다: 회사명 · 단계 칩 · 다음 행동(색) · 마지막 접촉, 오른쪽에 [전화][문자].
- 위 띠와 보기 탭은 가로로 밀어 넘긴다.
- 카드를 왼쪽으로 밀면 '다음 연락일 바꾸기', 오른쪽으로 밀면 '연락함 기록'.

## 3. 한 건 상세(오른쪽 패널) — 이동 없이 처리
1. **머리:** 회사명, 단계 칩(바꾸기), 담당, 다음 행동(바꾸기), 빠른 버튼 [전화][문자][메일][미팅 잡기][견적][업무 만들기].
2. **타임라인(전체 이력):** 전화 기록, 문자·메일 발송, 업무 생성·완료와 그 업무의 댓글·첨부(#460 양방향 링크), 단계 변경, 견적·계약, 연결된 공고. 종류별로 거를 수 있다.
3. **정보:** 담당자 여러 명(직함·연락처), 주소·지역, 분류, 규모(세대 수 등 회사 설정 필드), 태그, 메모.
4. **연결:** 관련 공고·낙찰 결과, 계약서(전자계약 #116), 견적, 매출.
5. 업무를 완료하면 바로 이 패널의 '다음 행동'을 묻고, 고른 날짜에 담당자 업무를 자동으로 만든다.

## 4. 놓침 방지 장치
- **매일 아침 알림(담당자):** 오늘 연락 n건, 지난 n건, 다음 행동 없음 n건. 관리자는 팀 전체를 본다.
- **자동 경고:** 진행 중인데 14일(설정 가능) 이상 접촉이 없으면 '오래 쉼' 표시를 붙이고 주간 보고에 넣는다.
- **신규 리드 SLA:** 리드 광고·전화 문의·웹 문의로 들어온 건은 5분 안에 첫 연락하도록 업무와 재알림을 보낸다(#454 리드 광고와 같은 규칙).
- **종결은 사유 필수:** '대상아님·반려'도 사유를 남긴다. 6개월 뒤 다시 볼 날짜를 고를 수 있다(재접촉 후보).
- **중복 방지:** 사업자번호·전화·회사명이 비슷하면 합치기를 제안한다. 공고에서 넘긴 건이 이미 거래처면 새로 만들지 않고 연결한다.

## 5. 일괄 작업·관리
- 여러 건을 골라 담당 변경, 단계 변경(사유 창), 다음 연락일 일괄 지정, 태그, 내보내기(CSV), 문자·메일 발송을 한 번에 한다.
- 가져오기: 엑셀·CSV 열 맞춤(미리보기 → 중복 표시 → 반영).
- 권한은 기존 영업 권한을 따른다(담당만 / 팀 / 전체). 다른 회사 데이터는 404.

## 6. 공고 → 영업 → 업무 → 2차 관리 흐름(#460 포함)
```
공고·DB 행 [영업 진행으로 넘기기] → 거래처(없으면 생성)·담당 지정 → 업무 자동 생성
 → 업무에서 미팅·자료 진행(댓글·첨부가 거래처 타임라인에 자동 공유)
 → 업무 [완료] → "다음 연락일 / 종결 사유" 선택 필수
   → 다음 연락일: 그날 담당자 업무 자동 생성(제목: '[2차] 회사명 — 할 일')
   → 종결: 사유 저장, '종결' 탭으로 이동(대상아님·반려 포함, 바로 보임)
```

## 7. 구현 순서 제안
1. 데이터: `next_action_at`, `next_action_note`, `closed_reason`, `last_contact_at`을 추가형으로 넣고 기존 활동 로그를 이어 붙인다.
2. 목록: 보기 탭 7개, 오늘 볼 것 띠, 표 열, 정렬·필터·저장된 보기. 반려 탭이 들어가면 #459는 끝.
3. 완료 → 다음 행동 강제와 자동 업무 생성, 업무 ↔ 거래처 타임라인 연결(#460).
4. 상세 패널 타임라인 통합.
5. 알림(아침·오래 쉼·SLA)과 주간 보고 연동.
6. 휴대폰 카드·밀기 동작, 칸반 끌기와 사유 창.
7. 일괄 작업·가져오기·중복 합치기.

## 8. 시험 기준
- **놓친 거래처:** 진행 중 거래처 10건 중 다음 연락일 없는 3건이 '다음 행동 없음' 보기와 띠 숫자 3으로 맞게 나온다.
- **2차 관리:** 업무를 완료하면 다음 연락일 창이 뜨고, 고른 날짜에 담당자 업무가 1건 생긴다. 그 업무 댓글이 거래처 타임라인에 보인다.
- **반려 탭:** '대상아님(반려)' 건이 '종결' 보기에서 체크박스 없이 보인다.
- **보기 저장:** 정렬·필터·열 설정을 저장하고, 새로고침·다른 기기에서도 유지된다.
- **권한:** 다른 회사 거래처는 404다.
