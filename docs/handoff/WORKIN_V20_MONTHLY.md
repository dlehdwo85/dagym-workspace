# WORKIN V20 — 업무 월별 보관·이월 (2026-10-15 대표 지시)

## 결정
- **진행 중 업무는 월로 나누지 않는다.** 한 목록에 계속 있고, 달이 바뀌면 자동으로 "이월" 표시만 붙는다(데이터를 옮기거나 복사하지 않음).
- **완료 업무는 완료일 기준 월별로 보관한다.** 이미 상단 "완료" 칩이 완료일 기준 월별 묶음(V6 5번, `TaskViews.tsx` group==='month')이므로 이를 다듬는다.
- **매월 1일 "월 마감 기록"을 남긴다.** 지난달 완료·이월·지연 숫자를 고정 저장(나중에 업무가 바뀌어도 그 달 기록은 그대로).

## 1. 이월 표시 (진행 중 업무)
- 기준: 완료 안 된 업무 중 **마감일이 지난달 이전**이면 이월. 마감일이 없으면 생성일 기준.
- 업무 줄·상세에 작은 표시: `이월 · 9월부터` (2개월 이상이면 `이월 2개월`). 색은 회색 계열, 지연(마감 지남) 빨간 표시와 겹치지 않게 지연이 우선.
- 필터에 "이월만 보기" 추가(담당자 묶음 안에서도 동작).
- DB 이동·복사 없음. 화면/조회에서 계산(Asia/Seoul 기준 월).

## 2. 완료 월별 보관 다듬기
- "완료" 칩: 이번 달 묶음만 펼치고 **지난달들은 접힌 상태**(제목에 개수: `2026년 9월 · 42건`). 펼칠 때 그 달만 불러오기(한 번에 전부 불러오지 않음, API `doneMonth=YYYY-MM`).
- 맨 위에 달 고르기(◀ 2026년 10월 ▶)로 바로 이동.
- 기본 업무 목록은 지금처럼 "진행 중 + 오늘 완료"만(`includeDone=recent` 유지) — 완료가 쌓여도 목록이 길어지지 않음.
- 각 달 안에서는 담당자별 묶음 → 완료일 최신순.

## 3. 월 마감 기록
- 매월 1일 00:10(KST) 자동 실행(기존 cron 경로에 추가): 조직별 지난달 스냅숏 저장.
  - 새 테이블(추가형 마이그레이션) `task_month_close(org_id, month 'YYYY-MM', user_id null=전체, done_count, carried_count, overdue_count, created_count, created_at)`, unique(org_id, month, user_id).
  - 전체 + 담당자별 행.
- 보는 곳: 리포트(`/reports`)에 "월별 기록" 표 — 달별 완료/이월/지연 추이. 담당자별 펼치기.
- 대표(owner)에게 1일 아침 알림 1건: "9월 마감: 완료 42 · 이월 7 · 지연 3" → 누르면 리포트.
- 이미 지난 달(이번 배포 이전)은 첫 실행 때 최근 3개월치를 현재 데이터로 채워 넣되 "추정(소급)" 표시.

## 시험
- 9월 마감 진행 중 업무 → 10월에 `이월 · 9월부터` 표시, 완료하면 10월 완료 묶음에 들어감.
- 완료 칩에서 지난달 접힘·펼칠 때만 요청, 달 이동 버튼.
- cron 수동 실행 → task_month_close 전체·담당자 행 생성, 두 번 실행해도 중복 없음(upsert), 다른 조직 데이터 안 섞임.
