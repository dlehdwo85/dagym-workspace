# WORKIN V35 — 첨부 눈에 띄게 · 연차/근무 상태 (2026-10-16 대표)

## 1. 첨부 자료 더 잘 보이게
대표: "업무에 첨부된 자료가 더 잘 보이게 색상 같은 걸 표시하면 좋겠다. 첨부된 건지 잠깐 더 봐야 한다."
- 업무 목록·보드·캘린더 카드: 첨부가 있으면 **색 배지 "📎 2"**(파란 바탕 연한 칩, 지금 회색 아이콘+숫자보다 진하게), 고객에게 보낸 자료가 있으면 "보냄" 초록 칩, 고객이 열람했으면 "열람" 칩.
- 업무 상세: "자료·첨부 n" 섹션을 접혀 있어도 머리에 색 배지+파일 종류 아이콘(PDF 빨강·엑셀 초록·이미지 보라·한글 파랑) 3개까지 미리 표시, 섹션 배경 연한 색. 파일 줄은 종류 색 아이콘 + 이름 굵게 + [보기][받기] 버튼 크기 44px.
- 휴대폰: 업무 상세 맨 위 요약줄(담당·마감 옆)에 "📎 첨부 2" 칩 → 누르면 첨부 섹션으로 스크롤.
- 목록 필터 "첨부 있음".

## 2. 연차·근무 상태 (V30 ③ 간이 근태·④ 휴가 결재 보강)
대표: "연차인 직원에게는 업무 알림이 안 가게 하거나 배정이 불가하게 — 다만 배정 불가는 팀 전체 업무 등 리스크가 있다. 연차에 따라 직원 근무 상태를 확실하게 확인할 수 있으면 좋겠다. 일전에 비교해 둔 것(경쟁사 부재중 설정)도."
- **근무 상태 표시(어디서나)**: 사람 아바타 옆 점·배지 — 근무 중(초록) / 연차·반차(회색, "연차 ~10/18") / 출장·외근(파랑) / 출근 전·퇴근(빈 점, V30 ③ 출퇴근 기록과 연동). 담당자 고르기 목록·업무 상세 담당자·메신저·조직도·사용자 관리·캘린더 사람 필터에 동일. (참고: 경쟁사 메신저의 "부재중 설정" — 사용자가 직접 부재 기간·메시지를 설정하면 상대에게 표시 — 같은 기능을 워크인에도: 설정 > [부재중 설정] 기간·자동 응답 문구·대리인)
- **배정**: 막지 않음(팀 전체 업무·급한 일 리스크) → 연차자에게 배정하려 하면 "○○님은 10/16~10/18 연차입니다" 경고 + [대리인 ○○님에게 배정] [복귀일로 마감 조정] [그대로 배정] 선택. 일괄 배정(팀 전체·여러 명)은 연차자를 자동 제외할지 체크(기본 제외, 표시).
- **알림**: 연차 중에는 푸시·메신저 알림을 **보류**(앱 안 알림은 쌓임) → 복귀일 아침 "부재 중 받은 알림 n건 요약" 1번. 긴급(지시자가 "긴급" 표시한 업무·검토 요청)은 본인 설정에 따라 받기/대리인에게만. 지시자 화면에는 "연차 중 — 복귀 후 확인 예정" 표시.
- **대리인**: 연차 등록 시 대리인 지정(선택) → 그 기간 새 배정·검토 요청이 대리인에게 사본, 업무에 "대리 처리" 기록.
- **연차 등록 경로**: V30 ④ 휴가 결재 승인 → 자동 부재 등록(캘린더·상태). 결재 없이 쓰는 회사는 본인 [부재 등록](관리자 승인 선택).
- **관리자 화면**: 오늘 근무 현황(출근·연차·출장·미출근 수, 명단), 월별 연차 사용표, 엑셀.
- 주의: 근무 상태는 같은 회사 직원에게만 보이고, 연차 사유는 본인·관리자만.
