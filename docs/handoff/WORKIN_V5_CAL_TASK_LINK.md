## 1. "캘린더에서 업무 내용이 안 보임" — 휴대폰 주 보기 정리 (Google 캡처 기준)

## 2. 홈에서 일정 만들기
- 홈 상단(오늘 할 일 위)에 **"+ 일정"·"+ 업무"** 빠른 버튼, 하단 가운데 + 버튼 메뉴에도 "일정"·"업무" 둘 다. 일정 빠른 등록 = 캘린더와 같은 시트(제목·날짜·시간·반복·업무에도 추가).

## 3. 일정 ↔ 업무 연동 (각각의 화면은 유지, 서로 반영)
- **업무 → 캘린더**: 마감일을 정하면 캘린더에 표시(V4 마감 표시). 마감 시각이 있으면 그 시각에 30분 블록, 없으면 종일 칸. 업무에서 마감 바꾸면 캘린더 즉시 반영.
- **캘린더 → 업무**: 일정 등록 시트·편집 창에 **"업무에도 추가" 체크**(기본 끔). 체크하면 연결된 업무 생성: 제목 = 일정 제목, 마감 = 일정 날짜(시각 포함), 담당자 = 나(참석자가 있으면 선택), 지시자 = 나, 업무 상세에 "연결된 일정" 표시. 체크된 일정은 블록에 ✓ 표시.
- **양쪽 수정 동기화**: 연결된 일정 시간 변경 → 업무 마감 변경, 업무 마감 변경 → 연결 일정 날짜 이동(시간 길이 유지). 업무 완료 → 일정 블록에 취소선. 한쪽 삭제 시 "연결된 업무/일정도 삭제할까요?" 확인.
- 데이터: 기존 `events.task_id`(task_block) 를 쓰거나 `link_kind` 구분(추가형 마이그레이션). 반복 일정에 업무 추가 시 회차마다 업무를 만들지 말고 "반복 업무"로 연결(4번).
- 권한: 업무로 만든 사람/담당자 규칙은 기존 access.ts 그대로, 다른 조직 404 유지.

## 4. 반복 설정 (업무·일정 모두)
- 일정: 빠른 등록 시트와 편집 창에 반복(안 함·매일·평일·매주 ○요일·매월 ○일·매년·사용자 지정, 종료: 없음/날짜/횟수). 반복 일정 수정·삭제 시 "이 일정만/이후 모두/전체" (기존 rrule 처리 확인).
- 업무: 한 줄 추가의 칩 줄과 상세에 "반복" 칩(기존 `recurrence_rule` 사용, 반복은 마감 필요 안내). 완료하면 다음 회차 자동 생성(기존 jobs) — 목록에 🔁 표시.
- 연동: 반복 일정 + "업무에도 추가" = 같은 규칙의 반복 업무.

## 5. 완료 기준
- 대표 삼성 앱 주 보기에서 업무 마감 제목이 읽히고 Google 처럼 블록에 제목 줄바꿈
- 홈에서 일정 생성, "업무에도 추가" 체크 시 업무 목록·캘린더 양쪽 표시, 한쪽 날짜 바꾸면 다른 쪽 반영
- 업무·일정 반복 설정·다음 회차 생성
- E2E 360/390px 캡처, API 시험(연결 생성·동기화·삭제 확인)
