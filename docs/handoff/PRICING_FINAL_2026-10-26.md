### 2-3. 지문인식기 API 직접 연동의 비용·위험
1. **제조사마다 다르다.** 슈프리마 BioStar 2 는 2026-06-30 신규 판매 종료(지원 2029-06-30), 후속은 BioStar X(고객사 서버 설치형 API)와 BioStar Air(클라우드 REST API, API 키). 유니온커뮤니티 등은 SDK 방식. 고객사가 어떤 단말기를 쓰는지 모르는 채 "지문 연동"을 약속할 수 없다.
2. **생체정보는 민감정보**(개인정보보호법 제23조). 지문 템플릿을 우리 서버에 두면 별도 동의·암호화·접근 통제·처리방침 명시가 따른다. 단말기(또는 BioStar)에 템플릿을 두고 우리는 **출입 이벤트(누가·언제)만 받는 구조**여야 한다.
3. **단말기 값과 설치**: 지문 단말기 대당 수십만 원(모델별 어림 20~40만, 견적 확인 필요), 얼굴 단말기는 더 비쌈 + 네트워크·설치. 5~50인 사업장이 근태 때문에 단말기를 새로 사게 하는 건 판매 장벽이다.
4. **매출 효과**: 플렉스 기준 +2,000원/인. 10인이면 월 2만 원. 개발·지원 비용(제조사별 연동·장애 대응) 대비 작다.

### 2-5. 대표 반론(10/26 02:25)에 대한 답 — 앱 근태의 한계와 하이크비전

- "단말기 저렴한 모델도 있고, 우리는 이미 하이크비전 출입통제기기 연동 사례가 있다" → 그러면 2-4 ③④ 순서를 바꾼다: **1순위 하이크비전 출입기 연동**(이미 해 본 방식 재사용, 저가 단말기 모델 있음), 2순위 하이링크 얼굴 출입기(우리 플랫폼), 3순위 슈프리마 BioStar Air(요청 시). 지문 템플릿·얼굴 데이터는 단말기(또는 고객사 출입 서버)에 두고 워크인은 **출입 이벤트(누가·언제·어느 문)만** 받는다. 확인할 것: 기존 연동이 어떤 방식이었는지(ISAPI 이벤트 수신/HikCentral API/하이크 파트너 클라우드), 단말기 모델·대당 가격(견적), 고객사 내부망 이벤트를 우리 서버로 보내는 길(공인 IP·중계기·클라우드).
- 요금은 바꾸지 않는다. 근태 Pro 19,000~59,000(회사당)은 '기기 연동 + 근무표·52시간·급여 내보내기' 값으로 시장(출입장비 연동 +2,000/인)과 맞다. 단말기 값은 고객 부담(또는 하이링크 영업 묶음에서 할인).
