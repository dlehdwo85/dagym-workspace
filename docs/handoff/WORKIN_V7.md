# 워크인 7차 — 달성률 제거·홈 우선순위·보기 메뉴 잘림 (대표 지시 2026-10-14)

웹 코드만, 한 커밋으로 main.

## 1. 달성률 제거
- 대표: "달성률 다시 없앱니다." → 홈·주간 보고의 달성률 카드, 사람별 막대, `/api/stats` 화면 노출 제거(API 는 남겨도 됨, 메뉴·카드에서 안 보이게). 프로젝트 진행률 바·주간 목표는 대표 확인 전까지 숨김.

## 2. 홈 = "오늘 할 일" + "이번 주 일정"이 주인공
- 대표: "홈 화면에서 오늘의 할 일, 이번 주 일정이 더 중요함."
- 홈 맨 위부터: **① 오늘 할 일**(기한 지남 빨간 줄 먼저 → 오늘 마감(시간순) → 오늘 시작, 끝에 한 줄 추가 + 저장 버튼) **② 이번 주 일정**(오늘부터 7일, 날짜별 묶음, 일정 + 시간 있는 업무 마감 섞어 시간순, 날짜 칸 탭 → 빠른 등록). 두 영역은 다른 카드보다 크게, 첫 화면(휴대폰 한 화면)에 둘 다 보이게.
- 그 아래로 내리기: 새로 받은 업무, 이달의 일정, 알림 요약 등 나머지(필요 없으면 접힘).

## 3. 업무 "보기" 메뉴에서 엑셀·휴지통이 잘림 (대표 삼성 앱)
- 보기(⋯) 팝오버가 화면 오른쪽/아래 밖으로 나가 "엑셀 내려받기·휴지통" 항목이 잘림. 휴대폰에서는 **아래에서 올라오는 시트**로, PC 는 화면 안쪽으로 위치 자동 보정(가장자리 8px 여백), 항목 최소 높이 44px. 360/390px E2E 캡처로 확인.

## 4. 캘린더 표시 통일 + 개인/회사 2색 + 색 선택 (대표 요청, 마케팅 세션 경유 2026-10-14)
- 대표 원문 요지: "캘린더에 업무와 일정 표기가 사이즈·색상이 다르다. 통일하고, 개인 일정인지 회사 일정인지에 따른 색 구분만, 색상 선택도 가능하게."
- ① **업무 마감과 일정을 같은 모양·크기**로: 같은 둥근 블록(종일이면 종일 칸 같은 높이 칩), 같은 글자 크기·줄바꿈. 업무는 블록 앞 작은 ✓ 아이콘만 차이(완료 시 취소선).
- ② **색은 두 가지만**: 개인 일정(개인 캘린더·내/남의 개인 업무) / 회사 일정(회사 캘린더·본사 공유 일정·업무). 사람별·캘린더별·우선순위별 색 구분 제거. 사람 구분은 블록 안 이름 머리글자로.
- ③ **색 선택**: 캘린더 왼쪽(휴대폰은 설정 시트)에서 "개인 일정 색 / 회사 일정 색"을 각각 팔레트(Google 처럼 12색)로 고름. 기본값 = 대표가 고른 색, **사용자별 저장**(각자 자기 화면 색), 대표가 "모두에게 기본값으로" 지정 가능.
- 업무를 개인/회사 어느 쪽으로 볼지: 업무가 회사 프로젝트·본사 조직이면 회사, 담당자 개인 업무(프로젝트 없음)면 개인 — 클라우드 판단 후 NEXT_ACTION 에 규칙 기록.
