## 3. 잔디 대비 부족한 점 디벨롭 (점수 낮은 순, 이번 차수 범위)
1. **메신저(0점)** → **업무·프로젝트별 대화방 + 1:1 대화**: 실시간(SSE/폴링), 읽음 표시, @멘션, 파일·사진, 대화에서 바로 "업무로 만들기", 푸시 알림, 알림 끄기. (전사 채팅은 프로젝트 "전체" 방으로.)
2. **신뢰·지원(1점)** → 앱 안 "도움말·문의"(FAQ·사용 안내·문의 남기기 → 플랫폼 운영 화면 접수함), 서비스 상태 페이지(공개 health), 변경 소식(업데이트 노트).
3. **외부 연동(1점)** → ① 캘린더 **ICS 구독 주소**(구글·아웃룩·애플 캘린더에서 워크인 일정 보기 — 연결 없이 링크만), ② **이메일 알림**(선택, 일 요약), ③ 웹훅(나중).
4. **보안(2점)** → **2단계 인증(OTP 앱)** 선택·관리자 강제, 로그인 기록·다른 기기 로그아웃, 비밀번호 정책, 개인정보 내보내기/삭제 요청.
5. **파일(2점)** → R2 적용 후 PDF·이미지 미리보기, 자료실 폴더 권한(전체/관리자만).
6. **모바일(2점)** → 스토어 정식 출시는 로컬 몫(별도) — 클라우드는 오프라인 보기·빠른 실행(바로가기) 정리.

## 4. PC 업무 상세 패널 닫힘 동작
- 지금: 오른쪽 상세 패널이 **닫기 버튼으로만** 닫힘. 요청: ① 다른 업무 행 클릭 → 패널 내용이 **그 업무로 바뀜**(닫지 않고 교체), ② 목록 빈 곳·다른 화면(사이드바 메뉴 등) 클릭 → 닫힘, ③ Esc → 닫힘, ④ 입력 중 내용이 있으면 자동 저장 후 닫힘. 패널이 목록 오른쪽 열을 가리지 않게 폭 조정(캡처: 목록 칩·마감 열이 패널에 가려짐).

## 5. 담당자 여러 명 선택 — 한 줄 추가에도
- 현재 여러 명 일괄 생성은 **업무 등록 시트(QuickAddTask)에만** 있고, PC 목록의 한 줄 추가(InlineAddTask) 담당자 칩은 1명만. → 한 줄 추가 담당자 선택도 **체크 여러 개**, 2명 이상이면 저장 버튼 "n명에게 각각 만들기". 담당자 선택창 맨 위 "여러 명 선택" 안내.

## 6. 상태 변경 권한 + "확인 완료" 단계
- 단계: **배정됨(확인 전) → 확인 완료 → 진행 중 → 검토 요청 → 완료**(+보류).
- **담당자만** 확인 완료·진행 전/진행 중·검토 요청을 바꿀 수 있음. 지시자·관리자는 검토 요청 업무의 **승인(완료)/반려(진행 중으로)**, 보류만. 서버 `updateTask` 에서 권한 검사(403), 화면은 권한 없는 상태 칩 비활성 + 이유 툴팁.
- **확인 완료**: 담당자가 배정 알림을 눌러 앱/웹에서 그 업무를 열면 자동으로 "확인 완료"(기존 `assignee_ack_at` 사용) + 지시자에게 "○○님이 확인했습니다" 알림. 목록 상태 칩에 "확인 전"(빨간 점)·"확인 완료" 표시.
- 푸시 알림 탭 → 앱이 열리며 그 업무 상세로 이동하는지 실기기 확인(로컬).

## 7. 검토 요청 → 지시자에게 자동 알림
- 담당자가 "검토 요청"하면 **지시자(requested_by, 없으면 만든 사람)** 에게 즉시 앱 알림+푸시(“○○님이 검토를 요청했습니다 — 승인/반려”), 알림에서 바로 승인·반려 버튼. (V6 15번과 통합, 즉시 dispatchPending 확인)
