## 3. 잔디 대비 부족한 점 디벨롭 (점수 낮은 순, 이번 차수 범위)
1. **메신저(0점)** → **업무·프로젝트별 대화방 + 1:1 대화**: 실시간(SSE/폴링), 읽음 표시, @멘션, 파일·사진, 대화에서 바로 "업무로 만들기", 푸시 알림, 알림 끄기. (전사 채팅은 프로젝트 "전체" 방으로.)
2. **신뢰·지원(1점)** → 앱 안 "도움말·문의"(FAQ·사용 안내·문의 남기기 → 플랫폼 운영 화면 접수함), 서비스 상태 페이지(공개 health), 변경 소식(업데이트 노트).
3. **외부 연동(1점)** → ① 캘린더 **ICS 구독 주소**(구글·아웃룩·애플 캘린더에서 워크인 일정 보기 — 연결 없이 링크만), ② **이메일 알림**(선택, 일 요약), ③ 웹훅(나중).
4. **보안(2점)** → **2단계 인증(OTP 앱)** 선택·관리자 강제, 로그인 기록·다른 기기 로그아웃, 비밀번호 정책, 개인정보 내보내기/삭제 요청.
5. **파일(2점)** → R2 적용 후 PDF·이미지 미리보기, 자료실 폴더 권한(전체/관리자만).
6. **모바일(2점)** → 스토어 정식 출시는 로컬 몫(별도) — 클라우드는 오프라인 보기·빠른 실행(바로가기) 정리.

## 4. PC 업무 상세 패널 닫힘 동작
- 지금: 오른쪽 상세 패널이 **닫기 버튼으로만** 닫힘. 요청: ① 다른 업무 행 클릭 → 패널 내용이 **그 업무로 바뀜**(닫지 않고 교체), ② 목록 빈 곳·다른 화면(사이드바 메뉴 등) 클릭 → 닫힘, ③ Esc → 닫힘, ④ 입력 중 내용이 있으면 자동 저장 후 닫힘. 패널이 목록 오른쪽 열을 가리지 않게 폭 조정(캡처: 목록 칩·마감 열이 패널에 가려짐).

## 5. 담당자 여러 명 선택 — 한 줄 추가에도
- 현재 여러 명 일괄 생성은 **업무 등록 시트(QuickAddTask)에만** 있고, PC 목록의 한 줄 추가(InlineAddTask) 담당자 칩은 1명만. → 한 줄 추가 담당자 선택도 **체크 여러 개**, 2명 이상이면 저장 버튼 "n명에게 각각 만들기". 담당자 선택창 맨 위 "여러 명 선택" 안내.

## 6. 상태 변경 권한 + "확인 완료" 단계
- 단계: **배정됨(확인 전) → 확인 완료 → 진행 중 → 검토 요청 → 완료**(+보류).
- **담당자만** 확인 완료·진행 전/진행 중·검토 요청을 바꿀 수 있음. 지시자·관리자는 검토 요청 업무의 **승인(완료)/반려(진행 중으로)**, 보류만. 서버 `updateTask` 에서 권한 검사(403), 화면은 권한 없는 상태 칩 비활성 + 이유 툴팁.
- **확인 완료**: 담당자가 배정 알림을 눌러 앱/웹에서 그 업무를 열면 자동으로 "확인 완료"(기존 `assignee_ack_at` 사용) + 지시자에게 "○○님이 확인했습니다" 알림. 목록 상태 칩에 "확인 전"(빨간 점)·"확인 완료" 표시.
- 푸시 알림 탭 → 앱이 열리며 그 업무 상세로 이동하는지 실기기 확인(로컬).

## 7. 검토 요청 → 지시자에게 자동 알림
- 담당자가 "검토 요청"하면 **지시자(requested_by, 없으면 만든 사람)** 에게 즉시 앱 알림+푸시(“○○님이 검토를 요청했습니다 — 승인/반려”), 알림에서 바로 승인·반려 버튼. (V6 15번과 통합, 즉시 dispatchPending 확인)

## 8. "자료를 올리면 AI가 정리해서 업무로 배정" (대표 시나리오, 캡처 `local-screens/59-shoot-request-table.png`)
- 대표 예: 촬영 요청서(7개 게시물·필요한 사진·촬영 팁 표 이미지)를 올리고 "김민수 본부장·김소담 부사장에게 각 지점 자료 받아오라고 배정, 마감 10/22 14:00, 메모에 간단한 설명" → AI 가 업무 생성.
- 현재 AI 비서(`src/lib/ai/assistant.ts`)는 자료실 검색·첨부·업무 제안은 되지만 **첨부 이미지/PDF 내용을 읽지 못함**(파일 이름만 전달). 요청:
  1. AI 요청 칸에 **파일·사진 첨부**(또는 자료실 파일 선택) → 이미지는 Claude 비전 입력(base64), PDF·엑셀·문서는 텍스트 추출해 전달.
  2. 도구 `create_tasks`(여러 담당자 일괄·체크리스트·설명·마감 시각·우선순위·지시자·첨부 연결) → **제안 카드**(담당자별 1건, 체크리스트 7개, 메모 미리보기) → 대표 "만들기" 확인 후 생성(쓰기는 제안→확인 원칙 유지).
  3. 원본 자료는 R2 자료실 "AI 요청 첨부"에 저장하고 만든 업무에 자동 첨부.
  4. 업무 등록 시트에서도 "📎 자료로 채우기": 첨부를 읽어 제목·설명·체크리스트 자동 작성.
- 비용: 이미지 1장 분석 수십 원 수준, 회사별 AI 한도에 포함.

## 9. 파일 끌어다 놓기(드래그) 업로드 + 업로드 실패 원인 (대표 신고 2026-10-14)
- 업로드 실패 원인(로컬 확인): `storage.ts` 는 S3/R2 면 브라우저가 **presigned PUT 으로 R2 에 직접** 올리는데 버킷에 CORS 규칙이 없었음 → 로컬이 R2 `workin-files` CORS 설정 완료(origins: 운영 도메인·https://localhost·capacitor://localhost, GET/PUT/HEAD, content-type, ETag 노출). 업로드 실패 시 화면 오류 문구에 원인(CORS/권한/용량)을 사람이 알 수 있는 말로 표시 요청.
- **드래그 업로드**: 업무 상세 첨부 영역·자료실·댓글 입력·AI 요청 칸에 파일을 끌어다 놓으면 업로드(여러 개), 놓을 수 있는 영역 강조 표시, 휴대폰은 기존 버튼·카메라 유지. 업로드 진행률 막대.

## 10. 업로드 영역에 "끌어다 놓기" 안내 문구 (대표 지시 2026-10-14)
- 1e7dc26 로 드래그 업로드는 동작하지만 사용자가 모름. 업무 첨부·자료실·댓글·AI 요청의 업로드 영역에 **점선 상자 + 아이콘 + "파일을 여기로 끌어다 놓거나 눌러서 선택하세요 (사진·PDF·문서, 최대 50MB)"** 상시 표시(PC). 휴대폰은 "눌러서 사진 찍기·파일 선택"으로 문구 변경(드래그 불가).
- 파일을 끌고 들어오면 화면 전체에 "놓으면 이 업무에 첨부됩니다" 오버레이, 놓을 수 없는 곳은 표시 안 함.
- 자료실 빈 화면 안내에도 같은 문구.
