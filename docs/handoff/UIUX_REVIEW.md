구현 담당: 클라우드 (`src/`). 대표 지시에 따라 클라우드 개발은 그대로 두고, 로컬은 명세·재검수만 합니다.

## 0. 버그 (디자인 작업 전 먼저)
| ID | 증상 | 재현 | 수정안 |
|---|---|---|---|
| U-0a | **알 수 없는 주소 값이면 업무 화면 전체가 "불러오지 못했습니다 / 입력값을 확인해 주세요"** | `/tasks?view=board` (보기 전환은 `mode=` 인데 `view=` 로 들어오면 API 400) | 화면에서 모르는 `view` 값은 무시하고 기본값 사용, API 도 모르는 값은 400 대신 무시 |
| U-0b | 오류 문구가 "입력값을 확인해 주세요" 하나뿐 — 무엇이 틀렸는지 모름 | 위와 같음, 로그인 등 모든 검증 오류 | `detail.fieldErrors` 를 항목 이름과 함께 한국어로 표시 |
| U-0c | 서버에 닿지 못하면 영어 `Failed to fetch` 가 그대로 보일 수 있음 (`login/page.tsx` 가 `e.message` 표시) | 서버 재시작 중 로그인 | "서버에 연결할 수 없습니다. 잠시 후 다시 시도하세요" + 다시 시도 |
| U-0d | **Pretendard 글꼴을 지정만 하고 불러오지 않음** → Windows 는 맑은 고딕으로 표시(화면이 거칠고 오래돼 보이는 주원인) | `tailwind.config.ts` fontFamily, `layout.tsx`·`globals.css` 에 @font-face 없음 | Pretendard Variable(웹폰트, 서브셋 dynamic) 를 `next/font/local` 로 `public/fonts` 에 포함 |

> 대표 계정 로그인 오류: 로컬 서버에는 대표의 로그인 시도 기록(성공·실패 모두)이 없었습니다. 이 PC 브라우저에서 대표 시험 계정은 정상 로그인됨. 유력 원인은 ① 로컬 서버를 최신 코드로 재시작하던 1~2분 동안 접속(연결 실패) ② 휴대폰 등 다른 기기에서 PC 주소로 접속(현재 서버는 이 PC 전용) ③ 운영 주소는 아직 배포 전. 화면에 나온 문구를 대표에게 확인 중. U-0b·U-0c 를 고치면 원인이 화면에 바로 드러납니다.

## 1. 지금 화면의 문제 (Asana 와 나란히 본 결과)
| 영역 | 현재 | Asana | 문제 |
|---|---|---|---|
| 글꼴·글자 | 맑은 고딕, 13~14px 위주, 굵기 차이 적음 | 세련된 산세리프, 제목·본문·보조 위계 뚜렷 | 전체가 평평하고 촌스러워 보임 |
| 아이콘 | 글자 기호(⌂ ☑ ☰ ▦ ▤ ❏) + 알림만 컬러 이모지 🔔 | 일관된 선 아이콘 세트 | 기기마다 모양이 다르고 섞여 보임 |
| 색 | 남색 1색 + 회색. 상태 배지만 연한 색 | 브랜드 색 + 필드별 색 배지, 담당자 아바타 색 | 정보가 색으로 구분되지 않음, 생기 없음 |
| 담당자 | 이름 글자만 | 이니셜 아바타(색) | 누가 맡았는지 한눈에 안 보임 |
| 업무 행/카드 | 제목 + 작은 회색 글자 나열 (`10. 14. (수) 이직원 다짐 강남점 ● 다짐 💬1 📎1`) | 원형 완료 체크, 아바타, 날짜 칩(지남=빨강), 필드 배지 | 정보 밀도는 높은데 훑어보기 어려움 |
| 상단 | 없음 (검색·만들기는 각 화면 안) | 상단 바: 만들기 · 전역 검색(Ctrl K) · 계정 | 어디서나 같은 동작을 할 수 없음 |
| 사이드바 | 고정 메뉴만, 프로젝트 목록 없음, 관리자 메뉴는 아이콘 없이 글자 | 즐겨찾기·프로젝트 목록, 접기 | 자주 쓰는 프로젝트로 바로 못 감 |
| 필터 | 입력 7개가 한 줄에 같은 크기로 늘어섬(날짜 입력 `연도-월-일`) | "필터 · 정렬 · 그룹" 버튼 → 펼침 | 화면 윗부분을 필터가 차지, 기본 상태도 복잡 |
| 빈 화면 | 회색 "없음" | 그림 + 다음 행동 버튼 | 처음 쓰는 사람이 할 일을 모름 |
| 대시보드 | 숫자 카드 4개 + 표, 차트 빈칸("합계 0건") | 막대·도넛·추이 차트 | 대표가 보는 첫 화면이 밋밋함 |
| 업무 상세 | 전체 페이지, 입력칸 12개가 격자로 노출(폼처럼 보임) | 오른쪽 패널, 속성은 "라벨: 값" 한 줄씩, 클릭 시 편집 | 읽기보다 입력 화면처럼 느껴짐 |
| 로그인 | 가운데 흰 상자 하나 | — | 회사 첫인상이 약함 |
| 상호작용 | 저장 시 피드백 약함, 로딩은 글자 | 토스트, 스켈레톤, 부드러운 전환 | 반응이 느리고 불확실하게 느껴짐 |

## 2. 디자인 시스템 (먼저 만들고 모든 화면에 적용)
- **글꼴**: Pretendard Variable. 크기 단계 12 / 13 / 14(본문) / 16 / 20 / 24 / 30, 굵기 400·500·600·700. 숫자는 `tabular-nums`.
- **색 토큰** (`tailwind.config.ts` + CSS 변수, 다크 모드 대비):
  - 기본: `brand` 남색 유지(#1F3A5F) + 강조 `accent` 하나(예: #3B82F6), 배경 `#F7F8FA`, 카드 흰색, 경계 `#E5E7EB`
  - 상태: 예정 slate · 진행 blue · 검토 요청 amber · 보류 gray · 완료 green · 지연 red — 배지·보드 열 머리·타임라인 막대에 같은 색
  - 우선순위: 긴급 red · 높음 orange · 보통 없음 · 낮음 gray (깃발 아이콘)
  - 브랜드: 다짐 / 하이링크 / BODY LAB 각 1색 (조직 칩·캘린더 색)
  - 사람: 이름 해시로 8색 중 하나 → 아바타 배경
- **간격·모서리·그림자**: 4px 단위, 카드 radius 12, 입력 8, 그림자 2단계(카드 `0 1px 2px`, 떠 있는 패널 `0 8px 24px`)
- **아이콘**: `lucide-react` 하나로 통일 (홈 House, 내 업무 CircleCheck, 전체 업무 ListTodo, 프로젝트 FolderKanban, 캘린더 CalendarDays, 알림 Bell, 템플릿 LayoutTemplate, 관리자 Users·Network·ScrollText·Activity)
- **공통 부품**: Avatar(이니셜·색·겹침), StatusBadge, PriorityFlag, DueChip(오늘=파랑, 지남=빨강, 3일 이내=주황), Toast, Skeleton, EmptyState(그림+설명+버튼), CommandPalette(Ctrl K), SidePanel, Popover 편집(속성 클릭 → 작은 선택창)

## 3. 화면별 개선
| 순서 | 화면 | 바꿀 것 |
|---|---|---|
| 1 | 공통 틀 | **상단 바**(왼쪽 사이드바 접기 · 가운데 검색 Ctrl K · 오른쪽 "+ 만들기"(업무/일정/프로젝트) · 알림 종 · 아바타 메뉴). 사이드바에 아이콘 통일, "즐겨찾는 프로젝트" 목록, 관리자 묶음 접기 |
| 2 | 업무 목록 | 행 높이 40px, 왼쪽 원형 완료 체크(누르면 바로 완료/검토 요청), 제목, 오른쪽 열: 아바타 · DueChip · 상태 배지 · 우선순위 깃발 · 댓글/첨부 수 아이콘. 묶음 머리(내 업무 자동 묶음) 접기·개수. 필터는 "필터(2) · 정렬 · 묶기" 버튼 한 줄로 접고, 적용된 필터는 칩으로 표시 |
| 3 | 보드 | 열 머리 상태 색 띠 + 개수, 카드: 제목 2줄, 아래 한 줄에 DueChip·아바타·첨부 수, 우선순위 긴급/높음은 왼쪽 색 띠. 끄는 중 그림자·자리 표시, 빈 열 "여기로 끌어 놓기" |
| 4 | 업무 상세 | **오른쪽 패널(B-1)**. 위: 완료 버튼 · 상태 · 링크 복사 · 더보기. 제목 큰 글씨 바로 편집. 속성은 "라벨: 값" 2열 목록(담당자 아바타, 마감 DueChip, 소속 칩), 비어 있는 속성은 흐리게 "+ 추가". 설명·체크리스트(진행률 막대)·하위 업무·첨부(사진 썸네일 격자)·댓글·변경 이력 탭 |
| 5 | 홈(대표 대시보드) | 인사 + 날짜, 숫자 카드에 지난주 대비 증감 화살표, 현장별 표 → 현장 카드(지연·검토 대기 색 강조), 완료 추이 막대 차트, 담당자 업무량 가로 막대(과부하 빨강). 빈 상태는 "첫 업무 만들기" 버튼 |
| 6 | 캘린더 | 일정 색 = 캘린더 색 채움, 업무 마감은 점선 테두리 유지, 오늘 열 강조, 주 보기 기본(데스크톱), 일정 클릭 시 작은 미리보기 팝오버 → 편집 |
| 7 | 모바일 | 하단 탭 아이콘 통일, + 버튼은 탭 바 가운데로(현재 오른쪽 아래 둥근 버튼이 내용 가림), 업무 등록은 아래에서 올라오는 시트, 목록 행 스와이프(완료·보류) |
| 8 | 로그인·초대·설정 | 왼쪽 브랜드 영역(회사 로고 3개·한 줄 소개) + 오른쪽 입력, 비밀번호 보기 토글, Caps Lock 경고, 오류 문구 구체화(U-0b·U-0c) |
| 9 | 피드백 | 저장·이동·완료 시 토스트(되돌리기 포함), 첫 로딩 스켈레톤, 단축키 도움말(`?`) |

## 4. 완료 기준 (로컬이 재검수)
- 1440px·390px 에서 위 화면 캡처를 이전(`local-screens/01`~`13`)과 나란히 비교, Asana 화면과 같은 시나리오로 비교
- 글꼴이 Windows 에서도 Pretendard 로 보일 것 (개발자 도구 Computed font 확인)
- 색 대비 WCAG AA(본문 4.5:1), 키보드만으로 업무 등록·완료·패널 닫기 가능
- 기존 E2E 전체 통과 + 새 E2E: 상단 검색, 패널 열고 닫기, 원형 체크 완료, 필터 칩
- U-0a~U-0d 재현 시나리오가 더 이상 재현되지 않을 것
