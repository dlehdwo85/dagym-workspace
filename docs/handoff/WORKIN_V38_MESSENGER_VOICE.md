# WORKIN V38 — 메신저 흔들림·고도화 · 음성 대화(운전 중) · 업무 첨부 자동 자료실 저장 (2026-10-16 대표)

## 1. 메시지방이 위아래로 움직임 (버그, 먼저)
- 대화방이 위아래로 흔들림/튐 → 카카오톡 수준 안정성: 새 메시지·읽음 갱신·이미지 로딩 때 스크롤 점프 금지(이미지 자리 미리 확보 aspect-ratio), 맨 아래 보고 있을 때만 자동 따라가기, 위로 올려 보는 중엔 "새 메시지 n ↓" 버튼, 키보드 열림 시 입력줄만 올라가고 목록 위치 유지(visualViewport), 폴링 갱신이 목록 전체를 다시 그리지 않게(키 고정). 휴대폰 390px E2E: 새 메시지 수신 중 scrollTop 유지.

## 2. 메신저 고도화 (경쟁사 참고: 카카오톡·잔디·카카오워크 기능 중 업무용으로 의미 있는 것)
1차: 메시지 답장(인용)·반응(이모지)·**읽음 수 표시(안 읽은 사람 수)**·메시지 고정(공지)·검색(방 안/전체)·사진/파일 묶음 보기(방 서랍)·멘션 알림·메시지 → 업무 만들기(이미 있으면 강화: 담당·마감 바로)·예약 전송·메시지 수정/삭제(1시간)·링크 미리보기.
2차: 투표(V30 P2)·방 공지·방 안 할 일·즐겨찾기 방·보관(나가지 않고 숨김)·알림 끄기(방별)·외부 손님 초대(제한).

## 3. 음성 대화 — 운전 중 손 안 대고 (우선)
대표: "음성으로 대화할 수 있는 기능을 우선 붙여 달라. 운전할 때 편하게 쓰고자 한다."
- 메시지방·AI 비서에 **[음성 모드]** 버튼(큰 마이크, 화면 꺼짐 방지):
  - 듣기: 새 메시지를 **소리로 읽어 줌**(TTS, "김민수 본부장: 3시 미팅 장소 바뀌었습니다") — 음성 모드 켜진 방만.
  - 말하기: 마이크 누르거나(한 번) "보내" 라고 말하면 받아쓰기 → 읽어 주고 "보낼까요?" → "보내/취소" 음성 확인 후 전송(오발송 방지). V24 음성 인식 플러그인(@capgo speech-recognition) 재사용, 웹은 Web Speech API.
  - AI 비서 음성: "오늘 남은 업무 알려 줘", "3시 미팅 30분 미뤄 줘", "김민수에게 도착 10분 늦는다고 보내 줘" → 실행 전 음성 확인.
  - 운전 중 안전: 큰 버튼·한 손 조작·화면 글자 크게, 차량 블루투스 마이크/스피커 사용, 긴 글은 요약해서 읽기.
- 네이티브(로컬): TTS 플러그인(@capacitor-community/text-to-speech 등) 설치·권한, 화면 꺼짐 방지(KeepAwake), 블루투스 오디오 라우팅 확인. 이후: Android Auto/CarPlay 는 메시징 앱 인증이 별도라 다음 단계 검토.

## 4. 업무에 올린 자료 자동으로 자료실 저장
대표: "업무 볼 때 올리는 자료들은 자동으로 자료실에 저장되도록."
- 업무 첨부 업로드 시 자료실에 **자동 등록**(폴더: 프로젝트 이름 또는 "업무 첨부/연-월", 업무 링크·올린 사람·태그 자동, AI 자동 정리 규칙 적용). 같은 파일 하나만 저장(업무 첨부 = 자료실 파일 참조, V34-C 의 attachments.library_file_id 와 같은 구조 → 기밀 등급도 한 곳에서).
- 업무 권한 밖 사람에게는 자료실에서도 그 파일이 보이지 않게(업무 비공개면 자료실 등급 "업무 참여자만"), 회사 설정 "업무 첨부 자료실 자동 저장" on/off(기본 켬), 기존 첨부 일괄 등록 마이그레이션(선택).
