## 2. 워크인 원가 (실측, V23 5장)

## 3. 결론
### ① 과금 단위 → **인당 + 최소 5인 기본료 + 현장(라이트) 계정**
- 묶음(5·10·15·20)은 쓰지 않는다: 6명 회사가 10명 값을 내는 구조는 국내 경쟁사(전부 인당) 대비 불리.
- 대신 플로우처럼 **"5인 기본료"**로 시작 금액을 단순하게(5인 이하도 5인 요금) → 초과 1인당 같은 단가.
- **현장(라이트) 계정**: 현장 관리자·아르바이트처럼 업무 받고·보고·일정·공지·메신저만 쓰는 사람은 싼 좌석으로 — 다짐(운영 3 + 현장 10) 같은 고객이 그대로 맞음. 경쟁사에 드문 차별점.
- 30인 이상 10%, 100인 이상 별도 견적.

### ② AI → **기본 요금에 소량 포함 + "회사 공유 AI 크레딧" 별도 상품**
- 인당 AI(ClickUp·플로우 방식)는 안 쓰는 현장 인원까지 돈을 내게 함 → 우리 고객층에 안 맞음.
- 완전 합산(총액)은 많이 쓰는 회사에서 적자 위험.
- 그래서: 기본 요금에 **원가 기준 소량 AI 를 회사 공유로 포함**(맛보기·가벼운 사용 충분) + 더 쓰는 회사는 **회사 단위 AI 상품**(인원과 무관) → 원가 2배 원칙으로 가격.
