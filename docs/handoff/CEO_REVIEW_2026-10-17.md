> 각 항목 옆 □에 표시해 주시고, 이상한 것은 화면 캡처만 보내 주시면 됩니다. 예상 소요 약 20~30분.

## A. 꼭 봐 주세요 (휴대폰 앱, 10분)
- [ ] 1. **알림 아이콘**: 알림이 올 때 느낌표가 아니라 워크인 모양(달력+체크)인지
- [ ] 2. **iPhone 상단**: 화면을 아래로 끌어내려도 흰 공간이 안 생기고 시계·배터리가 보이는지
- [ ] 3. **파일 내려받기**(갤럭시): 업무 첨부 파일 이름 누르기·[내려받기] → Chrome 으로 열리며 받아지는지 (iPhone 은 공유 창 → "파일에 저장")
- [ ] 4. **체크리스트**: 업무 상세에서 체크해도 화면이 댓글로 안 내려가는지
- [ ] 5. **메시지방**: 키보드 열고 닫기·사진 보내기·위로 올려 보는 중 새 메시지 올 때 흔들리지 않는지
- [ ] 6. **음성 업무 등록**: "다음 주 금요일까지 김민수 본부장한테 푸르지오 비교 파일 검수 후 보고 배정해 줘" → 업무명 짧게·담당 김민수·마감 다음 주 금요일, 말이 겹치지 않는지, 5초 쉬면 끝나는지
- [ ] 7. **뒤로 가기**: 업무 목록 → 업무 A → 그 안의 다른 업무 → 뒤로 = 업무 목록인지
- [ ] 8. **문자 보내기**: 업무 → 문자 시안이 위아래로 스크롤되고 [보내기] 버튼이 가리지 않는지

## B. 화면·사용감 (휴대폰 또는 PC, 10분)
- [ ] 9. **업무 목록**: 제목 한 줄·둘째 줄 정보가 줄어 한 화면에 충분히 보이는지, 상태 버튼 크기(24px) 괜찮은지
- [ ] 10. **홈 "오늘의 일정"**: 오늘 일정(시간순) + 오늘 마감·지난 업무, 내가 지시한 업무는 한 줄로 묶여 있는지
- [ ] 11. **첨부 표시**: 첨부 있는 업무에 파란 "📎 2"·"보냄"·"열람" 표시가 잘 보이는지
- [ ] 12. **마감 연장**: 업무 마감 칩 → [마감 연장] (담당자는 사유 적고 요청 → 지시자 화면에 승인 배너)
- [ ] 13. **캘린더**: 빈 칸 누르면 일정 등록(업무 아님)·[저장] 버튼 보임·바깥 누르면 저장, 일요일부터 시작, 시간 목록 07~22시
- [ ] 14. **이동 일정**: 장소 넣은 일정에 📍·"출발 권장" 표시·30분 전 알림
- [ ] 15. **근무 상태 점**: 휴가인 사람 회색 점, 외근(장소 일정 중) 파란 점
- [ ] 16. **답글 @태그**: 댓글에 @ 치면 사람 목록, 긴 댓글이 둘로 안 나뉘는지
- [ ] 17. **카카오톡 보내기**: 업무 → 보내기 창 [카카오톡] 탭 → 카카오톡이 열리는지
- [ ] 18. **[+ 만들기] AI로 채우기**: 말로 적은 내용이 업무 칸에 채워지는지
- [ ] 19. **알림 화면**: 누르면 바로 읽음·숫자 감소, "방금·n분 전" 시각 표시
