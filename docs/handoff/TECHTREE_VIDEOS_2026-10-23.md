# 온크트리 「AI 빌드업 테크트리」 EP.1~13 분석 — 다짐·하이링크·워크인 적용안

- 작성: 2026-10-23 로컬 조사. 브라우저는 쓰지 않았고 유튜브 자막·공개 자료만 봤다.
- 대상: 유튜브 채널 「온라인 사업 전략, 온크트리」(@online_techtree)의 시리즈 「AI 빌드업 테크트리」 13편. 게시는 2026-01-03 ~ 03-06, 촬영은 2025-12 ~ 2026-01이다.
- 읽는 법: 2장은 영상 내용(채널의 주장)을 내 말로 요약했다. 3~5장은 우리 회사에 적용한 판단이다. 영상의 매출·조회수는 채널이 스스로 밝힌 숫자이고 검증하지 않았다.

## 0. 결론 먼저

1. **가장 쓸모 있는 한 가지(EP.12)**: 콘텐츠는 참여(시청 지속·저장·공유·댓글)로 퍼지고, 광고는 전환 행동으로 퍼진다. 그래서 둘을 다르게 만들어야 한다. 광고는 첫 문장에서 특정 상황·대상을 지목하고, 처음부터 대놓고 제안한다. 같은 제품도 상황을 여러 개로 쪼개 컨셉을 따로 만들어 동시에 시험한다.
2. **네이버 파워링크(EP.7)**: 파워링크는 '깔아 두는 광고'로 다룬다. 영상의 기본값은 확장 검색 켬(100%), 네이버 매체만 노출, PC 60%·모바일 120%, 자동 추적 URL 파라미터 켬, 소재 노출 '성과 기반', 상품별 연결 URL, 단어 그룹 조합으로 롱테일 키워드 수백 개 등록이다. **워크인 파워링크 세팅안에는 이 설정 대부분이 아직 없다.**
3. **인스타(EP.11·EP.10 대체 영상)**:
   - 캐러셀은 비교·방법·유형별 추천 형식을 쓴다. 규격은 1080×1350이고 마지막 장 CTA는 '댓글에 키워드'다.
   - 숏폼 대본은 질문 → 내 이야기 → 반전 → 비교 → 자문자답 → CTA 순서이고, 화면은 1~2초마다 바꾼다.
4. **'3단계 = AI 직원'(같은 채널의 후속 공개 영상)**: 역할별 AI가 정해진 시각에 초안을 올리고 대표는 채택·반려만 한다. 워크인 운영실의 '제안 → 승인' 구조와 같은 방향이다. 여기에 역할 이름, 일정, 채택 기록 학습을 더하면 된다.
5. **워크인 구현 우선순위**:
   1. 콘텐츠형/광고형 두 모드로 나누기(훅 채점도 분리)
   2. 파워링크 세팅안 기본값 보강
   3. Meta 리드 단계를 Conversions API(CRM)로 돌려보내기
   4. '상황 매트릭스' 소재 생성기
   5. 캐러셀 장별 생성기
   6. 경쟁 광고 아카이브(링크는 사람이 붙이고 분석은 AI)
6. **다음 주(10/26~30) 우리 회사**:
   - 상황 매트릭스로 다짐·하이링크 컨셉을 각각 3개 만든다.
   - Meta 리드 광고를 캠페인 1·광고세트 1·소재 3개로 시작한다.
   - 파워링크 키워드 조합 세트를 만든다.
   - 브랜드별로 캐러셀 1개, 릴스 1개를 올린다.
   - 금요일에 첫 점검을 한다.
7. **주의할 점**:
   - 내용이 저가 의류 쇼핑몰(B2C·충동구매) 기준이고, 채널의 유료 도구·아카데미 판매 동선이 섞여 있다.
   - EP.10은 멤버십 전용이라 보지 못했다. 같은 채널의 공개 영상 3편으로 보완했다.

## 2. 편별 요약(우선순위 순)

### EP.12 — 2026년 Meta 광고의 핵심 [자막]

**핵심 주장**
- 2025년까지는 캐러셀·숏폼·'고객이 찍은 듯한' 게시물만 꾸준히 올려도 팔렸다.
- 2026년엔 모두가 그렇게 해서 포화됐다. 콘텐츠(1차 퍼널)에 광고를 더해야 팔린다.
- 자사몰은 Meta 광고, 네이버는 GFA이고 원리는 같다.
- 둘의 본질적 차이는 '퍼지는 기준'이다.
  - 콘텐츠는 참여(시청 지속·공유·저장·댓글)로 퍼진다.
  - 광고는 전환 행동(장바구니, 결제 시작, 구매 — 보통 구매로 지정)으로 퍼진다.
  - 그래서 콘텐츠는 판매 의도를 늦게 드러내고, 광고는 처음부터 대놓고 판다.

**광고 소재 구조**(15~20초 영상 기준. 대본만 정하면 끝난다는 입장)
1. 첫 문장에서 특정 상황·대상을 지목한다('이번 겨울 ○○ 여행 때 입은 바지' 같은 식). 그 상황에 있는 사람만 멈추게 하는 것이 목적이다.
2. 바로 제품명과 가격을 말한다.
3. 문제를 짧게 짚는다(춥다, 부해 보인다 같은 감정).
4. 장점 2~3개.
5. 그 상황에 맞춘 권유로 끝낸다.

- 막연한 비교('아직도 ○○핏 입으세요?')보다 상황 지목이 더 뾰족하다.
- 상품명만 넣은 소재(일반 명사형)는 Meta의 AI가 '누가 좋아하는지' 학습할 수 없어 효율이 안 난다.

**운영 방식('Meta 광고는 시스템')**
- 한 제품의 사용 상황·대상을 여러 개로 쪼개 소재를 각각 만든다.
  - 돌려 보면 예상 밖 대상(예: 밤낚시)에서 반응이 나온다. 그러면 그 대상에 맞춰 변주한다(색·성별·헤어 등).
- 이론 틀을 정해 두고 소재를 매일 만든다. 테스트 → 살아남은 소재 변주 → 예산 증액 순서다. 채널은 대행사가 이렇게 해 주지 않는다고 주장한다.
- 소재 하나가 주 50전환 이상 나오면 Meta가 비슷한 사람을 매우 잘 찾는다(머신러닝 학습).
- 예상은 자주 빗나간다. 반응이 없을 줄 알았던 특정 대상이 더 반응하는 경우가 많다.
- 사례: 기모 조거를 '배달 기사' 상황으로 지목하자 댓글 논쟁이 붙었고, 확산과 전환으로 이어졌다.
- 상세페이지 기획(제품별 근거, 스토리보드)을 꼼꼼히 하던 사람이 소재도 잘 만든다.
- 과제: 주 7·7·7·7 루틴(상품 등록·캐러셀·광고 영상·게시물 각 7개, 합 28개). 한 달 뒤 상품 200개 이상.

**우리에게**
- B2B 리드 광고에 그대로 맞는 틀이다. '관리소장·입대의 회장·시행사 담당'처럼 대상·상황을 지목하는 훅과 '무료 진단·제안서' 같은 명확한 제안을 묶으면 된다.
- 단 '주 50전환'은 우리 예산으로는 불가능하다. 3장 B를 참고.

### EP.7 — 파워링크·쇼핑검색광고 세팅 [자막]

**상황**
- AI로 일주일에 27개를 등록했지만 하루 유입은 5~15명이었다. 목표는 하루 100명.
- 해법 순서: ① 상품을 더 등록 → ② 광고(파워링크·쇼핑검색, 이후 GFA·Meta·릴스) → ③ 버티컬 입점·자사몰.

**관찰한 숫자**
- 쇼핑검색 클릭률 1.09%(채널이 말하는 기준선 0.75%보다 높음), 첫 캠페인은 1.41%. AI 이미지도 클릭을 받는다는 근거로 제시했다.
- 광고비 1만 원쯤 쓰면 첫 주문이 들어온다고 예상했다.
- 네이버 광고주센터는 GFA와 검색광고 계정이 하나로 합쳐졌다(광고비도 한 잔액에서 빠짐).

**쇼핑검색 세팅(영상 그대로)**

| 단계 | 설정 |
|---|---|
| 캠페인 | 유형 쇼핑검색. 이름 = 도매 상품명 + 도매처명. 하루 예산 15만 원(상한 개념). 고급 옵션 '자동 추적 URL 파라미터' 켬 — 어떤 검색어로 들어왔는지 보는 용도이고 ROAS를 올리지는 않음 |
| 광고그룹 | 쇼핑몰 상품형. 기본 입찰 200~300원(예 280원). 하루 15만 원. 노출 매체 '유형 선택' → 파트너 매체 제외 + 이름에 '네이버'가 없는 매체 제외(ZUM 등은 리타게팅이 안 됨). 당근마켓도 제외 목록에 넣음(자막은 '추가'라고 하지만 결과가 '네이버 매체만 남김'이라 제외로 해석). PC 60% / 모바일 120% |
| 소재 | 상품 검색·추가 → 상세 → 수정 → '노출용 상품명'에 키워드를 조합형으로 넣어 노출 키워드를 넓힘 |

**파워링크 세팅**

| 단계 | 설정 |

**확장 검색에 대한 채널 설명**
- 예전 파워링크는 등록 키워드와 정확히 같아야 노출됐다. 전환율은 높지만 볼륨이 작았다.

- 볼륨과 전환이 안 나오면 일치 검색으로 돼 있을 가능성이 높다.

**사실 확인(perplexity 정리. 네이버 도움말 1522·1126 등을 인용했으나 원문 재확인 권장)**

### EP.10 — 숏폼 [불가 → 공개 대체 S1·S2·S3]

EP.10은 멤버십 전용이라 내용을 확인하지 못했다. 아래는 같은 채널의 공개 숏폼 영상 내용이고, 본편과 같다는 보장은 없다.

**S1 숏폼 5단계(2025-08)**
- 순서: ① 상품 선정 → ② 대본 기획 → ③ 대본 줄마다 시각 자료 기획 → ④ 녹음 → ⑤ 촬영·편집(캡컷).
- 원리: 2초짜리 영상 20~30개 + 목소리 + 자막.

대본 구조:

| 순서 | 내용 | 요령 |
|---|---|---|
| 훅 | 질문으로 시작('혹시 ~ 알고 계셨어요?' 유형) | 훅 10가지 중 가장 쉬운 것. 처음부터 장점을 나열하지 말 것 — 판다는 의도는 늦게 |
| 내 이야기 | 내가 원래 어떻게 생각했는지(공감) | 자극보다 담담하게 |
| 반전 | '그런데 다 별로였다' → '그러다 찾은 게 이것' | 내 얘기를 하고 싶은 얘기로 끌고 오는 연결 고리 |
| 필살기 | 제품의 핵심 장점 하나 | |
| 비교 | 비교 대상의 문제 → 그로 인한 불편 → 우리의 해결 | 장점만 늘어놓으면 설득력이 떨어짐 |
| 자문자답 | 예상 반박을 내가 묻고 답함(예: 세탁하면 줄지 않나? → 직접 10번 돌려 봄) | 장점 사이의 연결을 재미있게 |
| 나열 | 남은 장점은 짧게, '게다가'로 연결 | 길게-짧게 리듬 변주. 고객의 말투로 |
| 마무리 | 한 줄 정리 | |
| CTA | 원래 가격 → 지금 혜택 → 행동(팔로우 + 댓글 키워드를 남기면 링크를 DM) → 기한(7일만) | CTA가 없으면 조회수만 남고 휘발 |

시각 자료와 녹음 규칙:
- 말은 천천히 해도 화면은 1~2초마다 바뀌게 한다.
- 줄마다 1차원적으로 맞는 장면을 붙인다(세탁 → 세탁기를 가리키는 장면).
- 장면이 애매한 줄은 감정 동작(팔짱·박수·책상 치기)으로 채운다.
- 반전 지점에는 특이한 장면을 넣는다(역재생 등).
- 문제는 과장해서 보이게 한다.
- 녹음은 본인 목소리, 휴대폰, 원테이크, 또박또박, 감정을 실어서. AI 목소리·음성 변조는 쓰지 말라고 한다(S1).

**S2 AI 아바타 숏폼(2026-09)**
- 목소리까지 한 번에 입히는 AI 영상 도구는 입 모양·손짓에서 티가 난다. 그래서 3단계로 나눈다.
  1. 아바타: 체형 참고 사진 + 코디 참고 사진을 합쳐 세상에 없는 인물을 만든다(저작권·초상권 회피 목적).
  2. '모션 카피': 내가 대본대로 말하며 같은 구도로 찍은 영상의 동작을 아바타가 따라 한다.
  3. 목소리: 일레븐랩스로 만들고 한 목소리로 고정한다. 캡컷으로 편집한다.
- 선글라스·마스크로 입을 가려 립싱크 문제를 없앤다.
- 대본은 해외에서 검증된 바이럴 포맷 8가지(예: '이것만 기억해', '조합 추천', '사요/안 사요', '티어 리스트')에 내용만 바꿔 넣는다.
- 비수기에는 광고 대신 숏폼으로 팔로워(모수)를 키우고, 성수기에 광고를 시작한다. 광고비 0원으로 14일 동안 팔로워가 약 2만 명 늘었다고 주장한다.
- **S1(본인 목소리)과 S2(AI 목소리)는 권고가 서로 다르다.** 1년 사이에 채널 입장이 바뀌었다.

**S3 수강생 사례(2026-04)**
- 만드는 법: 피팅 모델 이미지에 내 상품 사진을 입힌다 → 9:16으로 자른다 → 간단한 동작(손하트) 영상을 만든다 → 음악 비트마다 룩을 바꾼다(룩 6개). 생성 창 5개를 병렬로 돌린다.
- 결과(본인 주장): 팔로워 110명에서 시작해 첫 영상 3만 → 70만 → 200만·300만 조회. 한 달 만에 팔로워 2.3만 명. 자사몰 매출 대부분이 AI 숏폼에서 나온다.
- 아이디어: 남의 숏폼 + 내 감각. 인기 주제(하객룩)에 웃긴 구체 상황 훅을 얹었다. '문제 → 코디로 해결' 구조가 잘 됐다.
- 상세페이지는 90점짜리 하나보다 60점짜리를 빨리 많이 만든다. 비교 대상 같은 기본 요소는 유지한다.

### EP.13 — 중간 정리 [자막]

- **매출 = 유입 × 전환 × 객단가.**
  - 1~4편(기본 세팅·소싱·AI 피팅·AI 상세)은 전환 요소다.
  - 5~9편(쇼핑검색·파워링크·버티컬·자사몰·카드뉴스·숏폼·GFA·Meta)은 유입이다.
  - 전환 요소를 먼저 갖추고 유입을 붙인다.
- 파워링크·쇼핑검색은 '루틴 광고'다. 작은 클릭 단가로 고정해 깔아 두고 세밀하게 만지지 않는다.
- 숫자: 약 20일 누적 매출 약 600만 원. 첫 AI 릴스(30분 제작)가 7만 조회. 인스타 팔로워가 3명인데도 자사몰 주문이 들어왔다.
- 상품 1~7개로는 안 팔린다. 최소 40~60개가 필요하고, 품질을 스스로 점검해야 한다.
- 사업은 넣은 만큼 바로 나오지 않는다(축적 기간이 필요). 이룬 것에 집중하라고 한다.

  - 자사몰: Meta·인스타
- **정리 업무 자동화(EP.2)**: 사람이 하던 정리를 '캡처 → AI 추출 → 장부(진행 단계·반납 기한 D-day) → 엑셀/구글시트'로 바꾼다.
- **버티컬 입점(EP.9)**: 상품 3~5개로 신청하면 거절되고 30일을 기다려야 한다. 15~20개를 갖춘 뒤 신청한다.
- **카페24 자사몰(EP.9)**:
  - 결제는 토스페이먼츠 하나(+ 네이버페이·카카오페이)로 해서 부가세 정리를 단순하게 한다.
  - 디자인은 고객이 익숙한 스마트스토어와 비슷하게 한다(반응형, 모바일·PC 둘 다 확인).
  - 자사몰 상품명은 키워드 대신 직관적으로 짓는다.
  - 무통장입금은 즉시 현금이다. 입금자 자동 매칭 앱을 쓴다.
- **자사몰 통로(EP.9)**: 통로가 없으면 방문은 0이다. 틱톡·유튜브·인스타에 공통으로 올릴 수 있는 숏폼이 가장 쉬운 통로다.

### 의류 전용 편 — 한 줄 정리(옮겨 쓸 부분만 덧붙임)

- **EP.3 소싱**
  - 내용: 검색량(아이템스카우트)은 '시장조사 신호'로 본다. 버티컬에서 핏·디테일·가격대를, 무신사 랭킹에서 브랜드 디자인 흐름을 본다(가품 금지).
  - **옮겨 쓸 것**:
    - Meta 광고 라이브러리에서 경쟁사가 여러 소재로 반복해 돌리는 상품 = 팔리는 상품.
    - 인스타 광고 중 반응(좋아요·댓글)이 많은 것 = 힌트.
    - 첫 진입은 저관여·저가 상품으로 판매 경험부터 쌓는다.
    - '다 올려 보고 팔리는 것에 볼륨을 싣는다'.
- **EP.4 AI 피팅컷**
  - 내용: 아무 데서나 찍은 실사 한 장 + 이미지 생성 모델(나노바나나 프로). GPT가 짧은 지시를 긴 프롬프트로 바꿔 준다.
  - **옮겨 쓸 것**:
    - 배경을 AI가 지어내게 하지 말고, 실제 촬영한 배경 사진을 파일명('배경 A')으로 지정해 넣는다.
    - 신발·색상도 참고 파일('신발 A', '브라운 컬러 레퍼런스')로 지정한다.
    - 생성 창을 여러 개 띄워 병렬로 돌리고 좋은 것을 고른다.
    - AI 티는 시선 돌리기, 입 가리기, 그레인·채도 보정으로 줄인다.
- **EP.5 도구 시연**
  - 내용: 피팅컷 1장 → 포즈 5장, 디테일컷 추출, 색·제품·포즈·배경 바꾸기, 이미지 → 영상(움직임을 최소화해 질감이 보이게).
  - **옮겨 쓸 것**:
    - '사용자는 짧게 말하고 품질 설계는 뒤에서 한다'(누구나 같은 품질).
    - Veo 계열은 소리가 들어가 의류 외 업종에는 쓸 만하다. 다만 카메라 고정과 1:1 비율이 약하다는 평가다.
- **EP.8 3PL**
  - 내용: 의류 대리발송 업체 사용법(설명란 제휴처).
  - **옮겨 쓸 것**: 'AI로 1시간의 가치가 커졌으니 포장·배송 같은 저부가 업무는 외주로'.

### 보충 — '3단계' AI 직원(L1~L5)

**3단계 정의(L1)**
- 1단계 채팅(묻기) → 2단계 코워크(파일·사이트·엑셀을 대신 조작) → 3단계 코덱스·클로드 코드(반복 업무를 프로그램으로 만들어 'AI 직원'으로 씀).
- 기본 설정: 전체 권한, 로컬 메모리, 휴대폰 원격 제어, 크롬 허용.
- 자주 쓰는 지시 3개:
  1. '중학생 수준으로 번호 매겨 차근차근 알려 줘'
  2. '우리 대화를 바탕으로 내 사업에 적용할 프로그램 5개 추천해 줘' — 아이디어를 AI에게서 받고 하나를 골라 만든다
  3. '매일 아침 9시에 보고해'
- '스킬' = 한 번 가르친 일을 저장하는 것. '방금 한 작업을 스킬로 만들어 줘' 하면, 다음부터 상품 정보만 주고 실행한다.
- 프로젝트는 사업체·부서별로, 대화창은 역할별로 나눈다.

**AI 직원 8명 조직도(L2)**
- 역할: 콘텐츠 기획, 디자인, CS, 광고 2명(소재 수집·집행), 발주, 회계, 상세페이지.
- 원칙:
  1. 직원(역할)마다 프로젝트를 따로 둔다.
  2. 반복 업무는 프로그램으로 떼어 낸다.
  3. 나머지 업무는 기록이 프로젝트에 쌓여 시간이 갈수록 잘하게 된다.
  4. 최종 확인과 결재는 대표가 한다(몇 초).
  5. 한 번에 다 만들지 말고 하나씩, 가장 귀찮은 일부터.
- 예: 새벽에 기획 담당이 그날 주제안을 슬랙에 올린다 → 아침에 대표가 채택·반려 → 채택 기록이 쌓이며 대표 취향을 학습한다.

**업무 사이클 전체에 AI 투입(L3)**
- 소싱 직원: 6시간마다 플랫폼 랭킹과 네이버 검색량을 교차해 S/A/B 등급으로 보고한다(하루 4번).
- 상품 등록: 10분짜리 작업 화면 녹화를 주고 스킬로 만든다.
- 광고 담당 AI 3명:
  - 소재 수집기
  - 폴더에 소재를 넣으면 캠페인·세트·소재를 세팅하는 담당
  - 정해진 시각에 대표가 정한 기준으로 일예산을 증액·감액·끄기 하는 담당
- CS 대시보드: 여러 플랫폼 문의를 한곳에 모으고 답변 초안을 붙여 '전송' 버튼만 누르게 한다.
- CRM: 기획전 랜딩 페이지를 만들어 알림톡으로 보낸다.
- 자동화가 끝나면 쇼핑몰을 하나 더 연다(파이프라인 늘리기).

**경쟁 광고 아카이브(L4)**
- 크롬 확장으로 광고 라이브러리 화면에서 '수집'을 누르면 날짜·페이지·링크가 시트에 쌓인다.
- 자동 모드: 벤치마크 업체를 등록해 두면 노출 상위 5개씩 가져온다.
- 대본 추출: 영상 → 음성 → 텍스트.
- 활용:
  - 대본 첫 문장만 쭉 훑어 훅 유형(질문형·가격형·상황극형)을 파악한다.
  - 좋은 대본을 묶어 AI에게 '공통 구조를 분석해서 내 상품 대본 3개'를 시킨다.

**카드뉴스 분업(L5)**
1. 코덱스(머리): 주제 → 표지 카피·장별 헤드라인·본문 → (다른 세션에서) 이미지 프롬프트 → 톤이 같은 9장(파일명에 번호).
2. 클로드 코워크(손): 미리캔버스에서 정해진 서체·크기·위치로 배치한다. 작업 화면을 녹화해 스킬로 가르쳤다.
3. 대표: 최종 선택.
- 한 세션에 다 시키면 품질이 떨어진다.
- HTML로 만들어 이미지로 바꾸는 방식은 서체·줄바꿈이 어색해 AI 티가 난다고 지적한다.
- 굳은 작업은 Playwright 스크립트로 옮겨 가볍게 한다.

### A. 공통 — '콘텐츠형'과 '광고형'을 따로 만든다 [제안, 1순위]

- **근거**: EP.12(퍼지는 기준이 다름) + S1(콘텐츠는 판매 의도를 늦게).
- **할 일**: 자동 제작·제작의뢰실·광고 문구에 '목적: 콘텐츠(참여) / 광고(전환)' 선택을 두고, 틀과 검사를 분리한다.

| 항목 | 콘텐츠형 | 광고형 |
|---|---|---|
| 첫 3초 | 질문·공감·이야기. 가격·제안 금지 | 대상·상황 지목 + 무엇을 주는지(제안·가격)를 2초 안에 |
| 구조 | 이야기 → 반전 → 비교 → 자문자답 → CTA(저장·댓글 키워드) | 지목 → 제안 → 문제 한 줄 → 장점 2~3개 → 행동 |
| 길이(제안값) | 30~45초(이야기형) | 15초 |
| 성공 지표 | 시청 지속·저장·공유·댓글 | 리드·문의 단가, 적격 리드 비율 |
| 훅 채점 | 지금 엔진 + '처음부터 판다' 감점 | '대상 호명·제안 명확성' 가점, 제안이 없으면 감점 |

- **지금 문제**: 엔진이 두 경우를 같은 기준으로 채점한다. 그래서 광고 제목이 정보성 훅이어도 좋은 점수를 받을 수 있다.

### B. Meta 광고 자동 세팅(리드 광고 중심) [제안]

**1. 세팅안 기본값**(우리 예산 현실 반영 — `docs/handoff/MKT_AGENT_SKILLS_2026-10-22.md` 3-1)

| 항목 | 기본값 |
|---|---|
| 구조 | 캠페인 1 · 광고세트 1 · 서로 다른 컨셉 3~4개. 같은 컨셉에서 색·모델만 바꾼 변주는 1개로 센다 |
| 목표·최적화 | 리드(인스턴트 양식). 예산이 커지고 리드가 월 200건을 넘으면 '전환 리드' 목표 검토 |
| 대상 | 지역 반경 + Advantage+ 대상(넓게). 대상을 좁히는 대신 소재가 대상을 고르게 한다 |
| 소재 | 광고형 15초 영상 또는 정지 이미지(1:1·4:5). 컨셉마다 '대상·상황·제안' 정보를 붙인다 |
| 양식 | 질문 3~4개(B2B: 단지명·세대수·입주 시기 또는 운영 형태·연락처) + 개인정보 고지 + 감사 화면에 다음 단계(연락 시간) |
| 판단 | 학습 2~4주 전에는 확실한 실패(지출만 있고 클릭 0 등)만 정리. 주 1회 하위 1~2개 교체 |

**2. '상황 매트릭스' 소재 생성기**(EP.12의 '경우의 수 쪼개기')
1. 입력: 제품·서비스 + 구매자 역할 목록 + 상황 목록(입주 전, 운영 중 문제, 재계약 등) + 고통.
2. AI가 '대상 × 상황' 표에서 컨셉 후보 8~12개를 낸다.
3. 대표가 3~4개를 채택한다.
4. 채택한 컨셉으로 광고형 대본·이미지를 생성한다.
- 채택·반려 기록은 브랜드 메모리에 저장한다(L2의 취향 학습).

**3. 이긴 소재 → 다음 컨셉**
- 이긴 컨셉의 '대상·상황'은 유지하고 형식·각도를 바꾼 새 컨셉을 만든다.
- EP.12처럼 색·성별·헤어만 바꾸는 변주는 효과가 작다고 본다. 우리 설계 문서의 판단(비슷한 소재 20개 = 사실상 1개)을 따라 컨셉 단위 변주를 기본으로 한다.

**4. 리드 품질 신호를 Meta에 돌려준다(CAPI for CRM)** [제안, 우선순위 높음]
- **왜**: EP.12의 '광고는 전환 행동으로 퍼진다'를 B2B로 옮기면, 양식 제출보다 '적격 리드'가 학습 신호여야 한다.
- **보낼 이벤트**: 워크인 영업 리드 단계가 바뀔 때마다 Meta Conversions API로 보낸다.
  - 새 리드 = Lead
  - 연락함 = Contacted
  - 적격 = QualifiedLead
  - 계약 = ConvertedLead
  - 부적격 = DisqualifiedLead
- **필수 조건**:
  - Meta lead_id(15~17자리)를 **숫자가 아닌 문자열로 저장**한다. 자바스크립트 숫자는 16자리를 넘으면 반올림된다.
  - action_source = system_generated, custom_data.event_source = crm, lead_event_source = 워크인.
  - 단계마다 이벤트 1건.
  - 하루 1회 이상 전송. 이벤트 시각은 7일 이내여야 한다.
- **'전환 리드'(적격 리드 최대화) 목표 요건**:
  - 월 리드 200건 이상, 목표 단계 도달률 1~40%, 28일 안에 도달, 매일 업로드.

  - 200건 미만이어도 지금부터 보내 두면 보고와 맞춤 대상에 쓸 수 있다.
- **먼저 할 일**: 지금 metaLeads 구현에서 lead_id를 문자열로 저장하는지 확인한다.

**6. 경쟁 광고 아카이브(L4·EP.3) — 수집은 사람이, 분석은 AI가** [제안]
- **사실**: Meta 광고 라이브러리 API는 정치·사회 이슈 광고와 EU·영국에 게재된 광고만 준다. 한국 일반 광고는 웹 화면에서만 보인다(Meta 공식 안내). 채널처럼 크롬 확장으로 긁는 방식은 워크인 정책('크롤링 금지')과 맞지 않는다.
- **대안**:
  1. 고객이 광고 라이브러리 링크를 붙여 넣거나 영상을 올린다.
  2. 워크인이 대본을 추출한다(음성 → 텍스트).
  3. 첫 문장 훅 유형을 분류한다(질문·가격·상황극·비교).
  4. 여러 개를 묶어 '공통 구조 → 우리 대본 3안'을 만든다.
- 함께 기록할 것: 광고 시작일(오래 돌린 광고 = 효과가 있을 가능성), 같은 업체가 비슷한 소재를 반복한 횟수.

### D. 숏폼·릴스 구조 [제안, 3순위]

1. **템플릿 두 가지**: 콘텐츠형 대본 틀(S1)과 광고형 대본 틀(EP.12)을 만든다. 생성 결과에 단계를 표시한다(훅/이야기/반전/비교/자문자답/CTA).
2. **화면 컷 계획**:
   - 대본 한 줄마다 컷 2~3개(각 1~2초).
   - 지금 구성표의 '장면 4초' 경고는 낭독 길이 기준이다. 화면 컷 수 기준을 따로 둔다(편당 20~30컷).
   - 줄마다 '1차원 장면'을 자동 제안하고, 애매한 줄은 감정 동작, 반전 지점은 특이 장면으로.
3. **길이 프리셋**: 광고형 15초 / 콘텐츠형 30~45초. 지금 기본값 15초는 이야기형에는 짧을 수 있다. 시험으로 판단한다.
4. **포맷 라이브러리 8~16개**(S2·L3)
   - 예: '이것만 기억해', '조합 추천', '한다/안 한다', '티어 리스트', 'A vs B', '체크리스트', '전후 비교', '자주 받는 질문'.
   - B2B 예: '입주 전 커뮤니티 준비 — 한다/안 한다', '아파트 커뮤니티 시설 티어 리스트(운영 난도)'.
5. **목소리**: 기본은 실제 직원 목소리(S1, B2B 신뢰). AI 목소리는 선택 사항(S2). AI 인물을 쓸 때의 표시 규칙은 5장 13번.
6. **CTA 검사**: 마지막 3초에 행동 1개와 이유(기한·혜택)가 있는지 본다.

### E. 인스타 성장 루틴 [제안]

- **강도 프리셋**
  - '의류식 최대': 캐러셀 매일, 숏폼 매일, 광고 소재 하루 2~3개.
  - 'B2B 기본': 캐러셀 주 2~3개, 릴스 주 2~3개, 광고 컨셉 주 1~2개 교체. 지금 주 3회 운영과 맞물리게 한다.
- **캐러셀 생성기**(EP.11 '캐러셀 5.0' 대응)
  1. 제품·서비스 입력
  2. 주제 후보(A vs B, N가지 방법, 유형별 추천, 체크리스트)
  3. 장별 문구·이미지 계획
  4. 디자인 규칙 적용(1080×1350, 제목 밑 20% 검정 상자, 굵기 대비, 마지막 장 CTA '댓글에 ○○')
- **템플릿 품질(L5)**: HTML을 그대로 이미지로 찍은 듯한 카드뉴스는 티가 난다는 지적이 있다. 브랜드별 '디자이너 템플릿'(서체·굵기·위치·여백 고정)을 만들고 그 안에 글만 넣는 방식이 안전하다. 우리 자동 제작이 어떤 렌더링을 쓰는지는 이번에 확인하지 않았다.
- **댓글 키워드 → 리드**
  - 흐름: 댓글 키워드 → DM 초안 → 리드(설계 문서 아이디어 4번과 연결).
  - 캐러셀·릴스 CTA를 '댓글에 체크리스트' 같은 키워드로 통일하면 문의 흐름이 자동으로 이어진다.
  - 채널은 매니챗(추정)으로 자동 발송한다. 워크인은 '사람이 [보내기]'가 원칙이다. 키워드 응답만 자동으로 할지는 5장 19번을 참고(대표 결정).
- **반응 좋은 게시물 재활용**: 아웃라이어 리포트와 연결해 상위 게시물의 구조를 다음 주 계획에 자동 반영한다.
- **비수기 모수 키우기(S2)**: 광고 효율이 낮은 시기엔 콘텐츠 비중을 늘리고 성수기 직전에 광고를 시작한다. 업종별 시즌 캘린더(V44 아이디어 9)와 연결한다.
