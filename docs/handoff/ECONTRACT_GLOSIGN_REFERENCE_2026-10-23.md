# 전자계약 — 글로싸인 레퍼런스 비교와 2차 개편안 (2026-10-23, 로컬 → 클라우드 #463 · #116 재요청)

대표 지적(10/23 08:59): "전자계약서 글로싸인을 레퍼런스하라고 했는데 전혀 반영되지 않았습니다."
로컬이 대표 글로싸인 체험 계정(대표 가입·휴대폰 인증)으로 계약 만들기 5단계를 끝까지 따라가며 화면을 확인했습니다. 시험 문서는 '검토' 단계에서 멈췄고 **최종 확인을 누르지 않아 아무에게도 보내지 않았습니다.** 캡처는 로컬 비공개 폴더(.local-private/glosign, 커밋 안 함)에 두고, 이 문서에는 구조와 동작만 적습니다. 글로싸인 문구·디자인을 그대로 베끼지 말고 흐름과 기능만 참고합니다.

## 1. 핵심 차이 한 줄
- **글로싸인:** 내가 가진 문서(PDF·한글·워드·사진)를 올림 → 서명자마다 색을 정함 → 문서 위에 서명·도장·텍스트·날짜 칸을 **끌어다 놓음** → 보냄. 계약은 **'계약 관리'라는 독립 메뉴**에서 상태별로 관리합니다.
- **워크인(현재):** 근로계약서·비밀유지서약서 **텍스트 서식**에 빈칸을 채워 직원에게 보냅니다. 서명은 문서 맨 끝 한 곳에만 들어갑니다. 위치는 **관리 › 사용자 관리 안의 모달**이라 메뉴로 찾을 수 없습니다. 영업 쪽 '제안·계약'은 계약 만료·재입찰 관리일 뿐 전자서명과 연결되어 있지 않습니다.
- 대표가 원한 것은 **"회사가 쓰는 아무 계약서나 올려서 바로 전자서명 받는 도구"**입니다. 지금의 직원 입사 서류 기능은 그 일부로 흡수해야 합니다.

## 2. 글로싸인 화면 구조 (확인한 그대로)
### 2-1. 첫 화면 '계약 관리'
- 위 메뉴는 **계약 관리 · 문서 관리 · 서식 관리** 3개이고, 왼쪽 위에 큰 **[계약 시작하기]** 버튼이 있습니다.
- 왼쪽 상태 분류
  - 진행 중 계약: 전체 / **내 서명 필요** / **상대 서명 필요** / **대면 진행 중** / **작성 중**
  - 서명 완료 계약
  - 취소 계약
  - 폴더(폴더 관리)
  - 스마트 분류
- 목록 위: 초기화, 정보 다운로드(목록 내보내기), 이동(폴더), 조회 기간(기본 최근 60일), 페이지 넘김
- 빈 화면: "해당 폴더에 속한 문서가 없습니다" 아래 [전자서명 시작하기]
- 그 밖의 메뉴: 대량 전송, 링크 계약(링크 하나로 여러 명이 서명), 전자도장 만들기

### 2-2. 계약 만들기 5단계 (위에 진행 막대: ①문서 업로드 ②계약 방법 ③참여자 설정 ④위치 지정 ⑤검토, 오른쪽 위 [이전]·[다음], 왼쪽 위 [나가기])
| 단계 | 화면 내용 |
|---|---|
| ① 문서 업로드 | 여러 파일을 올릴 수 있고(hwp·pdf·jpg·png·doc·docx, 20MB 이하) 순서를 바꿀 수 있습니다. 내 PC 말고 구글 드라이브·드롭박스·내 문서함·내 서식함에서도 가져옵니다. **계약 설정**: 계약명, 전체 메시지, 감사추적인증서 언어(한국어·중국어·영어), 알림 설정 |
| ② 계약 방법 | 카드 3장: **본인 서명**(내 서명만 — 무료) / **비대면 계약**(참여자가 각자 기기로) / **대면 계약**(한 기기로 만나서). 카드마다 ? 도움말 |
| ③ 참여자 설정 | **일괄 설정**: 전송 언어, 만료일(n일 안에 서명), 휴대폰 전송(카카오톡 / 문자) + [적용]. **계약 생성자** 줄(이름·메일). 탭은 **서명 참여자 / 계약 참조자**(서명하지 않고 결과만 받는 사람). 참여자 줄: 순서 켜기·끄기, 이름(주소록에서 고르기), 이메일, 카카오톡·문자 번호, 전송 언어, 만료일, 개별 메시지, 본인인증 같은 접근 설정. 참여자마다 왼쪽에 **색 띠**(빨강·노랑…)가 붙고 [+]로 추가 |
| ④ 위치 지정(편집기) | 왼쪽 세로 도구: **서명, 도장, 텍스트, 서명자 입력 텍스트, 날짜, 체크박스, 드롭다운, 이미지**. 아래 칸은 참여자 목록·서식·도움말. 그 옆 '서명 참여자' 목록(참여자 색, 클립 아이콘 = **참여자에게 첨부파일 요청**). 가운데 문서 위로 끌어다 놓고, 놓은 칸은 **그 참여자 색**으로 칠해집니다. 위 막대: 메모, 확대(120%), 폭 맞춤·쪽 맞춤, 되돌리기·다시 하기, 삭제. 오른쪽 속성: 정렬 6종, **좌표(px)**, 담당 참여자 바꾸기, **필수**, 이동 가능, 태그 등록, 복사·삭제. 날짜 칸은 '자동 입력(서명일)' 또는 '참여자 입력'에 형식(YYYY-MM-DD 등)과 글자 크기를 고릅니다. 처음 들어오면 4단계 안내 말풍선이 뜹니다. 참여자마다 서명·도장 칸이 최소 1개 있어야 다음으로 넘어갑니다. 단축키 안내와 [미리보기] |
| ⑤ 검토 | '계약 내용 검토': 계약명, 감사추적인증서 언어, 전체 메시지, 요청자 알림 설정. 참여자마다 전송 언어, 만료일, 접근 설정, 본인인증, 개인 메시지, **조건 수(서명 2 · 날짜 1처럼 아이콘과 개수)**. 마지막에 [최종 확인] = 발송 |

### 2-3. 그 밖의 화면
- **문서 관리:** 내 문서함(모든 문서·중요 문서, 폴더 관리). 문서를 올려 두었다가 계약에 씁니다. 삭제·이동·다운로드·제목 검색·기간 선택이 있습니다.
- **서식 관리:** 자주 쓰는 계약서에 칸을 미리 배치해 두고 반복해서 보냅니다. 대량 전송과 링크 계약도 서식을 기반으로 합니다.

## 4. 2차 개편안 — 워크인 '전자계약' (업종 중립 문구)
### 4-1. 메뉴
- 공통 메뉴에 **'전자계약'**을 넣습니다(업무·영업 두 공간 모두. 권한 = 관리자 + '계약 담당' 권한자).
- 사용자 관리의 [전자계약서] 버튼은 남기고, 누르면 이 화면의 '새 계약'을 직원이 채워진 상태로 엽니다.
- 영업 '제안·계약'의 거래처 줄과 리드·거래처 상세에 **[전자계약 보내기]**를 둡니다. 거래처 담당자가 서명자로 자동으로 들어갑니다.

### 4-2. 첫 화면 = 계약 관리
- 왼쪽(휴대폰에서는 위쪽 칩)
  - 진행 중: **내 서명 필요 · 상대 서명 필요 · 대면 진행 중 · 작성 중**
  - 완료 · 취소·거절·만료
  - 폴더
- 표 열: 계약명·문서번호 | 참여자 진행(●●○ 2/3, 누르면 참여자별 상태·열람 시각) | 상태 | 보낸 날·만료일(D-n) | 연결(직원·거래처·업무) | 작업(재발송·취소·완료본)
- 위쪽: 검색(계약명·참여자·번호), 기간, 내보내기(CSV), 오른쪽 위 **[새 계약]**

### 4-3. 새 계약 5단계 (글로싸인과 같은 순서, 위 진행 막대, [이전]·[다음]·[임시 저장])
1. **문서:** 아래 세 가지 중에서 고릅니다. 공통 설정은 계약명, 전체 메시지, 만료일 기본값입니다.
   - ⓐ 파일 올리기(PDF·이미지 바로, 한글·워드는 서버에서 PDF로 변환하고 변환이 안 되면 "PDF로 저장해 올려 주세요" 안내)
   - ⓑ 자료실에서 고르기
   - ⓒ 회사 서식(기존 근로계약서·비밀유지서약서 텍스트 서식은 PDF로 렌더해 같은 흐름에 태움)
2. **계약 방법:** 내 서명만 / 비대면(각자 링크) / **대면(이 기기에서 차례로 서명)**
3. **참여자:**
   - 서명자 줄: 순서, 이름, 메일, 휴대폰, 접근 코드 전달 방법(문자 자동·메일·직접 전달), 만료일, 개별 메시지, **첨부 요청**(예: 신분증 사본, 통장 사본)
   - 사람 고르기: 주소록·직원·거래처 담당자에서 검색합니다.
   - 참조자 탭: 완료본만 받습니다.
   - 일괄 설정 줄
   - 서명자마다 색이 정해집니다.
4. **위치 지정 편집기:**
   - PDF를 쪽 단위 이미지로 보여 줍니다.
   - 도구: 서명, 도장, 텍스트(서명자 입력), 날짜(자동=서명일 / 직접 입력), 체크박스, 선택 목록
   - 칸을 끌어 놓은 뒤 크기를 조절하면 칸이 서명자 색으로 칠해집니다.
   - 속성: 담당 서명자, 필수, 날짜 형식, 글자 크기, 복사·삭제
   - 편집 동작: 되돌리기, 확대·폭 맞춤, 쪽 썸네일
   - 다음으로 넘어가려면 **서명자마다 서명·도장 칸이 1개 이상** 있어야 합니다.
   - 처음 들어오면 3~4단계 안내 말풍선을 보여 줍니다.
5. **검토:** 계약 요약, 서명자별 조건 수(서명 n·날짜 n·텍스트 n), 만료일, 전달 방법을 보여 주고 **[보내기]**로 발송합니다.

### 4-4. 서명자 화면 (/sign/[token] 개편)
- 접속 코드를 확인하면 문서 전체를 보여 줍니다. 내 칸만 서명자 색으로 강조하고, **[다음 칸]** 버튼으로 차례대로 이동합니다.
- 칸을 누르면 종류별 입력 창이 열립니다: 서명(그리기·저장된 서명), 도장(이미지 올리기·자동 생성), 텍스트, 날짜, 체크.
- 첨부 요청이 있으면 [파일 올리기] 칸을 보여 줍니다.
- 필수 칸을 다 채우면 [서명 완료] → 동의 체크 → 완료로 넘어갑니다.
- 휴대폰에서 먼저 쓰기 좋게 만듭니다: 가로 폭 맞춤, 칸 확대.

### 4-5. 완료본·감사 추적
- 칸 값을 원본 PDF의 좌표에 합성해 완료본을 만들고, 맨 뒤에 **감사 추적 쪽**을 붙입니다. 감사 추적 쪽에는 참여자별 열람·서명 시각, IP, 기기, 원본 해시(SHA-256), 완료본 해시가 들어갑니다.
- 보관은 지금처럼 자료실에 합니다(인사 계약은 기밀, 거래처 계약은 영업 폴더). 연결된 거래처·업무의 타임라인에 '계약 완료'를 남깁니다(SALES_LEADS_REVAMP #461과 연결).
- 완료되면 모든 참여자와 참조자에게 완료본 링크를 보냅니다(메일·문자).

### 4-6. 서식(반복)
- 4단계에서 배치한 칸을 '서식으로 저장'할 수 있습니다. 다음 계약은 서식을 고르면 칸이 그대로 놓입니다.
- 대량 전송(같은 서식을 여러 명에게 각각 보냄)과 링크 계약(공개 링크 하나로 여러 명 서명)은 **3차**로 미룹니다.

## 5. 데이터(추가형 마이그레이션 제안)
- contracts에 `source_file_id`(원본 PDF), `method`(self·remote·inperson), `page_count`, `original_sha256`, `final_sha256`, `link_type`(employee·account·none), `account_id`, `task_id`, `folder`를 추가합니다.
- 새 표 `contract_fields`: id, contract_id, signer_id, type(sign·stamp·text·date·check·select), page, x, y, w, h(쪽 기준 비율 0~1), required, props jsonb, value, filled_at
- 새 표 `contract_ccs`: contract_id, name, email, phone
- 새 표 `contract_attachments_req`: signer_id, label, file_id
- 서식 칸: contract_templates에 `source_file_id`와 `fields_layout` jsonb를 추가합니다.
- 기존 텍스트 서식과 계약은 그대로 동작해야 합니다. 렌더 결과를 PDF 한 장짜리 원본으로 보고, 칸이 없으면 지금처럼 끝장에 서명합니다.

## 6. 구현 순서
1. 메뉴와 계약 관리 목록(상태 바구니·참여자 진행)을 만들고, 기존 계약을 그대로 보여 줍니다.
2. PDF 올리기, 위치 지정 편집기(서명·도장·텍스트·날짜), 서명자 화면에서 칸 채우기, 좌표 합성 완료본까지 만듭니다. **여기까지가 대표가 말한 '글로싸인 반영'의 최소선입니다.**
3. 거래처 대상 계약(영업 연결), 참조자, 첨부 요청, 문자 자동 발송을 붙입니다.
4. 대면 계약, 칸을 놓은 서식 저장을 붙입니다.
5. 한글·워드 변환, 체크박스·선택 목록, 감사 추적 언어를 붙입니다.
6. 대량 전송·링크 계약(3차)

## 7. 시험 기준
- 2쪽짜리 PDF를 올리고 서명자 2명(순서 1·2)에게 각각 서명 1·날짜 1·텍스트 1칸을 놓아 보냅니다. 1번이 서명해야 2번에게 링크가 가고, 완료본 **같은 좌표**에 서명·날짜·텍스트가 찍히는지 봅니다. 감사 추적 쪽의 원본 해시가 올린 파일의 해시와 같아야 합니다.
- 서명자에게 서명 칸이 없으면 4단계에서 '다음'이 막힙니다.
- 휴대폰(375px)에서 서명자가 [다음 칸]만 눌러 모든 필수 칸을 채울 수 있어야 합니다.
- 상태 바구니 숫자가 맞아야 합니다: 내 서명 필요(내가 서명자이고 내 차례), 상대 서명 필요(내가 보냈고 남이 남음).
- 거래처 계약이 완료되면 그 거래처 타임라인에 완료 기록과 완료본 링크가 남습니다.
- 기존 근로계약서 텍스트 서식을 보내도 지금처럼 동작해야 합니다(회귀 시험).
- 다른 회사 계약은 404입니다.

## 8. 참고
- 글로싸인 체험 계정은 대표 명의이고 30일 무료입니다. 결제하지 않습니다. 화면을 더 봐야 할 때만 로컬이 다시 엽니다.
- 시장 포지션: 글로싸인·모두싸인·이폼사인은 '계약만' 하는 도구입니다. 워크인은 **직원 입사 서류 + 거래처 계약 + 업무·영업 기록이 한 곳에 묶이는 것**을 차별점으로 설명합니다. 요금표에 넣을 경우 건당 과금 비교는 별도 시장표를 만들어 올립니다(메모리 원칙: 금액 제안에는 시장 분석을 함께 붙입니다).
