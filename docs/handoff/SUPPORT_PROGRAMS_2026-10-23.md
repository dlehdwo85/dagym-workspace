2. **청년일자리도약장려금 (경기경총, ~2027-03-31)** — 취업애로청년 정규직 채용 시 1인당 최대 720만원. 채용 전에 고용24 참여신청부터 하고, 2027년 유형 개편 전 2026 기준으로 확보.
3. **중진공 정책자금 11월 접수 (경기·인천 11/4 10시 ~ 11/5 17시)** — 업력 7년 미만 창업기반지원 등 저리 융자. 12월 접수 여부가 공지되지 않아 연내 사실상 마지막 확정 회차.
4. **경기도 중소기업육성자금 2차 (~12/31) + 용인시 특례보증 (최대 3억, 예산 소진 시)** — 경기·용인 이전 후 바로 쓸 수 있는 지역 운전자금(이차보전·보증). 조기 마감 전에 신청.
5. **경기산학융합원 R&D 기획·컨설팅 (예산 소진 시)** — 1월 디딤돌·2~3월 경기도 R&D 계획서 작성 전문가비 지원. 같은 시기에 연구개발전담부서 신고를 시작하면 두 사업 요건을 함께 맞춤.

곧 열리는 핵심 일정 (예상): 디딤돌 1차(12월 말 공고·1월 접수) → 창업도약패키지(1월 말~2월) → SW고성장클럽(1~2월) → 경기도 기술개발·IP나래·용인 긴급지원 1차(2~3월) → 데이터·AI바우처(2~3월) → NIPA SaaS 개발·사업화(3~4월).

## 3. 용인시 지식재산 긴급지원 3차 결과

**결론: 2026-10-23 기준, 3차 선정결과는 어디에도 공개 게시되지 않았음. 결과는 RIPC PMS 개별 통보 방식이라 대표가 PMS에 로그인하거나 담당자에게 전화로 확인해야 함 (확인 필요).**

공고 사실관계
- 공고명: [경기] 2026년 용인시 지식재산 긴급지원 사업(국내상표, 디자인출원) 모집공고(3차), 공고번호 경기-26-N4931 — [RIPC PMS 공고 상세](https://pms.ripc.org/pms/biz/applicant/notice/info.do?noticeSeq=4931&bizYear=2026)

- 지원: 상표 42만원·디자인 48만원 이내 국내출원 비용, 기업분담 40%(현금). 기업당 2,000만원 이내.

- 용인기업지원시스템(용인시산업진흥원) 공지·지원사업: 해당 결과 없음 — [용인기업지원시스템](https://ybs.ypa.or.kr/)
- 용인시 4차 공고는 없음 (같은 시기 화성시 3차, 남양주·연천·고양 4차만 있음).

## 4. 워크인 자동 수집용 공개 API

키 발급에는 기관·신청자·연락처 입력과 약관 동의가 필요하므로 대표(또는 담당자)가 직접 신청해야 함. 발급된 키는 저장소에 커밋하지 말고 환경변수로만 보관.

### 4-1. 기업마당 지원사업정보 API (기업마당 직접 제공)
- 제공 페이지: [기업마당 정책정보 개방 > 지원사업정보 API](https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi) (행사정보 API도 별도 제공)
- 요청: `GET https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do` — 응답 JSON 또는 XML(RSS)
- 인증: `crtfcKey` (필수). 같은 페이지 하단 'API 사용 신청'에 기관명·신청자명·이메일·전화·시스템명·시스템 IP 또는 URL 입력 → 등록 즉시 키 표시·이메일 발송. 문의 02-867-9765
- 파라미터: `dataType`(rss/json), `searchCnt`(0이면 전체), `searchLclasId`(01 금융·02 기술·03 인력·04 수출·05 내수·06 창업·07 경영·09 기타), `hashtags`(예: `경기,기술` 다중), `pageUnit`, `pageIndex`
- 갱신: 문서에 갱신주기 명시 없음. 공고 등록 시점 반영으로 보이며 응답 `ttl`=60 (**확인 필요**)
- 주요 필드: `pblancId`(공고ID), `pblancNm`(공고명), `pblancUrl`, `jrsdInsttNm`(소관기관), `excInsttNm`(수행기관), `bsnsSumryCn`(사업개요), `pldirSportRealmLclasCodeNm`(분야), `reqstBeginEndDe`(신청기간), `trgetNm`(지원대상), `reqstMthPapersCn`(신청방법), `refrncNm`(문의처), `rceptEngnHmpgUrl`(신청URL), `hashTags`, `creatPnttm`(등록일), `inqireCo`, `flpthNm`/`fileNm`(첨부), `printFlpthNm`/`printFileNm`(본문 출력파일), `totCnt`
- 비고: `hashtags=경기`로 경기도·시군·경과원·경기TP 공고가 조회됨 (10/23 기준 기업마당 '경기' 진행 공고 129건). RIPC 지역센터 공고 일부도 기업마당에 등록됨.

### 4-2. 공공데이터포털 '중소벤처기업부_중소기업 지원사업 공고 조회 서비스' (기업마당 데이터)
- 제공 페이지: [data.go.kr 15157820](https://www.data.go.kr/data/15157820/openapi.do)
- 요청: `GET https://apis.data.go.kr/1421000/bizinfo/pblancBsnsService` — REST, JSON+XML
- 인증: 공공데이터포털 `serviceKey` (활용신청: 개발단계 자동승인, 운영단계 심의승인), 개발계정 트래픽 10,000
- 갱신주기: 일간
- 파라미터: `serviceKey`(필수), `dataType`, `pageNo`, `numOfRows`, `searchLclasId`, `hashtags`, `pblancId`, `registDe`(등록일자), `updtPnttm`(수정일자 — 증분 동기화에 유용)
- 주요 필드: `pblancNm`, `pblancUrl`, `pblancId`, `jrsdInsttNm`, `excInsttNm`, `bsnsSumryCn`, `pldirSportRealmLclasCodeNm`, `creatPnttm`, `updtPnttm`, `reqstBeginEndDe`, `trgetNm`, `inqireCo`, `flpthNm`, `fileNm`, `printFlpthNm`, `printFileNm`, `hashtags`, `reqstMthPapersCn`, `refrncNm`, `rceptEngnHmpgUrl`, `totalCount`
- 이용허락: 공공누리 제3유형(출처표시·변경금지) — 워크인 화면에 고객용으로 노출할 때 출처 표시, 원문 변형 금지 유의

### 4-3. K-Startup 사업공고 API (공공데이터포털)
- 제공 페이지: [data.go.kr 15125364 '창업진흥원_K-Startup(사업소개,사업공고,콘텐츠 등)_조회서비스'](https://www.data.go.kr/data/15125364/openapi.do)
- 요청: `GET https://apis.data.go.kr/B552735/kisedKstartupService01/getAnnouncementInformation01` (그 밖에 `getBusinessInformation01` 통합공고, `getContentInformation01`, `getStatisticalInformation01`) — REST, JSON+XML
- 인증: 공공데이터포털 `serviceKey` (개발·운영 모두 자동승인), 개발계정 트래픽 10,000
- 갱신주기: 실시간
- 파라미터: `serviceKey`, `page`, `perPage`, `returnType`(json/xml, 기본 xml), 필터 `cond[biz_pbanc_nm::LIKE]`, `cond[supt_regin::LIKE]`, `cond[rcrt_prgs_yn::EQ]`(모집중 Y), `cond[pbanc_rcpt_bgng_dt::GTE]`, `cond[pbanc_rcpt_end_dt::LTE]`, `cond[biz_enyy::LIKE]`(창업기간), `cond[supt_biz_clsfc::LIKE]`, `cond[aply_trgt::LIKE]`, `cond[intg_pbanc_yn::EQ]` 등
- 주요 필드: `pbanc_sn`(공고일련번호), `biz_pbanc_nm`(공고명), `supt_biz_clsfc`(지원분야), `supt_regin`(지역), `aply_trgt`·`aply_trgt_ctnt`(신청대상), `biz_enyy`(창업기간), `pbanc_rcpt_bgng_dt`·`pbanc_rcpt_end_dt`(접수 시작·종료 yyyyMMdd), `rcrt_prgs_yn`(모집진행), `pbanc_ntrp_nm`(지원기관), `sprv_inst`(주관기관), `biz_aply_url`(공고 상세 URL), `detl_pg_url`(신청 URL), `prch_cnpl_no`(연락처), `aply_excl_trgt_ctnt`(제외대상), `pbanc_ctnt`(공고내용)

- **경기도·경기도경제과학진흥원 지원사업 '공고' 전용 Open API는 찾지 못함 (확인 필요)**. 경기기업비서(egbiz.or.kr)의 공개 API·RSS도 확인되지 않음 → 경과원 문의 필요.
