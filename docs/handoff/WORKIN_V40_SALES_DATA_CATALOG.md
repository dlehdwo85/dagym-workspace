# 워크인 V40 영업 공간 — 리드 발굴용 공공데이터 카탈로그

- 작성: 2026-10-17, 로컬 세션 (조사만 함, 활용신청·키 발급은 아직 안 함)
- 확인 방법: 공공데이터포털(data.go.kr) 검색 결과와 각 데이터 상세 페이지를 직접 열어서 확인했습니다. 상세 페이지에서 직접 본 값만 적었고, 못 본 값은 **확인 필요**로 남겼습니다.
- 수집 방식 전제: 우리 회사 data.go.kr 계정 1개로 한 번 수집하고 모든 고객사가 같이 봅니다. 회사마다 따로 갖는 것은 메모와 진행상태뿐입니다.

## 0. 읽는 법

| 칸 | 뜻 |
|---|---|
| 번호 | data.go.kr 데이터 번호. 주소는 `https://www.data.go.kr/data/{번호}/openapi.do`(API) 또는 `/fileData.do`(파일) |
| 형태 | API = OpenAPI, 파일 = CSV 같은 내려받기 파일 |
| 승인 | 개발 / 운영 단계 승인 방식. "자동/자동"이면 바로 쓸 수 있고, "자동/심의"면 운영계정 전환 때 기관 심사가 있습니다 |
| 개발한도 | 개발계정의 하루 호출 한도. 운영계정은 활용사례를 등록하면 늘려 달라고 신청할 수 있습니다 (포털 공통 안내) |
| 상업 | **가능** = 이용허락범위 "제한 없음" 또는 공공누리 1유형(출처표시). **가능(변경금지)** = 공공누리 3유형. **불가** = 상업적 이용금지 유형 |

### 행안부 지방행정 인허가 API 공통 조건 (아래 표의 "인허가" 항목 전부 해당)

- 2026-01 행정안전부가 지방행정 인허가 데이터 195종과 생활편의 데이터 14종을 공공데이터포털로 합쳤습니다. 예전 LOCALDATA 포털(localdata.go.kr)은 기사 기준 2026-04-15까지만 같이 운영한다고 했으므로, **새로 만들 때는 data.go.kr의 `행정안전부_○○ 조회서비스`를 씁니다.**
- 업종마다 API가 따로 있고, 업종마다 활용신청을 따로 해야 합니다.
- 상세 페이지 47개를 직접 열어 보니 조건이 모두 같았습니다: 갱신 **일간**, 승인 **자동/자동**, 개발한도 **10,000**, 상업 **가능**(이용허락범위 제한 없음), 형식 REST(JSON+XML), 최종수정 2026-04-15~16.
- 주요 필드: 인허가일자, 영업상태(영업/폐업), 사업장명, 소재지 주소, 좌표, 폐업일자 등. 참고문서로 `개방자치단체코드_영업상태코드.xlsx`가 붙어 있습니다.
- 리드로 쓰는 공통 방법: **최근 인허가일자 = 새로 연 곳(개업 리드)**, **영업상태 '영업' + 지역 = 지금 있는 곳 전체 목록**, **최근 폐업 = 자리를 비운 곳(재임대·철거·원상복구 리드)**.
