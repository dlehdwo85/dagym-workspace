원본에서 가져올 원칙
- **초안은 AI, 게시·발송은 사람.** 자동 팔로우·좋아요·댓글·DM 은 약관 위반으로 계정 정지 위험 → 워크인도 금지 유지. 게시는 지금처럼 공식 API + 대표 승인만.
- **지어내지 않는다.** 숫자·고객·성과가 없으면 `{{숫자}}` 자리로 비워 경고(워크인은 이미 '재료에 있는 값만' 규칙 — 같은 방향).
- **훅 점수는 나쁜 훅 거르기용.** 원본 실측: 나쁜 훅 구별 AUC 0.83, 좋은 훅끼리 승자 고르기 0.56(동전 던지기 수준). → 점수로 '탈락'만 시키고 승자는 실제 성과로 판단.
- **플랫폼 숫자는 바뀐다.** 인스타 해시태그 상한 30 → 5개(2025-12-18). 규칙 값은 설정표로 빼서 운영자가 고칠 수 있게.

## 2. 워크인 AI 마케터 스킬 묶음(전 채널)
모든 스킬은 운영실 카드(제안 → 승인)와 제작 화면 버튼으로 노출. 브랜드별로 동작(브랜드 섞임 금지 규칙 유지).

### P1 글 품질 엔진 — 모든 생성기(자동 제작·제작의뢰실·광고 문구·답글)에 공통 적용
1. **브랜드 말투 프로필(voice)**: 브랜드 키트 확장 — 주제·타겟·자주 쓰는 말·절대 안 쓰는 표현·존댓말/반말·이모지 사용·파는 것·잘 된 글 예시 5개. [잘 된 글로 말투 만들기] 버튼(최근 게시 상위 글에서 자동 초안 → 대표 승인).
2. **훅 라이브러리·훅 점수**: 원본 26공식을 한국어로(반전·숫자·아무도 안 알려주는·남의 결과·최상급·공개…). 점수 5항목(앞부분 집중·구체성·걸린 것·대상 호명·궁금증) + 탈락 사유(인사로 시작, "스크롤 멈추세요", 내용 없는 서두). 릴스·쇼츠 첫 3초, 피드 첫 줄, 광고 제목에 적용. 시안마다 훅 3개 + 점수, 낮은 훅은 자동 재작성.
3. **대본 → 초 단위 구성표**: 한국어 낭독 속도(분당 약 300음절)로 줄별 시간 → 훅 3초 초과·한 장면 4초 초과(이탈 구간)·구체성 없는 연속 줄·끝이 처음과 연결되는지(반복 시청) 경고. Higgsfield 프롬프트에 장면별로 그대로 전달.
4. **채널별 글 검사기(설정표로 숫자 관리)**
   | 채널 | 검사 |
   |---|---|
   | 인스타 피드·릴스 | 첫 125자 '더 보기 전' 미리보기 상자, 해시태그 최대 5, 요청(CTA) 1개, 검색 키워드 포함 |
   | 스레드 | 500자, 첫 줄 훅, 링크 1개 |
   | 페이스북 | 첫 2줄 미리보기, 링크 카드 |
   | 유튜브 쇼츠·영상 | 제목 100자(앞 40자 핵심), 설명 첫 2줄, 고정 댓글 |
   | 네이버 블로그 | 제목 키워드 앞쪽, 소제목·사진 수, 본문 키워드 반복 과다 |
   | 광고 문구 | 구글 제목 30/설명 90(한글 2배폭), 네이버 제목 15/설명 45, Meta 기본 문구 첫 125자 |
5. **AI 티 제거(휴머나이저)**: 한국어 상투어 사전(예: "~해 보는 건 어떨까요", "놓치지 마세요", "지금 바로", "다양한", "혁신적인", "~의 모든 것", 과한 느낌표·이모지 나열) + 보이지 않는 문자·특수 대시 제거 + 같은 길이 문장 반복·3개 나열 습관 경고 → '사람다움 점수'. 70점 미만은 승인함에 '다듬기 필요' 표시.

### P2 계획·분석
6. **주간 운영 계획**: 월 목표를 주 단위로 쪼개 채널×형식×요일·시각 + 이번 주 소통할 계정 10곳(관련 업계·지역 계정 후보) → 콘텐츠 캘린더 주 보기에 초안 칸으로.
7. **성과 아웃라이어 리포트(주간)**: 내 게시물을 '브랜드 최근 중앙값 대비 배수'와 공유·저장/도달 기준으로 순위 → 잘 된 구조(훅 공식·형식·시간)를 다음 주 계획에 반영. 공식 Insights API(인스타·페북·스레드·유튜브) 사용.
8. **벤치마크(바이럴) 리서치**: 경쟁·참고 계정의 공개 게시물을 Instagram Graph API Business Discovery(공개 비즈니스 계정 지표를 공식 조회) 또는 대표가 붙여넣은 목록으로 수집 → 계정 중앙값 대비 배수 순위 + 훅 공식 분류 → 브랜드별 스와이프 파일. 크롤링 금지.
9. **프로필 점수(100점)**: 인스타·유튜브 채널·스레드·네이버 플레이스 각 루브릭(사진·이름 검색어·소개 첫 줄·링크·하이라이트·고정 게시물·연락 수단 등) → 고쳐 쓴 문구.
10. **재활용**: 영상 1개·블로그 1편 → 일주일치(릴스 3·카드뉴스 2·스레드 3·쇼츠 2), 각자 단독으로 읽히게.

### P3 소통(초안만, 보내기는 사람)
11. **내 게시물 댓글 답글 초안**: 공식 API로 댓글 읽기(인스타 instagram_manage_comments 권한 — Meta 앱 심사 항목에 추가) → 분류(문의/리드·질문·칭찬·불만·잡음) → 급한 순 답글 초안 → [승인하면 답글 게시](공식 API 답글은 허용) 또는 복사. 문의는 리드·업무로 자동 연결(기존 문의 흐름).
12. **소통 댓글·DM 초안**: 남의 게시물 댓글 9유형, 협업 제안 DM + 후속 2회 — 복사 버튼만. 같은 문장 반복 금지 검사.
13. **스토리 시퀀스**: 하루 스토리 흐름 + 스티커 역할 + DM 으로 이어지는 동선.

## 3. 광고 최적화 엔진(Meta 중심, 네이버·구글 포함)
지금 운영 신호(CTR 절반 이하 소재 교체·충전 필요)를 아래 규칙으로 확장. 처음엔 **제안 카드만**, 대표 승인 시 담당 업무 또는 API 실행(2단계).

### 3-1. Meta 광고 최적화 규칙(2026 기준, Andromeda·Advantage+)
| 영역 | 규칙 | 신호 → 제안 |
|---|---|---|
| 학습 단계 | 광고세트는 최근 7일 최적화 이벤트 약 50건이 있어야 안정 | 50 미만 '학습 제한' → 광고세트 합치기 / 더 자주 일어나는 이벤트로 최적화(가입 → 랜딩 조회·문의 클릭) / 최소 일예산 = 목표 CPA × 50 ÷ 7 |
| 편집 | 타겟·최적화 이벤트·입찰·예산 20% 넘는 변경은 학습 재시작(다음 주 ROAS 5~15% 손해) | 예산 조정은 1회 20% 이하, 3~4일 간격. 학습 중 7일 편집 금지 경고 |
| 구조 | 캠페인·광고세트 최소화, 같은 대상 중복 금지 | 광고세트 4개↑ 또는 대상 중복 → 통합 제안 |
| 크리에이티브 다양성 | 비슷한 소재 20개 = 사실상 1개. 광고세트당 구조적으로 다른 컨셉 5~10개(훅·형식·가치 제안), 정지·영상·캐러셀 3형식 | 컨셉 3개 미만 / 형식 1종 → 신규 컨셉 제작 의뢰(훅 라이브러리와 연결) |
| 피로도 | 빈도 3 초과, CTR 주간 −10% 이상, CPM 주간 +25%, CPA 주간 +15%, 한 소재 지출 90%↑ | 하위 20~30% 소재 주간 교체, 신규 2~4개 투입. 교체 전 추적(픽셀·CAPI) 이상부터 확인 |
| 대상·배치 | 브로드 + Advantage+ 오디언스·배치가 기본 | 좁은 관심사 타겟 → 브로드 전환 제안 |
| 측정 | 픽셀 + Conversions API 같이, 중복 제거, 이벤트 매칭 품질 관리 | **워크인 가입·문의 이벤트를 서버에서 CAPI 로 전송**(우리 서버가 가입 시점을 정확히 앎) |
| 입찰 목표 | 주 50~100 전환 + 수익 CPA 확인 뒤 목표 입찰, 최근 평균보다 10~20% 느슨하게 시작 | 조건 충족 시 '목표 입찰 전환' 제안 |

**우리 예산 현실(월 15만 원 Meta)**: 주 50 전환은 불가 → 캠페인 1·광고세트 1·서로 다른 컨셉 3~4개에 집중, 최적화 이벤트는 상위 단계(랜딩 조회/문의 클릭), 30일 안정화, 한 달 단위로 판단. AI 마케터는 이 전제를 알고 '학습 제한'을 실패로 보고하지 않는다.

### 3-2. 네이버 검색광고
- 키워드별(이미 수집 중) 클릭·비용·전환 → 7일 비용 상위인데 전환 0 키워드 OFF/입찰 하향 제안, CTR 낮은 소재 교체, 소재 2개 이상 A/B, 제외 키워드(검색어 보고서), 시간대·지역 조정, 품질지수 낮은 키워드 랜딩·문구 정합.
### 3-3. 구글(실적 최대화·검색)
- 애셋 성과 등급 '낮음' 교체, 검색어 인사이트로 검색 테마·제외 키워드, 전환 추적(가입 이벤트 + 향상된 전환), 예산 대비 제한 상태.
### 3-4. 공통
- 매체 통합 '광고 진단' 카드(매일 아침 브리핑에 1줄 + 주간 상세), 각 제안에 근거 숫자·기대 효과·비용, 승인 시 실행.
- 실행 단계(2차): Meta(ads_management)·네이버·구글 API 로 예산 ±20%·소재 일시중지/재개만 허용, 그 외는 담당 업무.

## 4. 구현 순서(클라우드)
1. P1 글 품질 엔진(말투 프로필·훅·구성표·채널 검사기·휴머나이저) — 기존 품질 검사(mktAuto)·제작의뢰실·광고 문구에 연결, 규칙 숫자는 플랫폼 설정표.
2. 광고 최적화 엔진 3-1~3-4 제안 카드(데이터는 이미 동기화 중인 캠페인·키워드·소재) + 워크인 가입·문의 CAPI 전송.
3. P2 주간 계획·아웃라이어 리포트·프로필 점수·재활용.
4. P3 댓글 답글 초안(Meta 앱 심사에 댓글 권한 추가 필요)·소통 초안·스토리.
시험: 규칙별 단위 시험(경계값: 빈도 3.0, CTR −10%, 50 이벤트, 20% 예산), 품질 엔진은 일부러 나쁜 글 세트로 걸러지는지.

## 5. 대표 확인 필요
- Meta 앱 심사 범위에 댓글 관리(instagram_manage_comments)·광고 관리(ads_management) 추가 여부.
- 광고 자동 실행(예산 ±20%, 소재 중지)을 2차에 허용할지 — 기본은 제안만.
