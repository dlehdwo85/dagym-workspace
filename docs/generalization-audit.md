- 코드 전체(`src`, `db/migrations`, `public`, `mobile`, `scripts`)를 세 갈래(고유명사·브랜드 / 업종 용어·예시 / 조직·방식·기본 노출)로 나눠 조사했습니다. 주석 안의 언급(약 1,400줄)은 사용자에게 보이지 않아 표에서 뺐습니다.
