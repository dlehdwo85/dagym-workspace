## 데이터는 모두 지어낸 값

- 회사 '윤슬공간'(인테리어·공간 디자인), 브랜드 '윤슬공간'·'윤슬 리빙', 직원 6명 이름, 전화 010-0000-xxxx, 메일 example.com.
- 우리 직원 실명(김민수·김소담·이동재)은 쓰지 않았습니다.
- 입찰 공고의 기관(가람시청·누리구청·한울교육지원청·솔빛도시공사·다온 청소년수련관)과 공고 제목·금액도 지어낸 것입니다.
- 승인함 시안 그림은 캡처 스크립트가 도형과 글자로 직접 그렸습니다(남의 사진·로고 없음, 글꼴은 저장소의 Pretendard).
- 화면 그대로이고 그림 편집은 없습니다. 단, 스크롤 막대를 숨기고 처음 한 번만 뜨는 안내(연결하면 좋아요 카드·상태 말풍선)는 써 본 사람처럼 닫은 상태로 찍었습니다.

## 영업 화면 주의

이 회사는 영업 공간 쓰기를 연 상태(앱 심사 계정과 같은 설정)로 찍었습니다. 지금 새 고객사는 플랫폼 운영에서 영업 자료 전환을 하기 전까지 영업 공간이 보기 전용입니다.
