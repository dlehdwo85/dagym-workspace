# 계약서 보관·만료일 관리 — 설계 메모

작성 2026-11-19 · 고침 2026-11-20(대표 11/19 20시 방향 반영) · 클라우드. 대표 11/19 "계약서를 업로드하고 만료일자에 따른 계약서 관리 기능을 구현하고자 한다". **아직 구현하지 않았습니다 — 점검 기능 다음에 시작합니다(겹치지 않으면 나란히).**

**대표 11/19 20시 방향(#1069)** — 이 메모에 반영함:
- 계약 종류에 따라 칸을 달리하지 않는다 → **모든 회사가 같은 칸**을 쓰고, 종류는 **꼬리표**로 붙인다(다른 회사에도 팔 수 있게).
- 알림 받을 사람은 **계약마다 지정**(기본: 담당자 + 등록한 사람).
- 알림 날짜 **90·60·30·7일 전**을 기본값으로 승인. 회사 기본값과 계약별 값 모두 바꿀 수 있게.
- 자동 연장 계약의 '해지 통보 기한' 알림은 설계에서 판단(아래 4절 3번).

## 1. 한 장 요약

- 지금 있는 '전자계약'(/contracts)은 **서명 받는 도구**입니다. 거기의 '만료'는 서명 기한이지 계약 기간이 아닙니다. 거래처·고객과 맺은 계약서를 보관하고 **계약 만료일로 챙기는 기능은 없습니다.**
- 새 표 2개 + 메뉴 권한 1개 + 화면 1개(목록·등록·상세) + 정기 알림 1개로 얹을 수 있습니다. **기존 표는 바꾸지 않습니다**(다짐 화면·자료 영향 없음).
- 파일은 자료실의 기밀 폴더에 넣습니다 → 회사별 분리, 기밀 열람 기록, 저장공간 한도 계산, 글자 찾기가 이미 됩니다.
- 알림은 지금 있는 '날짜 n일 전 한 번 알림' 틀을 그대로 씁니다.
- 작업량: 1단계 2~3일, 2단계(선택) 1~2일.

## 3. 자료 구조

**agreements** — 회사(tenant) 칸 필수, 다른 회사 것은 404
- **칸은 모든 회사·모든 계약이 같음**(종류별 전용 칸 없음): 계약명 · 상대방(글자 + 선택: 연락처/영업 거래처 연결) · 금액(선택) · 담당자 · 소속(선택) · 메모
- **꼬리표**(여러 개, 회사가 자유롭게 만듦 — 예: 용역·임대·구매·유지보수): 종류 구분·거름·찾기는 꼬리표로. 처음 쓰는 회사에는 예시 꼬리표 몇 개만 보여 줌(지워도 됨)
- 지금 기간: 시작일 · 만료일 · 자동 연장 여부 · 해지 통보 기한(만료 n일 전, 선택)
- **알림 받는 사람**(계약마다 지정, 여러 명): 기본값 = 담당자 + 등록한 사람. 담당자를 바꾸면 새 담당자가 자동으로 들어감
- **알림 날짜**(계약마다 바꿀 수 있음): 비워 두면 회사 기본값(처음 값 90·60·30·7일 전, 회사 설정에서 고침)
- 상태: 진행 중 / 만료 임박 / 만료 / 종료(해지) — 진행 중·임박·만료는 날짜로 계산, 종료만 사람이 정함
- 지금 계약서 파일(자료실 파일 연결) · 알림 보낸 단계 기록 · 만든 사람·시각

**agreement_terms** — 갱신 이력
- 계약 · 차수 · 시작일 · 만료일 · 금액 · 계약서 파일 · 메모 · 등록한 사람·시각

## 4. 기능

1. **등록**: 파일(PDF·사진, 50MB 까지) 올리기 + 위 칸 입력. 파일 없이도 등록 가능(나중에 붙임).
2. **목록**: 만료 임박순 기본. 상태·상대방·꼬리표·담당자 거름, 찾기. 맨 위에 "30일 안 만료 n건 · 90일 안 n건". 엑셀 내려받기.
3. **알림**: 기준일 **90·60·30·7일 전**(회사 기본값, 계약별로 바꿈)에 그 계약의 '알림 받는 사람'에게 알림함·푸시. 같은 단계는 한 번만, 날짜를 고치면 다시 셈. 늦게 등록해도 가장 가까운 단계 하나만.
   - 선택(기본 켬): 첫 단계에 '[계약 갱신 검토] ○○' 업무 1건을 담당자에게 만듦.
   - **기준일 판단(자동 연장·해지 통보 기한)**:
     - 보통 계약(자동 연장 아님): 기준일 = **만료일**. 문구 "○월 ○일 만료 — 갱신·종료를 정해 주세요".
     - 자동 연장 + 해지 통보 기한이 있는 계약: 기준일 = **해지 통보 마감일**(만료일 − 통보 기한). 이 날이 지나면 손쓸 수 없으므로 알림을 이 날짜 기준으로 당김. 문구 "○월 ○일까지 통보하지 않으면 자동 연장됩니다(만료일 ○월 ○일)". 마감일이 지나면 한 번 더 "해지 통보 기한이 지났습니다 — ○월 ○일에 자동 연장됩니다".
     - 자동 연장인데 통보 기한을 적지 않은 계약: 기준일 = 만료일, 문구 "자동 연장 예정 — 계약서의 해지 통보 기한을 확인해 주세요".
   - 자동 연장 계약도 기간을 스스로 늘리지는 않음: 만료일이 지나면 목록에 '연장 확인 필요'로 보이고 사람이 [갱신 등록]을 눌러 새 기간을 적음(계약마다 연장 조건이 달라 자동으로 날짜를 바꾸면 틀릴 수 있음).
4. **갱신**: [갱신 등록] → 새 기간·새 파일을 잇고 이전 기간은 이력으로. [종료(해지)]는 사유와 함께.
5. **홈 카드**: 권한 있는 사람에게 "만료 임박 계약 n건".
6. **권한**: 기본값 — 대표·관리자: 편집 / 현장 관리자: 없음 / 직원: 없음(대표가 권한 표에서 바꿈). 파일은 이 권한이 있는 사람만 열고, 열람은 기밀 열람 기록에 남음.

### 들어가는 길과 쓰는 순서
1. 관리 › **계약 관리**(‘전자계약’ 바로 아래). 권한은 메뉴 권한 표의 "계약 관리(계약서 보관·만료 알림)" — 처음에는 대표·본사 관리자만 조회·편집. 권한이 없는 사람에게는 메뉴가 보이지 않습니다.
2. **[계약 등록]**: 계약명 · 상대방 · 꼬리표(종류를 쉼표로) · 시작일·만료일 · 자동 연장 여부와 해지 통보 기한 · 금액 · 담당자·소속 · 알림 받는 사람 · 메모.
3. 등록하면 상세가 열리고 **[파일 올리기]**로 계약서를 붙입니다. 파일은 자료실과 따로 보관하고, 계약 관리 권한이 있는 사람만 엽니다(연 기록이 감사 기록에 남음). 회사 저장공간에 함께 셉니다.
4. 목록은 **챙길 것(만료·연장 확인·통보 기한 지남) → 만료 임박 → 진행 중** 순서. 위에 30일 안·90일 안 만료 수.
5. 만료가 가까워지면 알림 받는 사람에게 알림이 가고, 담당자에게 **"[계약 갱신 검토] ○○"** 업무가 1건 생깁니다(계약마다 끌 수 있음).
6. 갱신했으면 상세의 **[갱신 등록]** — 지난 기간은 "지난 기간"에 남고 새 만료일로 이어 갑니다. 끝났으면 **[종료]**(까닭과 함께, 알림 멈춤).
7. **[알림 날짜]**: 회사 기본(처음 값 90·60·30·7일 전). 계약마다 따로 정할 수도 있습니다. **[엑셀]**: 목록 내려받기.

### 알림 규칙(그대로 구현)
- 기준일 = 만료일. **자동 연장 + 해지 통보 기한**이 있으면 기준일 = 해지 통보 마감일(만료일 − 통보 기한) — 그날이 지나면 손쓸 수 없으므로.
- 같은 단계는 한 번. 늦게 등록한 계약은 지난 단계를 몰아 보내지 않고 **가장 가까운 단계 하나만**.
- 기준일이 지나면 한 번 더: "계약이 만료됐습니다" / 자동 연장이면 "해지 통보 기한이 지났습니다"·"연장 확인 필요".
- 자동 연장 계약도 기간을 스스로 늘리지 않습니다(계약마다 조건이 달라서) — 사람이 [갱신 등록].
- 알림 받는 사람이 계약 관리 권한이 없으면 알림(계약명·만료일)만 받고 계약·파일은 열 수 없습니다.

## 9. 홈 '계약' 카드 (2026-11-20 · 클라우드)

- **보이는 사람**: 계약 관리 권한(조회 이상)이 있는 사람. 권한이 없는 사람의 홈에는 나오지 않습니다.
- **보이는 때**: 아래 계약이 하나라도 있을 때만(없으면 카드 자체가 없음 — 홈을 늘리지 않음).
  - **챙길 것**: 만료가 지남 · 자동 연장 확인 필요 · 해지 통보 기한이 지남
  - **30일 안**: 30일 안에 손써야 하는 계약 — 기준일은 목록과 같음(만료일, 자동 연장 + 통보 기한이 있으면 통보 마감일)
- **보이는 것**: 챙길 것 n · 30일 안 n · 가까운 순 3건(계약명 · 상대방 · 남은 날) · 더 있으면 "그 밖에 n건" · [계약 관리]. 줄을 누르면 그 계약 상세가 열립니다.
