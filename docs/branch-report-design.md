## 1. 켜는 방법 — 다짐에만

- 서버 스위치 `BRANCH_REPORT_TENANTS`(쉼표로 회사 id). **기본값 `default`(다짐)** — 값을 따로 넣지 않아도 다짐만 켜지고 그 밖의 회사는 꺼짐
- 꺼진 회사: 메뉴에 안 보이고, API 는 404, 화면 주소는 '찾는 화면이 없습니다'. 요금제·소개 화면·도움말·마케팅 문구에는 넣지 않음
- 다짐의 기존 설정(조직 단위·메뉴 권한·공간·주간 보고 메일 등)은 건드리지 않음. 지금의 '주간 보고'(월요일 8시, 회사 전체 업무 수치)와는 따로인 기능
- 메뉴 '지점 보고'는 다짐 관리자와 보고 지점의 작성·검토 담당에게만 보임

## 2. 보고 지점 목록과 권한

- 관리자 화면 [보고 지점]: 이름을 한 줄에 하나씩 **한 번에 붙여 넣기** → 지점마다 작성 담당·검토 담당(다짐 사용자 중 고름)·숨김·순서
- 처음 **10곳**(대표 #1102: 음성 더 퍼스트는 워크인에서 필요 없음)은 운영에서 관리자가 붙여 넣음(지점 이름 목록은 공개 저장소에 쓰지 않음). 쓰지 않게 된 지점은 숨김
- 보고서가 있는 지점은 지울 수 없음(숨김으로) · 이름을 바꿔도 같은 지점(보고서 유지)

| 누구 | 보는 지점 | 초안·고치기·제출 | 제출 취소 |
|---|---|---|---|
| 작성 담당(지점 관리자, '직원' 역할로 초대) | 자기 지점만 | 자기 지점 | 못 함 |
| 검토 담당 | 숨기지 않은 전체 지점(읽기) | 자기가 검토 담당인 지점 | 자기가 검토 담당인 지점 |
| 대표·관리자 | 전체(숨긴 지점 포함) | 전체 | 전체 |

## 3. 들어오는 자료

- **D(기본)**: 지점 관리자가 금요일에 카톡에 올리는 주간보고 글을 그대로 붙여 넣음(`<이용인원>`, `<특이사항 건의사항 및 민원>`, 시설별 블록)
- **M(선택)**: 카카오톡 대화 내보내기 파일 — PC txt · macOS·iOS csv · 모바일 txt · zip. 카카오에 단체방을 읽는 공식 API 가 없어 파일을 올림(비공식 연동은 계정 정지 위험)
  - 날짜 줄로 날짜를 이어 받고, 사진·파일·이모티콘·입퇴장 줄은 뺌. 같은 메시지(시각+보낸 사람+내용)는 한 번만 — 같은 파일을 두 번 올려도 됨
  - 실측(노트북 11/21): PC txt 5,609건, 주마다 19~103건

## 5. 주간보고 초안(양식 A)

- 보고일 = 금요일(11:00 기준), 기간 = 지난 금요일 ~ 목요일. 금요일 11시 뒤 정기 작업이 그 주 보고서가 없는 지점의 작성 담당에게 알림(한 번)
- [초안 만들기] → AI(구조화 출력)가 양식 A 를 채움. **AI 는 초안만**(자동 제출 없음)
  1. 이용 인원 현황(이용권별 인원) + 락커 사용 현황(구분·사용·전체·사용률)
  2. 시설 점검 보고 — 시설별 총 이용인원·청소 상태·시설 상태 + `· 항목 : 상태 / 조치` 줄
  3. 특이사항·건의사항·민원 — 제목·세부·처리 상태
- 항목마다 처리 상태(완료 / 진행 중 / 확인 필요)와 근거 번호(D줄·M메시지). 서버 검사:
  - 청소 상태·시설 상태는 그 시설 블록(`<헬스장>` 등)의 '청소상태'·'시설상태' 줄에 적힌 값만, 시설 상태는 등급 단어(양호·부분양호·미흡·청결 등)만 — 아니면 '확인 필요'(로컬 11/21: 청소 상태 '청결'을 시설 상태에 옮겨 적던 것)
  - 등급 단어로 시작하고 뒤에 설명이 붙으면('청결 / 연습실 내부룸 먼지로 청소완료') 등급만 칸에, 설명은 원문에 있을 때 점검 줄로(로컬 재확인 — 통째로 거부하던 것 고침)
  - 점검 줄 이름에서 원문 칸 이름('청소상태 부가 설명 :' 등)을 떼고 '…완료'는 상태로 · 줄 글과 근거 원문 줄 모두에 '완료'가 있으면 '확인 필요' → 완료('예정'은 그대로)
  - #1105(대표 11/21): 점검 줄 값이 0·O·○ 하나뿐이면 '이상 없음'·완료 — 원문 줄(근거 D 줄 또는 그 시설 블록에서 항목 이름이 든 줄)의 콜론 뒤 값으로 확인, 근거가 없으면 그 줄 번호. '진행0'처럼 붙은 0·숫자 칸은 그대로
  - 없는 근거 번호는 지움 · 근거 없는 '완료'는 '확인 필요'로 · D 에 없는 숫자는 '확인 필요'로
- 검토 화면: 표 칸을 바로 고침, 항목 더하기·빼기, [근거 N]을 누르면 가린 원문 줄, '확인 필요 N곳' 표시 → [저장] → [제출](잠김) → 인쇄·PDF
- 고친 기록: 감사 기록(branch_report.setup·chat_upload·draft·edit·submit·unsubmit)

## 6. 월간보고(2단계 — 클라우드 11/21 개발)

- 화면: [지점 보고] 위 [주간 | 월간] → 달 고르기(그 달 주간 제출 n건 표시) → [월간 초안 만들기] → 고치기·[저장]·[제출] → [미리 보기·PDF]·[엑셀]
- 입력: 그 달(보고일 금요일이 그 달) **제출된** 주간보고만 — 초안·다른 달은 빼고, 없으면 만들지 않음
- 양식 B(월간 업무 보고서): 머리(작성자·소속 '주식회사 다짐 운영팀'·기간 1일~말일·보고일·결재/담당 칸)
  - ■ 당월 중요업무 내역(업무내용 | 결과/산출물) · ■ 업무 진행사항(주차 | 실천업무 | 중점 확인사항 | 결과 | 비고) · ■ 차월 업무목표 및 실천사항 — **이 세 칸만 AI**(근거 = 주간보고 W번호)
  - 서버 검사: 없는 W번호 지움, 근거가 없거나 주간보고에 없는 숫자가 든 줄은 '근거 확인' 표시(노란 칸)
- **미완료 추적(프로그램 계산)**: 특이사항·점검 줄을 주마다 이어 봄(띄어쓰기 무시) — 마지막 상태가 완료가 아니면 '미완료(다음 달 확인)', 앞에서 진행 중이다가 뒤에 완료면 '이 달 안에 완료로 바뀐 것'(완료 주). 완료 뒤 다시 열리면 미완료
- 양식 C(시설별 이용 현황): 시설 | 전달 인원 | 이번달 인원 | 증감 | 증감률(▲▼%) + 전 시설 합계 — **#1106 대표 11/21: 이용 인원·방문 수 집계는 하이링크가 함 → 하이링크 이용현황 파일에서**
  - 월간 화면 C 칸 [하이링크 이용현황 올리기](PDF·엑셀·CSV, 4MB 까지) → 표를 읽어 줄을 채움(시설·전달·이번달·증감·증감률을 원문 그대로, '전시설 총 이용현황'·'합계' 줄은 합계로). PDF 는 글자 PDF 만(스캔본은 못 읽음)
  - 못 읽으면 원본을 첨부로 붙이고 인쇄·엑셀에 '하이링크 이용현황 첨부 … 원본 첨부'로 표시. 원본은 보고서에 보관(마이그레이션 269 branch_report_files), 화면에서 내려받기·빼기
  - 올린 파일이 없으면 빈칸 + '하이링크 이용현황을 올려 주세요'. 주간 글로 계산한 값(월말)은 기본에서 빼고 [주간 값으로 채우기] 단추로만. 손으로 고치기 그대로(값을 고치면 증감·합계는 계산값으로)
  - 월간 초안을 다시 만들어도 올린 하이링크 값·첨부는 그대로. 하이링크 자동 연동(API)은 하지 않음(대표 확인 뒤 따로)
  - 실측(로컬 11/21 운영): 월간 초안 1번 약 $0.021(약 30원) · 합계는 칸과 같은 단위로('543명')
- 내려받기: PDF(인쇄 화면, A4 — C 는 다음 쪽) · 엑셀(시트 '월간 업무 보고서'·'시설별 이용 현황'). 주간보고도 엑셀 내려받기 추가
- **회원(이용권) 현황 — #1112 대표 11/22**: C 칸 옆 [하이링크 회원목록 올리기](하이링크에서 내려받은 '회원목록_YYYY-MM-DD.xlsx', 3MB 까지)
  - '전체' 시트만 읽음(동별 시트는 같은 내용 중복). 머리줄 이름으로 칸을 찾음: 동·호수·이용권명·금액·시작일·종료일·이용권 상태·락커 — **이름·연락처 칸은 찾지도 읽지도 않음**
  - 동·호수는 세대 수·동별 수를 세는 데만 쓰고 저장하지 않음. **원본 파일은 보관하지 않고 집계 숫자만 저장**(마이그레이션 270 `branch_member_stats`: 지점·달별 집계 1줄)
  - '이용권 상태'를 믿음(활성만 셈) · 이용권명 '-' 는 이용권 없는 등록 세대원이라 빼고 셈
  - 계산(프로그램, AI 아님): 활성 이용권 · 활성 세대 · 묶음별 활성(헬스·통합(헬스+골프+수영)·GX·수영 강습·독서실·락커·골프 레슨·PT·기타) · 월 부과 합계 · 이번 달 신규(시작일) · 이번 달 종료(종료일) · 동별 활성
  - 시험·직원 줄 제외(기본 켬, 화면에서 끌 수 있음): 이용권명 '테스트' · 동 999·9999·111·빈칸 — 제외 건수 표시. 두 경우를 모두 계산해 두고 고르기만 함(대표 11/22 확인: 999동은 직원 계정 = 시험 계정 → 기본 제외)
  - 전달 집계가 있으면 증감·증감률, 30% 넘게 줄면 빨간 줄 '(30% 넘게 줄어듦)' · 첫 달은 '비교할 지난달 없음'
  - 월간 초안을 다시 만들어도 그대로 · 화면 저장으로 집계 숫자를 바꿀 수 없음 · 인쇄(PDF)·엑셀('회원 현황' 시트)에 들어감 · AI 한 줄 요약은 아직 안 만듦(선택)
