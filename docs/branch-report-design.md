- 요청: 대표 #1096(11/21) — 지점 주간보고 초안 → 검토·제출 → 월간 취합
- 범위 결정: 대표 #1097(11/21) — **상업화하지 않고 다짐 회사에만**. 다른 회사·체험 회사의 메뉴·요금제·소개·도움말·마케팅 문구에 나오지 않음
- 상태: **1단계(주간) 개발 끝 — 클라우드 11/21**. 2단계(월간 B·C, 미완료 추적, 내려받기)는 1단계 운영 확인 뒤

## 1. 켜는 방법 — 다짐에만

- 서버 스위치 `BRANCH_REPORT_TENANTS`(쉼표로 회사 id). **기본값 `default`(다짐)** — 값을 따로 넣지 않아도 다짐만 켜지고 그 밖의 회사는 꺼짐
- 꺼진 회사: 메뉴에 안 보이고, API 는 404, 화면 주소는 '찾는 화면이 없습니다'. 요금제·소개 화면·도움말·마케팅 문구에는 넣지 않음
- 다짐의 기존 설정(조직 단위·메뉴 권한·공간·주간 보고 메일 등)은 건드리지 않음. 지금의 '주간 보고'(월요일 8시, 회사 전체 업무 수치)와는 따로인 기능
- 메뉴 '지점 보고'는 다짐 관리자와 보고 지점의 작성·검토 담당에게만 보임

## 2. 보고 지점 목록과 권한

- 관리자 화면 [보고 지점]: 이름을 한 줄에 하나씩 **한 번에 붙여 넣기** → 지점마다 작성 담당·검토 담당(다짐 사용자 중 고름)·숨김·순서
- 처음 **10곳**(대표 #1102: 음성 더 퍼스트는 워크인에서 필요 없음)은 운영에서 관리자가 붙여 넣음(지점 이름 목록은 공개 저장소에 쓰지 않음). 쓰지 않게 된 지점은 숨김
- 보고서가 있는 지점은 지울 수 없음(숨김으로) · 이름을 바꿔도 같은 지점(보고서 유지)

| 누구 | 보는 지점 | 초안·고치기·제출 | 제출 취소 |
|---|---|---|---|
| 작성 담당(지점 관리자, '직원' 역할로 초대) | 자기 지점만 | 자기 지점 | 못 함 |
| 검토 담당 | 숨기지 않은 전체 지점(읽기) | 자기가 검토 담당인 지점 | 자기가 검토 담당인 지점 |
| 대표·관리자 | 전체(숨긴 지점 포함) | 전체 | 전체 |

## 3. 들어오는 자료

- **D(기본)**: 지점 관리자가 금요일에 카톡에 올리는 주간보고 글을 그대로 붙여 넣음(`<이용인원>`, `<특이사항 건의사항 및 민원>`, 시설별 블록)
- **M(선택)**: 카카오톡 대화 내보내기 파일 — PC txt · macOS·iOS csv · 모바일 txt · zip. 카카오에 단체방을 읽는 공식 API 가 없어 파일을 올림(비공식 연동은 계정 정지 위험)
  - 날짜 줄로 날짜를 이어 받고, 사진·파일·이모티콘·입퇴장 줄은 뺌. 같은 메시지(시각+보낸 사람+내용)는 한 번만 — 같은 파일을 두 번 올려도 됨
  - 실측(노트북 11/21): PC txt 5,609건, 주마다 19~103건

## 4. 개인정보 — 저장·AI 전송 전에 가림

| 가리는 것 | 바꾼 모양 |
|---|---|
| 전화번호(010-…, 02-…, 붙여 쓴 번호, 목록 표시 '-' 바로 뒤 번호 포함) | `[전화]` |
| 동·호수(101동 1203호, 1203호) | `[호수]` |
| 주민등록번호 | `[주민번호]` |
| 계좌번호·카드번호 | `[계좌]`·`[카드]` |
| 차량번호(12가3456, 서울12가3456) | `[차량]` |
| 이메일 | `[이메일]` |

- 보낸 사람 이름은 그대로(담당 칸에 필요). 본문 속 입주민 이름은 자동으로 가리기 어려움(확인 못함)
- 붙여 넣은 글(D)도 가린 뒤 저장·전송. 원본 파일은 저장하지 않음
- AI 동의: 초안을 만드는 사람의 AI 동의·회사 AI 예산 검사(기존과 같음)

## 5. 주간보고 초안(양식 A)

- 보고일 = 금요일(11:00 기준), 기간 = 지난 금요일 ~ 목요일. 금요일 11시 뒤 정기 작업이 그 주 보고서가 없는 지점의 작성 담당에게 알림(한 번)
- [초안 만들기] → AI(구조화 출력)가 양식 A 를 채움. **AI 는 초안만**(자동 제출 없음)
  1. 이용 인원 현황(이용권별 인원) + 락커 사용 현황(구분·사용·전체·사용률)
  2. 시설 점검 보고 — 시설별 총 이용인원·청소 상태·시설 상태 + `· 항목 : 상태 / 조치` 줄
  3. 특이사항·건의사항·민원 — 제목·세부·처리 상태
- 항목마다 처리 상태(완료 / 진행 중 / 확인 필요)와 근거 번호(D줄·M메시지). 서버 검사:
  - 없는 근거 번호는 지움 · 근거 없는 '완료'는 '확인 필요'로 · D 에 없는 숫자는 '확인 필요'로
- 검토 화면: 표 칸을 바로 고침, 항목 더하기·빼기, [근거 N]을 누르면 가린 원문 줄, '확인 필요 N곳' 표시 → [저장] → [제출](잠김) → 인쇄·PDF
- 고친 기록: 감사 기록(branch_report.setup·chat_upload·draft·edit·submit·unsubmit)

## 6. 월간보고(2단계)

- 양식 B(월간)·C(시설별 이용 현황). 그 달 제출된 주간보고를 모아 중복 합침 → 주요 업무·민원 처리·보수/점검·미완료
- 전주 '진행 중'이 뒤 주에 완료되면 최종 결과로 반영. 끝까지 근거가 없으면 '미완료'
- 내려받기(PDF·엑셀)

## 7. 데이터(추가형 마이그레이션 268 — 다짐 외에는 비어 있음)

- `branch_sites` — 보고 지점(회사·이름·숨김·순서·작성 담당·검토 담당)
- `branch_chat_uploads` — 올린 묶음(기간·올린 사람·건수 — 파일은 저장 안 함)
- `branch_chat_messages` — 보낸 시각·보낸 사람·가린 글·중복 확인 값
- `branch_reports` — 지점·종류(주간/월간)·기간·보고일·상태(초안/제출)·가린 붙여 넣은 글·본문(양식 구조)·제출 기록

## 8. AI 비용 추정(실측 크기로 다시 계산 — 추정, 실제 값은 첫 사용 뒤 'AI 사용 내역'의 branch_report 로 확인)

앱 요금표(`src/lib/ai/provider.ts`) 기준 — 기본 모델 Sonnet 5.5 입력 $2 / 출력 $10 (100만 토큰당), 환율 1,400원.

| 항목 | 실측·가정 |
|---|---|
| 주간보고 글(D) | 최근 한 주 약 2,500자(가린 뒤) — 노트북 실측 |
| 대화(M, 선택) | 주 19~103건 × 약 40자 ≈ 최대 4,000자 — 노트북 실측 건수 |
| 지시·양식 | 약 1,500자 + 출력 양식(JSON 스키마) |
| 한글 토큰 | 글자당 약 1토큰으로 잡음(확인 못함) |

- 주간 초안 1번: 입력 약 5천~8천 토큰 · 출력 약 2천~3천 토큰 ≈ $0.03~0.05 ≈ **약 40~70원 / 지점**
- 지점 1곳 한 달(주 4.3번 + 다시 만들기 몇 번) ≈ **약 300원**, **10곳 ≈ 월 3,000~4,000원**
- (예전 추정 지점당 월 800~1,000원은 '대화 전부를 입력'으로 잡은 값 — 대표 결정으로 D 가 기본 입력이 되어 줄어듦)
- 회사 AI 예산(이미 있는 월 한도)에 함께 잡히고, 예산을 넘으면 만들지 않음

## 9. 단계

1. ✅ 스위치·메뉴(다짐만) · 해석기(여러 형식·zip·날짜·중복) · 가림 — 7bbb3ae
2. ✅ 보고 지점 목록 · 대화 올리기(가린 글만) · 주간 초안(AI) · 근거 · 검토·제출·제출 취소 · PDF · 금요일 알림 · 30일 삭제 · 처리방침 — 이번 커밋
3. 2단계: 월간(B·C) 취합 · 미완료 추적 · 내려받기
4. 나중: 하이링크 이용 현황(락커·이용권) 자동 채우기
