# 지점 주간·월간보고 AI 자동화 — 설계 (다짐 전용)

- 요청: 대표 #1096(11/21) — 지점 카카오톡 단체방 대화에서 업무를 뽑아 주간보고 초안 → 검토·제출 → 월간 취합
- 범위 결정: 대표 #1097(11/21) — **상업화하지 않고 다짐 회사에만**. 다른 회사·체험 회사의 메뉴·요금제·소개·도움말·마케팅 문구에 나오지 않음
- 상태: 설계(클라우드 11/21). 1단계 개발은 아래 "대표 확인" 3가지 중 ①②가 정해지면 끝까지 갑니다(그 전에는 해석기·가림처럼 결정과 상관없는 부분만)

## 1. 켜는 방법 — 다짐에만

- 서버 스위치 `BRANCH_REPORT_TENANTS`(쉼표로 회사 id). **기본값 `default`(다짐)** — 값을 따로 넣지 않아도 다짐만 켜지고 그 밖의 회사는 꺼짐. 화상회의의 `MEETINGS_TENANTS` 와 같은 방식
- 꺼진 회사: 메뉴에 안 보이고, 주소·API 는 404(있는 줄도 모르게). 요금제·소개 화면·도움말·마케팅 문구에는 처음부터 넣지 않음
- 다짐의 기존 설정(메뉴 권한·공간·주간 보고 메일 등)은 건드리지 않음. 지금의 '주간 보고'(월요일 8시, 회사 전체 업무 수치)와는 따로인 기능
- 범용 용어 설정·양식 편집기는 만들지 않음(다짐 전용이라 단순하게)

## 2. 들어오는 자료 — 카카오톡 대화 내보내기 파일

카카오에는 단체방 대화를 읽는 공식 API·단체방 챗봇이 없음(로컬 확인 11/21). 비공식 연동은 계정 정지 위험이라 쓰지 않음 → **담당자가 내보내기 파일을 올림**.

- 받는 형식: PC(Windows) txt `[이름] [시간] 내용` · macOS·iOS csv `Date,User,Message` · 모바일 txt · zip(안의 txt·csv)
- 기기·버전마다 날짜 모양이 달라 해석기가 여러 모양을 받음. 날짜 줄(예: `--------------- 2026년 11월 21일 금요일 ---------------`)로 날짜를 이어 받고, 형식에 안 맞는 줄은 앞 메시지의 이어진 줄로 붙임
- 사진·파일·이모티콘·입퇴장 같은 시스템 줄은 내용에서 뺌("사진", "동영상", "○○님이 들어왔습니다")
- **기간 자동 인식**(첫·마지막 메시지 날짜) · **같은 메시지 중복 제거**(보낸 시각 + 보낸 사람 + 내용이 같으면 한 번 — 같은 주 파일을 두 번 올려도 됨) · 올린 사람·시각 기록

## 3. 개인정보 — AI 로 보내기 전에 가림

단톡방에는 직원·입주민의 정보가 섞임. AI(바깥 회사, 국외)로 보내기 **전에** 가림.

| 가리는 것 | 바꾼 모양 |
|---|---|
| 전화번호(010-…, 02-…, 붙여 쓴 번호) | `[전화]` |
| 동·호수(101동 1203호, 1203호) | `[호수]` |
| 주민등록번호 | `[주민번호]` |
| 계좌번호·카드번호(긴 숫자 묶음) | `[계좌]`·`[카드]` |
| 차량번호(12가3456, 서울12가3456) | `[차량]` |
| 이메일 | `[이메일]` |

- 사람 이름(보낸 사람)은 "담당" 칸을 채우려면 필요 → 보낸 사람 이름은 그대로, 본문 속 입주민 이름은 가리기 어려움(확인 못함 — 아래 "대표 확인" ③)
- 저장: **원본 파일은 저장하지 않고 가린 메시지만 저장**(추천 — 근거 원문 보기도 가린 글). 보관은 제출 뒤 30일(로컬 추천값) 뒤 자동 삭제
- AI 동의: 파일을 올리고 초안을 만드는 사람의 AI 동의가 있어야 함(지금 AI 동의와 같은 검사). 처리방침의 국외 이전·위탁 항목에 "지점 대화 내용(가린 뒤)"을 더해야 함 — 법률 판단은 확인 못함

## 4. 주간보고 초안

- 언제: 매주 금요일 오전(정기 작업) 자동 + 화면의 [지금 만들기]. AI 는 **초안만** 만들고 제출하지 않음
- 근거로 쓰는 것: 그 지점·그 주의 가린 메시지 + (선택) 같은 지점·같은 주의 워크인 자료(업무·점검·결재)
- 결과(항목마다): 분류(아래 5개) · 제목 · 내용 · 발생일 · 담당(보낸 사람 이름) · 처리 상태(완료 / 진행 중 / 확인 필요) · **근거 메시지 번호**
- 규칙: 근거 메시지가 없거나 처리가 분명하지 않으면 '확인 필요' 또는 '진행 중' — **임의로 완료 처리 금지**. 같은 일을 여러 번 말한 것은 한 항목으로 합침. 서버가 근거 번호가 실제 메시지인지 확인하고, 없으면 그 항목을 '확인 필요'로 내림
- 양식: 대표 원본 양식이 오기 전에는 요청서의 5개 항목 — 시설 운영 현황 · 민원/조치 · 시설 점검/보수 · 업무 진행 · 특이사항. 원본이 오면 다짐 양식 하나로 맞춤(편집기 없이 코드로)

## 5. 검토·제출

- 초안이 생기면 그 지점 작성자에게 알림. 검토 화면에서 항목 고치기·지우기·추가, 항목마다 [근거 보기](메시지 시각·보낸 사람·가린 글)
- [제출] 전에는 작성자·검토자만 봄. 제출하면 잠기고(고치려면 [제출 취소] 기록), 고친 기록이 남음
- 권한: 그 지점(조직 단위)에 접근할 수 있는 사람만 — 지금의 조직 권한(accessibleUnitIds) 그대로. 작성자 = 지점 관리자, 검토자 = 대표·관리자(대표 확인 대기)

## 6. 월간보고(2단계)

- 그 달 제출된 주간보고를 모아 중복 합침 → 주요 업무 · 민원 처리 · 보수/점검 · 미완료로 정리
- 전주 '진행 중'이 뒤 주에 완료되면 최종 결과로 반영(완료일 함께). 끝까지 근거가 없으면 '미완료'로 남김
- 실적·특이사항 요약 → 월간 초안 → 검토·제출 → 내려받기(PDF·엑셀)

## 7. 데이터(추가형 마이그레이션 — 다짐 외에는 비어 있음)

- `branch_chat_uploads` — 지점·기간·올린 사람·시각·메시지 수(파일은 저장 안 함)
- `branch_chat_messages` — 지점·보낸 시각·보낸 사람·가린 글·중복 확인 값·올린 묶음 · 30일 뒤 삭제
- `branch_reports` — 지점·종류(주간/월간)·기간·상태(초안/제출)·작성·제출 기록
- `branch_report_items` — 보고서·분류·제목·내용·발생일·담당·처리 상태·근거 메시지 번호들·순서
- 고친 기록은 감사 기록(audit_logs)에

## 8. AI 비용 추정(대표 요금 확인 원칙 — 추정이며 실제 파일로 다시 잼)

앱 요금표(`src/lib/ai/provider.ts`) 기준 — Sonnet 5.5 입력 $2 / 출력 $10 (100만 토큰당), 환율 1,400원.

| 가정 | 값 |
|---|---|
| 지점 단톡방 | 하루 150건 × 7일 ≈ 1,050건, 건당 40자 → 약 4만 2천 자 |
| 한글 토큰 | 글자당 0.7~1.0 토큰으로 잡음(확인 못함 — 첫 실제 파일로 잼) |
| 주간 초안 1번 | 입력 약 3만~4만 5천 토큰(대화 + 지시·양식) · 출력 약 5천 토큰 |

- 주간 초안 1번 ≈ $0.11~0.14 ≈ **150~200원** / 지점
- 월간 초안 1번(주간 4개 입력 약 2만 토큰 · 출력 5천) ≈ $0.09 ≈ **130원** / 지점
- **지점 1곳 한 달 ≈ 800~1,000원**(주 4.3번 + 월 1번). 지점 30곳이면 약 2만 4천~3만 원/월
- 대화가 3배 많으면(하루 450건) 약 3배. 다시 만들기를 누를 때마다 주간 1번 값이 더 듦
- 회사 AI 예산(이미 있는 월 한도)에 함께 잡히고, 예산을 넘으면 만들지 않음

## 9. 대표 확인(정해지면 1단계 끝까지)

1. **원본 파일 저장 여부** — 추천: 저장하지 않고 가린 메시지만(30일). 원본이 꼭 필요하면 암호화 보관 + 지점 권한자만
2. **작성자·검토자** — 지점 관리자가 작성, 누가 검토·확인하는지 + 지점 목록(다짐 조직 단위 그대로 쓸지)
3. **처리방침·고지** — 단톡방 대화(가린 뒤)를 국외 AI 로 보내는 것을 처리방침에 적는 문구, 단톡방 참여자에게 알릴지(법률 판단 확인 못함)
4. 주간·월간 양식 원본(대표가 보내 주는 중)

## 10. 1단계 개발 순서

1. 스위치·메뉴(다짐만) · 해석기(여러 형식·zip·날짜·중복) · 가림 — 결정과 상관없어 먼저
2. 올리기 화면·저장(가린 메시지만, 30일) — 위 ① 결정 뒤
3. 주간 초안(AI) · 근거 확인 · 검토·제출 · 금요일 정기 작업 · 알림 — ②③ 결정 뒤
4. 2단계: 월간 취합·미완료 추적·내려받기
