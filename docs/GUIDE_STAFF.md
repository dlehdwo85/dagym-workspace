# 직원용 간단 안내

## 시작하기
1. 관리자에게 받은 **초대 링크**를 열고 비밀번호(8자 이상)를 정하면 바로 시작됩니다.
2. 휴대폰에서는 **업무일정 앱**(배포 후 안내)이나 휴대폰 브라우저로 같은 주소에 접속하세요. 같은 계정과 데이터를 씁니다.
3. 비밀번호를 잊어버렸다면 관리자에게 "비밀번호 재설정 링크"를 요청하세요.

## 매일 쓰는 화면
| 화면 | 하는 일 |
|---|---|
| 홈 | 오늘 할 일, 기한 초과, 이번 주 일정 |
| 내 업무 | 내가 담당하거나 협업 중인 업무 |
| 캘린더 | 회사·내 현장·개인 일정과 업무 마감일(점선 ☑) |
| 알림 | 배정·멘션·마감 임박·검토 결과·일정 변경 |

## 업무 처리 순서
1. 오른쪽 아래 **+** 버튼으로 업무를 등록합니다. 템플릿(현장 점검, 회원 민원 등)을 골라 시작할 수도 있습니다.
2. 업무를 열고 **시작**을 누르면 "진행 중"으로 바뀝니다.
3. 체크리스트를 체크하고, **사진 촬영** / **파일 첨부** / **문서 링크 연결**로 자료를 남깁니다.
4. 댓글에서 **@ 멘션**으로 사람을 부르면 그 사람에게 알림이 갑니다.
5. 다 끝나면 **완료 → 검토 요청**을 누릅니다. 관리자가 확인하면 "완료"가 되고, 보완 요청이 오면 다시 "진행 중"이 됩니다.
6. 실제로 일할 시간을 잡아 두려면 업무 화면의 **실행 시간 배정**을 누르세요. 캘린더에 시간 일정으로 들어갑니다.

## 일정
- 캘린더에서 날짜를 누르거나 끌어서 일정을 만듭니다. 휴가·출장은 "종류"에서 고르세요.
- 일정을 끌어 옮기면 바로 저장됩니다. 반복 일정은 **이번 일정만 / 이번 및 이후 / 모든 일정** 중 하나를 고릅니다.
- 참석자 시간이 겹치면 저장 전에 **일정 충돌 안내**가 나옵니다.

## 알림 설정
설정 → 알림 종류별로 앱 내 알림·푸시를 켜고 끌 수 있습니다. "마감 임박"을 몇 시간 전에 받을지, 푸시를 받지 않을 시간대도 정할 수 있습니다. PC 브라우저는 "이 브라우저에서 알림 받기"를 누르세요.

## 인터넷이 끊겼을 때
업무 등록과 댓글은 휴대폰에 보관됐다가 다시 연결되면 **자동 전송**됩니다(화면 위 "전송 대기 N건"). 같은 내용이 두 번 올라가지 않습니다.

## Google Calendar 연결 (선택 기능 — 회사가 켠 경우에만 보임)
모든 업무·일정 기능은 회사 계정만으로 쓸 수 있으며 Google 계정은 필요 없습니다. 관리자가 이 기능을 켰다면 설정 → Google Calendar 연동 → 읽기·쓰기 또는 읽기 전용을 고르고, 연결할 Google 캘린더와 회사 캘린더를 선택합니다. 연결을 끊어도 양쪽 일정은 지워지지 않습니다.
