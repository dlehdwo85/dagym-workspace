- 정직하게: 실장비(하이크비전 단말기)로 이벤트가 들어오는 것을 확인하기 전까지는 어떤 연동도 "구조 시험 통과 · 실제 연동 미확인"이다. 단말기 쪽 설정(알림 서버 주소 입력·펌웨어)은 현장(설치업체·로컬) 몫.

## 3. 1차-β 출입기 연동

### 3-1. 공통 수신층 — 어느 단말기든 같음 (2일) + 파일 올리기 안전망 (1일)

- **장치 등록**: 근태 › 장치 탭(이름·현장·제조사/연동 방식·상태·마지막 이벤트 시각) · 장치별 비밀 토큰(원문 1회 표시, 해시 저장 — 문의 연동 토큰과 같은 방식) · 토큰 → 회사(테넌트) 결정, 다른 회사 404.
- **사람 매핑**: 단말기 사번(employeeNo)·카드번호 ↔ 워크인 사용자. 관리자 표에서 연결, 미매핑 이벤트는 '누군지 모름' 칸에 모아 뒀다가 연결하면 소급.
- **원시 이벤트 표** `attendance_device_events`: 장치·외부 사번·장치 시각·수신 시각·문·방향(입/출/없음)·인증 종류(얼굴/지문/카드 — 종류 이름만, 생체 데이터 없음)·원문 요약 JSON(사진 필드는 버림) · 중복 제거(장치+일련번호, 없으면 장치+사번+시각) · 장치 시계가 서버와 5분 이상 어긋나면 경고.
- **출퇴근 도출**: 근무일 첫 '입' = 출근, 마지막 '출' = 퇴근(방향 없는 단말기는 첫 찍음·마지막 찍음) · 앱 찍기와 병합: 단말기 기록 우선, 앱은 보조 · 표·엑셀에 출처 표시(단말기/앱/QR/정정) · 자정 넘김은 근무표 기준.
- **연결 상태**: 24시간 이벤트 없으면 관리자 알림('장치가 끊겼을 수 있음'), 장치 목록에 마지막 수신 시각.
- **파일 올리기(안전망, 1일)**: 단말기 관리 프로그램이 내보낸 엑셀/CSV 올리기 → 열 매핑(사번·시각·문) → 같은 이벤트 표에 적재. 연동 전에도, 연동이 끊겨도 쓴다.
- 보안: 수신 주소는 세션 없는 공개 handler(기존 `public: true` 틀) + 본문 크기 제한 + 장치당 분당 횟수 제한 + 토큰 실패 기록.

### 3-2. 하이크비전 ⓐ~ⓓ — 길마다 고객사 쪽 조건과 공수

| 길 | 어떻게 | 고객사 쪽 필요 | 워크인 공수 | 위험·확인할 것 |
|---|---|---|---|---|
| **ⓐ 단말기 ISAPI 이벤트 푸시**(HTTP 알림 서버) | 단말기 설정의 '알림 서버(HTTP Host)' 칸에 워크인 수신 주소를 적으면 단말기가 출입 이벤트(사번·이름·카드번호·시각·이벤트 종류)를 우리 서버로 POST 한다. 끊겼던 동안 밀린 이벤트를 다시 보내는 모델이 있다(검색 결과 기준, 모델·펌웨어별 확인) | 단말기가 인터넷으로 **나갈** 수만 있으면 됨(들어오는 포트 개방·공인 IP 불필요) | **2~3일**: 수신 파서(XML·JSON·multipart 셋 다), 이벤트 종류 필터(인증 성공만), 장치 시계 보정, 설정 안내 화면('단말기에 적을 값') | 모델·펌웨어별 본문 차이 · https 인증서를 검증 못 하는 모델은 http 만 되므로 토큰을 주소에 넣는 방식 추가(https 권장) · **실장비 시험 1일(현장)** |
| **ⓑ HikCentral Professional OpenAPI**(고객사에 HCP 서버가 있을 때) | HCP 의 OpenAPI(파트너 키·비밀, 서명 호출)로 ① 이벤트 구독(HCP → 워크인 콜백) 또는 ② 출입 이벤트 주기 조회(워크인 → HCP, 5분) | HCP + OpenAPI(출입 통제 모듈 라이선스에 포함된다고 판매 페이지에 적혀 있음) · ②는 HCP 가 인터넷에서 닿아야 해서 어려움 → ① 권장 | **3~4일**: 서명 방식·구독 등록·HCP 사람 ID 매핑·콜백 수신 | 공식 OpenAPI 문서는 하이크비전 파트너 포털에서 받아야 함(공개 검색으로 세부 확인 못 함) · HCP 버전 차이 |
| **ⓒ Hik-Partner Pro 클라우드 OpenAPI**(설치업체용 클라우드) | 파트너 계정으로 클라우드 API 사용 | 설치업체(파트너) 계정, 장치가 그 클라우드에 묶여 있어야 함 | 조사 0.5~1일 뒤 결정 · 가능하면 2~3일 | 출입 이벤트 웹훅 제공 여부를 공개 자료로 **확인 못 함** · 한국 리전·약관·데이터 위치 · 파트너 심사 |
| **ⓓ 하이링크 얼굴 출입기**(우리 플랫폼, 2순위) | 하이링크 쪽에 '출입 이벤트 웹훅'(워크인 주소 + HMAC 서명 + 재전송) 추가 → 워크인은 공통 수신층 재사용 | 하이링크 쪽 개발 | **워크인 1일** + 하이링크 쪽 n일(하이링크 세션 몫) | 두 제품 묶음 영업("출입기가 곧 근태기")의 근거 |

- 고르는 법: 기존 사례가 ⓐ였으면 ⓐ, ⓑ였으면 ⓑ-①. ⓒ는 조사 뒤. **1차-β 에는 한 길만** 넣고 나머지는 고객 요청이 3곳 이상일 때(슈프리마 BioStar Air 도 같은 기준, 3~5일 + 데모 장비).
- 답이 오기 전 기본값 ⓐ 인 이유: 고객사 방화벽에 구멍을 내지 않고, 저가 단말기도 같은 규격이며, 공통 수신층만 있으면 바로 붙는다.
- 하이링크 세션에 물을 것(로컬 전달): ① 기존 연동이 ⓐ/ⓑ/ⓒ 중 무엇이었나 ② 단말기 모델·대당 가격(견적) ③ 고객사 내부망 이벤트가 밖으로 나가는 길(공인 IP·중계기·클라우드) ④ 그때 코드가 남아 있으면 이벤트 본문 예시 1건(개인정보 가린 것).

### 3-3. 개인정보·보안

- 생체 템플릿은 수신·저장하지 않는다. 일부 단말기는 이벤트에 얼굴 캡처 사진을 붙여 보내는데 **버린다**(저장 안 함).
- 개인정보 처리방침에 '출입 기록(시각·문)' 항목 추가와, 직원에게 "출입 기록이 근태로 쓰인다"는 고지(취업규칙·근로계약 조항)는 노무사·법무 확인 — 로컬 몫.
- 장치 토큰은 장치별·회사별. 이벤트 수신은 토큰으로 회사를 정하고 다른 회사는 404. 실패 시도는 기록만 하고 본문은 남기지 않는다.

## 5. 못 하는 것 · 2차로 미루는 것

- 금액 계산(급여·수당·세금·4대보험), 급여 프로그램 특정 양식(샘플 받은 뒤).

## 6. 대표 결정 요청 — 이 답이 와야 착수

1. **1차 범위**: α-최소(6~7일) / α-전체(9~11일) / α-전체 + β(공통 2 + 파일 1 + 하이크비전 한 길 2~4 → **총 14~18일**).
2. **하이크비전 기존 연동 방식**(ⓐ/ⓑ/ⓒ)·단말기 모델·대당 가격·설치업체 — 하이링크 세션/대표(§3-2 질문 ①~④).
3. 급여 내보내기 = 근거 시간표까지(금액 없음)로 가도 되는지.
4. 회사 설정 기본값(주 시작 월 · 소정 09~18 휴게 60분 · 5인 이상 가산 표시) — 다짐 기준으로 시작해도 되는지.
5. QR 방식: 현장 태블릿에 QR 을 띄우고 직원이 찍기(추천, 네이티브 작업 없음) vs 직원 휴대폰 QR 을 태블릿이 찍기.
6. 근태 Pro 요금 잠금 시점: 1차 배포 때는 회사 설정 플래그로 열고, #546 공간 잠금 때 요금제에 묶기.
