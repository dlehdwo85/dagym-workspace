## A. 회사가 수집 원천을 직접 추가 (#1181 3번)

**지금**
- 영업 › 데이터 설정의 '직접 추가한 출처'(사이트·키워드·엑셀)는 메모용이라 자동으로 모으지 않습니다.
- 게시판 감시(협력사 모집)는 운영사 목록에만 있고, 다짐 전용입니다.

**만들 것**

| 무엇 | 내용 |
|---|---|
| 등록 | 데이터 설정 › '내 수집 원천' [게시판·RSS 주소 추가] — 이름·주소·찾을 낱말(선택). 회사당 10개 |
| 수집 | 하루 2번(09·15시) 그 페이지를 받아 '게시일이 있는 글 줄'만 공고로(협력사 감시와 같은 글 줄 규칙). RSS 이면 항목 그대로 |
| 보이는 곳 | 영업기회 허브 '내 원천' 탭 · 아침 메일 '내 원천' 구역 · 업무로 넘기기·미참여 같은 단추 |
| 저장 | 회사 전용 표(새 DB). 공용 공고 줄(sales_src_rows)에는 넣지 않음 — 다른 회사·다짐 목록에 섞이지 않고, 영업 쓰기 전환(cutover) 규칙도 건드리지 않음 |
| 상태 | 주소마다 '연결됨 / 연결 안 됨(3번 연속 실패) / 막힘(사이트가 수집 금지)' + 마지막으로 받은 때. 고객에게는 원인 대신 상태만 보여 줌 |

**안전 장치(필수)**
- 주소 제한: http·https 만 받습니다.
- 내부 주소 막기: 주소를 IP 로 바꾼 뒤 사설·내부 주소로 가는 요청은 막습니다(127·10·172.16~31·192.168·169.254 메타데이터·::1·localhost·.local). 리다이렉트는 3번까지 허용하고, 단계마다 다시 검사합니다.
- 크기·시간 상한: 1MB·10초. 회사당 하루 요청 상한을 둡니다.
- 수집 금지 존중: 사이트의 수집 금지(robots.txt)를 따르고, 금지면 등록을 거절합니다. 로그인이 필요한 페이지는 받지 않습니다.
- 서버 요청: 이 요청은 우리 서버 주소로 나갑니다. 해외 서버가 막히는 사이트는 서울 중계로 보내고, 중계 허용 목록에 등록된 호스트만 넣습니다.

**다짐**: 영향 없습니다. 다짐 협력사 감시는 그대로입니다.
**비용**: 0원(외부 유료 서비스 없음).
**대표 결정**: 필요 없습니다(수집 금지 존중·회사당 10개는 기본값).

## B. 회사별 기능 켜기 (#1181 4번 · #1175 회사별 베타 기능)

**지금**
- 코드 약 35곳이 `tenant === 'default'`(다짐인가)로 기능을 나눕니다. 대상은 지점 보고·문의 연동·현장 매출·후속조사 자동·출퇴근 위치·마케팅 체험 등입니다.
- '점검' 메뉴는 모든 회사에 늘 보이고 끌 수 없습니다(이번 시험 F2).

**만들 것**
- 기능 표(새 DB `tenant_features`): 회사 · 기능 · 켬/끔 · 누가 · 언제 · 메모.
- 코드의 기본값 표: 다짐 = 지금 동작(모두 켬), 다른 회사 = 업종 묶음 기본값.
- 판단은 한 함수 `featureOn(tenant, 기능)` 으로 합니다. 'default' 비교 35곳을 묶음별로 이 함수로 바꿉니다.
  - 다짐 기본값이 지금 동작이라 결과는 같습니다.
  - 묶음마다 다짐 판정 스냅샷과 화면 시험으로 확인합니다.
- 화면:
  - 플랫폼 › 회사 상세 '기능' 칸: 운영자가 켜고 끕니다(감사 기록 남김). 베타 기능도 여기서 회사별로 켭니다.
  - 회사 관리자 › 설정 '쓰는 기능': 고객이 끌 수 있는 것만 보입니다(점검·메모·출퇴근 위치 등).
- 첫 묶음: 점검 메뉴 끄기(F2), 내부 회사 이름 정의를 한 곳으로(customerScope.ts 와 mktAuto.ts 중복).

## C. 고객 요청함 (#1175)

- 플랫폼 '고객 요청함' 한 화면으로 모읍니다.
  - 출처: 상담 신청 · 앱 문의 · 운영자 메모 · 메일
  - 분류: ①설정으로 해결 ②공통 개선 ③맞춤 개발(유료, '견적 후 진행') ④불가
  - 상태: 접수 → 검토 → 진행 → 완료/반려
- 요청마다 담당자와 고객에게 보낸 답변을 기록합니다.
- 같은 요청은 한 줄로 묶고 '요청한 회사 n곳'으로 셉니다. 공통 개선의 우선순위가 됩니다.
- 맞춤 개발 금액은 화면에 쓰지 않고 '견적 후 진행'만 표시합니다(D-26).
