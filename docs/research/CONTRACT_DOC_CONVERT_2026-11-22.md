# 전자계약: 워드·한글·엑셀 → PDF 바꾸기 방법 비교 (#1125, 2026-11-22 클라우드)

대표 요청(11/22): "한글 워드 엑셀 pdf 이미지 등 모두 업로드 가능하도록" — 근로계약서 워드(docx)가 전자계약에 안 올라감.

## 지금 상태
- **보관용 칸은 이미 모든 형식**(실행 파일만 막음): 업무 첨부 · 자료실 · 업무 메일 첨부 · 계약 관리 계약서 파일(형식 제한 없음).
- **용도가 정해진 칸**(읽어서 숫자를 만드는 곳이라 형식 제한 유지): 지점 보고 하이링크 이용현황(PDF·xlsx·CSV), 회원목록(xlsx), 대화 파일(txt·csv·zip), 점검 사진·신고 사진(사진), 회의록 녹음(소리), 정산(xlsx·csv·txt), 운영 이력 옮기기(json).
- **전자계약(서명 받기)**: PDF·png·jpg 만 — 서명 칸을 쪽 그림 위에 놓아야 해서. 11/22 부터 워드·한글·엑셀을 놓으면 막지 않고 "PDF 로 바꿔 올리는 기능 준비 중 — [파일 › 다른 이름으로 저장 › PDF] 뒤 올리기 · 보관만이면 계약 관리에 그대로" 안내.
- **직원 입사 서류(관리 › 사용자 › 전자계약서)**: 파일을 올리는 칸이 없음(기본 서식 글 + 칸 채우기). 회사 서식(워드)을 올려 쓰고 싶다면 아래 변환이 정해진 뒤 같은 방법으로.

## 바꾸는 방법 후보 (대표 결정 필요)

| | 방법 | 정확도 | 비용 | 계약서 내용이 어디로 | 한글(hwp·hwpx) |
|---|---|---|---|---|---|
| ① | 우리 서버(Vercel)에서 무료 라이브러리 | 낮음 — docx→HTML→PDF 는 표·머리글·글꼴이 틀어짐. LibreOffice 는 Vercel 함수에 못 올림(크기) | 0원 | 우리 서버 안 | 사실상 불가 |
| ② | 브라우저 안에서 바꾸기(docx·xlsx 미리 보기 라이브러리 → PDF) | 중간 — 단순한 계약서는 됨, 복잡한 서식은 틀어질 수 있음 | 0원 | 사용자 PC 밖으로 안 나감 | hwp 는 정확도 낮음(확인 필요) |
| ③ | 외부 변환 서비스(유료 API) | 높음 | 건당 과금(금액 확인 필요) | **외부(해외일 수 있음)로 계약서·개인정보가 나감** — 처리방침·위탁 고지 필요, 대표 승인 필수 | 서비스마다 다름(확인 필요) |
| ④ | 변환 전용 서버를 따로 하나(LibreOffice 묶음, 예: Gotenberg) — 우리 클라우드 계정에 | 높음(워드·엑셀은 거의 그대로) | 작은 서버 월 비용(사용량 따라 — 확인 필요) | 우리가 운영하는 서버(외부 회사로 안 나감) | 옛 hwp 일부만(확인 필요), hwpx 는 어려움 |

**클라우드 추천**: 먼저 ②(무료·개인정보 밖으로 안 나감)로 워드·엑셀을 받아 보고, 서식이 틀어지는 계약서가 많으면 ④. ③은 개인정보 때문에 추천하지 않음. 한글은 당분간 "PDF 로 저장 뒤 올리기" 안내 유지.

확인 못함: 각 방법의 실제 정확도(대표 근로계약서 원본은 개인정보라 열지 않음 — 결정되면 가짜 서식으로 시험), 비용 금액.

## 2단계 — ② 브라우저 안 변환 적용 (2026-11-23, 대표 위임: 돈·삭제·스토어 공개 없는 결정은 추천안)

- 전자계약 [새 계약] 1단계에 **워드(.docx)·엑셀(.xlsx)** 을 놓거나 고르면 이 브라우저 안에서 PDF 로 바꿔 올림. 원본 워드·엑셀 파일은 서버로 보내지 않고, 서버에는 바뀐 PDF 만 감(화면 시험으로 확인).
  - 워드: docx-preview(0.4.1, Apache-2.0)로 쪽을 그림 → 그림으로 찍음(html-to-image 1.11.13, MIT) → PDF(pdf-lib). 워드가 저장해 둔 쪽 나눔 표시를 따르고, 표시가 없으면 글줄 사이에서 자르며 머리글·바닥글은 쪽마다 다시 붙임.
  - 엑셀: 자체 읽기(src/lib/xlsxSheet.ts — 값·병합·열 너비·행 높이·굵게·정렬·채움·테두리·천 단위·날짜) → 표를 그려 쪽 너비에 맞춤, 행 경계에서 쪽 나눔. 줄바꿈 없는 글은 엑셀처럼 오른쪽 빈 칸까지 보임.
  - 바꾼 쪽 미리보기(최대 4쪽)와 "원본과 많이 다르면 [다른 이름으로 저장 › PDF] 한 파일을 올려 주세요" 안내.
  - 한글(.hwp·.hwpx)·옛 워드(.doc)·옛 엑셀(.xls)·파워포인트는 안내만(그대로).
- 한계: PDF 안 글자는 그림이라 고를 수 없음(서명 칸 놓기·서명에는 지장 없음). 엑셀 테마 색·조건부 서식·그림, 워드의 복잡한 글상자·도형은 틀어질 수 있음. 글꼴은 그 PC 에 있는 글꼴로 그림(윈도우는 맑은 고딕).
- 시험(가짜 근로계약서 — tests/fixtures/contract-sample.docx·xlsx, 표·머리글·바닥글·서명란): 원본(LibreOffice 로 그린 쪽)과 우리 변환을 나란히 —
  - 워드 2쪽: [contract-convert-1125/compare-docx.png](contract-convert-1125/compare-docx.png) — 머리글·바닥글 두 쪽 모두, 표·서명란 같음. 쪽 나뉘는 곳이 한 조항 차이(원본 9조 뒤 / 우리 10조 뒤).
  - 엑셀 1쪽: [contract-convert-1125/compare-xlsx.png](contract-convert-1125/compare-xlsx.png) — 제목 병합·머리 채움·테두리·천 단위·서명 줄 같음.
- 확인 못함: 실제 회사 근로계약서(개인정보라 열지 않음)·윈도우 PC·휴대폰 브라우저에서의 모양 — 로컬이 가짜 서식으로 확인. 많이 틀어지면 ④(변환 서버, 월 비용) 결정 자료를 로컬이 올림.
