## 3. 회사 지원사업 프로필 (`support_profiles`)

본점 시·도·시·군·구 · 설립일(업력) · 규모(예비창업·소상공인·소기업·중기업·중견기업) · 상시근로자 · 연 매출(선택) · 업종 · 키워드 · 보유 인증(벤처·이노비즈·메인비즈·기업부설연구소·연구개발전담부서·SW사업자 …) · 브랜드·사업부 · 관심 분야(IP·R&D·수출·고용·SaaS·마케팅·창업·자금·시설·교육·인증) · 빼는 낱말 · 회사 소개.
저장 전에는 회사 정보에서 기본값(업종·회사 정보 주소의 시·도·시·군·관심 사업 이름·사업 소개). 고치기는 관리자.

## 4. 1차 규칙 (서버, AI 없음)

| 조건 | 판정 |
|---|---|
| 공고 시·도 ≠ 본점 시·도 | ❌ (같으면 ✓ +20) |
| 제목·대상·해시태그의 시·군이 본점 시·군과 다름 | ❌ (같으면 ✓ +25). 기관 이름에만 있으면 ⚠ '지역 제한 확인' |
| 업력: K-Startup 업력 칸 · '창업 N년 이내/미만' · '창업기업'(법정 7년 이내) | 넘으면 ❌, 안이면 ✓ +10, 설립일 없으면 ⚠ |
| 예비창업자 대상인데 설립일 있음 | ❌ |
| 상시근로자 N인 이상/미만 | 안 맞으면 ❌, 맞으면 ✓, 근로자 수 없으면 ⚠ |
| 소상공인 대상인데 중기업·중견 | ❌ (소상공인·소기업 ✓) |
| 기업부설연구소·연구개발전담부서 보유 문구 | 없으면 ⚠, 있으면 ✓ +10 |
| 벤처·이노비즈·메인비즈 인증 문구 | 없으면 ⚠, 있으면 ✓ +10 |
| SW사업자 문구 | 신고 없으면 ⚠ |
| 기출원 건 지원 불가 · 협약 후 출원 | 늘 ⚠ '이미 출원한 건은 지원 불가 — 선정·협약 전에 출원하지 않기' |
| 관심 분야·키워드·업종 낱말 | 제목 +12 / 본문 +6(최대 40), 짧은 영문(IP·AI)은 낱말 경계로만 |
| 빼는 낱말 | ❌ |

판정: ❌ 가 하나라도 있으면 '해당 없음'(맞춤 탭에서 빼고 '보기'로 펼침), 관심 분야가 맞고 점수 12 이상이면 '해당', 나머지 '확인 필요'.
맞는 순: AI 판단(✅ → ⚠) → 1차 '해당' → 1차 점수 → 마감 가까운 순.

## 5. AI 판단 (누를 때만 · AI 세일즈 한도)

- 입력: 회사 프로필 + 공고(기관·대상·업력·지역·신청 기간·규모·해시태그·본문 9,000자). 기관 공지는 그때 본문 페이지를 한 번 읽어 저장(등록된 감시 페이지와 같은 호스트만).
- 지시: 공고와 프로필만 근거, 없는 조건·금액·서류는 지어내지 않음. 꼭 대조할 자격 = 본점 시·군 · 업력 · 상시근로자 · 연구소/전담부서 · 벤처/이노비즈 · SW사업자 · 기출원 불가 · 중복 수혜.
- 출력(JSON): 해당 여부(fit/maybe/no) · 이유 2~5줄 · 맞는 브랜드(프로필 브랜드·관심 사업 목록 안에서만) · 준비 서류(공고에 적힌 것만, 최대 12) · 요약 · 지원 규모.
- 한도: 회사 월 AI 한도·요금제 요청 수·사람별 한도·크레딧 차단을 지킴. 사용량 `ai_usage.purpose = 'sales_support'`(AI 세일즈 줄). 관리자는 [위 5건 AI 판단](맞춤 순 위에서 아직 판단 안 한 것).

## 6. 진행 · 업무 · 알림

- [관심] → 담당 업무 '[지원사업] 공고명 — 검토'(마감 = 신청 마감 7일 전, 체크리스트: 공고문·자격 요건 확인 / 신청 여부 결정).
- [신청 준비] → 같은 업무를 '— 신청 준비'로(마감 = 신청 마감) + 체크리스트에 AI 가 읽은 준비 서류('서류: …') + 공고문·양식 내려받기 / 신청서 작성 / 온라인 제출·접수 확인. AI 판단이 없으면 '준비 서류 목록 정리(공고문 기준)'.
- 업무는 영업 공간 업무(`tasks.sales_ref.kind = 'support'`) — 업무 목록에 '지원사업' 배지. 담당을 바꾸면 열린 업무도 넘기고 새 담당에게 알림.
- 신청 완료·선정·탈락·포기 → 열린 업무 완료. 신청일(신청 완료 때 오늘)·결과일·선정 금액·결과 메모·메모, 기록(`support_work_log`).
- 마감 알림(정기 점검, KST 08~20시): 관심·신청 준비 공고가 7일 안이면 'D-n' 1번, 3일 안이면 1번 더(3일 안에 처음 잡힌 건 하나만). 담당(없으면 처음 누른 사람)에게, 알림 종류 `support_deadline`.
- [직접 추가]: 목록에 없는 공고·지난 신청 이력(예: 9/12 신청 → 결과 대기 메모). 그 회사에만 보이고(다른 회사 404), 고치기·지우기는 넣은 사람·관리자.
- 영업 홈 카드 '마감 임박 지원사업 n'(7일 안: 관심·준비 중 + 맞춤 '해당') → 마감 임박 탭.

## 7. 화면 · API

- 사이드바 영업 메뉴 '지원사업'(하단 탭에는 없음 — #438). 탭: 맞춤 · 마감 임박(14일) · 관심·준비 · 신청·결과 · 전체. 찾기, 숨기기(회사 전체, 되돌리기), 상세 창(원문·첨부·1차 판단·AI 판단·진행 단계·담당·신청일·결과·업무 링크·기록).
