# AI 크레딧 설계 (V45, 2026-10-19 클라우드) — 요금 금액은 대표 결정 대기

## 1. 단위
- **1크레딧 = 원가 10원**(정가 단가 × 환율 1,400, `ai_usage.cost_usd` 그대로 환산). 사용자는 '회' 대신 크레딧으로 씀.
- 예상: 조회 질문 1~4크레딧(빠른 모델) · 만들기·배정 질문 4~8 · 문서 작업 15~20 · 자료실 자동 정리·분류 0~1(반올림, 10크레딧 미만 작업은 0.1 단위 누적).

## 2. 저장(추가형, 다음 단계)
- 새 칸 없이 계산: 월 사용 크레딧 = `sum(ai_usage.cost_usd) × 1400 / 10` (회사·사람별). 이미 있는 회사·사람 한도(달러)는 크레딧 = 달러 × 140 으로 바꿔 보여 줌.
- 요금제 포함량: `plans.ai_credits`(회사 공유 또는 1인당) — 금액 확정 뒤 migration 으로 추가.

## 3. 화면
- 사용량: "이번 달 AI 남은 양 **62%**" 막대 + "질문 약 **40번** 남음"(남은 크레딧 ÷ 최근 30일 내 질문 1번 평균 크레딧, 기록 없으면 6크레딧 기준).
- AI 비서 답 아래 비용 줄: "약 0.5크레딧" (지금 '약 7원' 자리).
- 80%·100%: 기존 한도 알림 그대로(문구만 크레딧).

## 4. 원가 절감(이번 배포)과 연결
- 고정부(규칙·회사 정보) 캐시 구간 분리, 의도별 도구 묶음(+ `more_tools` 로 전체), 조회 질문 = 빠른 모델, 대화 이력 최근 6턴 + 앞부분 요약, 답 5줄 안팎.
- 측정: `POST /api/admin/ai-bench`(플랫폼 관리자, 실제 호출 약 5번) → 질문별 원 단위·모델·캐시 읽기 토큰, 기준 중앙 73원과 비교.
