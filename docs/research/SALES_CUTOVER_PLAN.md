# 영업 공간 전환 계획(쓰기) — V41 단계 2 마무리 (2026-10-19 초안)

> 지금 상태:
> - 영업관리(Supabase)의 원본 행을 `sales_src_rows`(090)로 옮겼다. 공용 표는 scope=global, 회사별 표는 scope=회사이고, 공용 표 안의 회사별 칸은 `<표>__progress` 로 떼어 두었다.
> - 영업 공간 화면 7개(현황·리드·파이프라인·제안·입찰·허브·지역)는 **읽기 전용**이다.
> - [매일 가져오기]가 켜져 있으면 원본을 다시 덮어쓴다.
> - 원본 사이트는 지금도 운영 중이다(V39 E: 이전이 끝날 때까지 그대로 → 끝나면 읽기 전용 2주 → 종료).
>
> 이 문서는 "워크인에서 쓰기를 언제·어떻게 시작하는가"를 정한다.

## 1. 왜 지금 바로 쓰기를 열면 안 되는가

- 원본과 워크인 **두 곳에서 동시에 쓰면** 매일 가져오기가 워크인 수정분을 덮어쓰거나, 원본 수정분이 빠진다. 운영실 KV 이전과 같은 원칙(동시 운영 중 이중 쓰기 금지)을 적용한다.
- 원본의 회사별 칸(분류 변경·연락 상태·메모)은 지금 `__progress` 에 행 그대로(jsonb) 들어 있다. 쓰기용 정식 표(칸 타입·제약·감사)로 아직 바뀌지 않았다.

## 2. 전환 순서(제안)

| 단계 | 내용 | 누가 |
|---|---|---|
| T-1 | 쓰기용 정식 표 추가(추가형). 리드·상담·제안·계약·일정·업무는 회사별 표, 공고·시설·협력사의 회사별 진행 칸은 `*_progress` 표. 원본 id 를 그대로 키로 쓴다(`src_id`). 화면은 아직 읽기 전용 | 클라우드 |
| T-2 | **동결 시각 공지** → 원본 영업관리를 읽기 전용으로 바꿈(원본 쪽 RLS·화면 잠금) | 대표 결정·영업 세션 |
| T-3 | 마지막 [적용](원본 → sales_src_rows) → **정식 표로 1회 변환** → 건수 대조(V39 E 기준: 거래처 21·상담 4·업무 8/하위 1·시점 2·진행기록 30·신규단지 22·협력사 164·공고 4,356·시설 4,346, **관련 654**). 하나라도 다르면 T-2 를 풀고 원본으로 되돌아감 | 클라우드 실행, 로컬 대조 |
| T-4 | [매일 가져오기] 끄기(회사 진행 칸 덮어쓰기 금지). 공용 수집 데이터(공고·시설·협력사·신규단지)는 워크인 수집기 12+1개로 계속 들어옴 | 클라우드 |
| T-5 | 워크인 쓰기 열기(아래 3절). 원본은 읽기 전용 2주 → 종료 | 클라우드, 대표 확인 |

**되돌리기**: T-5 전까지는 원본이 정본이다. T-3 대조가 실패하면 동결만 풀면 된다(워크인 쪽은 버리고 다시 적용).

## 3. 쓰기 첫 묶음(V39 D 반영) — T-5 에서 같이 연다

1. 리드 상태 변경(파이프라인 11단계)
   - 실패·보류는 **어디서 바꾸든 사유 필수**(칸반·목록·빠른 메모 같게).
   - 칸반 실패 시 되돌리고 안내한다.
   - 휴대폰은 길게 눌러 이동하거나 상태 선택 시트를 쓴다.
2. 다음 연락일·메모·담당 변경. 담당자 필터·변경 권한은 서버(access.ts)가 검사한다. 원본처럼 ?owner= 를 그대로 믿지 않는다.
3. 입찰·공고 진행
   - 상태 7종·미참여·[진행 목록으로 되돌리기]
   - 완료 탭 필터 시 탭 유지
   - 0037 정정 트리거: 새 차수로 진행 기록을 옮긴다
4. 시설·협력사 연락 상태(회사별 칸)
5. CSV
   - 내보내기: 화면에 보이는 조건 그대로 + 한글 헤더
   - 가져오기: CP949 자동 판별·한글 헤더 별칭
6. 모든 날짜 계산(지연·오늘·KPI)은 Asia/Seoul. 정체 표시는 14일로 통일.
7. 업무·일정 연결(`lead_id`)은 워크인 업무·캘린더를 그대로 쓴다(A 같이 쓰기).
8. 원본 업무 8·하위 1은 워크인 업무로 옮기고, 원본 일정 2는 워크인 일정으로 옮긴다.

옮기지 않는 것: 백업 표 2개, 관측·실행 이력 표, 미사용 코드(V39 D·E).

## 4. 대표 결정 필요

- **동결(전환) 날짜·시각**: 영업 담당이 원본에 쓰지 않는 시간대를 권장한다(예: 금요일 18시 → 월요일 오전 열기).
- 원본 읽기 전용 기간(V39: 2주)과 종료 뒤 원본 데이터 보관(백업 파일 보관 위치).
- 영업관리 사용자 중 워크인 계정이 없는 사람 처리. 지금은 대표에게 연결되는데, 계정을 만들지 정해야 한다.

## 5. 지금 바로 할 수 있는 것(대표 결정 없이)

- T-1 정식 표 + 변환 함수 + 건수 대조 시험. 화면은 읽기 전용 유지, 원본 영향 없음.
- 쓰기 화면·API 를 **잠금 상태로** 만들어 두기: 회사 설정 `sales_writes_open=false` 면 409 + "전환 전에는 영업관리에서 수정" 안내.
