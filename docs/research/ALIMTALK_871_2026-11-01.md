# 카카오 알림톡 — 결제·약관 동의 안내 (#871, 304차)

작성: 2026-11-01 클라우드 · 상태: **코드 배포(꺼짐 기본) · 실제 발송 확인 못함** (업체 가입·채널·템플릿 검수·키 입력 전)

## 1. 대표 결정 (11/01)

- 카카오 알림톡을 쓴다. **결제할 때 · 이용약관 동의할 때만.** 광고·홍보 메시지는 보내지 않는다(모두 정보성).
- 받는 사람: 그 회사 **대표·관리자 중 '알림톡 안내 받기'에 동의하고 휴대폰을 적은 사람**만.
- 실패하면 **메일만**(이메일 안내는 원래대로 항상 감). 문자 대체 발송은 비용이 들어 **끔**.

## 2. 보내는 때 5가지 (= 템플릿 5개)

| 종류(코드) | 언제 | 받는 사람 | 같은 안내 두 번 막기 |
|---|---|---|---|
| `trial_d3` 무료 체험 종료 3일 전 | 정기 실행(체험 안내 d3 단계) | 동의한 관리자 | 회사·단계·체험 끝 날짜마다 1번 |
| `trial_d0` 무료 체험 종료 당일 | 정기 실행(체험 안내 d0 단계) | 동의한 관리자 | 〃 |
| `pay_ok` 결제 완료 | 결제 승인(영수증 메일 직후) | 동의한 관리자 | 결제 1건마다 1번 |
| `pay_fail` 정기 결제 실패 | 정기 결제 실패(첫 실패·3일·7일 재시도) | 동의한 관리자 | 회사·날짜마다 1번 |
| `signup` 가입(약관 동의) 완료 | 이메일 확인 끝(소셜 가입은 바로) | 동의한 본인 | 사람마다 1번 |

- 설계 파트너 기간 끝 안내는 알림톡을 보내지 않는다(슈퍼관리자 알림으로 처리 중).
- 앱 화면에는 결제 권유가 없다(#861). 알림톡은 카카오톡으로 가는 정보성 안내다.

## 3. 템플릿 초안 5개 (카카오 검수용 · 정보성 · 변수는 `#{이름}`)

발신 프로필: **판매 명의 사업자(하이링크)의 '워크인' 카카오톡 채널**. 버튼은 넣지 않는다(링크 검수·변수 링크 문제를 피함 — 필요하면 나중에 '웹 링크: 사용량·요금제' 1개 추가).

### ① 무료 체험 종료 3일 전 안내 (`trial_d3`)
```
[워크인] 무료 체험 종료 안내

#{회사명}의 워크인 무료 체험이 #{종료일}에 끝납니다(#{남은일수}일 남음).

체험이 끝나면 보기와 내보내기만 할 수 있습니다. 계속 쓰시려면 관리자 화면 > 사용량·요금제에서 요금제를 골라 주세요. 데이터는 그대로 남습니다.

※ 이 메시지는 알림톡 안내 받기에 동의한 관리자께만 보내는 정보성 안내입니다.
```

### ② 무료 체험 종료 당일 안내 (`trial_d0`)
```
[워크인] 무료 체험 종료 안내

#{회사명}의 워크인 무료 체험이 오늘(#{종료일}) 끝납니다.

오늘이 지나면 보기와 내보내기만 할 수 있습니다. 결제하면 바로 다시 쓸 수 있고, 데이터는 지우지 않습니다.

※ 이 메시지는 알림톡 안내 받기에 동의한 관리자께만 보내는 정보성 안내입니다.
```

### ③ 결제 완료 안내 (`pay_ok`)
```
[워크인] 결제 완료 안내

#{회사명}의 결제가 완료되었습니다.

상품: #{상품}
금액: #{금액}원 (VAT 포함)
결제 일시: #{결제일시}

영수증은 관리자 이메일로 보내 드렸습니다.

※ 이 메시지는 알림톡 안내 받기에 동의한 관리자께만 보내는 정보성 안내입니다.
```

### ④ 정기 결제 실패 안내 (`pay_fail`)
```
[워크인] 정기 결제 실패 안내

#{회사명}의 워크인 정기 결제가 실패했습니다.

사유: #{사유}
다음 시도: #{다음시도}

등록한 카드를 확인해 주세요. 미납 7일이 지나면 보기 전용, 30일이 지나면 이용이 멈춥니다. 데이터는 지우지 않습니다.

※ 이 메시지는 알림톡 안내 받기에 동의한 관리자께만 보내는 정보성 안내입니다.
```

### ⑤ 가입·약관 동의 완료 안내 (`signup`)
```
[워크인] 가입 완료 안내

#{이름}님, 워크인 가입과 이용약관·개인정보 수집·이용 동의가 완료되었습니다.

회사: #{회사명}
동의 일시: #{동의일시}
무료 체험: #{체험종료일}까지

동의 내용은 설정 > 계정에서 언제든 확인할 수 있습니다.

※ 이 메시지는 알림톡 안내 받기에 동의한 관리자께만 보내는 정보성 안내입니다.
```

코드의 글(`src/lib/alimtalk.ts` `ALIM_TEMPLATES`)과 위 글은 같다. 검수에서 글을 고치면 코드 쪽 변수 이름만 맞으면 된다(본문은 카카오에 등록된 글이 나감).

## 4. 발송 업체 비교 (공식 요금표·공개 자료 기준, VAT 별도)

| 업체 | 구분 | 알림톡 단가 | 근거 | 결제 | 비고 |
|---|---|---|---|---|---|
| 인포뱅크 비즈고 | 카카오 공식 딜러 | 건당 약 7.14원(기본 요금제) | 비즈고 자사 블로그 2026-07-27 비교표(자사 글이라 견적 확인 필요) | 후불 | 공식 딜러 15곳 중 하나 |
| NHN Cloud Notification | 카카오 공식 딜러 | **확인 못함** — 공식 요금 페이지에 금액이 비어 있음(요금 계산기·문의) | nhncloud.com 요금 페이지 | 후불(클라우드 청구) | 개발 문서가 잘 되어 있음 |
| 솔라피(SOLAPI) | 재판매 | 건당 **13원**(월 1~9,999건), 1만 건 이상 10원 | solapi.com/pricing 공식 요금표 | 선불 충전 | 월 기본료·API 비용 없음, 대체 문자 끄기 가능 |

참고: 비즈고 비교표의 공식 딜러 단가는 7~10원, 재판매 10~14원(같은 글 5,000건 기준).

### 추천: **솔라피** (지금 규모 기준)

- 우리 발송량은 결제·가입 때만이라 **월 수십~수백 건**이다. 300건/월이면 솔라피 3,900원 · 비즈고 약 2,140원 — **차이 월 2천 원 안팎**.
- 솔라피는 공식 요금표가 공개되어 있고, 선불 충전이라 계약·후불 심사 없이 바로 시작, 월 기본료 없음, 발신 프로필·템플릿 등록 화면이 있음, 문자 대체 발송을 메시지마다 끌 수 있다.
- 코드는 솔라피 방식(REST v4, HMAC-SHA256 인증)으로 만들었다. 월 1만 건이 넘으면 공식 딜러(비즈고·NHN Cloud) 견적을 받아 바꾸는 것을 다시 본다(어댑터만 추가).
- **확인 못함**: 솔라피 메시지 발송 API의 알림톡 항목 이름(`kakaoOptions.pfId`·`templateId`·`variables`·`disableSms`)을 공식 문서 전체로는 확인하지 못했다(인증 방식은 공식 문서로 확인). 키를 넣은 뒤 **[시험 발송]으로 실제 1건을 받아 보고** 그때 맞춘다.

## 5. 운영 설정 이름 (값은 대표가 Vercel 에 직접 — 저장소·대화에 쓰지 않음)

| 이름 | 내용 |
|---|---|
| `ALIMTALK_PROVIDER` | `solapi` (없으면 꺼짐) |
| `ALIMTALK_API_KEY` | 솔라피 API Key |
| `ALIMTALK_API_SECRET` | 솔라피 API Secret |
| `ALIMTALK_PF_ID` | 솔라피에 연동한 카카오 채널(발신 프로필) ID |
| `ALIMTALK_TEMPLATES` | 검수 통과한 템플릿 번호 JSON — 예: `{"trial_d3":"…","trial_d0":"…","pay_ok":"…","pay_fail":"…","signup":"…"}` (없는 종류는 그 종류만 안 보냄) |
| `ALIMTALK_FROM` | (선택) 발신번호 — 대체 문자를 끄므로 보통 비워 둠 |

네 개(PROVIDER·API_KEY·API_SECRET·PF_ID)가 다 있어야 켜진다. 하나라도 없으면 화면에 '발송 준비 중 — 지금은 이메일로만 안내'.

## 6. 대표 할 일 (순서대로)

1. **카카오톡 채널** '워크인' 개설(판매 명의 사업자로) → 비즈니스 채널 인증(사업자등록증).
2. **솔라피 가입**(사업자 인증) → 카카오 채널 연동(발신 프로필 등록) → `ALIMTALK_PF_ID` 확인.
3. 솔라피에서 **템플릿 5개 등록·검수 요청**(위 3번 글 그대로 붙여 넣기) → 통과하면 템플릿 번호 5개.
4. **충전**(예: 1만 원 = 약 770건) — 돈이 드는 일이라 대표가 직접.
5. Vercel(Production) 환경 변수 입력: 위 5번 표 — 값은 대표가 붙여 넣기(클라우드·로컬은 값을 보지 않음).
6. 운영 → 관리자 화면 > 사용량·요금제 > '카카오 알림톡 결제·가입 안내'에서 **내 휴대폰 + 받기 동의 저장** → (플랫폼 운영자만 보이는) **[시험 발송]**으로 5종 1건씩 받아 보기.

## 7. 화면·데이터

- 관리자 화면 > 사용량·요금제: '카카오 알림톡 결제·가입 안내' 카드 — 내 휴대폰(알림톡 전용, 명함 전화와 따로·동료에게 안 보임) + 받기 동의(선택) + 운영자 [시험 발송].
- 가입 화면(이메일·소셜): 약관 칸 아래 '결제·가입 안내를 카카오 알림톡으로 받기(선택)' → 고르면 휴대폰 칸. 전체 동의에는 넣지 않음(휴대폰이 필요해서).
- 동의 기록: `consents`(kind `alimtalk`, 동의·철회 모두) · `users.alimtalk_phone/alimtalk_ok/alimtalk_ok_at`(migration 234).
- 보낸 기록: `alimtalk_logs`(종류·성공·사유·메시지 번호, **전화번호는 남기지 않음**). 탈퇴 정리 때 알림톡 휴대폰도 지움.

## 8. 확인 못함

- 실제 카카오톡 도착(업체 가입·채널·검수·키 전) · 솔라피 알림톡 항목 이름 최종 확인 · NHN Cloud 공식 단가 · 비즈고 단가는 자사 글 기준.
- 시험은 가짜 솔라피 서버로 돌린 구조 시험이다(인증 헤더 모양·본문·두 번 막기·동의·실패 시 메일 그대로).
