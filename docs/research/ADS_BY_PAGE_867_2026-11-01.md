# 워크인 페이지별 광고 초안 (#867, 2026-11-01 클라우드)

상태: **초안 문서만** — 네이버 검색광고·메타 광고에 아무것도 만들지 않았습니다. 광고를 만들고 켜는 것은 **대표 승인 뒤**입니다.
메타 광고는 승인 뒤에도 **일시정지 상태 초안**까지만 만들고, 집행(켜기)과 예산은 대표가 정합니다(회사 공통 원칙).

근거: `docs/handoff/PAGE_GOALS_867_2026-11-01.md` §2 — "네이버 검색광고: 광고그룹 = 페이지, 최종 주소 = 그 페이지. 메타 광고는 일시정지 초안까지만".

## 공통 규칙

- 글은 각 소개 페이지(`src/lib/landingPages.ts`)에 적힌 **운영 기능만**. 과장 표현('최고'·'1위'·'완벽'·'보장')은 쓰지 않음.
- 요금 숫자는 쓰지 않습니다(#624 승인 전). 쓰는 문구는 '14일 무료 체험'뿐입니다.
- 남의 서비스 이름은 광고 글에 쓰지 않습니다. 검색어로 사는 것과는 별개입니다.
- '자동 게시'는 인스타그램·페이스북만 씁니다. 네이버 블로그는 '올리기 도우미'라고 씁니다.
- 최종 주소에 utm 을 붙입니다. 311차 집계가 처음 들어온 페이지와 UTM 을 가입까지 기억해서, 플랫폼 운영 › 가입 흐름 '소개 페이지별'에 잡힙니다.
  - 네이버: `?utm_source=naver&utm_medium=cpc&utm_campaign={페이지}`
  - 메타: `?utm_source=meta&utm_medium=paid_social&utm_campaign={페이지}`
- 네이버 파워링크 글자 수: 제목 15자, 설명 45자 이내. 아래 글은 모두 이 안에 들어갑니다(세어 확인함).
- 네이버 광고 글에는 가운뎃점(·)을 못 씁니다(11/01 로컬 초안 등록 때 확인) — 아래 네이버 표의 제목·설명은 쉼표로 적었습니다. 메타 광고 문구는 가운뎃점 그대로.

> 11/01 로컬 메타 초안 검수에서 고친 문구(대표 결정 뒤 만든 일시정지 초안과 같음): '엑셀' → '스프레드시트'(남의 상표), '마케터가 없어도 됩니다' → '마케터가 따로 없나요?'(단정 표현). 소개 페이지 문구도 316차에 같이 맞춤.

키워드 주의
- 'SNS 대행 비용'·'블로그 대행'은 대행을 찾는 검색어입니다. 광고 글에 '대행'이라고 쓰지 않았습니다(워크인은 대행사가 아님). 클릭 대비 가입이 낮으면 먼저 끕니다.
- 남의 서비스 이름(경쟁사 상표)을 키워드로 사는 것은 넣지 않았습니다. 상표 문제가 있을 수 있어 대표 판단 사항입니다.

## 3. 측정

- 네이버·메타에서 들어온 방문과 가입은 플랫폼 운영 › 가입 흐름 '소개 페이지별'(311차)과 출처(utm_source)별 주간 표에서 봅니다.
- 클릭 수·비용은 광고 성과 화면(기존 네이버 검색광고·메타 성과 모아보기)에서 봅니다.

## 4. 대표 결정 필요

1. 네이버 검색광고 캠페인을 만들지, 한다면 하루 예산.
2. 메타 광고 초안 5개를 일시정지로 만들어 둘지. 승인 뒤 로컬이 대표 계정으로 만듭니다.
3. 'SNS 대행 비용'·'블로그 대행' 키워드를 넣을지.
