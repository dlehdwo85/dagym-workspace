# #811 마케팅 영상 비용 줄이기 — 2) 실제 사진 영상(271차 반영) · 1) 앱 화면 녹화(설계)

대표 10/29 21:00 '마케팅 AI 영상 제작 비용 최소화'. 로컬 안(21:18): 워크인·하이링크 = 데모 회사 앱 화면 녹화, 다짐·바디랩 = 현장 사진 슬라이드쇼, 한 편을 릴스·쇼츠·페이스북에 같이, AI 영상은 훅 3~5초만.
순서는 로컬과 합의한 대로 **2) 실제 사진 영상 → 1) 앱 화면 녹화**.

## 2) 실제 사진 영상 — 271차에 들어간 것

| 항목 | 내용 |
|---|---|
| 엔진 | 서버 ffmpeg(ffmpeg-static) — 기존 제작의뢰실 영상 합성(v2)과 같은 길. AI 생성 호출 없음 |
| 화면 | 1080×1920 세로 · 30fps · H.264(veryfast, crf 20) |
| 장면 | 사진 1장 = 2.6초. 사진을 화면보다 16% 크게 두고 왼→오·오→왼·위→아래·아래→위 번갈아 천천히 움직임. 장면 사이 0.4초 겹쳐 넘김 |
| 글 | 원고 문장을 장면마다 한 줄 자막(해시태그·링크·이모지 뺌, 30자 안) · 끝 화면(브랜드 한 줄·전화) · 배경음·내레이션은 기존 설정 그대로 |
| 사진 | 이 글에 맞는 자료실 실사 3~6장(글자 든 그래픽·다른 브랜드·가까운 글에 쓴 사진·기밀 빼고). 승인함에서는 직접 3~8장 고를 수도 있음 |
| 비용 | 생성 비용 0(크레딧 원장 줄 없음). '이번 달 영상 n편' 한도에도 안 셈 |
| 걸린 시간 | 시험 서버(4코어)에서 사진 6장 → 15.6초 영상 합성 **8.3~9.7초**(내레이션 없음). 운영 서버(Vercel 함수) 시간은 **확인 못함** — 운영에서 한 번 돌려 봐야 앎 |

쓰는 곳
- 승인함 릴스·쇼츠 카드 **[실제 사진으로 영상 만들기 · 0원]**(관리자) → 다 되면 새 판으로 올라옴.
- 브랜드 키트 › 영상 끝 화면·자막 위 **'릴스·쇼츠 영상 만드는 방법'** = 자료실 실제 사진으로 영상 · 0원 → 자동 제작 원고가 나오면 바로 그 판에 영상을 붙임(새 판 없음). 주 묶음 원고는 초안 그대로(묶음 올릴 때 함께). 사진이 3장이 안 되면 제작 요청 카드로 남고 판 메모에 이유.
- 같은 칸 '앱 화면 녹화 · 0원' = 제작 요청 카드가 '앱 화면 녹화로 만듭니다(생성 비용 0)'·예상 0크레딧으로 바뀜(녹화 파일을 붙이는 일은 아래 1)).

## 1) 앱 화면 녹화 — 설계(2~3일)

녹화는 **로컬 PC 크롬**에서(로컬이 맡기로 함). 서버는 녹화 파일에 자막·끝 화면을 붙이는 쪽만.

1. **데모 회사**: 실제 고객·직원 개인정보가 화면에 나오지 않게 녹화 전용 회사(가상 이름·가상 업무·가상 일정)를 만드는 시드 스크립트 `scripts/marketing/demo-seed.mjs`(클라우드). 운영 DB 에 넣을 때는 대표 승인 뒤 로컬이 실행.
2. **녹화 대본 파일**: `scripts/marketing/screens/<브랜드>-<주제>.json` — 장면마다 `goto`·`click(data-testid)`·`type`·`wait`·자막 한 줄. 버튼 이름은 E2E 시험이 쓰는 data-testid 를 그대로 써서 화면이 바뀌어도 대본이 덜 깨짐.
3. **녹화 실행기** `scripts/marketing/record-screen.mjs`(클라우드가 만들고 로컬 PC 에서 실행): Playwright 휴대폰 화면(390×844, 3배) `recordVideo` → webm → ffmpeg 로 1080×1920 mp4 → 자료실 '마케팅/화면 녹화'에 올림(로컬 PC 에 로그인된 관리자 세션 · 비밀번호는 저장소·대화에 안 씀).
4. **녹화로 영상 만들기**: 승인함 릴스·쇼츠 카드에서 자료실 녹화 파일을 고르면, 이미 있는 '한 편짜리 원본 나눠 쓰기'(187차 ⑦) 길로 길이를 재 장면을 나누고 자막·끝 화면·배경음을 붙임 — 생성 비용 0.
5. **자동 제작**: 브랜드 방법이 '앱 화면 녹화'면 원고의 대본에 맞는 녹화 파일(주제 태그)이 자료실에 있을 때 4)를 바로, 없으면 지금처럼 카드.

일정: 1일차 1~3(시드·대본 2개·실행기) → 2일차 4~5 → 3일차 워크인·하이링크 시범 각 1편, 로컬 운영 확인.

## 기간 의견

- 2)는 271차로 바로 쓸 수 있음. 1주치(화·금) 시안은 다짐·바디랩 = 2), 워크인·하이링크 = 1) 녹화 전까지 2)(사무실·현장 사진이 3장 넘으면) 또는 카드.
- 1)은 2~3일. 녹화 대본은 처음 4~6개만 만들고, 잘 된 것만 늘리는 게 비용·시간 모두 적음.
- AI 영상(크레딧)은 훅 3~5초만 — 브랜드 방법을 'AI 영상'으로 둔 브랜드에서만. 월 실제 비용 한도(270차)가 상한.

## 확인 못함

- 운영 서버에서 한 편 합성에 걸리는 시간·화질(시험 서버 값만 있음).
- 다짐·바디랩 자료실에 브랜드별 쓸 만한 현장 사진이 몇 장인지(운영 자료실 — 로컬 확인).
