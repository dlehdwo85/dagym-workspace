> 대표 지시: "인스타·페이스북은 통합 API 로 더 단순하게". 이 문서는 5-2 를 시작하기 전에 둘을 **비용·심사 기간·위험** 기준으로 비교한다.
> 근거는 로컬 조사 문서 `docs/handoff/WORKIN_V42_PUBLISH_PRICING_RESEARCH.md`(2026-10-17, 공식 페이지 우선)이다. 가격·기간은 계약 직전 다시 확인한다. 환율은 1달러 = 1,400원으로 가정한다.
> 판매 명의는 하이링크(워크인).

## 제안

1. **5-2 = 통합 게시 API(B)로 시작한다.** 처음은 Upload-Post Professional 정액(25개사, 화이트라벨)이다.
   - 우리 회사 계정으로 실연동 게시를 시험한다. 가짜 서버 시험은 "구조 시험"으로만 기록한다.
   - 고객 약관·개인정보 처리방침에 게시 위탁(업체명)을 추가한다.
2. **Meta 직접 연동(A)은 고객사가 약 25~30개를 넘거나 업체 의존이 문제가 될 때** 심사를 병행해 옮긴다. 그 전까지 Meta 앱은 만들지 않거나, 만들어도 개발 모드로만 둔다.
3. 네이버 블로그는 계속 게시 도우미(⑤-1, 사람이 마지막 [발행]).

## 대표 결정 필요

- 통합 게시 API 업체 선택(Upload-Post / Zernio)과 결제 명의(하이링크)
- 직접 연동을 나중으로 미룰지
- 미루지 않는다면 Meta 앱을 새로 만들지 운영실 앱을 옮길지, 그리고 비즈니스 인증 주체
