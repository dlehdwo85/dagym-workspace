# 새 고객사 기준 전체 흐름 시험 결과 (#1181-1, 2026-11-26)

대표 지시(11/26): "그 회사만을 위한 개발이 최대한 들어가지 않도록 상업화를 위한 개발을 마쳐 두라. 전체 업무·영업·마케팅을 검수하라."

- 시험 방법: 시험 서버·시험 DB에서만 진행했고, 운영 계정·운영 DB는 쓰지 않았습니다.
  - 빈 회사 '누리소프트'(업종 IT·소프트웨어)가 공개 가입부터 마케팅 게시 예약까지 순서대로 진행합니다.
  - 화면마다 확인한 것: 서버 오류, 화면 오류, 다른 회사(운영사) 이름, 시설관리 업종을 가정한 말, 내부 낱말.
  - 메일과 알림 글도 새 회사로 간 것만 같은 기준으로 확인했습니다.
- 스크립트: `tests/e2e/commercial-1181.mjs` (`npm run build && node tests/e2e/commercial-1181.mjs`)
- 자동 결과: `docs/screens/commercial-check-2026-11-26/REPORT.md`, 화면 `NN-이름.jpg` 65장(PC 1366 · 휴대폰 390)

## 결론

- **단계 20개 모두 통과**했습니다.
- 다른 회사 이름, 업종 가정 말, 내부 낱말이 걸린 글은 **0건**입니다(허용 목록 제외).
- **화면 오류와 서버 오류(5xx)는 0건**입니다.
- 흐름이 끊긴 곳은 없습니다. 다만 '고객별 개발 없이 쓰게 하려면' 고칠 빈틈 5가지를 찾았습니다(아래 표의 F).
