# 아이폰 앱 심사 거절 대응 (#839) — 2026-10-31 클라우드 294차

워크인 iOS 1.1.1, 10/28 23:52 App Store 심사 거절 4건. 1)·3)은 코드(294차), 2)는 스크린샷 새 대본(아래 §2, 로컬이 만들기), 4)는 설명 문구 안(아래 §3, 대표 승인 뒤 로컬이 App Store Connect 에서 바꿈).
App Store Connect 맨 위 'Apple Developer Program 사용권 계약 업데이트'는 **계정 소유자(대표)가 동의해야** 업데이트·제출이 됩니다(코드로 못 함).

## 1. 코드 (294차) — 아이폰 앱은 '로그인만'

판별: 앱이 붙이는 표시 `WorkInApp` + 안드로이드 아님(아이패드 WebView 는 맥 표시라 기기 이름으로 못 가림), 화면에서는 Capacitor `ios` 도 같이 봄. 안드로이드 앱·웹은 그대로.

| 거절 | 고친 것 |
|---|---|
| 4.8 로그인 서비스(제3자 로그인만, Apple 로그인 없음) | 아이폰 앱에서 카카오·네이버·구글 로그인 버튼을 보이지 않음(로그인·초대·계정 연결 모두). 이메일·비밀번호 로그인만. 'Apple로 로그인'은 넣지 않음(아래 주의) |
| 3.1.1 앱 안 기업·조직 계정 가입 | 로그인 화면의 '14일 무료 체험'(가입) 링크 대신 "계정은 회사 관리자의 초대로 만들어집니다." · 서버가 `/signup`·`/signup/*`·`/welcome`·`/landing/*` 를 아이폰 앱이면 `/login` 으로 돌려보냄(307) · 아이패드 가로 화면 왼쪽 소개 판의 '14일 무료 체험' 문구 → '회사 관리자가 초대한 계정으로 로그인' |
| 3.1.1(앱 밖 결제 안내) | 아이폰 앱에서 무료 체험 띠 숨김(읽기 전용이 됐을 때만 "이용 기간이 끝나 읽기 전용입니다 · 회사 관리자에게 문의하세요") · 미납 띠·이용 중지 창은 "회사 관리자에게 문의하세요"(‘요금제는 PC 웹에서’ 안내 없음) · 사용량 화면 안내 = "이 화면은 사용량만 보여 줍니다." · 사용량 화면 경로 이름(관리 › 사용량)·AI 한도 표의 '요금제' 설명 줄 숨김 · 마케팅 자동 제작의 'OO 요금제'·'요금제를 고르면' 글자 숨김 |

함께 고친 것(점검 중 발견): 카카오톡·인스타그램·페이스북·네이버·라인·밴드 앱 안 브라우저를 우리 앱으로 잘못 봐서, 그 브라우저로 첫 주소(/)에 들어온 사람이 소개 화면 대신 로그인 화면을 보던 문제 — 광고·공유 링크로 온 사람은 이제 소개 화면.

주의
- 카카오·네이버로만 가입한 사람은 아이폰 앱에서 비밀번호가 필요합니다. 로그인 화면 안내: "비밀번호를 잊었거나 카카오·네이버로만 가입했다면 회사 관리자에게 비밀번호 재설정 링크를 요청하세요."(관리 › 사용자 › 재설정 링크, 기존 기능). 그런 사람이 많으면 'Apple로 로그인'을 따로 넣는 방법이 있음(Apple 개발자 설정·키가 필요해 대표·로컬 작업 + 1~2일).
- 앱 안의 AI 사용 금액(예: AI 비서 '내 이번 달 남은 AI 15,100원', 자동 제작 '$4.14 / $30')은 결제가 아니라 회사 사용 한도라 그대로 둠. 스크린샷에는 넣지 않음(§2).
- 웹 화면이라 앱을 새로 빌드하지 않아도 운영 배포만으로 바로 적용됨(1.2.0 이 아닌 지금 앱에도). 다만 앱이 붙이는 `WorkInApp` 표시는 10/19(c24c674) 뒤 빌드부터 있음 — 1.1.1 이후 빌드면 됨.

## 3. App Store 설명 문구 안 (공개 문구 — 대표 승인 뒤 로컬이 App Store Connect 에서)

`docs/handoff/WORKIN_STORE_LISTING.md` 49줄을 바꿉니다(그 밖 설명은 그대로).

- 지금: "소규모 팀은 무료로 시작할 수 있습니다. 요금제 관리는 PC 웹(관리자 화면)에서 합니다."
- 안: "회사(조직) 관리자가 초대한 계정으로 로그인해 사용합니다. 계정은 회사 관리자가 만듭니다."
- 문의 줄(dagym-in@naver.com)은 그대로. 키워드·부제는 가격 말이 없어 그대로.
- 구글 플레이 설명도 같은 문장으로 맞추기를 권함(가입 정책은 다르지만 '5명 무료'는 10/23 대표 결정으로 이미 없어진 말).
