# 화상회의 자체 엔진 계획 (#766 · 2026-10-28 클라우드)

요청: 대표 10/28 "영상회의는 엔진을 자체적으로 만들어봐주세요 가능한지? 라이브킷 클라우드 기능 자체를 우리가 새로 만드는거죠" (로컬 19:50 전달).
앞 문서: `VIDEO_MEETINGS_DESIGN_2026-10-28.md`(218·219차 — 회의 자료·권한·입장권·대기실·회의 기록·화면은 이미 만들어 둠, 엔진만 '가짜'로 시험).

## 결론
- **가능합니다.** 다만 '영상 중계 서버(SFU)'를 처음부터 짜는 길(①)은 6개월 넘게 걸리고 위험이 커서 권하지 않습니다.
- **추천 = ②-나 먼저 → 필요하면 ②-가로**: 라이브킷 클라우드가 해 주던 일을 **우리 서버에서 공개 소스 라이브킷 서버로 직접** 돌립니다(외부 클라우드 의존 없음, 이용료 없음). 쓰임이 확인되고 코드까지 우리 것으로 가져가고 싶으면 미디어수프로 바꿉니다 — 엔진 어댑터(`src/lib/meetings/engine.ts`) 덕에 화면·권한·회의 기록은 그대로.
- 어느 길이든 **Vercel 에서는 영상 중계가 안 됩니다**(UDP·오래 열린 연결). 서울 가상 서버 1대가 필요합니다 — 대표 승인(결제) 뒤.

## 길 세 가지
| 길 | 하는 일 | 기간(추정) | 위험 |
|---|---|---|---|
| ① 처음부터 직접 | 연결(ICE·STUN·TURN), 암호화(DTLS-SRTP), 영상 패킷 중계(RTP), 화질 단계(simulcast), 끊김 복구(NACK·PLI), 대역폭 추정, 코덱 협상(SDP), 녹화 | 6~12개월+ | 큼 — 아이폰 사파리·회사망·휴대폰망 예외가 끝없이 나옴, 보안 구멍 |
| ②-가 미디어수프(공개 소스 라이브러리)를 우리 코드에 | 우리가 연결 안내 서버(웹소켓)·방 관리·참가자 화면 코드를 짜고, 패킷 중계는 미디어수프가 함 | 6~10주 | 중간 — 화면 쪽 재연결·화면 공유·휴대폰 앱 웹뷰 시험을 우리가 다 함 |
| ②-나 라이브킷 공개 소스 서버를 우리 서버에서 운영 | 라이브킷 서버 설치·설정(우리 서버) + 기존 어댑터 연결 + 화면에 영상 붙이기 | 0단계 3일 + 화면 1~2주 | 작음 — 이미 많이 쓰이는 서버, 우리 몫은 설치·운영 |

## 필요한 서버 (②-가·②-나 같음)
- 서울 지역 가상 서버 1대: 4코어·8GB 정도로 시작(동시 참가 수십 명 기준 추정), 공인 IP, **UDP 포트 범위 열기**, TURN(회사망·휴대폰망에서 막힐 때 TCP 443 우회 — coturn 또는 라이브킷 내장 TURN).
- 주소 1개(예: `meet.회사도메인`) + 인증서.
- 비용(추정 — 계약 전 견적으로 확인): 서버 월 수만~10만원대 + **데이터 전송량**(10명이 1시간 회의하면 수십 GB까지 나갈 수 있어 업체별 전송 요금 차이가 큼). 이용자 수가 늘면 서버를 늘림.
- 녹화·회의록 자동 작성은 별도(녹화 서버·음성 인식 비용) — 3단계, 대표 결정 ④ 뒤.

## 대표가 할 일(②-나 기준)
1. 가상 서버 업체·요금제 승인(돈이 드는 일 — 대표 승인 뒤에만 진행).
2. 서버 계정에 클라우드가 쓸 접근 방법을 대표가 만들어 주기(비밀값은 대표가 직접 넣음 — 저장소·대화에 쓰지 않음).
3. 도메인 관리 화면에서 `meet` 주소 1줄 추가.
4. Vercel 환경변수에 `MEETING_ENGINE=livekit` · `LIVEKIT_URL` · `LIVEKIT_API_KEY` · `LIVEKIT_API_SECRET` 넣기(값은 대표가 붙여넣기).
5. 첫 시험: 대표·직원 2~3명이 PC·아이폰·안드로이드 앱에서 10분 회의.

## 클라우드가 할 일
- ②-나: 설치 설명서(명령·설정 파일, 비밀값 자리만 표시) · 어댑터 실제 연결 시험 · 회의 화면 영상 붙이기(참가자 타일·말하는 사람 강조·화면 공유·음소거) · 재연결·네트워크 약할 때 화질 낮추기 · 시험(가짜 엔진 + 실제 서버 1회).
- ②-가로 바꿀 때: 연결 안내 서버(웹소켓, 우리 서버) · 방·참가자·화질 단계 관리 · 화면 쪽 미디어수프 클라이언트 · 같은 화면 시험 재사용.
