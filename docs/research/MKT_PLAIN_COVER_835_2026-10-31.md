# 시안 표지 수준 (#835) — 단색 표지 금지 · 레퍼런스 대조표 (클라우드 295차, 2026-10-31)

대표 원문(10/31): "문구랑 전혀 상관없는 사진이거나 배경 단색에 글자 하나 툭 놓고 단조롭거나 아직 수준이 너무 낮다. 디벨롭하라, 레퍼런스를 하라고 분명 각 사업별로 안내해줬는데 레퍼런스를 안 한 느낌이다. 실사 사진 상태가 별로면 제작을 하거나 새로운 사진 혹은 필요한 사진은 요청해 달라(촬영해서 받는 데 1주일 정도)."

기준 문서: `docs/handoff/MARKETING_REWORK_2026-10-25.md` §2-1(레퍼런스 안쪽 확인), `docs/handoff/BRAND_FEED_REFERENCE_2026-10-24.md`.

## 1. 단색 표지 금지 (코드)

| 단계 | 동작 |
|---|---|
| 틀 고르기 | 표지 틀 중 '제목형·큰 글씨 강조형·리포트 표지형'(그리고 기간 없는 이벤트 포스터)은 **단색 틀**. 사진·화면·도표(번호 목록·VS·가격·4분할) 틀이 하나라도 되면 단색 틀을 쓰지 않음. 키트에 그런 틀이 없으면 공통 틀(사진 + 그러데이션 · 사진 덧칠 · 휴대폰 화면 · 노트북 화면 · 번호 목록)을 키트 색으로 씀 |
| 그래도 단색일 때 (인스타·페이스북 피드·스토리) | 승인함 대신 **수정 요청** + 사유 "표지가 단색 바탕 + 글자뿐 — …" · 알림 제목 '표지 사진 필요' · 시안 기록 `visual.plain` |
| 표지 사진 채우기 | 빈 칸 채우기(실사 참고 생성)에 **표지 칸** 포함 — 회사 설정 photo_gen 이면 정기 실행이, 아니면 관리자가 상세 [빈 칸 생성으로 채우기]. 표지가 사진 틀로 바뀌면 사유 줄을 지우고 승인 대기 + 알림 '표지 사진을 채웠습니다' |
| 예전 시안 | 승인 대기·수정 요청 중인 예전 단색 표지(피드·스토리)는 정기 실행이 한 번 다시 그림(rv 8). 사진이 없으면 단색 표시 + 수정 요청으로 옮기고 되풀이하지 않음 |
| 블로그 | 대표 이미지는 단색 금지 사유를 걸지 않음(본문 사진 3장 규칙이 따로 막음). 틀 고르기(사진·도표 먼저)는 같이 적용 |
| 피드 틀을 아직 안 고른 브랜드 | 예전 방식 그대로(브랜드 색 바탕 표지 + 빈 칸 채우기가 표지를 채움) — 운영 4개 브랜드는 피드 틀을 쓰므로 해당 없음(로컬 확인) |

참고 실사가 없는 브랜드(예: 워크인 — 앱 화면만)는 생성도 못 하므로 수정 요청에 남는다 → #836 자료 요청 페이지(다음 차례)로 '필요한 사진·화면 녹화'를 요청.

## 2. 레퍼런스 대조표 (자동 제작 화면 › 레퍼런스 대조표)

승인 대기·수정 요청 글을 한 줄씩, AI 호출 없이 저장된 시안 기록·원고·사진 설명으로만 판정.

| 항목 | 피드·스토리 | 블로그 | 레퍼런스 근거 |
|---|---|---|---|
| 표지 사진·화면·도표 | 단색이면 ✗ | 같음 | 대표 10/31 · 공통 '표지 = 큰 제목 2줄 + 사진/오브젝트' |
| 표지 머리말 | 시리즈 라벨(card.kicker) 있음 | — | 공통 '시리즈 라벨' (플로우 Customer Interview 등) |
| 장 수 | 피드 4~8장 · 스토리 3~5프레임 | — | 사례형 7~8장 · 요청 C 4~6장 |
| 사진 장 절반 이상 | 사진·화면 장 ≥ 절반 | — | 공통 '사진 장이 절반 이상' |
| 본문 사진 3장+ | — | 표지 뒤 3장 이상 | 요청 C §3-1 |
| 마지막 장 행동 | 행동(cta) 장 | — | 공통 '마지막 장 = 행동(주소·검색)' |
| 소제목 ■ | — | 2~4개 | 요청 C §3-1 |
| 첫 줄 훅 | 8~40자 제목형 | 같음 | 공통 '캡션 첫 줄 = 제목형 훅' |
| 해시태그 끝에 | 문장 사이 해시태그 없음 | — | 공통 '해시태그는 끝에 묶음' |
| 사진 검사 | 흔들림·브랜드 밖·겹침 0 | 같음 | #818·#814-2 |

API: `GET /api/marketing/refcheck?status=pending,changes` (마케팅 공간 사람만). 영상(릴스·쇼츠)은 제작 보류라 대조하지 않음.

## 3. 로컬 확인 순서

1. 자동 제작 화면 › 레퍼런스 대조표 [대조표 열기] → 브랜드별 미통과 항목 확인(대기 32건) → 차이표를 대표에게(어느 항목을 '틀 다시'의 먼저 할 일로 할지)
2. 정기 실행 뒤 예전 단색 표지 글이 다시 그려졌는지(시안 기록 '단색 바탕 + 글자 표지 바꿈'), 사진 없는 브랜드는 수정 요청 '표지 사진 필요'로 갔는지
3. 회사 설정 photo_gen 켜짐이면 표지 칸 생성 → 승인 대기로 돌아오는지(장당 크레딧 원장)
4. 아직 남은 것: 표지 머리말·사진 장 비율·마지막 장 행동이 미통과로 많이 나오면 그 항목부터 생성 틀을 고침(차이표 결과를 보고 다음 차)
