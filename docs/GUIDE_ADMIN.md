# 관리자용 안내 (대표 · 본사 관리자)

## 최초 설정 (운영 배포 직후 1회)
1. `https://<운영주소>/setup`에서 설정 비밀값(SETUP_SECRET)과 대표 정보를 입력해 대표 계정을 만듭니다. 사용자가 0명일 때만 동작합니다.
2. **조직 구성**: 본사 아래에 부서를 추가하고, 브랜드(다짐·하이링크·BODY LAB)별로 지점·위탁운영 현장을 추가합니다. 조직마다 공유 캘린더가 자동으로 생깁니다.
3. **사용자·권한 → + 직원 초대**: 이름·이메일·권한·소속을 고르면 초대 링크가 나옵니다. 본인에게만 전달하세요(1회용, 7일 뒤 만료).

## 권한 요약
| 권한 | 볼 수 있는 범위 | 할 수 있는 일 |
|---|---|---|
| 대표 | 전체 | 모든 기능, 대표 권한 부여 |
| 본사 관리자 | 전체 | 사용자·조직 관리, 감사 기록, 운영 상태 (대표 권한 부여·대표 계정 변경은 불가) |
| 부서 책임자 | 소속 조직 + 하위 | 프로젝트·템플릿 생성, 검토 확인, 회사 일정 등록 |
| 현장 관리자 | 소속 현장 + 하위 | 프로젝트·템플릿 생성, 검토 확인(최종 완료) |
| 직원 | 소속 현장 + 본인이 배정·협업·작성한 업무 | 업무·일정 등록, 검토 요청 |

## 소속 변경·퇴사
- 사용자·권한 → 편집에서 소속을 바꾸면 접근 범위가 즉시 바뀝니다.
- 상태를 **사용 중지** 또는 **퇴사**로 바꾸면 모든 기기에서 바로 로그아웃되고 로그인도 막힙니다. 푸시와 Google 동기화도 멈춥니다. 작성한 업무 기록은 남습니다.

## 검토(최종 완료) 운영
- 업무를 만들 때 "완료 시 관리자 최종 확인 필요"가 기본으로 켜져 있습니다. 직원은 "검토 요청"까지만 할 수 있습니다.
- 홈의 **검토 대기** 목록에서 "완료 확인" 또는 "보완 요청"(사유를 입력하면 댓글로 남음)을 누릅니다.

## 감사·운영
- **감사 기록**: 로그인, 로그인 실패, 초대, 권한·소속 변경, 비밀번호 재설정 링크 발급
- **운영 상태**: DB·스케줄러·파일 저장소·푸시 설정, 정기 실행 기록, 푸시 성공·실패, Google 동기화 오류, 서버 오류
- 장애 대응·백업·복원·비용 확인: [OPERATIONS.md](OPERATIONS.md)
